# v0.23.2 Service Import Cutover — Old → New Module Migration Table

> Baseline: v0.23.1 release commit `b2ba7a7f`. This document is the authoritative
> old symbol → exact defining module migration table for the 23 legacy service
> modules physically deleted in v0.23.2.

The machine-readable manifest lives at
`apps/api/tests/_fixtures/removed_service_modules.json` (23 modules, 233 frozen
symbols). This human-readable table mirrors it with per-domain grouping.

## How to migrate

Replace every `from app.services.<legacy> import <Symbol>` with the new module
path listed below. For `gpu_arbiter` (the only multi-source facade), the exact
sub-module is determined by the symbol's `__module__` — see the frozen manifest
for the per-symbol mapping.
