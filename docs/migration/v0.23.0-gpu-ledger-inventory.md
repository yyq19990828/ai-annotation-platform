## D. Patch targets

`grep` over `app/`, `tests/`, `scripts/` finds **no** `mock.patch("...gpu_arbiter_store.X")`
or `monkeypatch.setattr("app.services.gpu_arbiter_store.X", ...)` *string* targets. All
public-symbol references are plain `from app.services.gpu_arbiter_store import ...`.

However `tests/test_gpu_arbiter_redis.py` does access **private module globals** via the
module object alias `gpu_arbiter_store_module` (the initial P0 sweep missed this because
it only looked for string patch paths):

- `monkeypatch.setattr(gpu_arbiter_store_module, "_REDIS_CALL_DEADLINE_SECONDS", ...)`
  (L8814) — patches the runtime deadline the store reads as a bare global.
- `gpu_arbiter_store_module._LEDGER_REVISION_REBASE_THRESHOLD` (read at L8444/8476/8507/8628).

P1 handling (per plan §4.1 "allowed changes"): these tests are repointed at the new
implementation modules. `_REDIS_CALL_DEADLINE_SECONDS` is patched on
`app.services.gpu_arbitration.ledger.store` (the namespace the store's functions read
the bare global from); `_LEDGER_REVISION_REBASE_THRESHOLD` is imported directly from
`app.services.gpu_arbitration.ledger.types`.
