# v0.13.9 · 点云俯视框选画框 + BEV 重置视角

> 计划日期 2026-06-04 · 范围:3D 点云标注台「初始画框」从「点地面固定大小放置」升级为「拖框选 footprint → autofit 高度/贴地」,并新增一个「俯视(BEV)」相机复位按钮(类比现有「重置视角」)。

## 1. 背景与目标

调研结论(详见 `docs/research/14-point-cloud-image-fusion.md`):SUSTechPOINTS / xtreme1 / CVAT 都**不**做 2D 风格的精确拖拽定尺,主流范式是「粗框选 + 点云自动贴合」(SUSTechPOINTS `create_box_by_points`、xtreme1 三点法 + `getMiniBox1`)。本平台已具备等价的 autofit 内核(`autofit.ts` 的 `fitSize/fitBottom/fitSizeAndBottom`),因此第 1 点诉求(初始画框不能控制尺寸)的最优解是**复用 autofit**,而非另写 2D 拖拽数学。

本版本只做第 1 点(2D→3D 投影抬升留作后续,业内尚属空白)。两处已敲定的开放点:

- **① XY 处理**:采用推荐方案 —— 框选拖出的 XY footprint **保持不动**,只拟合 Z(高度)并贴地(`fitHeightAndBottom`)。理由:用户拖出的地面投影正是其意图,XY 不应被点云 AABB 二次漂移;高度难手画,交给点云。
  - **实测修订 1(2026-06-04)**:试过把贴合升级成「全收紧」`fitHeightAndBottom → fitYaw → fitSizeAndBottom`,更糟(框收成贴地薄片、朝向被地面点带歪)。
  - **实测修订 2 — 改 frustum 选点(最终方案,2026-06-04)**:加诊断日志拿到真实数字后定位:即使在俯视(BEV)下,因 BEV 是**透视**相机、目标偏离正下方,`screenToGround`(屏幕射线打 `z=groundZ` 单一平面)仍有视差 —— footprint 被推到目标后方,只捞到一层地面点(实测框内点 z 仅 -0.93~-0.23,车身上半截不在 footprint 内)。**「投单一地面平面取 footprint」对有高度物体天生有视差,换 fit 函数救不回。** 改为 SUSTechPOINTS 范式的 **frustum 选点**:`selectPointsInScreenRect` 把每个点投到屏幕 NDC,选中落在拖框矩形内的真实点 → `psrFromPoints` 取其 world AABB 建框。选屏幕里的真实点,与视角/物体高度无关、零视差。**废弃** `coarsePsrFromGroundRect` / `fitHeightAndBottom` / `screenToGround` / `getGroundZ`(连同其单测一并移除)。
- **② 视口**:不强制切正交,改为**新增一个「俯视(BEV)」复位按钮**(类比「重置视角」)。点一下把主相机摆到稠密区正上方俯看,车头朝屏幕上方,便于在地面平面拖出 footprint。仍是透视相机,不引入正交相机模式(改动小、与既有 OrbitControls/gizmo 兼容)。

### 成功判据

1. 在 box 工具下,在主视图按住拖出一个矩形 → 松手生成一个紧贴该地面 footprint、高度已贴合框内点云并落地的 3D 框,且自动选中、回到 select 工具。
2. 拖动距离 < 4px(等同点击)→ 退化为旧的「固定大小放置」(向后兼容)。
3. 点「俯视(BEV)」→ 相机正上方俯视;点「重置视角」→ 回到原斜视向(camera.up 正确还原 (0,0,1))。
4. 新增纯几何函数 `coarsePsrFromGroundRect` / `fitHeightAndBottom` 各有单测;`pnpm lint` / `pnpm test` 通过。

## 3. 纯几何层

### 3.1 `triview.ts` — `coarsePsrFromGroundRect`

由地面上两个 world 点(拖框起点 A、终点 B,均已落到 z=groundZ 平面)生成初始粗框 PSR:

```ts
/**
 * v0.13.9 · 由地面矩形两角(world 系, 同 z=groundZ)生成初始粗框 PSR。
 * footprint = XY 轴对齐矩形 [|dx|, |dy|]; 高度给一个"探针"高 probeHeight(够高以罩住
 * 典型目标, 后续 fitHeightAndBottom 收紧); 底贴 groundZ ⇒ cz = groundZ + probeHeight/2。
 * size 各分量 clamp 到 MIN_SIZE。yaw 默认 0(v1 不做朝向猜测, 交给后续 fitYaw / 手调)。
 */
export function coarsePsrFromGroundRect(
  p0: Vec3,
  p1: Vec3,
  groundZ: number,
  probeHeight: number,
  yaw = 0,
): Psr {
  const cx = (p0[0] + p1[0]) / 2;
  const cy = (p0[1] + p1[1]) / 2;
  const sx = Math.max(MIN_SIZE, Math.abs(p1[0] - p0[0]));
  const sy = Math.max(MIN_SIZE, Math.abs(p1[1] - p0[1]));
  const sz = Math.max(MIN_SIZE, probeHeight);
  return {
    center: [cx, cy, groundZ + sz / 2],
    size: [sx, sy, sz],
    rotation: [0, 0, yaw],
  };
}
```

单测:对称两点 → center 在中点;size = |Δ|;cz = groundZ + probeHeight/2;退化(两点重合)→ size 落 MIN_SIZE。

### 3.2 `autofit.ts` — `fitHeightAndBottom`

只拟合 Z + 贴地,XY 中心与 XY 尺寸完全不动:

```ts
/**
 * v0.13.9 · 只拟合高度 + 贴地: 保 cx/cy + sx/sy + 朝向不动, 由框内点 world Z 跨度定 sz、底贴 zMin。
 * sz = (zMax - zMin) + 2×padding (clamp MIN_SIZE); cz = zMin + sz/2。
 * 框内空 → 返回原 PSR 不动。用于俯视框选: 用户拖出 XY footprint 是其意图, 不二次漂移 XY。
 */
export function fitHeightAndBottom(
  positions: Float32Array,
  psr: Psr,
  padding: number = 0.05,
): Psr {
  const inside = collectInsidePoints(positions, psr);
  if (inside.count === 0) {
    return { center: psr.center, size: psr.size, rotation: psr.rotation };
  }
  let zMin = inside.worldZ[0];
  let zMax = zMin;
  for (let i = 1; i < inside.count; i++) {
    const z = inside.worldZ[i];
    if (z < zMin) zMin = z;
    else if (z > zMax) zMax = z;
  }
  const sz = Math.max(MIN_SIZE, zMax - zMin + 2 * padding);
  return {
    center: [psr.center[0], psr.center[1], zMin + sz / 2],
    size: [psr.size[0], psr.size[1], sz],
    rotation: psr.rotation,
  };
}
```

> 注:初始粗框的 `probeHeight` 必须够高罩住目标(否则 `collectInsidePoints` 只收到部分点)。取一个偏大的常量(如 5m,够罩车/人/骑行;建/构筑物不在车载目标范围),fit 后收紧。这点写进 `BOX_SELECT_PROBE_HEIGHT` 常量并注释假设。

单测:构造一簇已知 Z 跨度的点,验证 sz 与 cz;框内空 → 原样返回;XY 字段不变。

## 4. 场景层 `PointCloudScene.ts`

```ts
/** v0.13.9 · 框选用: 屏幕点只与 z=groundZ 水平面相交(不吸附点云命中点,
 *  否则两角 z 不一致 footprint 失真)。射线平行地面 → null。 */
screenToGround(clientX: number, clientY: number): [number, number, number] | null {
  const rect = this.renderer.domElement.getBoundingClientRect();
  const ndc = new THREE.Vector2(
    ((clientX - rect.left) / rect.width) * 2 - 1,
    -((clientY - rect.top) / rect.height) * 2 + 1,
  );
  this.raycaster.setFromCamera(ndc, this.camera);
  const plane = new THREE.Plane(new THREE.Vector3(0, 0, 1), -this.groundZ);
  const hit = new THREE.Vector3();
  if (!this.raycaster.ray.intersectPlane(plane, hit)) return null;
  return [hit.x, hit.y, this.groundZ];
}

getGroundZ(): number { return this.groundZ; }

/** 框选拖拽期禁用 OrbitControls(同 gizmo 拖拽的做法), 避免拖框时相机乱转。 */
setBoxSelecting(active: boolean) { this.controls.enabled = !active; }

/** v0.13.9 · 俯视(BEV)复位: 相机摆到稠密区正上方俯看 -Z, 车头(forward)朝屏幕上方。 */
bevView() {
  const c = this.viewCenter;
  const r = this.viewRadius;
  this.controls.target.copy(c);
  this.camera.up.copy(this.forward);              // 看 -Z 时 up 必须水平, 取车头方向
  this.camera.position.set(c.x, c.y, c.z + r * 2.5);
  this.camera.near = Math.max(r / 100, 0.1);
  this.camera.far = r * 50;
  this.camera.updateProjectionMatrix();
  this.controls.update();
}
```

`frameView()` 内在 `controls.update()` 之前补一行 `this.camera.up.set(0, 0, 1);`,确保从 BEV 切回「重置视角」时 up 正确还原(BEV 把 up 改成了水平 forward)。

## 5. 交互层 `ThreeDWorkbench.tsx`

把「点击放置」升级为「按下-拖动框选,拖动过小退化为点击放置」。

- `pointerDownRef` 已有,扩展记录是否在 `placing` 模式按下。
- 新增 `boxSelectRef`(起点屏幕坐标)+ `previewRect` state(预览矩形 px)。
- `onMouseDown`(viewport):若 `placing` → `scene.setBoxSelecting(true)`、记起点、开始预览;否则维持原行为(记 down 点供 click 判定)。
- `onMouseMove`(新增,仅 placing 拖拽期挂):更新 `previewRect`。
- `onMouseUp`(新增):`scene.setBoxSelecting(false)`、清预览;
  - 位移 < `DRAG_CLICK_TOL` → `handlePlace(x, y)`(旧固定框,向后兼容);
  - 否则 → `handleBoxSelect(A, B)`。

```ts
const BOX_SELECT_PROBE_HEIGHT = 5; // m, 初始探针高(罩住目标), 由 fitHeightAndBottom 收紧

const handleBoxSelect = useCallback((a: {x:number;y:number}, b: {x:number;y:number}) => {
  const scene = sceneRef.current;
  if (!scene || !placeClass) return;
  const g0 = scene.screenToGround(a.x, a.y);
  const g1 = scene.screenToGround(b.x, b.y);
  if (!g0 || !g1) return;
  const coarse = coarsePsrFromGroundRect(g0, g1, scene.getGroundZ(), BOX_SELECT_PROBE_HEIGHT);
  const positions = scene.getPointPositions();
  const psr = positions ? fitHeightAndBottom(positions, coarse) : coarse;
  const geometry: Box3DGeometry = {
    type: "box_3d", center: psr.center, size: psr.size, rotation: psr.rotation,
  };
  createAnnotation.mutate(
    { annotation_type: "box_3d", tool_unit_id: LIDAR_TOOL_UNIT, class_name: placeClass, geometry },
    { onSuccess: (created) => onSelectBox(created.id) },
  );
  onSetThreeDTool("select");
}, [placeClass, createAnnotation, onSelectBox, onSetThreeDTool]);
```

> 注意 `Box3DGeometry.center/size/rotation` 是可变 `[number,number,number]`,而 `Psr` 字段是 `readonly Vec3`;构造 geometry 时要 `[...psr.center]` 拷成可变元组(或在 handleBoxSelect 内显式展开),避免 TS 只读赋值报错。

### 预览矩形(CSS)

在 `viewportWrap` 内加一个绝对定位 `div`,`previewRect` 为 null 时不渲染。样式走既有 token(§6:不发明变量名、不写 fallback、不硬编码色):边框用 `var(--color-accent)`,半透明填充用既有 overlay token(若无则在 `tokens.css` 先补 light+dark 再用,不就地造名)。

## 6. 边界情形

| 情形 | 处理 |
|---|---|
| 拖动 < 4px | 退化为 `handlePlace`(旧固定框) |
| `screenToGround` 返回 null(射线平行地面,极端掠视角) | 静默 abort,不建框 |
| footprint 某维 ~0(细长拖动) | `coarsePsrFromGroundRect` clamp 到 MIN_SIZE |
| 框内无点(空地拖框) | `fitHeightAndBottom` 原样返回探针框,用户可手调 / 再 autofit |
| 非 box 工具下拖动 | 维持原 OrbitControls 转视角(不拦截) |
| BEV ↔ 重置视角 来回切 | `bevView` 设 up=forward,`frameView` 还原 up=(0,0,1) |
| 只读 / 未配类别(`!placeClass`) | `placing` 为 false,不进入框选分支 |
