# v0.20.9 · 父子标注的前端呈现、一层深度约束与级联删除

状态：草案（draft）。四问探讨 Q2 的落地。是 Q1b（v0.20.11 选中框二次推理产出子框）的**前置打底**。

## 背景

「选中一个标注做二次推理」会产出两类物：属性型（写回原框）和几何型（在原框内检测出子物）。
几何型需要「父子框」表达「车牌属于车」「零件属于整机」。调查发现：这套数据结构**后端早已存在
且已在产生数据**，只是前端从未呈现——本版把它接通，不新增数据模型。

## 现状（已核实）

- **字段已在**：`annotations.parent_annotation_id`（自引用，nullable）。
- **后端已在产子框**：`annotation.py:1159`（`convert_video_track_to_bboxes`）、`annotation.py:1362`
  （`_split_video_track`）创建的框已挂 `parent_annotation_id`——库里已有父子数据。
- **前端完全不用**：所有创建点硬编码 `parent_annotation_id=null`
  （`useWorkbenchAnnotationActions.ts:161`、`useTasks.ts:96`）；侧栏 `AIInspectorPanel` 平铺渲染、
  只按 `group_id` 分桶（`AIInspectorPanel.tsx:963-996`）；无缩进/连线/父子高亮。
- **无一层深度约束**：`create` 不校验 parent 是否已有 parent（`annotation.py:90-128`）。
- **无级联删**：`delete` 只把自身 `is_active=False` 软删（`annotation.py:344-351`），删父不动子。

## 目标

前端能呈现一层父子关系（列表缩进 + 画布关联高亮）；后端保证「只一层深度」并在删父时级联软删子。
数据模型零改动（字段已在）。

## 工作项

### WS1 · 前端呈现（主要工作量）

- **侧栏 `AIInspectorPanel`**：分桶逻辑（`AIInspectorPanel.tsx:963-996`）加 parent 维度——父行下缩进
  渲染子行。与现有 `group_id` 卡片头**共存**：一个标注可能同时有 `group_id`（图像编组）和
  `parent_annotation_id`（父子），二者正交。**先定呈现优先级规则**：parent 缩进为主结构、group
  卡片头为次，避免两套分组在同一列表打架（这是本版真正要想清的设计点，不是渲染难度）。
- **画布**：选中父框时子框描边高亮（复用现有选中态样式，轻量）。
- 前端 `parent_annotation_id` 打通读路径（`types/index.ts:408` 已有字段，只是没消费）。

### WS2 · 后端一层深度约束

- `create`/`update`（`annotation.py:90-128`）校验：若传入的 `parent_annotation_id` 指向的框本身
  已有 `parent_annotation_id`，拒绝（返回 400，语义明确「父子仅一层」）。应用层校验（不下沉 DB 约束，
  留后手支持未来多层）。

### WS3 · 级联删除

- `delete`（`annotation.py:344-351`）：软删父框时，级联软删其所有子框（`parent_annotation_id=父.id`
  且 `is_active=True` 的行一并 `is_active=False`）。明确策略，不留 orphan。
- 更新 `_update_task_stats` 计数覆盖级联删掉的子框。

### WS4 · 移动联动（可选，首版可不做）

- 默认**不联动**：子框是独立几何，只是「属于」父，移动/缩放父不动子。
- Alt+拖动父框时子框一起搬——列为可选后续，首版不做（[[feedback_button_terminology]]：拖拽键位
  语义动手前先与用户确认）。

## 风险

- **两套分组维度共存的 UI 规则**是本版核心难点：group 分桶 vs parent 缩进如何在一个列表里并存不冲突。
- 级联删要覆盖「父被批量删」「父在 group 里被删」等组合路径，避免漏删子成 orphan。

## 验收

- 库里已有父子数据（视频 split/convert 产生的）在侧栏能看到缩进层级、画布选父时子高亮。
- 尝试给已有 parent 的框再设 parent → 400。
- 删父框 → 子框一并消失（软删），task 计数正确。

## 依赖 / 不在范围

- 无前置依赖。**是 v0.20.11（Q1b 单框二次推理产出子框）的前置**。
- 不做：多层父子（>1 层）、跨帧父子（父子限帧内，跨帧走 track_id）、Alt 联动移动。
