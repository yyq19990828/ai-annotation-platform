# v0.23.8 · 原生 Mask AI 交互与视频局部纠错

> Status: Draft · Epic Phase 4
>
> 父 Epic：[图像 / 视频栅格 Mask 能力统一](2026-07-21-raster-mask-workbench-unification-epic.md)
>
> 硬前置：[v0.23.7 图片原生 Mask 工作台](2026-07-21-v0.23.7-image-mask-workbench-native-editing.md)

## 1. 目标

- 图片 / 视频单帧 SAM 可以直接返回、预览、精修并保存原生 RLE Mask。
- 当前 Mask 可作为下一轮 AI prompt，不再只用 bbox 或最大 polygon 回喂。
- 增加 scribble 正 / 负提示，补齐细长物、遮挡边界和局部排除区域的交互。
- 视频 Tracker 结果允许在少数关键帧局部纠错，并从纠错帧重传播，不必整 job 重跑。
- 候选、接受、重传播全程保留 backend、模型、prompt、source version 与人工修正 lineage。

## 2. 能力与协议

### P0 · Capability truth

- interactive backend 只有真实支持时才声明 `supported_geometric_outputs: [mask]`。
- prompt registry 增 `mask`、`scribble` 和 `correction_frame`，分别声明 input encoding、坐标系与上限。
- 图片 / 视频请求显式传 `output_geometry=mask`；不支持时 UI 展示回落原因，允许用户选择 polygon。
- 修正 SAM3 / grounded-SAM2 setup 声明与真实实现不一致；contract tests 直接核对 `/setup` 和实际响应。
- 空帧 / outside 响应仍返回协议一致的 mask result，不用 bbox placeholder 冒充。

### P1 · 单帧原生 Mask

- grounded-SAM2 / SAM3 bool mask 直接编码共享 COCO RLE，不先 `pickPrimaryRing`。
- multimask 候选分别保留完整 hole / components；score 排序不改变像素内容。
- 候选预览复用 committed Mask renderer / cache / picking。
- 接受所选候选时才上传永久内容对象；未选候选只保留短生命周期 session payload。
- 图片保存为 `raster_mask`；视频保存为当前帧 `video_track_mask` manual / prediction keyframe。
- prediction decision 与 annotation lineage 走服务端原子事务。

### P2 · Mask-as-prompt 与 scribble

- 选中已存 Mask 后可追加正 / 负点、框或 scribble；请求携带当前 RLE 或受控低分辨率 prompt mask。
- scribble 使用独立二值正 / 负层，有点数、线段数、总像素和 payload 上限。
- backend 可返回 low-resolution logits 供同一交互 session 迭代；logits 不持久化，session 结束释放。
- 网络失败保留 prompt 与当前 Mask；重试不重复提交 annotation。
- prompt 变更只使当前候选失效，不污染已保存 Mask。

### P3 · 视频局部纠错与重传播

- Tracker 候选审阅支持按轨迹 / 帧局部接受、拒绝，不再只能整 job 决策。
- 用户在错误帧编辑 Mask 后可选择“仅保存此关键帧”或“从此帧向前 / 向后重传播”。
- 重传播输入优先使用 corrected Mask / logits；backend 不支持时显式 bbox fallback 并记录 diagnostic。
- manual keyframe 默认保护；覆盖人工帧必须单独确认并生成 before / after 审计。
- 重传播只替换所选窗口和目标，不能清空其它轨迹或窗口外关键帧。
- 同一轨迹并发 correction job 通过源 annotation version 和 job lease 冲突保护。

### P4 · AI 交互可观测性

- 记录 prompt 类型、候选数量、选择 score、输出 geometry、fallback reason、decode / inference / upload 耗时。
- 不记录原始图片或完整 Mask 到普通日志；对象 digest 可用于关联诊断。
- UI 显示 backend capability、当前输出类型和 fallback，不让用户误以为 polygon 是无损 Mask。

## 3. 非目标

- 不实现文本到全场 semantic class-map。
- 不做自动光流 / morphing；Tracker 仍由 backend 产生帧序列。
- 不实现高级形态学或套索工具。
- 不持久化 logits，不建立长生命周期 SAM inference state 服务。
- 不自动覆盖 manual keyframe。

## 4. 验收场景

1. 图片正 / 负点产生三组原生候选，接受后 hole 与小岛保持。
2. 已存 Mask + 负 scribble 去除错误区域，刷新后结果一致。
3. Backend 不支持 mask 时 UI 明确回落 polygon，且不生成 `raster_mask` 假结果。
4. 视频当前帧 SAM 创建一个 Mask keyframe，可选择启动 Tracker。
5. Tracker 某帧漂移 → 人工修正 → 向后重传播，只替换目标窗口。
6. manual keyframe 保护、并发 correction 409 和取消恢复均通过。
7. 候选丢弃后临时对象按 TTL 回收；接受后只保留所选内容。
8. AI candidate 与 committed annotation 逐像素一致。

## 5. 测试与文档

- 共享 backend capability / response fixtures 覆盖 mask、polygon fallback、scribble 和 correction。
- grounded-SAM2、SAM3 multiplex、SAM3 PVS 各跑一次真实 Mask consumer 测试。
- 前端 E2E 覆盖候选、多轮 prompt、失败重试、局部接受和视频重传播。
- 更新 SAM 工具、视频传播、ML backend protocol、capability registry 和故障排查文档。
- CHANGELOG 按 Added / Changed / Fixed 记录。

## 6. 退出门

v0.23.9 进入前必须证明：

- 三种 backend capability 声明与实际输出一致；
- 单帧 AI 不再强制矢量化；
- correction job 不覆盖窗口外或 manual keyframe；
- 临时候选对象生命周期无泄漏；
- AI 原生 Mask 浏览器 E2E 全绿。
