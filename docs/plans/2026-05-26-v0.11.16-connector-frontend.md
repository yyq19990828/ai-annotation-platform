# v0.11.16 · 前端：连接器管理 + 导入向导第三模式 + 进度轮询

> 本切片把 v0.11.14/15 的后端能力接到 UI，功能正式对用户可见。

## 目标

用户可在界面上：管理存储连接器（按权限）、在导入向导里选"从连接器导入"、填源路径起异步 job、看实时进度直至完成。超管可管白名单。

## 现状

- 导入向导 `apps/web/src/components/datasets/ImportDatasetWizard.tsx`：3 步、两种模式（文件上传 / ZIP），并发上传用 `apps/web/src/utils/uploadQueue.ts`。
- 数据集 API/hook：`apps/web/src/api/datasets.ts`、`apps/web/src/hooks/useDatasets.ts`（已有 `useScanDatasetItems`）。
- 数据集页：`apps/web/src/pages/Datasets/DatasetsPage.tsx`（"上传"按钮开向导、"扫描导入"按钮）。
- async_jobs 前端：确认是否已有 job 列表/轮询组件可复用（若有，进度 UI 直接接；若无，本版加轻量轮询 hook）。
- 颜色 token 规则：新 CSS 只用 `apps/web/src/styles/tokens.css` 既有 `--color-*`，无 fallback、无 hardcode（CLAUDE.md §6，`pnpm lint:css-tokens` 把关）。

## 前端改动

### 1. API + hooks
- 新建 `apps/web/src/api/storageConnections.ts`：list/create/get/test/patch/delete + `importFromConnection(datasetId, body)`。
- 新建 `apps/web/src/hooks/useStorageConnections.ts`：对应 query/mutation，create/delete 后失效列表缓存。
- `useDatasets.ts` 加 `useImportFromConnection()`（起 job，返回 job_id）。
- 进度轮询：复用现有 async_jobs hook；若无则新建 `useAsyncJob(jobId)`（轮询 `GET /async-jobs/{id}`，completed/failed/cancelled 停轮询）。

### 2. 连接器管理 UI
- 新建 `apps/web/src/components/connections/`：
  - `ConnectionList` / `ConnectionForm`（kind 切 s3↔sftp 表单字段；密钥字段 write-only，编辑时占位提示"留空不改"）。
  - `ConnectionTestButton`（调 test，展示 ok / 错误原因 / 样例条目数）。
- 入口：
  - **超管**：系统设置页加"存储连接器"+"主机白名单"两块（白名单走现有 system_settings 表单机制）。
  - **项目管理员**：项目设置页（`apps/web/src/pages/Projects/sections/`）加"存储连接器"区，仅管 project-scope。

### 3. 导入向导第三模式
- `ImportDatasetWizard.tsx` Step2 加第三 tab/模式"从连接器导入"：
  - 选连接器（下拉，按可见性过滤）→ 填 `source_path` + `recursive` + 可选 `include_globs` → 提交起 job。
  - Step3 改为**进度态**：轮询 job，展示 progress_pct + added/skipped/errors，完成后给"查看数据集"。
  - 文件上传 / ZIP 两种旧模式行为完全不变。

### 4. 文案 / i18n
- 按现有 i18n 机制补连接器 / 白名单 / 导入进度相关文案。

## 验证

- `pnpm --filter web typecheck` + `pnpm --filter web lint`（含 `lint:css-tokens`）。
- dark mode 走查（B-32/36/38/39 教训：连接器表单、白名单表、进度条所有新 CSS）。
- 端到端手测（chrome devtools MCP 辅助看 API/console）：
  - 超管配白名单 → 建 global S3 连接器 → test ok。
  - 项目管理员建 project SFTP 连接器（白名单外被拒并有清晰提示）。
  - 导入向导第三模式 → 选连接器 + 路径 → 起 job → Step3 进度推进 → 完成后数据集出现新条目 + 缩略图。
  - 列表/详情响应不含密钥（Network 面板核对）。
  - 旧两种导入模式回归无变化。

## 回退

新增组件 + 新模式入口，旧路径不动。回退 = 移除第三模式入口 + 连接器管理入口（API 文件可留）。必要时第三模式挂 feature flag 灰度。
