# v0.11.7 · IssueLayer video frame pin

> [epic 索引](2026-05-25-v0.11-annotation-feedback-convergence.md) · B 组（前端）· 依赖：v0.11.4 issues tab

## 目标

让像素锚点 issue 在 video stage 支持 frame 维度：图钉按当前帧显隐，跨帧 issue 在时间轴上标记。

## 现状

- `anchor_position` 已预留 `frame` 字段（`{x, y, frame?}`，见 `annotation_feedbacks` 模型注释）。
- 当前 IssueLayer 只在 image stage 渲染，不区分 frame。

## 前端改动

- IssueLayer 在 video stage：按当前播放帧过滤 `anchor_position.frame` 命中的图钉显示。
- 时间轴（video track）上对有 issue 的帧加标记，便于跳转定位。
- issues tab 列表项显示所属 frame；单击跳到该帧 + 定位图钉（复用 v0.11.4 的定位逻辑 + seek frame）。

## 验证

- `pnpm --filter web typecheck` + `lint:css-tokens`。
- 走查 video 任务：在某帧落点建 issue → 切到该帧图钉显示、切走隐藏 → 时间轴标记正确 → 列表点击跳帧定位。

## 回退

纯前端增量，回退 = 还原 IssueLayer + video track 改动。

## 备注

后端 schema 已就绪（frame 字段预留），无后端改动。
