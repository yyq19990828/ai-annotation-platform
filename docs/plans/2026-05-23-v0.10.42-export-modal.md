# v0.10.42 · 项目导出：下拉浮层 → 居中 Modal 悬浮页

> **来源**：用户实测反馈 —— 导出入口位于项目列表行的 `<td>` 操作列里，`DropdownMenu` content 浮层在窄表格单元格上下文中展开既局促又难看，且没有空间承载更详细的导出设置。
> **性质**：纯前端改造（本版不碰后端导出契约）；为后续"导出范围过滤"等富能力预留承载容器。

---

## 0. 一句话目标

**把项目导出的下拉浮层换成复用 `Modal` 的居中悬浮页**，重排为宽松、可扩展的布局，让导出选项看得清、点得稳，并为将来更复杂的导出设置留出版面。

---

## 1. 现状事实（已读码确认）

- 导出 UI = `apps/web/src/pages/Dashboard/ExportSection.tsx`，当前用 `DropdownMenu` 的 `content` 模式（`ExportSection.tsx:39-60`）渲染内部 `ExportForm`（`:65-165`）。
- 入口按钮文案 `导出 ▾`，提交按钮文案 `导出`（`:50` / `:161`）。
- 唯一渲染点：`DashboardPage.tsx:147`，位于项目行 `<td className={styles.projectCellActions}>` → `rowActions` 容器内（`:145-161`）。窄单元格 + 表格 overflow 上下文 = 浮层局促的根因。
- 现有导出选项（全部保留）：
  - `format`：图片项目 `coco / yolo / aap_json`；视频项目 `video_json / aap_json / mot / kitti`（`ExportSection.tsx:13-27`）。
  - `videoFrameMode`：仅视频项目 + `video_json` 时有意义（`keyframes / all_frames`，`:73-74`）。
  - `includeAttributes`：默认 `true`（`:68`）。
- 导出 API：`projectsApi.exportProject(id, format, opts)`（`api/projects.ts:207-214`），异步入队返回 `{job_id}`。
- **后端导出接口仅接受三参数**：`format` / `include_attributes` / `video_frame_mode`（`apps/api/app/api/v1/projects.py:775-786`）。**无批次 / 状态 / 日期 / 仅已审核等过滤维度** —— 任何"按范围导出"的富能力都需后端配套，不在本版。
- 复用基础件：`Modal`（`components/ui/Modal.tsx`，`createPortal` + 蒙层点击关闭 + Esc 关闭 + `--modal-width`，已被 `CreateProjectWizard` 同款使用）。
- 单测：`__tests__/ExportSection.test.tsx` 通过 `getByText("导出 ▾")` 打开、`getByText("导出")` 提交，断言 `exportProject` 入参（4 个用例）。改 trigger / submit 文案会破测，需同步更新。

---

## 2. 决策底线（本版守住）

- **不改后端导出契约**：`exportProject` 调用签名、入参、异步入队语义全部不变。
- **不新增 backend-dependent 的导出设置**（范围过滤、仅已审核、日期区间等）——这些另立版本（见 §4）。
- 复用现有 `Modal`，不另造弹层骨架；与 `CreateProjectWizard` 保持同一交互范式（居中、蒙层、Esc 关闭）。
- 颜色遵循 CLAUDE.md §6：只用 `tokens.css` 已有 `--color-*`，不发明名、不写 fallback、不硬编码 hex（现有 `ExportSection.module.css` 里 `oklch(...)` 选中态/提交态属遗留，迁移时一并改用 token，详见 §3 步骤 2）。
- 触发按钮仍留在 `rowActions` 原位，仅把"点开后展开的东西"从 dropdown 换成 modal —— 不动 `DashboardPage` 表格结构。

## 3. 实施步骤（带验收）

### 步骤 1 · ExportSection 改用 Modal
- `ExportSection` 内部状态 `const [open, setOpen] = useState(false)`；trigger 按钮 `onClick` 改为 `setOpen(true)`（保留 `e.stopPropagation()`，避免冒泡到行的"打开项目"点击）。
- 移除 `DropdownMenu` 依赖，改 import `Modal`。
- `ExportForm` 提升进 `<Modal open title="导出标注数据" width={520} onClose>`，导出成功 / 取消时 `setOpen(false)`。
- **verify**：列表点"导出" → 居中悬浮页出现、蒙层 + Esc 可关；提交后 toast「导出已入队」且 modal 关闭。

### 步骤 2 · 重排 ExportForm 为宽松布局 + 富格式说明
- 格式从一行挤压的小按钮升级为**带说明的选项卡片**：每格式一行 `label + 一句话用途说明`（如 COCO「通用检测/分割标准，单 instances.json」、YOLO「每图一个 .txt + classes.txt」、AAP JSON「平台原生无损，含 predictions+annotations 双数组」、视频格式同理）。说明为纯前端静态文案，不依赖后端。
- 帧模式、`includeAttributes` 复选框 + helpText 沿用现有语义，纵向留白放宽。
- 提交按钮放 modal 底部，文案改 `开始导出`（与 trigger `导出` 区分，避免单测/可访问性歧义）。
- CSS：迁移到宽松布局类；把遗留 `oklch(...)` 选中态/提交态换成 token（`--color-accent` 系），消除硬编码。
- **verify**：`pnpm lint:css-tokens` 绿；图片 vs 视频项目格式集正确切换；窄屏下 modal 不溢出。

### 步骤 3 · 同步更新单测
- `ExportSection.test.tsx`：打开入口由 `getByText("导出 ▾")` → 新 trigger 文案（如 `导出`，注意与提交按钮 `开始导出` 不再撞文案）；提交点击改 `开始导出`。
- 4 个断言用例（默认 true / 勾掉 false / 切 YOLO / 视频 frame mode）的 `exportProject` 入参断言**保持不变**（契约未变）。
- **verify**：`pnpm test ExportSection` 4 用例绿。

### 步骤 4 · 文档收尾
- 普通 UI 改造，按记忆约定**可不记 CHANGELOG**；若按版本收尾习惯仍要记，则加 v0.10.42 一条 Changed。
- 检查用户手册导出章节（`docs-site/user-guide/`）是否有"点导出下拉"截图/描述需同步为"导出弹窗"。
- **verify**：grep 文档无"导出下拉"等过时表述残留。

## 4. 不做 / 留作触发项
- **导出范围过滤**（按批次 / 状态 / 仅已审核 / 日期区间导出）：需后端 `export_project` + `ExportService` 配套新增过滤参数，单独立版。本版只把"承载容器"（居中 modal）做出来。
- 多格式一次性打包导出、导出模板/预设记忆：未确认需求，暂不做。
- VOC 格式：后端保留同步 blob、前端早已隐藏，本版不复活。

---

## 5. 风险 / 注意
- **唯一渲染点在表格行内**：trigger 的 `e.stopPropagation()` 必须保留，否则点导出会误触发行级"打开项目"导航。
- Modal 用 `createPortal` 挂到 `document.body`，脱离表格 overflow 上下文 —— 这正是本次改造解决"局促"的关键，不要把 modal 塞回单元格内。
- 单测靠文案选择元素：trigger 与 submit 文案务必不相同，否则 `getByText` 命中歧义。
- 纯前端、无依赖变更 —— 走 vite HMR，无需 rebuild（CLAUDE.md §8）。
