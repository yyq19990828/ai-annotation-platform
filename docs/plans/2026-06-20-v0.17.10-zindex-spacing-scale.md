# v0.17.10 · 层级 + 间距标尺(z-index 语义化 + padding 收敛)

> 隶属 [设计系统第二阶段 Epic](./2026-06-20-v0.17.x-design-system-phase2-epic.md)。

## 1. 目标

- **z-index**:把散落无标尺的层级值收敛为一套语义 z 标尺。实测:`z-50`×18 / `z-[1000]`×6 / `z-60`×3 / `z-61`×2 / `z-[201]`×2 / `z-[55]`×2 / `z-30` / `z-20` / `z-10`…(浮层各猜一层,易压栈错位)。
- **padding**:把 **157 处** `p?-[Npx]` 一次性像素值尽量归并到 Tailwind spacing 刻度。

## 2. 语义 z 标尺(建议,按现有最高层反推固定梯度)

| 语义 token | 值 | 归位对象 |
|---|---|---|
| `z-base` | 0–10 | 页内局部堆叠(现 z-10/20/30 等) |
| `z-dropdown` | 50 | 下拉 / 选择浮层 |
| `z-popover` | 55 | popover(现 z-[55]) |
| `z-tooltip` | 60 | tooltip(现 z-60/61) |
| `z-modal-backdrop` | 200 | 遮罩(现 z-[201] 反推) |
| `z-modal` | 201 | Dialog / Drawer 内容 |
| `z-floating` | 210 | 工作台浮动面板 |
| `z-toast` | 1000 | sonner toast(现 z-[1000]) |

> 实际梯度落地前**核对现有压栈关系**(尤其 Dialog 内的 popover/tooltip 是否需高于 modal),不要凭表硬套。Radix/sonner 自带的 z 不在本表强改。

## 3. padding 收敛原则

- 能落到 Tailwind 刻度的归并:`px-[9px]`→`px-2`(8)或 `px-2.5`(10)按视觉就近;`py-[5px]`→`py-1.5` 等,**逐处过截图**确认无可见跳动。
- **保留**:画布像素定位、需精确对齐的极少数任意值列白名单。

## 4. 落地步骤

1. `shadcn.css` `@theme inline`(或 tailwind 配置)定义 z 标尺 token → `z-dropdown` 等工具类。
2. codemod 替换 z 值(按 §2 映射);padding 按 §3 就近归并。
3. 门禁:`check-tw-tokens.mjs` 加「禁裸 `z-[四位数]` / 提示用语义 z」(先 warning)。

## 5. 验收

- 浮层压栈顺序回归:Dialog / Drawer / Tooltip / Popover / 右键菜单 / Toast / 工作台浮动面板,亮暗双主题逐一确认无错位。
- `grep -rE "z-\[[0-9]+\]" apps/web/src` 收敛到白名单内。
- `pnpm lint && pnpm typecheck && pnpm test` 全绿。
- 完成后:Epic §2 表本行置 ✅;本 plan 补 `## Outcome`。

## Outcome

- 在 `shadcn.css` 定义 `--sc-z-*` 与 `.z-*` 语义 utilities;取值保持当前压栈关系,覆盖局部画布层、dropdown/popover/modal/drawer、notification、workbench modal 与 app drawer。
- 全量替换 `apps/web/src` 内裸 `z-N` / `z-[N]`;无剩余裸 z-index 调用点。
- 将 `p?-[Npx]` 任意 padding 归并到 Tailwind spacing 刻度;无剩余 `p?-[Npx]`。
- `check-tw-tokens.mjs` 新增裸数字 z-index warning,提示新增调用点改用语义 z utility。
