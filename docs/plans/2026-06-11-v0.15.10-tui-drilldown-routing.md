## 背景

v0.15.9 把 TUI 美化到位（Header/Footer、主题、计数边框），但交互仍是「键盘 + 单屏 tab + 行内详情面板」。用户希望更接近 WebUI 的操作手感:可点按钮、点行进「子页面」、悬浮面板。

## 不可破的红线（沿用）

1. **只消费 SDK 公开 API**,不碰 `_http`,**不臆造端点**。本版用到的全部是已有方法:
   `client.projects.list` / `client.jobs.list` / `client.jobs.cancel` / `client.ml_backends.list` / `client.exports.create`。
2. **维持「只读为主 + 2 个轻动作」**:导出 / 取消之外不加任何写操作（不加创建项目/数据集表单）。
3. TUI 限定在 `[tui]` extra 内,可整体删除;只用 Textual 公开 widget（`Screen` / `Button` / `TabbedContent` / `ModalScreen`）。

## 数据可行性（已核对 models.py）

- `Job.project_id: UUID | None` 存在 → 项目详情页的「任务」子 tab 可对 `jobs.list()` **客户端按 project_id 过滤**。
- `MLBackend.project_id` 存在;`ml_backends.list(project_id)` 本就是 project-scoped。
- `Project` 字段 + 服务端附加 `total_tasks/completed_tasks`(extra="allow")→ 概览进度。
- 全部无需新端点。

## 范围 A · 下钻子路由（Screen 栈）

行选中（回车 / 点击 / 「打开」按钮）→ `push_screen` 进专属详情屏,屏顶面包屑 `aap tui ▸ …`,`esc` / 「◀ 返回」`pop_screen`。**行内 `#*-detail` 面板被详情屏取代**（更像 web 的「点行进详情页」）。

- **`ProjectDetailScreen`（旗舰,带 scoped 子 tab）**:
  - 概览:项目字段 + 进度 + 「⬇ 导出」按钮（走原 ConfirmModal 二次确认 → `exports.create`）。
  - 任务:`jobs.list()` 客户端按本项目 `project_id` 过滤的表（沿用着色 / 进度条;行可再下钻进 JobDetail）。
  - Backends:`ml_backends.list(project_id)` 表（沿用 state 着色;行可再下钻进 BackendDetail）。
- **`DetailScreen`（通用,简单实体复用）**:面包屑 + 正文文本 + 动作按钮行 + 返回。
  - Job → 正文 `_job_detail`,动作 = 「✖ 取消」(仅 pending/running 启用,走 ConfirmModal)。
  - ML Backend → 正文 `_ml_backend_detail`,无写动作。
  - Dataset → 正文字段,无写动作。

## 范围 B · 动作按钮栏

每个主 tab 顶部加一条 `Horizontal.action-bar`(`Button`,鼠标 + 键盘都可触发,变体着色):

| Tab | 按钮 |
|---|---|
| Projects | 🔄 刷新 · ↳ 打开 · ⬇ 导出 |
| Datasets | 🔄 刷新 · ↳ 打开 |
| Jobs | 🔄 刷新 · ↳ 打开 · ✖ 取消 |
| ML Backends | 🔄 刷新 · ↳ 打开 |

`on_button_pressed` 按 `button.id` 派发到既有 `action_*`;「打开」= 对当前高亮行 push 详情屏。**键盘绑定全部保留**（`r/e/c/q` + 回车=打开),按钮只是并行的鼠标入口。

## 范围 C · 悬浮面板

- 复用现有 `ConfirmModal`（ModalScreen 浮层）做破坏性动作二次确认——导出 / 取消在主屏与详情屏共用同一条确认路径。
- 详情屏本身即「子路由页面」,与 web 抽屉/子页等价;不再额外造一套抽屉组件,避免重复。

## 测试策略（test_tui_app.py）

保留的契约:四 tab id / 表格列内容 / 状态翻转高亮 + 「完成」/ ml 着色 / `e`·`c`·`q` 键行为 / 终态 job「不可取消」。

需改 / 新增:
- **改** `test_ml_backend_detail_on_enter`:回车不再写行内 `#ml-detail`,改断言 push 出的 `DetailScreen` 正文含 `model_version: v1.2` / `util 73%`。
- **新增**:
  - Projects 行回车 / 「打开」→ push `ProjectDetailScreen`,概览/任务/Backends 三子 tab 在,任务子 tab 仅含本项目 job。
  - 详情屏「导出」按钮 + 确认 → `exports.created`。
  - Job 行下钻 → `DetailScreen`,「取消」按钮 + 确认 → `jobs.cancelled`;终态 job 取消按钮禁用。
  - `esc` / 返回按钮 pop 回主屏。
  - 主 tab 动作按钮点击触发对应 action（刷新 / 打开）。
