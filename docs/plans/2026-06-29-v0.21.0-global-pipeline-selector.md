# v0.21.0 · 全局跨项目编排选择器

状态：草案（draft）。minor 版本——v0.19.2 WS0 的**正主消费方**。把现在逐项目、临时的编排搭建
升级为全局、可命名、可复用的跨项目流水线选择器。是这一系列 plan 的 capstone。

## 背景

- v0.19.2 WS0 让 `/instances` 透传 `supported_inputs` + `resource_profile`，计划里写明这是
  **「全局编排选择器的前置」**——现在前置已就位，但选择器本身没建。
- 现状编排（`StageCard` / `ProjectDetailPanel`）走**项目级** `/capabilities`，每个项目从零搭流水线，
  无法跨项目复用「检测→车辆属性」这类常用编排。
- ROADMAP 已记 P3「项目编排多条命名持久化（`project_pipelines` 表）」——v0.18.x 落地走方案 A
  （`Project.preannotate_pipeline` 单列 JSONB，一项目一条当前编排）。全局选择器正是触发「升级到多命名编排」的需求。

## 目标

基于全局 `/instances`（跨项目可见的 backend/model 池）建一个编排选择器：从全局注册表选 backend/model 搭流水线、
存为**命名可复用**的编排模板、跨项目套用。把 WS0 的数据真正用起来。

## 工作项（高层，细节待立项时展开）

### WS1 · 数据模型：从单列 JSONB 升级到命名编排表

- 新建 `project_pipelines(id, project_id|null, name, stages JSONB, is_default, created_by, ...)`
  （`project_id=null` = 全局可复用模板；非 null = 项目私有命名编排）。alembic 迁移 + 把现有
  `Project.preannotate_pipeline` 单条迁成一条 `is_default` 行（零丢失）。
- 复用 v0.18.27 `_validate_saved_pipeline` + v0.19.3 抽出的 `pipeline_validation`（能力校验）。

### WS2 · 全局编排选择器 UI

- 新页/抽屉：左侧全局 backend/model 池（走 `/instances`，用 `supported_inputs`/`resource_profile`/`composition`
  过滤——只收 `atom` 作下游、按 `supported_inputs` 判父子可达性、按 `batchable` 标可批量），右侧画布搭 DAG。
- 复用 v0.18.16 `pipelineGraph.ts`（受限树形 → react-flow）+ v0.19.2 的 `stageWarning`/`StageCaps`
  全套配置期校验（可达性 / class / batchable / 属性落点）。
- 存为命名编排 → 选「应用到当前项目」/「设为项目默认」。

### WS3 · 跨项目套用 + 「当前题 AI」集成

- 项目设置 / 编排面板：从命名编排库选一条套用（替代从零搭）。
- 「当前题 AI」popover 的「运行当前题（按项目编排）」读 `is_default` 命名编排（与 v0.18.25 链路衔接）。

## 风险

高（新表 + 新 UI + 跨项目语义）：
- 全局编排引用的 backend 在某项目**未启用**时如何降级（v0.19.0 ADR-0044 的「项目启用」语义）：套用时校验启用态，缺则提示去启用。
- 命名编排的 backend/model 随注册表变化失效（model 下线）→ 套用期校验 + 失效提示。
- 权限：谁能建全局模板（超管？项目 owner？）—— 需 ADR 定。

## 验收

- 从全局选择器搭一条「detect→classify」编排、命名保存、应用到两个不同项目均生效。
- 选择器内全程有 v0.19.2 配置期校验（不可达 / class 缺 / batchable / 属性落点全部前移到画布）。
- 引用未启用 backend → 套用期明确提示，不静默失败。

## 排期与依赖

- **强依赖 v0.19.2 WS0**（已落，全局字段就位）。
- 受益于 v0.19.3（共享 `pipeline_validation`）、v0.19.4（徽标复用）。
- 体量最大，建议独立 ADR（命名编排表设计 + 全局模板权限 + 失效降级），分多个子 PR。

## 不在范围

- 编排模板市场 / 跨组织共享：先项目内 + 超管全局模板，SaaS 级共享另议。
- 加权 AB 路由等高级编排（ROADMAP 已单列）。
