> Status: Draft · Epic Phase 5
>
> 父 Epic：[图像 / 视频栅格 Mask 能力统一](2026-07-21-raster-mask-workbench-unification-epic.md)
>
> 硬前置：[v0.23.8 原生 Mask AI 交互与视频局部纠错](2026-07-21-v0.23.8-mask-ai-interaction-video-correction.md)

## 1. 目标

- 补齐高频像素编辑能力，让标注员不必在“圆笔刷”与“重新跑 AI”之间二选一。
- 所有操作作用于原生 Mask Buffer，并作为可撤销 history command。
- 建立实例之间的冲突 / 非重叠策略，同时保持默认行为向后兼容。
- 补视频 Mask 关键帧复制、粘贴、删除和局部实例操作。
- 提供显式 polygon / Mask 转换，不用隐式最大外环降级。

## 2. 工具集合

### P0 · 区域加减

- 圆形 / 方形 brush 与 eraser；半径、硬边和光标预览一致。
- Lasso / polygon add：闭合区域并入当前 Mask。
- Lasso / polygon subtract：闭合区域从当前 Mask 扣除。
- Flood fill：按当前二值连通区域填充或擦除，明确 4 / 8 邻域合同。
- 所有拖拽过程显示预览，pointer up 后提交一个 history command。

### P1 · 连通域与 hole

- 光标所在组件：保留、删除、复制为新实例。
- 删除小组件：按像素面积阈值预览，确认后批量删除。
- Fill holes：支持当前 hole、面积阈值以下和全部 hole 三种范围。
- Split components：将一个 Mask 的多个组件拆为多个同类 annotation / track，保留 lineage。
- Join masks：同类多个图片 Mask 合成一个；视频仅合成当前帧，不隐式合并整条轨迹。

### P2 · 形态学与边界

- 膨胀、腐蚀、开运算、闭运算，kernel 形状和半径有上限。
- 边界平滑、去毛刺与 simplify 只改变 Mask 像素，不偷偷转 polygon。
- 操作前后显示面积、组件数、hole 数和变化像素数。
- 大范围操作异步执行，可取消；失败不修改原 Buffer。

### P3 · 实例冲突策略

- 默认“允许重叠”，保持现有 instance segmentation 语义。
- 可选“从同类其它实例擦除”和“从全部其它实例擦除”非重叠模式。
- 冲突计算只处理当前媒体 / 帧可见、未锁定且有编辑权限的对象。
- 多对象 mutation 使用原子批量 API 或带版本列表的事务；任一版本冲突整批失败。
- 操作前显示受影响实例数和像素数，允许展开对象列表。

### P4 · 视频关键帧生产力

- 复制 / 粘贴当前 Mask keyframe，粘贴时可选择同轨或新轨。
- 显式删除当前 keyframe、标记 outside、恢复 held source。
- 当前帧组件拆分成新轨迹；不自动推断后续 identity。
- 从上一 / 下一关键帧复制后进入 dirty 编辑，不立即保存。
- 操作与 annotation history、Tracker correction lineage 一致。

### P5 · 转换中心

- polygon / multi_polygon → Mask 支持 hole、多个外环和分辨率预览。
- Mask → multi_polygon 输出所有组件 / hole，提供简化容差与 loss report。
- Mask → bbox / rotated bbox 明确是派生对象，可选择保留或替换原对象。
- 批量转换使用 dry-run 汇总：对象数、预计顶点、丢失像素、失败项。

## 3. UX 与快捷键

- 高级工具收进 Mask 浮动工具栏的二级菜单，不扩张全局字母快捷键冲突。
- 当前操作、范围、模式和影响对象必须可见；非重叠模式不能只靠颜色提示。
- 所有 destructive 操作先预览，支持 Enter 确认、Esc 取消、Ctrl/⌘+Z 撤销。
- 选择组件 / hole 使用 alpha hit，不使用 AABB。
- 操作在 locked / readOnly 对象上显示准确禁用原因。

## 4. 非目标

- 不做 5K / 8K tile；本版仍遵守现有尺寸门。
- 不实现 semantic / panoptic class-map 的 label painting。
- 不合并整条视频 Mask Track，不做跨帧组件 Re-ID。
- 不引入 Photoshop 式图层、软笔刷或羽化 alpha。
- 不增加新的持久 geometry。

## 5. 测试与验收

- 每个 operation 有 golden bitmap、边界、空结果、undo / redo 和取消测试。
- 4 / 8 邻域、hole 定义、kernel 和边界裁切由非正方形 fixture 固定。
- 非重叠批量 mutation 覆盖版本冲突、锁定对象、部分权限和原子回滚。
- 浏览器 E2E 覆盖 lasso add/subtract、component split/join、fill holes、morphology 和视频 copy/paste。
- 转换 dry-run / execute 的面积、组件与损失报告一致。
- 性能测试记录 1080p 常用操作 p50 / p95，为 v0.23.10 Worker / tile 设计提供基线。
