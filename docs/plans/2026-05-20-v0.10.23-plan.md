## 1. ⚠️ 已发现的前置 bug（两轨都要对齐）

**variant 命名不一致**：`/setup` enum 暴露 `sam_variant: ["tiny","small","base","large"]`（`main.py:250`），但 `SAM2_CONFIGS` 的 key 是 `["tiny","small","base_plus","large"]`（`predictor.py:55-60`）——`"base"` 在 predictor 里不存在。

当前因为 `readOnly`+backend 忽略 variant，这条死路没被触发。一旦 Track A 让 backend **真去消费** variant，选 `base` 会 422（`SAM2_CONFIGS["base"]` KeyError）。

**统一口径（两轨执行）**：`/setup` enum 改为 `["tiny","small","base_plus","large"]`，前端下拉直接渲染 enum 原值。Track A 改 `main.py:250`；Track B 渲染 enum 时不做名称映射。

## 2. Track A · Backend ModelPool（grounded-sam2-backend）

主战场，est ~5d。验收见源需求 §6。

### A1. 新增 `model_pool.py`
- `ModelPool(cap: int)`，内部 `OrderedDict[(sam_variant, dino_variant), GroundedSAM2Predictor]` LRU。
- `async get(sam_variant, dino_variant) -> GroundedSAM2Predictor`：命中 `move_to_end`；miss 在 **per-variant 锁**内 build（`run_in_executor`），超 cap 驱逐 LRU 项（`del predictor` + 复用 `_free_gpu_memory()`）。
- per-variant 锁：`dict[variant_key, asyncio.Lock]`，防并发同变体重复 build。
- pool 满 + 并发 miss：排队，超 `MODEL_POOL_BUILD_TIMEOUT` 返回 503「显存繁忙，稍后重试」。
- embedding cache 按变体分桶：`dict[variant_key, EmbeddingCache]`（不同变体 embedding 张量不可跨用）。驱逐 predictor 时连带 clear 该桶并 `_free_gpu_memory()`。
- 复用 idle watcher：超 `IDLE_UNLOAD_SECONDS` 清空整池 + 各桶 cache。

### A2. `main.py` 接入 pool
- `_predictor` 单例 / `_cache` 单例 / `_predictor_lock` 单锁 → 收进 `ModelPool`。保留 `_ensure_predictor_loaded` 语义（startup 预热 **默认变体** `(SAM_VARIANT, DINO_VARIANT)` 进 pool，保持现有「单变体常驻」不破）。
- `_run_prompt(file_path, ctx)`：读 `ctx.get("sam_variant")` / `ctx.get("dino_variant")`，缺省回退全局 env 默认；校验落在 `SAM2_CONFIGS`/`DINO_CONFIGS` key 集合内，非法值 422。
- `predictor = await pool.get(sv, dv)`；`cache_key = compute_cache_key(file_path, sv)` 传**请求级** sv；命中判定用该变体的 cache 桶。
- `MODEL_VERSION` / 返回 `model_version`：按本次请求变体拼，而非全局常量。抽 helper `_model_version(sv, dv)`。
- `/setup`（`main.py:248-261`）：去掉两个 variant 的 `readOnly: True`；enum 对齐 §1（`base_plus`）。
- `/health`（`main.py:173-213`）：新增 `pool` 子对象 `{cap, loaded_variants:[...], evict_count, per_variant_lru_ts}`。`/cache/stats` + `/metrics` 聚合各桶。
- `/unload` `/reload`：语义改为整池操作。

### A3. 配置 + compose + docs
- 新 env：`MODEL_POOL_CAP`（默认 1，保持现状）、`MODEL_POOL_BUILD_TIMEOUT`（默认 ~30s）。
- `docker-compose.yml:133-168`：grounded-sam2 service 加这两个 env + 显存预算注释。
- `.env.example`：加新 env，跑 `pnpm docs:gen-env-vars` 重生成 `docs-site/dev/reference/env-vars.md`。
- `docs-site/dev/reference/ml-backend-protocol.md`：`/predict` context 加 `sam_variant`/`dino_variant`、`/health` pool 字段、`/setup` 去 readOnly 说明。
- `docs-site/dev/deploy.md`：按显存预算配 pool cap 章节（4060 仅 1 / 3090 1–2 / A100 2–4，默认 1）。

### A4. 验收（源需求 §6）
1. tiny→large 两次 `model_version` 不同，第二次首调冷启 1–3s、之后命中无冷启。
2. `CAP=1` 行为同现状；`CAP=2` 两变体并存无重复 build。
3. embedding cache 命中只在同变体同图（`/cache/stats` 各桶独立）。
4. `/health.pool` 正确反映 loaded_variants/LRU；idle 后清空。
5. pool 满 + 并发 miss 不 OOM：排队或 503。
6. 非法 variant 422，不影响后续请求。

## 3. Track B · 前端面板收敛（纯前端，无 backend 依赖）

est ~2d。验收见源需求 §9.7。方向：**变体上移 AI 面板（设置型，会话级）**，**文本输入下沉子工具面板（动作型，跟工具走）**。

### B1. 设计 A · 变体选择移到 AI 面板（会话级）
- `AIInspectorPanel.tsx` 顶部加会话级变体选择区，选项来自 `/setup.params` 的 `sam_variant`/`dino_variant` enum（Track A 去 readOnly 后可改）。enum 原值直接渲染（不映射，对齐 §1）。
- 从 `SchemaForm` 渲染中**排除** variant enum 字段（`SchemaForm/index.tsx:114-131` 那两个不在每个子工具 drawer 重复出现）；子工具面板只留阈值滑块。
- 拆 `aiVariant` 出 `aiToolParams`（`useWorkbenchState.ts`），**作用域会话级、切工具不重置**——修 `WorkbenchShell.tsx:493-496` 重置逻辑（重置只清 tool 专属参数，不清变体）。
- 变体值在 `runPoint/runBbox/runText` 合进 context（链路已通，源需求 §1）。
- grounded-sam2 双轴用两个下拉；`/setup.params` 不含变体字段时（sam3）该区隐藏。

### B2. 设计 B · 文本输入下沉子工具面板
- 把 `SamTextPanel` 的输入段（文本框 + 输出模式 tab + 「找全图」确认按钮，`AIInspectorPanel.tsx:509-560`）搬进 `AIToolDrawer.tsx` 的 text-prompt 分支，替换现有 hint（`AIToolDrawer.tsx:118-122`）。
- 输入 → Enter/确认 → 复用现有 `WorkbenchShell.tsx:1278` → `useInteractiveAI.ts:183-192`（逻辑零改，仅挪渲染位置）。
- `samTextFocus`（`WorkbenchShell.tsx:493-496`）聚焦目标改为子工具面板输入框。
- **预测结果列表仍留 AI 面板**（结果展示属 inspector），只把「输入+确认」下沉。

### B3. 状态作用域（源需求 §9.5）
| 配置 | 落点 | 作用域 | 切工具 | state |
|---|---|---|---|---|
| 变体 sam/dino | AI 面板 | 会话级 | 保留 | 新 `aiVariant` |
| 阈值等 tool 参数 | 子工具面板 | tool 级 | 重置 | `aiToolParams` |
| 文本 prompt | 子工具面板 | tool 级瞬态 | 重置 | text-prompt 局部 state |

### B4. 验收（源需求 §9.7）
1. AI 面板设变体一次，切 point↔bbox↔text 子工具变体保持，子工具面板不再出现变体下拉。

3. 文本预测结果仍在 AI 面板展示与采纳。
4. 变体/阈值/文本落点与作用域符合 B3。
5.（端到端，需 Track A）AI 面板选 large → 文本检测 → 返回 model_version 含 large。
