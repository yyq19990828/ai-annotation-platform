## 1. 目标

- 建立 Mask 专属质量指标、问题定位、审阅决策和批量修复工作流。
- 视频增加跨帧稳定性、漂移、闪烁和传播断裂提示。
- Tracker 候选从整 job 审阅扩展为按轨迹、帧窗口和问题区域局部接受。
- 补齐主流 instance Mask 交换格式，并对无损 / 有损边界给机器可读报告。
- 建立跨格式 consumer 测试，不能只验证 ZIP 文件名或 JSON schema。

## 2. Mask QC

### P0 · 单帧指标

- 像素面积、AABB 占比、组件数、hole 数、最大 / 最小组件面积。
- 小岛、窄桥、锯齿边界、空 Mask、近空 Mask 和触边提示。
- 同类 / 跨类 Mask overlap 像素、IoU、containment 与冲突区域。
- annotation bbox / polygon 派生结果与 Mask 真值不一致检查。
- 阈值由项目 QC 配置管理；默认只提示，不阻止提交。

### P1 · 视频时序指标

- 相邻采样帧 Mask IoU、质心位移、面积变化率和边界变化率。
- flicker：短时出现 / 消失、组件数突变、hole 突变。
- drift：持续偏离人工 anchor 或目标外观，结合 tracker confidence / correction lineage。
- held 区间与 prediction 区间分开解释；nearest hold 不伪装为模型连续预测。
- outside / occluded 帧不按普通可见帧计算假异常。

### P2 · 问题模型与定位

- QC issue 有稳定 `code + annotation_id + frame/range + region digest` 去重键。
- 问题包含 severity、metric、threshold、像素区域 / AABB、来源和修复建议。
- 从问题列表可跳到图片对象或视频帧 / 轨迹；选中后高亮冲突像素。
- annotation version 变化后旧问题标 stale，异步重算；不把旧问题显示成当前真值。
- QC job 对 5K / 8K 使用 tile / streaming，不物化所有全帧 RGBA。

## 3. 审阅工作流

### P3 · Mask 对比

- reviewer 可切换 overlay、边界、差异 XOR、只看新增 / 删除像素。
- 显示与上一版本、AI 候选、邻近关键帧的 Dice / IoU 和变化像素。
- 审阅决策支持接受、退回、评论锚点和“接受但记录警告”。
- 评论可锚定 Mask region / boundary，不只锚定图片坐标点。

### P4 · 局部 Tracker 接受

- 按整 job、轨迹、帧窗口或单个问题区域接受 / 拒绝。
- 局部接受事务携带源 annotation version 和 candidate digest；冲突整组失败。
- manual keyframe、已审阅区间和 locked range 默认保护。
- 接受后 staged 引用按剩余未决候选精确保活；全部决策完成后清理。
- reviewer 可从 flicker / drift 问题直接创建 correction job。

### P5 · 批量修复

- 支持删除小岛、填小 hole、解决同类重叠、重新运行局部 SAM / Tracker。
- dry-run 显示对象、帧、像素与预计 mutation 数；批量写入原子或可恢复分片。
- 自动修复不能跨 locked / reviewed 边界；跳过项有逐条报告。
- 修复前后指标进入 audit，支持批量 undo / rollback job。

## 4. Instance Mask 格式生态

### P6 · 图片格式

| 格式 | 导入 | 导出 | 合同 |
|---|---|---|---|
| AAP JSON | 已有，补完整 consumer | 已有 | 原生 RLE 无损 |
| COCO instance | 已有，补 compressed / uncompressed | 已有 | RLE / polygon 显式 |
| Label Studio BrushLabels | 新增 | 新增 | PNG / RLE 按官方字段，逐像素验证 |
| Binary PNG per instance | 新增 | 新增 | 一实例一张 8-bit PNG + manifest |
| Indexed PNG instance map | 新增 | 新增 | 像素 ID + segments manifest，重叠需策略 |
| YOLO Seg | 显式转换 | 显式转换 | 有损 polygon，带 loss report |

### P7 · 视频格式

| 格式 | 导入 | 导出 | 合同 |
|---|---|---|---|
| AAP JSON | 已有 | 已有 | keyframe / RLE 无损 |
| COCO Frames RLE | 新增导入 | 已有 | 展开帧像素保真，轨迹语义有损 |
| DAVIS | 新增 | 已有 | palette PNG，overlap winner 明示 |
| YouTube-VOS 风格 | 新增 | 新增 | 稀疏标注帧 + object metadata |
| MOTS | 新增 | 新增 | class / track id + RLE，消费者验证 |
| Video JSON | 不新增可移植导入 | 已有 | ref-only，继续标记非备份格式 |

### P8 · 格式框架

- import dry-run 返回支持项、未知 label、尺寸冲突、重叠、ID 上限和预计对象数。
- export preflight 返回无损 / 有损分类、跳过项和具体原因；不静默降级。
- 每个格式有官方或事实标准 consumer fixture，至少逐像素读取一个真实包。
- 大包使用 streaming、分片和临时目录配额；失败清理中间产物。
- manifest 固定媒体路径、帧编号、padding、class / instance id 与 overlap 策略。

## 5. 非目标

- 不引入 semantic / panoptic class-map；留 v0.24.0。
- 不改变 instance `raster_mask` / `video_track_mask` schema。
- 不让自动 QC 阻止提交，除非项目管理员显式把规则设为 blocking。
- 不用单一 IoU 代替所有质量判断。
- 不把 Video JSON 宣传成包含像素对象的可移植备份。

## 6. 验收

- QC golden fixtures 覆盖小岛、hole、重叠、边界噪声、flicker、drift、outside 和 held。
- 问题定位跳转到正确 annotation / frame / region，版本变化后 stale 语义正确。
- 局部 Tracker 接受不修改窗口外、manual 或 locked 区域。
- 批量修复 dry-run 与实际变化像素 / mutation 数一致，可回滚。
- Label Studio、PNG、COCO Frames、DAVIS、YouTube-VOS、MOTS 至少各完成一次真实 consumer round-trip。
- 5K / 8K QC 和大包导入导出遵守 v0.23.10 内存 / 临时空间预算。
