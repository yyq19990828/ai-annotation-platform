# v0.21.32 · polyline track AI 中心线传播（已取消）

> Status: abandoned

状态：**已取消（2026-07-12）**。仓库现有 SAM2 / SAM3 tracker 原生输出 mask，通用 point tracker 只输出离散点，均不维护
开放折线的顶点顺序、拓扑、端点与中心线语义。原草案依赖“mask → 骨架化 → 最长路径 → 简化”的启发式后处理，并不是
模型原生的 polyline tracking；分叉、闭环、遮挡以及“轮廓边 / 中心线”语义都会产生不可消解的歧义，投入与通用价值不匹配。

决策：不实现本版本，不删除当前 400 安全拒绝，不把 polyline 静默降为 bbox / polygon。现有手工关键帧、弧长插值和导出
能力继续保留。只有出现明确的垂直领域需求（如车道线）、确定专用模型与数据集，并有真实客户用例时，才重新立项；不得直接
恢复本草案。

上游索引：[多几何 track 剩余切片](2026-07-12-multi-geometry-track-remaining-slices.md)。

以下内容仅保留为历史勘察与否决方案，不是待实施合同。

## 当前缺口

- `video_tracker_job_service.py` 在 propagate 入口拒绝 `video_track_polyline`，防止旧 runner 把它改写成空 bbox。
- `video_tracker_runner.py` 的 geometry coercion / persist 只区分 bbox 与 polygon。
- `video_tracker_adapters.py`、grounded-SAM2、SAM3 multiplex、SAM3 PVS 只接受
  `output_geometry="bbox" | "polygon"`。
- 前端传播回调、选中卡和 `VideoTrackerPropagateDialog` 仍按 bbox track 类型组织；polyline 显式禁用。
- staged preview 只把 `geometry.type="bbox"` 映射成候选框，points 结果即使返回也不可见。
- polygon / polyline 插值没有同时处理反向 winding / 反向端点，AI 连续帧若方向翻转会扭曲中间帧。

## 固定语义

polyline track 表达中心线对象，如车道线、线缆、裂缝。backend 接收 `output_geometry="polyline"` 后，对模型逐帧二值
mask 执行：

1. 去除小连通域并骨架化；
2. 分叉图取最长连通中心路径；
3. 闭环按离种子起点最近的像素确定断点；
4. RDP 简化并限制顶点数；
5. 输出方向与种子 polyline 首尾方向对齐；
6. 无有效路径或少于 2 点时返回 `outside=true`。

不允许把输出静默降为 bbox / polygon。若业务需要轮廓边而非中心线，应使用 polygon track。

## 目标

- 支持从 polyline track 发起三种真实 video tracker；
- 结果先进入 candidate，预览为开放折线，接受后仍是同一 `video_track_polyline`；
- 保留人工关键帧、原 track id、outside、source、多目标 identity 与采样网格语义；
- 旧 backend 未声明 polyline 输出时 UI 灰置并提示升级，而不是请求后才 422。

## 工作项

### WS0 · point-track 类型与插值硬化

- 前端引入窄 `AnyVideoTrackGeometry` / `AnyVideoTrackAnnotation` 与 keyframe 元信息 helper；只迁移传播、preview、
  selection、timeline / density、hidden / locked 等本版必经路径，不重构各 geometry 载荷。
- polygon 插值同时尝试正 / 反 winding；polyline 尝试原端点 / 反向端点，取总对应距离更小者。
- 后端 `video_tracks.py` 使用同一决策规则；前后端共享 golden fixtures，覆盖顶点数不等、方向翻转与 outside。
- server-side convert / split / merge / join 继续 bbox-only；非 bbox 上保持明确禁用。

### WS1 · 共享 mask → polyline 算法

- 在 `apps/_shared/mask_utils/` 增 GPU-free 纯函数，grounded-SAM2 与 SAM3 共用；禁止两份近似实现漂移。
- 算法测试覆盖：直线、弯线、分叉、闭环、多个连通域、噪声、退化单点、方向对齐、顶点上限。
- 简化容差相对 mask bbox / 图像尺寸表达，不能硬编码只适合 1080p 的像素阈值。
- 首先用固定 mask fixtures 完成 spike；算法合同未冻结前不解除平台 400。

### WS2 · ML backend 协议

- grounded-SAM2、SAM3 multiplex、SAM3 PVS 的 video tracker 接受
  `bbox | polygon | polyline`；逐帧 mask 在 backend 内转换后才返回 JSON。
- `/setup.models[].supported_geometric_outputs` 对每个 tracker model 如实声明支持集合；平台按匹配 tracker model 消费，
  不使用 backend 顶层含混并集判断。
- polyline 种子优先取按弧长抽样的正点提示；旧路径只能吃 bbox 时回退首关键帧外接框，但返回仍必须是 polyline。
- 跨窗续种使用上一窗末帧中心线的外接框或抽样点，不把 points 当 bbox 字段读取。

### WS3 · 平台 job、candidate 与 accept

- `VideoTrackerPropagateRequest`、`TrackerContext`、staged result 保留 `output_geometry="polyline"`；
- `_coerce_video_track_geometry`、结果持久化与多实例建轨从 `is_polygon` 改为 geometry-kind dispatch；
- polyline 结果写 `points`，少于 2 点转 outside；人工关键帧永不被 prediction 覆盖；
- candidate preview / accept / discard 保留 output geometry，不在 staged JSONB 中降级；
- 接受主实例时回填源 annotation，额外实例各建独立 polyline track，并继承类别 / tool unit / source 约定。

### WS4 · 前端发起与审阅

- point-track 选中卡 / 右键菜单出现 AI 追踪入口；能力不支持时展示准确禁用原因；
- 删除 `VideoTrackerPropagateDialog` 的无条件 polyline 禁用，但保留 backend capability 门禁；
- preview geometry 改为 `bbox | polygon | polyline` discriminated union；points 以开放 `<Line>` 叠加预览；
- review bar 的“候选框”统一改为“候选轨迹”，接受 / 丢弃行为不变；
- preview、接受后画布、刷新重载后三处必须显示同一 points 数据。

### WS5 · 文档与部署

- `docs-site/user-guide/workbench/video-track.md` 补 polyline AI 的中心线适用范围与退化语义；
- `docs-site/dev/reference/ml-backend-protocol.md` 正式记录 `output_geometry`、per-model 输出能力和 points response；
- `docs-site/dev/concepts/video-annotation-workbench.md` 更新多几何 candidate / accept 链；
- `CHANGELOG.md` 写入 `Unreleased / Added`；
- grounded-SAM2 / SAM3 代码位于镜像内，必须重建；runner 修改后必须重启 Celery worker。

## 验收

- 原“polyline 返回 400”测试改为 job 成功创建；能力不支持时仍在前端安全阻断；
- 正 / 反向、多窗、多目标、人工关键帧保护、低置信 outside、退化中心线全有 GPU-free 测试；
- staged preview 可见开放折线，accept 前 annotation 零污染，discard 后零改动；
- accept 后 geometry type、track id、manual keyframes、prediction points 均正确；
- 真实视频至少完成一次 `polyline → tracker → candidate → accept`，并在重建镜像 / 重启 worker 后验证。

## 非目标

- 任意轮廓边追踪；
- raster mask 持久化；
- point-track 的完整 split / merge / join / convert；
- 把中心线算法放进 apps/api；
- 绕过 candidate 流直接落库。
