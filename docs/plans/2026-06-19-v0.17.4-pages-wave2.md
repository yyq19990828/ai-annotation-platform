## 2. 迁移规约(与 v0.17.3 一致,子agent 必读)

> 参考已迁样板:`pages/Admin/SystemHealthPage.tsx`(表格 `[&_th]/[&_td]`、状态色 map、常量抽取)、`pages/Admin/AdminPeoplePage.tsx`(卡片/抽屉、`useElementStyle` 动态宽 `w-[var(--bar-width)]`、按钮组激活态、UA-safe select/input)、`pages/Dashboard/DashboardPage.tsx`(列表表格 + StatCard + sparkColor 映射)。

1. **颜色 token 映射**(禁硬编码 hex/rgb,只用语义类):
   - `--color-fg`→`text-foreground`;`--color-fg-muted`/`--color-fg-subtle`/`--color-fg-faint`→`text-muted-foreground`
   - `--color-bg`→`bg-background`;`--color-bg-elev`→`bg-card`;`--color-bg-sunken`→`bg-muted`;`--color-bg-hover`→`hover:bg-muted`
   - `--color-border`/`--color-border-subtle`→`border-border`
   - `--color-accent`→`text-brand`/`bg-brand`;`--color-accent-soft`→`bg-brand/10`;filterCount 式描边片→`border-brand/30 bg-brand/10 text-brand`
   - `--color-success`→emerald `text-emerald-600 dark:text-emerald-400`/`bg-emerald-500/10`/点`bg-emerald-500`
   - `--color-danger`→rose `text-rose-600 dark:text-rose-400`/`bg-rose-500/10`
   - `--color-warning`→amber `text-amber-600 dark:text-amber-400`/`bg-amber-500/10`
   - `--color-ai`→violet `text-violet-600 dark:text-violet-400`/`bg-violet-500/10`;SVG/sparkColor 用 `var(--sc-chart-4)`
   - 信息/总量 sky:`text-sky-600 dark:text-sky-400`/`bg-sky-500/10`
   - Sparkline/StatCard `color`/`sparkColor`(SVG 属性,非 className):蓝`var(--sc-brand)`/绿`var(--sc-positive)`/琥珀`var(--sc-caution)`/紫`var(--sc-chart-4)`
2. **彩色文字必暗色配对** `text-xxx-600 dark:text-xxx-400`;柔底 `/10`。语义:总量/信息=sky,正向/完成=emerald,AI=violet,进行中/警告=amber,错误/危险=rose。
3. **门禁硬规则**(`pnpm lint:css-tokens` + `lint:tw-tokens`):className 禁任何 hex/rgb/rgba/oklch;阴影用 `shadow-sm/lg/xl`,**禁** `shadow-[...rgba()]`(`rgba(` 出现在 className 任意位置即触发);不自创 token。
4. **禁 `style` JSX 属性**(eslint `no-restricted-syntax`)。动态值(宽高/位置/CSS 变量)用 `useElementStyle`:`const ref = useElementStyle<HTMLDivElement>({ "--foo": v } as CSSProperties); <div ref={ref} className="w-[var(--foo)]" />`。SVG `fill`/`stroke`/`width`/`height` 属性不是 style,保留;颜色走 `var(--sc-*)`。
5. **UA 漏样基线**(暂无全局 preflight):迁移的原生 `<button>`/`<input>`/`<select>`/`<textarea>` 必须 `appearance-none border-0 bg-transparent`(或显式 bg/border),可点击按钮 `cursor-pointer`。
6. **tw-scope**:
   - **路由级页面**根元素加 `tw-scope`(`DatasetsPage`/`SettingsPage`/`StoragePage`/`UsersPage`/`ModelMarketPage`/`ProjectSettingsPage`/`ProjectDataManagerPage`/`VideoTrackerJobsPage`)。
   - 渲染在已 tw-scope 页面内的**子面板/区块**(ModelMarket 各 Panel/Tab/Card、Projects 各 Section)**不需**自带 tw-scope。
   - 渲染在 `@/components/ui/Modal` 内的**弹窗内容**(各 `*Modal`)**不需**自带 tw-scope(Modal Content 已挂 tw-scope)。自绘 `createPortal` 浮层则需。
7. **优先复用已迁 `ui/` 组件**(Card/Button/Badge/Avatar/StatCard/ProgressBar/SearchInput/TabRow/Switch/Tooltip/Modal/Histogram/Sparkline/RadialProgress/DropdownMenu/ContextMenu 等),保持原 import 路径 + prop API,零调用点改动。
8. **只换表现,不改行为/props/逻辑/数据流,不删功能。**
9. **测试**:目标页/组件的 `*.test.tsx` 仅当断言了具体 CSS module 类名(`styles.foo`/`closest(".cls")`/`toHaveClass`)才改;语义查询(text/role/label/testid)无需动;不削弱覆盖。

## 3. 风险点与排序

- **`ProjectSettingsPage` 是 Tab 宿主**:各 `sections/*Section.tsx` 在其 Tab 面板内渲染。Section 迁移与 SettingsPage 迁移**互不依赖**(都只改自身 className),但 Section 的 Tailwind 工具类需 tw-scope 祖先 —— 最终态 SettingsPage 根有 tw-scope 即可,迁移顺序不限。
- **大量 `*Modal`**:多数走 `ui/Modal`(已挂 tw-scope),迁移即纯 className 替换;先确认每个 Modal 确实用 `ui/Modal` 而非自绘。
- **`BatchesSection`(435)/`CapabilityCatalogPanel`(495)/`ProjectDataManagerPage`(383)** 是三个最大单文件,数据密集(看板/目录/数据表),单独成块,重点验。
- **`Settings`(511)** 四分类设置体系(见 [project_workbench_settings_epic] 记忆),含开关/select 密集,UA 基线要全;**默认值=现状**红线不可破(只换皮,不改任何默认)。
- **共享 css**:逐文件确认无跨文件共享 `styles`(v0.17.3 的 `DashboardPage.module.css` 被两页共享是特例);ModelMarket / Projects 内若有共享需同改。
