# v0.20.19 · 二次推理条显隐开关

状态：**已落地（v0.20.19）**。用户反馈：二次推理**不一定常用**，想要个显隐开关「就像标注显隐一样」，
在多处能一键关掉这条浮顶控件。**依赖 v0.20.11**（`SecondaryInferenceBar` 存在）。

> 实现要点（与草案一致）：`useSecondaryBarHiddenPref` 读写 `User.preferences.ui.secondary_bar_hidden`
> （镜像 useTheme，authStore 乐观更新 + PATCH）；后端 `update_preferences` 给 `ui` 子树补深合并
> （否则 secondary_bar_hidden 的 PATCH 会冲掉 theme）；`UIPreferences.theme` 前端类型改可选（partial PATCH）。
> 三入口：设置抽屉 `toggle-secondary-bar` / 浮卡头部 ✦ 按钮（FloatingPanelShell 新增 `extraActions` 槽）/
> 右键菜单 `toggle-secondary-bar` 项（经 ImageStage→ImageWorkbench→StageHost 透传）。

## 背景

选中任一已落库框、非 AI 工具、图片任务时，二次推理条恒浮在画布顶部
（`useWorkbenchShellModel.tsx:2300-2311`）。对不跑二次推理的用户，这条一直占顶部、挡视线。需要一个
用户可控的「隐藏这条」开关，随手关、随手开。

## 设计

### 状态：一个共享布尔偏好

- `secondaryBarHidden`（默认 **false = 显示**，不回归现状——遵守「默认值=现状」红线）。
- gate 渲染：`useWorkbenchShellModel.tsx:2300` 的条件末尾 `&& !secondaryBarHidden`。
- **持久化：服务端 `User.preferences`（已定）**——跨设备一致。复用 `useAiToolParamPrefs.ts` 的
  `User.preferences` 服务端范式（`authApi.getPreferences` / 保存，debounce，多账户隔离），
  存 `User.preferences.ui.secondary_bar_hidden`（`ui` 子键，与 `ai.*` 参数偏好分开）。
  - `User.preferences` 是自由 JSONB，加子键即可，**无需 alembic**。
  - 读取链：偏好值 → 缺省 `false`（显示）。保存失败静默降级为组件内 state，不影响标注。
  - 注意：工作台设置抽屉现有开关（如 `hideOrphanAnnotations`）是纯会话级 `useState`
    （`useWorkbenchShellModel.tsx:586`）；本项**特意做成服务端持久化**，是首个跨设备存活的工作台 UI 开关。

### 文案（已定）

统一用「**二次推理面板**」（非「条」），动词 **打开 / 关闭**：
- 动作型入口（右键菜单 / 悬浮栏「更多」）按当前状态显示「打开二次推理面板」或「关闭二次推理面板」。
- 用「打开/关闭…面板」而非「显示/隐藏」，天然与 per-标注的「隐藏（这个框）」区分开，不会混淆。

### 三个入口（都读写同一个 `secondaryBarHidden`）

1. **工作台设置抽屉**（`WorkbenchSettingsDrawer`）——加一条 labeled toggle「二次推理面板」，
   与 `hideOrphanAnnotations` 开关同分组、同渲染范式（`data-testid="toggle-secondary-bar"`）。这是「设置」正门。
2. **标注信息悬浮栏头部按钮**——`SelectedAnnotationCard` 套 `FloatingPanelShell`，其头部右侧已有
   收起/合并/关闭 图标簇（`FloatingPanelShell.tsx:194-233`）。头部够宽，**直接在图标簇里加一个
   toggle 图标 button**（不做「更多」菜单），复用 `ICON_BUTTON_CLASS`，`title`/`aria-label` 按当前状态
   切「打开二次推理面板」/「关闭二次推理面板」，激活态（面板开着）加 `text-brand` 高亮。
   图标建议用 ✦/sparkle 系（与二次条标题 `✦ 二次推理` 呼应）。
3. **标注右键菜单**（`imageStageContextMenu.buildImageContextMenuItems`）——已有 per-标注
   「显示/隐藏」「锁定/解锁」范式（`imageStageContextMenu.ts:105-156`）。**加一条全局项
   「打开二次推理面板 / 关闭二次推理面板」**（按 `secondaryBarHidden` 当前值切文案），放到独立分区，
   与上面 per-标注的「隐藏」区隔。

## 工作项

- WS1 · 状态源：`useSecondaryBarHiddenPref` hook 读写 `User.preferences.ui.secondary_bar_hidden`
  （复用 `useAiToolParamPrefs` 范式，debounce 保存）；穿到 gate 条件。
- WS2 · 设置抽屉开关（入口 1）。
- WS3 · 右键菜单项（入口 3）。
- WS4 · 悬浮栏头部 toggle 图标 button（入口 2）。
- WS5 · 测试：gate 生效（hidden → 不渲染二次条即便满足其余条件）；三入口 toggle 同步一个状态。

## 决策（均已定）

1. **持久化范围** → 服务端 `User.preferences`（跨设备一致，见「设计」）。
2. **悬浮栏入口** → 头部图标簇直接加 toggle button（不做「更多」菜单，头部够宽）。
3. **文案** → 「打开/关闭二次推理面板」，用「面板」+「打开/关闭」与 per-标注「隐藏」天然区分。

## 依赖 / 不在范围

- **依赖 v0.20.11**。
- 不做：把交互条 / AI 面板等其他浮顶控件也纳入统一显隐（本项只管二次推理条；如需通用「浮顶控件显隐」
  框架另立）。
