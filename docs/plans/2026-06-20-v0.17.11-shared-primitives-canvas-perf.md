## 2. 画布取色效率(VideoKonva 层 per-render getComputedStyle)

`stage/colors.ts:56` 的 `cssVarToHex(varName)` 内部 `getComputedStyle(document.documentElement).getPropertyValue(...)`,被 `VideoKonvaTracksLayer`(`--sc-card`)与 `VideoKonvaIssueLayer`(`--sc-card` + 逐 issue `STATUS_VAR`)**每次 render 调用**。贵的 canvas 转换已在 `colors.ts` 的 `_canvasCache` 缓存,残留成本是每帧的 `getComputedStyle` 样式重算(视频播放 / 滚动热路径)。

- 改为 `useTheme()`-keyed `useMemo`:`const fill = useMemo(() => cssVarToHex("--sc-card"), [theme])`,**保留随主题切换重取的语义**(`colors.ts:54` 注释明确要这点),只消除非主题渲染的样式读。
- **两个画布层一起改**,避免 altitude 不一致;`VideoKonvaIssueLayer` 的逐 issue `STATUS_VAR` 取色同理(状态种类少,可在层内 memo 一张 `status→hex` 表)。
- 改后**真机验证**:亮↔暗主题切换时画布 track / issue 取色即时更新(不丢色、不滞后一帧)。
