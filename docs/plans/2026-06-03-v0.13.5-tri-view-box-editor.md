## 三视图坐标映射(自洽约定 · 实现时与 SUSTechPOINTS 对拍校准)

框 local 轴:**X=length、Y=width、Z=height**;yaw 绕 Z(`rotation[2]`)。三视图各正交相机对齐框 local 轴:

| 视图 | 相机看向(box-local) | 屏幕横轴 (u) | 屏幕纵轴 (v) | 拖边可改 | 拖角可改 | 方向线 |
|---|---|---|---|---|---|---|
| **Top 俯视** | −Z(从上往下) | local **X** (length) | local **Y** (width) | length / width | length+width | **yaw**(绕 Z)✅ |
| **Side 侧视** | −Y | local **X** (length) | local **Z** (height) | length / height | length+height | **pitch**(绕 Y,`rotation[1]`)✅ |
| **Front 正视** | −X | local **Y** (width) | local **Z** (height) | width / height | width+height | **roll**(绕 X,`rotation[0]`)✅ |

> ASCII 布局(主 3D 视图右侧三联栏,参考 SUSTechPOINTS 右栏):
> ```
> ┌──────────────────────────┬─────────────┐
> │                          │  ┌────────┐ │  Top  (X→ / Y↑)  + 方向线
> │                          │  └────────┘ │
> │      主 3D 透视视图        │  ┌────────┐ │  Side (X→ / Z↑)
> │   (PointCloudScene WebGL) │  └────────┘ │
> │   gizmo / orbit / 放置     │  ┌────────┐ │  Front(Y→ / Z↑)
> │                          │  └────────┘ │
> └──────────────────────────┴─────────────┘
>   未选中框 → 右栏三窗空(占位提示)
> ```

## 拖拽数学(2D 平面 → PSR,全边长口径,纯函数)

每个正交视图维护一个 **px↔米 缩放** `s`(px per meter,相机框住 box + margin 后定),以及视图屏幕坐标系(u 右、v 上)。设某视图屏幕横轴映射 box-local 轴 `a`、纵轴映射 box-local 轴 `b`。

**拖边**(拖动 `a` 轴正/负侧的一条边,对侧固定,`dir_a ∈ {+1,−1}`):
```
d_meter   = (screen_delta_u / s)          # 该边沿 a 轴的世界位移(米)
size[a]  += dir_a * d_meter               # 全边长直接加位移量(对侧固定)
center   += (dir_a * d_meter / 2) * Ŵ_a   # 中心沿 a 的世界方向 Ŵ_a 移半程
# Ŵ_a = box 局部 a 轴的世界单位向量 = boxToMatrix4 的旋转部分第 a 列归一化
# 约束:size[a] 下限 clamp(如 ≥ 0.05m),避免拖穿 / 负尺寸(呼应现有"负 size 兜底")
```
**拖角**(同时动 `a`、`b` 两轴):对 u 分量按 `a` 轴跑一遍拖边、对 v 分量按 `b` 轴跑一遍拖边,叠加 center / size。

**拖方向线(三视图各绕一轴,增量旋转 · 含 D4 多轴耦合处理)**:
每视图绕其法线对应的 **box-local 轴**转:Top→local Z(yaw)、Side→local Y(pitch)、Front→local X(roll)。
```
Δθ      = atan2(cur_v − center_v, cur_u − center_u) − atan2(start_v − center_v, start_u − center_u)
q_old   = quatFromEulerXYZ(rotation)
q_delta = quatAroundLocalAxis(viewLocalAxis, Δθ)   # 绕 box 自身轴的增量旋转
rotation = eulerXYZ(q_old · q_delta)               # 四元数复合后分解回 XYZ 欧拉
```
> ⚠️ **不直接赋 `rotation[k]=θ`**:存在多轴旋转(pitch/roll 非零)时直接赋欧拉分量会因 XYZ 耦合而错;必须走"增量 → 四元数复合 → 分解"。纯 yaw(其余两轴=0)时该式退化为 `rotation[2]+=Δθ`,与 SUSTech 一致。
>
> 单测自检(必覆盖):
> - **半/全边长**:size=[4,2,1.5],Top 拖 +X 边 +0.5m → `size[0]=4.5`、`center[0]` 沿 Ŵ_x 移 +0.25m、`size[1]/[2]` 不变(误用 SUSTech 半边长会得 5.0,须抓到)。
> - **三轴旋转**:分别在 Top/Side/Front 各转 Δθ,round-trip(转回 −Δθ)PSR 复原;且从非零 pitch 起再转 yaw,角点(`psrToCorners`)与四元数直算一致。

## 性能预算

- **框内点裁切(GPU)**:GPU clipping planes,**无 CPU 每帧重算**;PSR 变(拖拽中)只重算 6 个 `THREE.Plane`(O(1))+ 更新相机。点 buffer 复用主视图 BufferGeometry(CPU 数据共享;两个 context 各持一份 GPU 副本,~1e6 点 float32 xyz ≈ 12MB/context,可接受)。
- **三视图重绘(WebGL)**:拖拽中每帧 3 个 viewport 各跑一遍全点云顶点(GPU clip 丢框外片元),目标 60fps。**风险点**:1e6 点 ×3 viewport 的顶点开销;若掉帧,对三视图相机用**降采样点集**(只为看轮廓,绘制用 geometry 的 `setDrawRange`/抽样索引,主视图仍全量)。2D overlay 只画框矩形 + 数个 handle(极轻)。
- **回写**:拖拽中只更新本地 PSR + 重绘(不发请求);松手才防抖 PATCH(复用 250ms),与 gizmo 一致。

## 风险

- **坐标系一致性**(最高):三视图 local↔world↔screen 多层变换 + 半/全边长口径差(D3)+ **三轴欧拉耦合(D4)**。**对策**:B-0 纯函数单测(三轴旋转 round-trip + 非零 pitch 起调 yaw 不串轴)+ 与 SUSTech 同 scene 对拍,数学全收口在 `triview.ts`/`box3d.ts`,UI 层不写裸数学。
- **移植量**:本 epic 最重前端切片之一;已按 B-0..B-4 拆,可分次提交、必要时再拆。
- **WebGL 资源生命周期**(D2 引入):第二个 `WebGLRenderer`(三视图)+ GPU clip + 复用 geometry 的跨 context 副本 → dispose / context-lost 风险。**对策**:`TriViewRenderer` 收口所有 WebGL 资源,B-1 验证"反复进出 / 切任务无 context lost、无内存增长"。
- **性能**:GPU clip 下 1e6 点 ×3 viewport 顶点开销;见性能预算,掉帧则三视图相机用降采样点集。
