## 0. 已拍板决策（前提，不可违背）

- **D1 抽帧 = 逻辑采样**：不物理重采样、不取代原视频。采样只是「项目级导航/打点网格」视图。
- **D2 frame_index 永远存源帧号**：采样网格只是视图层；改采样密度不破坏旧标注。导出时再重编号。
- **采样配置归属项目级**（不是数据集级）。
- **播放 vs 导航两层分离**：连续播放走原生 `<video>`（完整原视频、原始 fps、所有帧）；采样只约束「逐帧导航 + 打点」。

## 1. 软网格算法规格（所有 agent 必须实现一致）

设 `step = N`（采样步长，源帧空间）；网格 = `{0, N, 2N, ...}`（**绝对网格，锚定 0**）。`maxFrame = frameCount - 1`。

```
gridNext(f)  = min(maxFrame, ceil((f + 1) / N) * N)   // 严格大于 f 的最近网格点；到尾部钳到 maxFrame
gridPrev(f)  = max(0, floor((f - 1) / N) * N)          // 严格小于 f 的最近网格点
snapToGrid(f)= clamp(round(f / N) * N, 0, maxFrame)    // 就近网格点（用于暂停吸附）
microStep(f, ±1) = clamp(f ± 1, 0, maxFrame)           // 逃生口：±1 源帧
```

- `step` 由采样配置派生：`mode="step"` → `step = frame_step`；`mode="fps"` → `step = round(source_fps / target_fps)`（≥1，按 pts_ms 就近时建议用 timetable，但 Phase 1 MVP 用 `round(fps/target_fps)` 整数步长即可）；`mode="none"` 或缺省 → `step = 1`（退化为现状，所有帧都是网格点）。
- **off-grid 关键帧合法**：通过 `microStep` 到达的任意源帧都能打点；网格只约束默认导航，不做存储/校验层禁令。
- **暂停吸附**：原生播放暂停（`pause()` 触发）时，把 `frameIndex` 用 `snapToGrid` 吸附并 seek 过去。

## 3. 键位重映射（解决冲突，关键设计点）

当前（`hotkeys.ts:235-244`）：`←/→`=±1 帧；`Shift+←/→`=选中轨迹跳关键帧 / 否则 ±10 帧；`,/.`=±1 备用。

**采样开启（step>1）时改为**：

| 键 | 现状 | 改为 |
|---|---|---|
| `←/→` | ±1 帧 | **gridPrev/gridNext**（网格跳，自动回正） |
| `Shift+←/→` | 关键帧跳 / ±10 | **microStep ±1**（逃生口，下钻源帧） |
| `Alt+←/→`（新增） | — | 选中轨迹跳关键帧（原 Shift 行为迁移至此） |
| `,/.` | ±1 备用 | **microStep ±1**（与 Shift+arrow 一致，备用） |

**采样关闭（step=1）时**：维持现状键位不变（向后兼容；step=1 时 gridNext≡+1，无感知差异，但 Shift 仍保留关键帧跳）。

> 实现：`dispatchKey` 的 video 分支需要知道 `samplingActive`，由 `videoMode` 旁加一个 flag 注入。新增 action `videoMicroStep`（delta ±1）+ `videoSeekKeyframe` 复用。`VideoStageControls` 加 `seekGrid(dir)` / `microStep(dir)` 方法。

## 7. 风险 / 待决

- **键位冲突**（§3）：Shift+arrow 从「关键帧跳/±10」改义，需在用户手册 + `KeyboardHintOverlay` 同步；Alt+arrow 承接关键帧跳。**这是唯一会改变现有肌肉记忆的点**，合并前确认。
- **fps 非整数比**（60→25）：Phase 1 用 `round(fps/target_fps)` 整数步长（60→25 实得 step=2 ≈ 30fps，非精确 25）。精确按 pts_ms 取帧留 Phase 1 之后 / sparse timetable 一起做（Agent-F）。
- **Wave 3 三项均为「按真实卡顿触发」**：若 Wave 1+2 落地后无卡顿数据，Wave 3 可降级为占位 / 推迟，不阻塞 v0.10.29 发版。
