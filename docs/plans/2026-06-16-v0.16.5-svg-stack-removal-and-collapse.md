## 3. 设计要点

### 3.1 删除顺序:自上而下断引用

- 先删交互层(已被 Konva 接管)→ 标注可视层 → 媒体/坐标层 → 最后旧主舞台 `VideoStage.tsx`。每删一个 `grep` 确认无引用再删下一个,避免编译断裂连锁。
- `useVideoBitmapCache`/`useVideoChunkDecoder`/`videoStageGeometry`/`videoStagePicking`/`colors` **保留**(纯逻辑或已被 Konva 复用)。

### 3.2 `<video>` 元素去向

- A1 路径:`<video>` 不再是显示层,降级为**隐藏解码源**(off-screen 或 `display:none`),`Konva.Image` 引它作 source。删 `VideoMediaLayer` 的显示职责,保留 video 元素的 ref 管理(并入 VideoKonvaStage 或 hook)。
- A2 路径(若 spike 当初降级):`<video>` 仍显示,则本版**不删** media 显示、改为正式契约保留;§2 删除清单按实际 A1/A2 裁剪——以 ADR 最终结论为准。

### 3.3 双路径塌缩验证

- `annotationVisual.ts` 删 SVG 分支后,图片与视频 draw 调用应**结构同形**(同一组纯函数 → Konva props);若仍有模态分叉,说明抽象未到位,记 follow-up(不强行本版抽公共基元)。

### 3.4 文档去版本号(CLAUDE.md §9)

- 概念文档写「当前状态」,不留「v0.16 起视频改 Konva」之类 changelog 式描述;provenance 入 HTML 注释或 frontmatter。版本变更只进 CHANGELOG / ADR。
