# v0.14.10 · 画布精细交互:snap / join / slice / attribute mode

> 规划日期 2026-06-07 · 范围:借鉴 CVAT 的画布精细交互,补齐图片/视频单帧工作台在密集 polygon / mask / 属性补录场景下的效率工具。只做前端工具和既有 annotation 更新,不改几何存储 schema。

## 1. 背景

本平台已具备 bbox、polygon、multi_polygon、rotated_bbox、polyline、keypoint、mask brush 等基础能力。但密集标注场景还有几个高频痛点:

- polygon 边界相邻时,手工贴边容易漏缝/重叠。
- 多个 polygon/mask 需要合并或切开。
- 大量对象只需要补属性,反复选框再找属性面板效率低。
- 已有右键菜单和快捷键,但缺几何专用精细操作。

CVAT 可借鉴的是 snap-to-contour / snap-to-point、slice/join、attribute annotation mode。不要照搬其 imperative canvas runtime,只取工具语义。

## 2. 目标

### A. Snap 工具

支持:

- snap-to-point:拖 polygon 顶点时吸附到附近已有顶点。
- snap-to-edge/contour:绘制 polygon 时吸附到已有 polygon 边。
- 可配置像素阈值,默认 8px。
- 按住 Alt 临时禁用 snap。

作用范围:

- image polygon / multi_polygon 外环。
- video_bbox 不参与。
- mask brush 不参与首版。

### B. Join / Slice

Join:

- 选中两个同类 polygon / multi_polygon。
- 合并为一个 multi_polygon 或 polygon union。
- 保留 class / attributes;若不同 class,要求用户选择目标 class。

Slice:

- 选中 polygon。
- 画一条切割 polyline。
- 生成两个 polygon;attributes 复制。

### C. Attribute Annotation Mode

属性补录模式:

- 左侧/顶部显示当前属性字段。
- 点击对象后直接循环设置该属性值。
- 快捷键数字选择属性值。
- 支持“下一个未填该属性的对象”。

首版目标:

- boolean / select / multiselect。
- bbox / polygon / rotated_bbox。
- 不覆盖 text/number/range。

## 3. 非目标

- 不改 annotation geometry schema。
- 不引入新的 polygon boolean 库;优先复用现有 `polygon-clipping`。
- 不做 mask RLE 独立几何。
- 不做 3D point_mask 编辑;它由 v0.14.6 覆盖。
- 不做任意复杂拓扑修复;失败时明确提示用户手动处理。

## 4. 设计

### 4.1 Snap

新增纯函数:

```text
snapPointToCandidates(point, candidates, thresholdPx)
snapPointToSegments(point, segments, thresholdPx)
buildSnapIndex(annotations, viewportTransform)
```

前端接入:

- polygon draw move。
- polygon vertex drag。
- 显示 snap indicator。

性能:

- 首版可用简单空间网格,不引入 R-tree。
- 只索引当前 viewport 可见 annotation。

### 4.2 Join

流程:

1. 用户多选两个或多个 polygon。
2. 右键或工具栏点 Join。
3. 用 `polygon-clipping.union` 合并。
4. 生成新 geometry,删除旧 annotation 或标记旧 annotation inactive。
5. 推入 history,可 undo。

决策:

- 如果 class 不同,弹确认选择 class。
- attributes 只有完全相同才保留;不同则清空或让用户选择一个来源。首版建议“选择来源 annotation”。

### 4.3 Slice

流程:

1. 用户选中 polygon。
2. 进入 slice mode。
3. 画一条 polyline 穿过 polygon。
4. 前端计算切割结果。
5. 两个新 annotation 替换原 annotation。

风险:

- polygon boolean 的切割比 union 更复杂。若实现成本过高,可先做 Join + Polygon Crop,Slice 顺延。

### 4.4 Attribute Mode

新增模式状态:

```text
attributeMode:
  enabled
  toolUnitId
  fieldKey
  currentValue
```

交互:

- 点击对象 = 更新该对象 attributes[fieldKey]。
- `[` / `]` 切换字段。
- 数字键选择枚举值。
- `N` 跳下一个未填字段对象。

与现有 AttributeForm 关系:

- AttributeForm 是单对象编辑。
- Attribute Mode 是批量补录路径。
- 两者写同一个 `annotation.attributes`。

## 6. 测试

纯函数:

- snap point threshold。
- segment projection。
- union 合并两个相邻 polygon。
- class/attribute merge policy。

组件:

- snap 开关。
- Join 菜单只在多选 polygon 时出现。
- Attribute mode 点击对象写 attributes。
- 输入框焦点下快捷键不触发。

手工:

- 两个相邻 polygon 吸附绘制,边界无缝。
- 两个同类 polygon join 后 undo。
- 属性模式下连续点击多个 bbox 设置 occluded。

## 7. 风险

- **几何算法失败**:boolean ops 对自交 polygon 敏感。失败时不应写坏数据,返回可读错误。
- **undo 语义**:join/slice 是多 annotation delete/create,必须作为一个 history command。
- **快捷键冲突**:Attribute mode 数字键可能和现有工具冲突,必须接入 hotkeys SoT。
- **性能**:snap index 在大量 polygon 下可能重;首版按 viewport 可见对象构建。

## 8. 与其他版本关系

- v0.14.6 覆盖 3D point_mask 的套索/加减点;本版覆盖 2D polygon/mask 精细操作。
- v0.14.8 Data Manager 的 saved views 可筛出“缺属性”任务;本版 attribute mode 负责高效补录。
- 不影响 v0.15 3D 时序计划。
