# v0.17.8 · 状态色语义化(183 色对 + 68 软底 → 语义工具类)

> 隶属 [设计系统第二阶段 Epic](./2026-06-20-v0.17.8-design-system-phase2-epic.md) · 范式 = **路线 A(语义工具类),已于 2026-06-20 拍板**。
> 本阶段 P0:最高 ROI、最痛、最易暗色回归 —— 先做。

## 1. 目标

把全站 **183 处** `text-<hue>-600 dark:text-<hue>-400` 状态文字对 + **68 处** `bg-<hue>-500/10` 状态软底,收敛为一套 `shadcn.css` 定义的语义工具类。改色一处生效、暗色一处定义,新增状态文案不再手抄 light/dark 两条。

涉及色相(实测):rose 86 / amber 41 / violet 26 / emerald 25 / sky 4。

## 2. 语义映射(取值 = 现状,见 §3 取值红线)

| 语义 | 现散点 hue | 工具类(新增) |
|---|---|---|
| danger | rose | `text-status-danger` / `bg-status-danger-soft` |
| caution | amber | `text-status-caution` / `bg-status-caution-soft` |
| positive | emerald | `text-status-positive` / `bg-status-positive-soft` |
| info | violet | `text-status-info` / `bg-status-info-soft` |
| info-alt | sky | `text-status-info-alt` / `bg-status-info-alt-soft` |

> sky 仅 4 处。落地选择单列 `info-alt`,避免把 sky 改成 violet 造成可见色相变化。

## 3. 取值红线(关键,勿踩)

现有语义变量 `--sc-destructive=#dc2626`(red 系)、`--sc-positive=#15803d`、`--sc-caution=#b45309`、`--sc-brand=#2563eb` 与散点实用的 **rose / emerald / amber / violet 并非同色**。「默认=现状」要求:

- 新 `--sc-status-*` 取值 = **Tailwind `rose/amber/emerald/violet` 的 600(light)/400(dark) 精确值**(落地时从 Tailwind v4 调色板引用,**不手抄 hex** 以免错),**不要**指向现有 `--sc-destructive` 等(那会把 rose 变 red,可见回退)。
- 软底 `*-soft` = 对应 hue 的 `500/10`(现状 `bg-<hue>-500/10`)。
- **遗留决策(不在本版做)**:全站状态色因此有 red(语义 `--sc-destructive`)/ rose(散点)两套近义色。是否统一为一套记入 Epic §3 待定,本版仅做等价替换,不合并。

## 4. 落地步骤

1. **定义 token**:`shadcn.css` `:root` + `[data-theme="dark"]` 各加 `--sc-status-{danger,caution,positive,info}`(light=600 值 / dark=400 值)与 `--sc-status-*-soft`(可用 `color-mix` 或固定 rgba 复刻 `/10`)。
2. **映射工具类**:`@theme inline`(18 行起)加 `--color-status-*`,并在 `@layer utilities`(207 行起)产出 `.text-status-*` / `.bg-status-*-soft`(各自内含 dark variant,调用点无需再写 `dark:`)。
3. **codemod**:把 183 处文字对 + 68 处软底批量替换为语义类。逐 hue 跑,改完即截图。
4. **门禁**:`check-tw-tokens.mjs` 暗色配对检测改为「命中 `text-status-*` 即通过;裸 `text-<hue>-600` 提示改用语义」(先 warning)。

## 5. 验收

- `grep -rE "text-(rose|amber|emerald|violet)-600" apps/web/src` 收敛到≈0(非状态语义的特例列白名单)。
- 全站状态徽标 / 错误文案 / 警告卡 / 严重度 chip **亮暗双主题**截图 diff 与基线一致(等价替换,零可见变化)。
- 改一处 `--sc-status-danger` 全站 danger 文字 + 徽标同步变化自测。
- `pnpm lint && pnpm typecheck && pnpm test` 全绿。
- 完成后:Epic §2 表本行置 ✅;本 plan 补 `## Outcome`。

## Outcome

- 在 `shadcn.css` 新增 `--sc-status-{danger,caution,positive,info,info-alt}` 与对应 `*-soft` token,并映射 `text-status-*` / `bg-status-*-soft` 工具类。
- 批量替换等价的 `text-<hue>-600 dark:text-<hue>-400` 状态文字对与 `bg-<hue>-500/10` 软底;sky 保留为 `info-alt`。
- `check-tw-tokens.mjs` 对新增裸状态色调用点输出 warning,不阻断当前版本。
