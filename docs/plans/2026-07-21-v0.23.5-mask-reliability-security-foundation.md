# v0.23.5 · Mask 编辑可靠性与安全地基

> Status: Draft · Epic Phase 1
>
> 父 Epic：[图像 / 视频栅格 Mask 能力统一](2026-07-21-raster-mask-workbench-unification-epic.md)
>
> 本版不新增生产 geometry 类型；先让现有图片 polygon 中转和视频 RLE 路径可靠、可诊断、可继续演进。

## 1. 目标

- 消除切题 / 切帧 / 异步加载覆盖未提交笔迹的风险。
- 统一图片 / 视频 Mask 会话状态、stroke undo / redo 和保存失败恢复。
- 关闭锁定、只读、Delete、Enter 与并发提交绕过路径。
- 修复后端解压、帧上传、tracker accept 和 staged 生命周期风险。
- 正确渲染既有 polygon holes / multi_polygon，禁止精修时静默丢环。
- 输出并接受 ADR-0052，为 v0.23.6 的共享 RLE schema 冻结边界。

## 2. 范围

### P0 · 可复现测试先行

- 为视频“加载中落笔后被迟到 GET 覆盖”写集成测试。
- 为图片保存失败后 Buffer 被清空、图片 stroke undo 未接线写测试。
- 为图片 / 视频锁定后 `M → pointer → Enter` 绕过写测试。
- 为视频 Delete 当前 Mask 时误删整轨、context-menu 缺失写测试。
- 为重复 Enter / 双击确认并发上传写测试。
- 为无限制 zlib 解压、超大交互帧和双 tracker job 并发 accept 写后端测试。

### P1 · 编辑会话状态机

统一 `idle / loading / ready / dirty / saving / error`：

- `sessionId + generation` 隔离旧请求；task、frame、selection、annotation version 构成 session key。
- loading / saving 禁止 pointer 写入；旧 GET、404 和 mutation 回包不能初始化新 session。
- task / frame / tool / route 离开 dirty 会话时显示“保存 / 丢弃 / 继续编辑”。
- 保存使用单飞 Promise；成功后才清 Buffer，失败保留 history、label、refine lineage 并可 retry。
- 图片 `ImageStage` 接入 `beginStroke / endStroke`，与视频共享 undo / redo 快捷键和工具栏状态。
- Escape 只取消当前 Mask session，不误撤销 annotation history。

### P2 · 权限与操作语义

- 抽取 `canEditMask`，供 toolbar、hotkey、pointer、context-menu、commit 共用。
- 同时检查 task readOnly、annotation / track lock、当前 assignment / segment lock 和 editor state。
- Enter 必须满足 `ready|dirty` 的真实提交条件；无变化不物化 held keyframe。
- Delete 删除图片对象或视频当前关键帧；整轨删除仅走 `Ctrl/⌘+Delete` 或确认动作。
- 图片 prediction refine 使用服务端 decision / lineage；刷新后原候选不复活。
- 单个视频 Mask load 失败只标记该对象，保留其它 records，并提供重试和诊断。

### P3 · 后端安全与并发

- bounded decompress：限制压缩输入、解压输出和 expansion ratio，超限前停止分配。
- 交互帧读取检查 Content-Length、流式累计字节、解码宽高、总像素和允许格式。
- tracker accept 同事务锁 job 与 Annotation，校验源 version、任务状态、assignment 和 segment lock。
- 并发冲突稳定返回 409；不得 last-writer-wins。
- accept / discard 后清除或归档 staged 引用；GC 只保留未终结或仍在宽限期的 job 对象。
- mask-content upload 增任务权限与 orphan 配额；对象存储 I/O 不阻塞 async event loop。

### P4 · Polygon 正确性止血

- `ImageStageShapes` 使用 even-odd fill 渲染 `holes` 与全部 `multi_polygon` 外环。
- selection、bbox、viewport fit、面积和 COCO helper 消费完整几何。
- 现有 Mask refine 若不能无损保存，入口禁用并说明原因；不再静默取最大环。
- 保存失败或版本冲突不丢稿；用户刷新前可复制诊断信息。

### P5 · ADR-0052

新增 `docs/adr/0052-shared-raster-mask-and-image-geometry.md`，至少冻结：

- `raster_mask` / `image_mask` 类型名；草案推荐 `raster_mask`。
- 共享 `coco_rle_ref`、图片静态 GET API 和 task-context validator。
- polygon ↔ Mask 显式转换、空 Mask、source / parent lineage 和 feature flag 语义。
- 4096 上限是否沿用，以及后续 tile / sparse 的触发条件。
- JSONB 加法扩展的部署顺序、forward-fix 与回滚限制。

## 3. 非目标

- 不创建 `raster_mask` annotation。
- 不改变图片 Mask 默认提交仍转 polygon 的现状，除非只是阻止有损提交。
- 不实现高级笔刷、AI 原生 Mask、格式导入或大图 tile。
- 不重构视频 nearest-hold、Tracker 算法或项目 tool binding。

## 4. 验收

- 图片、视频离开 dirty session 必须经过 guard；旧请求无法覆盖当前 Buffer。
- 保存失败后继续画、undo、redo、retry 均可用，最终只产生一次 mutation。
- 锁定对象经所有 UI / 快捷键路径不可修改。
- 视频 Delete 当前关键帧不删除整轨；整轨删除有明确动作与确认。
- zlib bomb、超大帧和并发 accept fixture 被前置拒绝。
- holes / multi_polygon 渲染与 COCO 输出不再只取主外环。
- ADR-0052 Accepted，v0.23.6 所需合同无开放阻断项。
