# v0.11.1 · DiscussionPanel 右栏两段布局骨架

> [epic 索引](2026-05-25-v0.11-annotation-feedback-convergence.md) · B 组（前端）· 依赖：无 · 可与 A 组并行
>
> **边界澄清（全 B 组适用）**：DiscussionPanel 只统一工作台内、绑当前 task/标注的反馈——`comment` + `issue` + `history(audit)`。`bug`（BugReportDrawer 产品通道）与 `reject`（task 状态机字段，审核流）**刻意不进**。"后端统一表" ≠ "前端统一面板"。

## 目标

兑现 ADR-0027「统一前端组件」收益的第一步（D3）：把 v0.10.19 plan 设计、v0.10.21 延期的右栏布局重构落地为**骨架**——只搭结构，不改任何现有行为。全 B 组挂在 `flags.discussionPanel` 后，最后 v0.11.5 去 flag。

## 现状

`WorkbenchLayout` 右栏只有 `AIInspectorPanel` 单容器（随 `selectedAnnotationId` 显隐）。评论走 `CommentsPanel`（嵌在 AIInspectorPanel 内），Issue 走画布 `IssueLayer`，无常驻 Tab 化讨论面板。

## 前端改动

- **新建空壳** `apps/web/src/pages/Workbench/shell/DiscussionPanel.tsx`：
  - props（按 v0.10.19 plan）：`{ annotationId: string | null, taskId, projectId, currentUserId }`
  - 仅 Tabs 外壳：`comments | history | issues`，内容区占位（后续 v0.11.2/3/4 逐 tab 填）。
- **`WorkbenchLayout.tsx`**：右栏改 `<RightColumn>` flex 容器——上段 `AIInspectorPanel`、下段 `DiscussionPanel`、中间复用 `ResizeHandle.tsx`；上下比例持久化 localStorage。
- **feature flag** `flags.discussionPanel`：
  - off（默认）：右栏维持现状，只渲染 `AIInspectorPanel`，**零行为变化**。
  - on：渲染两段布局 + 空壳 tab。

## 验证

- `pnpm --filter web typecheck` + `pnpm --filter web lint`（含 `lint:css-tokens`：DiscussionPanel 新 CSS 只用 `tokens.css` 既有 `--color-*`，无 fallback、无 hardcode）。
- flag off：人工确认工作台右栏与当前完全一致（无回归）。
- flag on：空壳 tab 可切换、分隔条可拖拽且比例持久化。
- dark mode 走查（B-32/36/38/39 教训）。

## 回退

flag 默认 off，骨架不影响生产路径。回退 = 删新组件 + 还原 WorkbenchLayout。

## 备注

本切片**不迁移任何数据/逻辑**，纯结构。逐 tab 内容在 v0.11.2（comments）/ v0.11.3（history）/ v0.11.4（issues）落地。
