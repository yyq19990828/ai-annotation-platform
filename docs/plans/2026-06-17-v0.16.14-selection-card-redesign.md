# v0.16.14 选中信息卡内容重设计(信息丰富 + 视觉统一)— Epic

> 版本顺延:原规划 v0.16.12,因 0.16.12(巨石拆分合并 0.16.9–0.16.12)/ 0.16.13(补测试再拆 + 点云 E2E 基线)已发布占号,本 epic 顺延至 v0.16.14。
>
> 背景:v0.16.8 已把"选中即现、可拖、可折叠、跨设备记忆"的浮动卡**基座**落地(图片/视频)。
> 但卡内**内容**是直接搬右栏的,信息单薄、AI 预测与视频单帧"啥也不显示"。本 epic 只重做**内容层**,不动基座。

## 1. 现状诊断(四个洞)

| 选中态 | 现状 | 根因 |
|---|---|---|
| ① 图片框 | 4 个图标按钮 + 单行 `矩形框·257×264px` | 直接搬右栏 `attrDock` 回调,未为浮动卡做信息设计 |
| ② **AI 预测框** | `已选中 1 个标注。`(啥也没有) | AI 预测是独立 `AiBox`/`predictionsData`,**不在 `visibleAnnotationsData`**,`selectedAnnotationForPanel` 取不到 → 掉进 placeholder;**置信度 / 模型来源 / 采纳决策全丢** |
| ③ 视频轨迹 | 整块 `VideoTrackPanel` 原样塞进卡 | `renderVideoTrackSidebar("current")` 复用右栏面板,未为卡裁剪,低频下拉占满首屏 |
| ④ 视频单帧框 | 没信息 | 视频单帧 `video_bbox` 不属轨迹,被轨迹面板过滤 |

**共同病根**:把"卡片"当成"右栏搬运容器",而非"为'我此刻选中了什么'量身定做的信息位"。

### 现有数据(大量被丢弃)

`AnnotationResponse` 现有却没展示的字段:`confidence`(AI 置信度)、`source`(manual/ml_backend/import)、`parent_prediction_id`(是否由 AI 采纳而来)、`created_at/updated_at`、`lead_time`、`z_order`、`group_id`、`ground_truth`。
AI 预测 `AiBox`/`PredictionShape` 另有独立 `confidence` + 模型来源 + `shape_index`(候选序号)。

## 2. 目标 / 非目标

**目标**
- 定义一套**卡片设计系统**:5 个共享积木,四种选中态按需组合,视觉统一、各有侧重。
- 把 AI 置信度、模型来源、采纳决策(②)和视频帧定位(④)这两个最大信息洞补齐。
- 图片框(①)从单行摘要升级为结构化指标网格;视频轨迹(③)裁剪首屏、统一卡头。

**非目标**
- 不动 v0.16.8 基座(`SelectedAnnotationCard` / `FloatingPanelShell` / `floatingSelection` 持久化)。
- 不动右栏 `attrDock` / `VideoTrackPanel` 自身(卡内复用其回调,不改其实现)。
- 不动后端业务 API / 数据模型。
- 不改 AI 预测的采纳/拒绝/精修**业务逻辑**(`handleAcceptPrediction/Reject/Refine` 复用,仅新增卡内入口)。

## 3. 设计系统:5 个共享积木

放在 `shell/selectionCard/` 子目录,与各端内容组件同级。

| 积木 | 职责 | 数据来源 |
|---|---|---|
| **IdentityHeader** | 类别色块 + 类名 + 来源徽章(手动/AI/采纳/导入)+ AI 置信度 pill | `class_name` / `source` / `parent_prediction_id` / `confidence` / `colors.ts` |
| **MetricGrid** | 2 列紧凑指标网格(尺寸/占图比/位置/宽高比/面积/周长…) | `geometryMetrics()`(新工具) |
| **AttributeBlock** | 属性表单(复用现有 `AttributeForm`,`hideHeading`) | `attributes` + `attributeSchema` |
| **MetaFooter** | 可折叠次要信息:ID 短码 / 来源 / 创建·更新时间 / z-order / 分组 | `id`/`created_at`/`updated_at`/`z_order`/`group_id` |
| **ActionBar** | 随类型变动作组(改类/隐藏/锁定/删除;AI=采纳/编辑/忽略;视频=跳帧等) | 各端回调 |

### 3.1 新工具 `geometryMetrics(geometry, imgW, imgH): Metric[]`

纯函数,放 `shell/selectionCard/geometryMetrics.ts`,**取代** `ImageSelectionCardContent` 里的 `geometrySummary` 单行字符串。返回 `{ label, value, hint? }[]`:

| 几何 | 指标 |
|---|---|
| `bbox` | 尺寸 W×H px · 占图 % · 位置(左上) x,y · 宽高比 W:H |
| `rotated_bbox` | 上 + 旋转角 N°(带转向小标) |
| `polygon` | 顶点 N · 面积 ≈px²(shoelace)· 占图 % · 周长 ≈px |
| `multi_polygon` | 环 N / 顶点 M · 总面积 · 占图 % |
| `polyline` | 点 N · 总长 ≈px |
| `keypoint` | 点 N(可见 v / 共 N) |

无 imgW/imgH 时降级为相对值/省略占图比。**带单测**(shoelace 面积、周长、占图比)。

### 3.2 视觉规范(遵守 CLAUDE.md §6 token 规则)

- 全部颜色走 `tokens.css` 的 `--color-*`,禁硬编码 / 禁 fallback。
- 置信度条配色按阈值:≥0.8 用 `--color-success`,0.5–0.8 用 `--color-warning`,<0.5 用 `--color-danger`(若缺语义 token,先在 tokens.css 补 light+dark)。
- 来源徽章:手动=中性灰、AI=accent、采纳=success/info、导入=次要色。
- 指标网格用现有 surface / border token,紧凑(label 11px 次要色 / value 13px 主色)。

## 5. 接线点(关键)— 调研已确认

- **②AI 预测分支(最重)**:疑点已查清,**无未知风险**。
  - **选中机制 = 与普通框同一个 `s.selectedId`**。点击预测框 → `s.selectedId = "pred-{predictionId}-{shapeIndex}"`(`transforms.ts:254`);`ImageStage.tsx:839` 用 `userBoxes.concat(aiBoxes).find(b => b.id === selectedId)` 统一查找,证明预测框和普通框共用选中态。
  - **反查钥匙 = `pred-` 前缀**。模型里 `aiBoxes`(`useWorkbenchShellModel.tsx:1387`)持有全部 `AiBox`。新分支判定:`if (s.selectedId?.startsWith("pred-")) → aiBoxes.find(b => b.id === s.selectedId)`,命中即走 AI 分支(放在 image+ann 分支之前)。这正是现在掉进 placeholder 的原因——`selectedAnnotationForPanel` 只查 `visibleAnnotationsData`,查不到 `pred-` id → null。
  - **AI 数据全在 `AiBox` 上**:`.conf`(0–1)、`.predictionSource`、`.cls`、`.predictionId`、`.shapeIndex`、`.tool_unit_id`、`.attributes`(OCR/doc_layout 透传)、`.geometry`。
  - **动作 handler 已就绪**:`handleAcceptPrediction / handleRejectPrediction / handleRefinePrediction(b: AiBox)` 已在模型,现传给 `AIInspectorPanel`,直接接卡内 ActionBar,**不新增业务逻辑**。
  - **动作集修正**(原计划"采纳/采纳并编辑/忽略"不准):真实三动作为 **采纳(accept)/ 精修(refine,仅 polygon 几何,开 Mask 笔刷)/ 忽略(reject)**。非 polygon 不渲染精修。
  - **AI 预测是图片专属**:`aiDisabled: isVideoTask`,视频无 AI 预测框 → AI 分支只在 image 端触发。
  - **diff 模式守卫**:`modeState.diffMode === "final"` 时 `aiBoxes=[]`,无预测可选,AI 分支自然不触发。
- **可直接复用的现成 helper**(避免重写):
  - `classColor(cls)` / `displayClassName(cls)`(`stage/colors.ts`)→ IdentityHeader 色块 + 类名。
  - `predictionSourceLabel(source)`(`state/transforms.ts`)→ 来源徽章文案。
  - `annotationToolMeta(b, imgW, imgH)`(`stage/BoxListItem.tsx`)→ 几何 label+detail,**可提炼为 `geometryMetrics` 的基础**(现返回单 detail 串,扩成结构化数组)。
  - `BoxListItem` 整体是最接近"卡内容"的现成 UI(置信度徽章 + 采纳/拒绝/精修 + OCR/版面 badge),作为 AIPredictionCardContent 的蓝本。
- **置信度条 token 已齐**:`--color-success / --color-warning / --color-danger`(+`-soft`)light+dark 均在 `tokens.css`,**无需新增 token**。
- ①③④ 分支已存在,替换 children 内容即可(③ 在 `renderVideoTrackSidebar` 之外为卡片态加裁剪,或给 `VideoTrackSidebar` 传"紧凑/卡片"变体 prop,避免改右栏)。
