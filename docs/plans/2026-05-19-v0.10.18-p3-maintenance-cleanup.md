# v0.10.18 · P3 维护项收尾（除 dev SMTP）

> 草稿文件名是 plan mode 系统分配的临时 handle，落地前按 [CLAUDE.md §7](../../CLAUDE.md) 规范重命名为 `2026-05-19-v0.10.18-p3-maintenance-cleanup.md`。

## Context

v0.10.17 落地后遗留 6 项 P3 维护事项。本期一次性收口其中 5 项（**排除 dev SMTP 测试链路**——单独排期），全部为非功能性的维护 / 基建 / 可观测改造，无 DB schema 变更、无 API 行为变更、无 client-facing 行为回归：

1. **截图 fixture 4 张空白态补齐 + 重跑**——文档站缺图，新人不知道空态长啥样。
2. **PerfHud 加 6 个浏览器侧指标**——为 §C.1 keyset 分页拐点判断铺底；目前只有后端 ML backend 指标。
3. **WorkbenchShell 拆分后续精简**——Shell 仍 1210 行，StageHostProps 30+ 字段，缺 focused render test。
4. **RenderingConfigSection 抽出 `RenderingConfigEditor`（受控视图）**——TemplateEditModal「渲染配置」tab 在 v0.10.17 仅有占位语，等本版抽出 editor 后接入。
5. **CreateProjectWizard step 拆分到 `steps/` 子目录**——文件 1405 行（v0.10.17 加 unitBindings 后超 1300 触发线），且 v0.10.18 复杂字段编辑器加入后会继续涨。

目标：**让 v0.10.18 成为代码瘦身 / 可观测增强版**，不引入新功能。

### Item B · PerfHud 加 6 个浏览器侧指标

**入口**：[`apps/web/src/components/PerfHud/PerfHud.tsx`](../../apps/web/src/components/PerfHud/PerfHud.tsx)（1–227 行）+ [`useMLBackendStats.ts`](../../apps/web/src/components/PerfHud/useMLBackendStats.ts)

**当前**：仅展示后端 ML backend 7 指标（GPU 利用率 / VRAM / CPU / RAM / GPU 温度 / 功率 / 缓存命中率），数据走 WS `/ws/ml-backend-stats`。

**新增 6 指标 + 数据源**：

| 指标 | 数据源 | 采集方式 | 显示 |
|---|---|---|---|
| FPS | requestAnimationFrame loop | 1s 滑动窗口 frame 计数 | 数字 + 历史曲线 |
| JS heap | `performance.memory.usedJSHeapSize`（Chrome 才有） | 1s 采样 | MB；非 Chrome 显示 "N/A" |
| longtask | `PerformanceObserver({type:"longtask"})` | 累计 60s 内 > 50ms 任务数 | 计数 + 最近一次时长 |
| API p95（最近 60s） | 在 [`apps/web/src/api/client.ts`](../../apps/web/src/api/client.ts) fetch wrapper 加 ring buffer 记 duration | 滑动 p95 | 毫秒 |
| WS 重连数 | [`useReconnectingWebSocket.ts`](../../apps/web/src/hooks/useReconnectingWebSocket.ts) 暴露全局 retry 计数 store | 累计 | 数字（reset 24h） |
| 当前 task 框数 | [`WorkbenchShell.tsx:606`](../../apps/web/src/pages/Workbench/shell/WorkbenchShell.tsx) `annotations.length`（按当前 taskId） | 直接订阅 | 数字 |

**实现层次**：
- 新建 `apps/web/src/components/PerfHud/useBrowserStats.ts`：暴露 `{ fps, jsHeapMB, longtaskCount60s, apiP95Ms, wsReconnects, taskBoxCount }`，60s ring buffer。
- 新建 `apps/web/src/api/_metrics.ts`：导出 `recordApiDuration(ms)` 全局函数，在 client.ts wrapper 调用；UI 测可清空。
- 新建 `apps/web/src/hooks/_wsMetrics.ts`：导出 `useWsReconnectCount()` 全局 Zustand store，`useReconnectingWebSocket` 重连时 inc。
- `PerfHud.tsx` 加 `BrowserPanel` 与现有 `BackendPanel` 并列。

**性能 budget**：rAF loop 每秒 1 次 setState；PerformanceObserver 是 push-based 几乎零开销；JS heap 1s 采样；总 overhead < 0.5% CPU。

**显隐**：复用现有 PerfHud `?perf=1` query 开关（已有），无需新 setting。
