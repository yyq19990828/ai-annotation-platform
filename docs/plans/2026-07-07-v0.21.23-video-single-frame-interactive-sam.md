## 定稿决策（拟）

- 新视频侧 `onVideoSamPrompt`：取当前帧 `ImageBitmap`（`useVideoBitmapCache`）→ 编码 → 调后端交互式 `/predict`（point/bbox/
  exemplar prompt，与图片同端点，**后端零改**）→ 拿候选（mask/polygon/bbox，归一化 0-1）。
- 交互派发复刻 `ImageStage.tsx:822-832`：视频栈 `samProbe` DragInit（mode=point/bbox/exemplar）松手派发到 `onVideoSamPrompt`。

### 2 · 候选渲染 + 采纳（扩 VideoKonvaAiLayer 出 bbox）
- `VideoKonvaAiLayer` 现只 bbox；扩出 polygon/mask 候选渲染（复用 v0.21.21/22 的几何渲染）。
- 采纳 → 落**单帧几何**（`video_polygon`/`video_bbox`，带当前 `frame_index`），复用 v0.21.21/22 提交层。

### 3 · magic-box（复用 SAM box → 紧凑外接矩形 → bbox）
- 图片 `MagicBoxTool`（`tools/index.ts:40-41`）：粗框 → SAM → polygon → 紧凑外接矩形 → 落 `bbox`。视频版落 `video_bbox`
  单帧，复用同一收紧逻辑。

### 4 · 工具栏 + 能力门控
- `VIDEO_TOOLS`（`ToolDock.tsx:81-84`）加 4 个 AI 工具；可用性由 `useMLCapabilities.isPromptSupported`（对齐图片 AI 工具置灰，
  `ToolDock.tsx:210-211`）+ 后端 `supported_prompts` 决定。
- **坐标红线**：交互式候选浮层归一化 0-1（对齐 memory「交互候选坐标系」：yolo exemplar 曾误发百分比致候选飞出画布）。

## 实现分阶段（PR）

- **PR1 · smart-point + smart-box**：视频栈 `samProbe` 交互 + `onVideoSamPrompt`（当前帧 bitmap → `/predict`）+ 候选渲染扩
  polygon/mask + 采纳落单帧几何。
- **PR2 · exemplar**：示例框 prompt（复用 PR1 管线的 exemplar mode）。
- **PR3 · magic-box**：粗框 → SAM 收紧 → 落 `video_bbox` 单帧。
- **验证**：每 PR E2E ① 某帧点/框/示例 → 候选出现在正确帧、归一化坐标；② 采纳 → 落单帧几何、带 `frame_index`；③ 切帧候选清理
  正确、不串帧；④ 后端不支持某 prompt 时工具置灰；⑤ 图片交互式 SAM 零回归。CHANGELOG（Added）+ 版本 bump。

## 不在范围

- 批量帧预标（frame-AI）——已存在（v0.21.4），本版本只加**交互式**逐帧。
- text-prompt 文本召回——本质批量能力，不入工具栏（对齐图片 `tools/index.ts:166-167`）。
- 轨迹几何 / 追踪 → v0.21.20 / 多目标 epic。

## 风险

- **逐帧 SAM 延迟/显存**：每次 prompt 送一帧图，交互体感依赖后端响应；需评估当前帧编码开销（bitmap 已缓存，省解码）。
- **候选归一化错配**：交互式候选须 0-1 归一化，与批量入库的百分比 0-100 不同域（memory「交互候选坐标系」）——两域别混。
- **VideoKonvaAiLayer 扩几何**：现只 bbox，扩 polygon/mask 候选须复用 v0.21.21/22 渲染器，避免第三份几何渲染实现。
- **单帧 vs track 语义混淆**：本版本候选一律落**单帧**几何；勿与 track 传播（SAM2 video）混淆入口。
