# v0.15.3 · 偏好 schema 四分树 + 工作台设置抽屉壳(设置体系地基)

> 规划日期 2026-06-11 · 范围:把 `WorkbenchPreferences` 从平铺字段重构为 `common / image / video / pointcloud` 四子树,在工作台内立起「设置抽屉」壳层(齿轮菜单扩建,实时预览),Settings 页「标注偏好」同步重构为四分类。**本版不新增任何用户可感知的设置项**,只做结构 + 归位,便于单独验证迁移零回归。Epic 见 [`2026-06-11-v0.15.x-workbench-settings-epic.md`](2026-06-11-v0.15.x-workbench-settings-epic.md)。
>
> **前置依赖**:无(与 v0.15.2 SDK/CLI 正交)。**被依赖**:v0.15.4 / v0.15.5 / v0.15.6 / v0.15.7 全部以本版子树 schema 与字段注册表为地基。

## 1. 背景与目标

### 1.1 现状

- 后端 `WorkbenchPreferences`(`apps/api/app/schemas/user.py:62-75`)是平铺的 5 个字段 + `layout` 子树,`extra="forbid"`。
- 前端入口割裂:Settings 页「标注偏好」一节(`SettingsPage.tsx`,`section === "workbench"`)承载 4 个控件;工作台 Topbar 齿轮菜单(`shell/Topbar.tsx:322` 附近)只有一个会话级「隐藏孤儿标注」toggle。
- 点大小、透明度、缩放手感这类参数在全局 Settings 页里调**看不到画布效果**——所见即所得的缺失是设置项「不好用所以没人用」的根因之一。
- 项目级锁定(`useWorkbenchConfig.ts:14-19` `LockableField` = smoothImage / cssImageFilter / controlPointsSize / snapToGrid)已可用,本版必须保持其行为不变。

### 1.2 本版三件事

| 能力 | 做什么 | 为后续解决什么 |
|---|---|---|
| **A. schema 四分树** | `WorkbenchPreferences` 拆为 `common/image/video/pointcloud` 子树 + alembic 数据迁移重写存量 JSONB | v0.15.4-7 加字段时只动对应子树,PATCH 子树合并(`me.py` exclude_unset)天然支持 |
| **B. 工作台设置抽屉** | `WorkbenchSettingsDrawer`:齿轮菜单加「工作台设置」入口,展示「通用 + 当前模态」两组,改动实时生效(300ms 防抖 PATCH,与 layout 同款) | 后续版本的字段有了所见即所得的家 |
| **C. 字段注册表** | `workbenchSettingsFields.ts` 单一来源声明每个字段(key/标签/控件类型/范围/默认值/所属分类/是否可被项目锁定),Settings 页与抽屉共用渲染 | 杜绝两处 UI 漂移;加字段 = 注册表加一行 |

### 1.3 字段归位表(本版唯一的「迁移内容」)

| 旧位置(平铺) | 新位置 | 理由 |
|---|---|---|
| `workbench.smoothImage` | `workbench.image.smoothImage` | 图像媒体渲染参数(视频 bitmap 层若复用,从 image 读,不复制字段) |
| `workbench.cssImageFilter` | `workbench.image.cssImageFilter` | 同上 |
| `workbench.controlPointsSize` | `workbench.image.controlPointsSize` | 2D 画布顶点手柄,图像专属 |
| `workbench.snapToGrid` | `workbench.image.snapToGrid` | 同上 |
| `workbench.longTaskSampleRate` | `workbench.common.longTaskSampleRate` | 性能观测,跨模态 |
| `workbench.layout` | **不动**(保持顶层) | 布局是壳层/设备维度,不属于四分类 |

`ProjectRenderingConfig` **保持平铺不动**(避免项目侧迁移);`useWorkbenchConfig.applyProjectOverride`(`useWorkbenchConfig.ts:349-371`)的合并逻辑改为映射到 `image.*` 子树字段。

### 1.4 不在本版本

- 任何新设置项(v0.15.4-6)。
- 项目级锁定字段扩充、性能档位(v0.15.7)。
- 「记住上次」粘性机制的新应用(各模态版自带);本版只保证 localStorage 键名约定文档化。
- Settings 页其余 section(profile / feedback / notifications / system)不动。

### 1.5 成功判据

1. **迁移零回归**:存量用户(含旧平铺 preferences 的行)迁移后 `GET /auth/me/preferences` 返回新子树形态、值不变;未设置过偏好的用户全默认值。alembic downgrade 可逆。
2. **项目锁定不破**:被 `ProjectRenderingConfig` 锁定的字段在新结构下仍正确覆盖用户值,Settings 页与抽屉中均显示「项目锁定」并禁用控件(复用现有 badge 逻辑)。
3. **抽屉可用**:工作台齿轮菜单 →「工作台设置」打开抽屉;抽屉按「通用 + 当前模态」分组渲染注册表字段;拖动 controlPointsSize 滑块,画布上顶点手柄**实时**变化;改动 300ms 防抖 PATCH 后端,刷新后保留。
4. **Settings 页四分类**:「标注偏好」section 重构为 通用/图片/视频/点云 四个分组(视频/点云本版为空壳 + 「即将到来」占位或直接隐藏空分组——实现时取后者,空分组不渲染),与抽屉读写同一份数据。
5. **单一来源**:抽屉与 Settings 页渲染同一份 `workbenchSettingsFields.ts`,无字段级重复 JSX。
6. `uv run pytest -q` / `pnpm test` / `pnpm lint` 全绿;openapi 快照由 pre-commit 钩子再生(不手动 dump)。

## 3. 各模块设计要点

### 3.1 schema(`user.py`)

```python
class WorkbenchCommonPreferences(BaseModel):
    model_config = {"extra": "forbid"}
    longTaskSampleRate: float = Field(default=0.05, ge=0.0, le=1.0)

class WorkbenchImagePreferences(BaseModel):
    model_config = {"extra": "forbid"}
    smoothImage: bool = True
    cssImageFilter: str = Field(default="", max_length=255)
    controlPointsSize: int = Field(default=6, ge=2, le=20)
    snapToGrid: bool = False

class WorkbenchVideoPreferences(BaseModel):      # v0.15.5 填充
    model_config = {"extra": "forbid"}

class WorkbenchPointcloudPreferences(BaseModel): # v0.15.6 填充
    model_config = {"extra": "forbid"}

class WorkbenchPreferences(BaseModel):
    model_config = {"extra": "forbid"}
    common: WorkbenchCommonPreferences = Field(default_factory=...)
    image: WorkbenchImagePreferences = Field(default_factory=...)
    video: WorkbenchVideoPreferences = Field(default_factory=...)
    pointcloud: WorkbenchPointcloudPreferences = Field(default_factory=...)
    layout: WorkbenchLayoutPreferences = Field(default_factory=...)  # 不动
```

### 3.2 兼容策略(部署窗口期)

`extra="forbid"` 下,已打开的旧前端 tab 在服务端升级后 PATCH 平铺键会 422。在 `update_preferences` 入口加一层**legacy 提升器**:收到 `workbench` 子树时,把已知的 5 个平铺键(若出现)提升到对应子树后再走 pydantic 校验。保留一个 minor 周期(v0.16 删),代码处注释标注移除时机(版本号只引用 CHANGELOG 真实存在的版本)。

### 3.3 alembic 数据迁移

- **up**:遍历 `users.preferences` 非空行,`workbench` 内平铺键按 §1.3 归位表搬入子树,未知键丢弃前先打日志;幂等(已是新形态的行跳过)。
- **down**:逆映射回平铺。
- 用 SQL `jsonb_set` 批量做,避免 ORM 全表逐行加载(大用户表场景,呼应 v0.11.30 scale 原则)。

### 3.4 字段注册表(`workbenchSettingsFields.ts`)

```ts
export interface WorkbenchSettingField {
  key: string;                 // "image.controlPointsSize"
  category: "common" | "image" | "video" | "pointcloud";
  label: string; description?: string;
  control: { type: "toggle" } | { type: "slider"; min: number; max: number; step: number }
         | { type: "select"; options: ... } | { type: "text"; maxLength: number };
  lockable?: boolean;          // 是否参与项目锁定(本版 = 现有 4 字段)
}
```

抽屉与 Settings 页都吃这份数组渲染;`SettingsFieldControl` 共享控件组件放 `components/`(两处复用)。新增字段的流程从此固定:后端子树加字段 → TS 类型同步 → 注册表加一行 → 消费点读配置。

### 3.5 设置抽屉(`WorkbenchSettingsDrawer.tsx`)

- 复用工作台既有抽屉/浮层交互范式(参考 `OfflineQueueDrawer` / `AIToolDrawer` 的壳)。
- 分组:顶部「通用」,其下当前模态组(由 workbench mode 推断 image / video / three-d → pointcloud);**不在抽屉里展示非当前模态的组**(要看全量去 Settings 页,抽屉底部放一个跳转链接)。
- 写路径:经 `useWorkbenchConfig` 暴露的 setter,300ms 防抖 PATCH(与 layout 写路径同款,复用其防抖与卸载 flush 逻辑 `useWorkbenchConfig.ts:462-495`);本地 state 立即生效 → 画布实时预览。
- 被项目锁定的字段:显示锁 icon + 禁用,hover 提示「由项目统一配置」。

## 5. 已知风险 / 未尽事项

- **JSONB 迁移是全表 UPDATE**:用户表目前规模小,但迁移脚本仍按批写(LIMIT 循环),留 scale 余地。
- **窗口期旧 tab 422**:legacy 提升器只覆盖 PATCH;旧前端 GET 到新形态后读平铺键会拿 undefined → 显示默认值,刷新即愈。可接受,CHANGELOG 注明。
- **抽屉与 Settings 页并发写**:两处同时开着改同一字段,后写覆盖先写(PATCH 子树合并粒度是子树内字段级,exclude_unset 保证互不踩)。不做实时同步,刷新对齐。
- **空子树渲染**:video/pointcloud 本版为空,Settings 页不渲染空分组——注册表驱动天然成立,无需特判。

## 6. 验证策略

- **迁移单测**(最重):构造旧平铺 JSONB 行 → upgrade → 断言子树形态与值;downgrade → 断言还原;已迁移行二次 upgrade 幂等。
- **API 测**:PATCH `{workbench: {image: {controlPointsSize: 10}}}` 只动该字段;PATCH legacy 平铺键被提升;未知键仍 422(forbid 不放松)。
- **前端测**:注册表每个字段渲染出正确控件;锁定字段禁用;抽屉改动触发防抖 PATCH(fake timers);SettingsPage 四分组快照。
- **手工端到端**:登录存量账号 → 工作台抽屉拖 controlPointsSize → 画布手柄实时变 → 刷新仍在 → Settings 页同字段显示同值;项目锁定 smoothImage 的项目里两处均禁用。
