## Context

ROADMAP §A 「项目模板」长期项。v0.10.11 已落「从已有项目复制配置」轻量形态（`_CLONEABLE_PROJECT_FIELDS` 16 字段）—— 即"项目级一次性快照"。原 ROADMAP 把"独立 ProjectTemplate 表 + 模板库 UI"挂在"无客户驱动不开工"。**用户 2026-05-18 决策开做**，理由是为后续 SaaS / 跨组织共享 / 公共模板预留底座。

**与 v0.10.11「复制配置」的边界**：

- v0.10.11「复制」是**项目级一次性快照**：复制时刻把字段 deepcopy 进新项目，源项目后续改动不影响新项目。
- v0.10.14 的 ProjectTemplate 是**独立资产**：模板可以无源项目（手工创建 / 内置模板）、可以跨组织共享、可以版本演进、可以被多个新项目引用。
- **两者并存**：v0.10.11 复制链路保留（短期内仍是 80% 场景），模板库作为更强力的二级能力。

**触发条件**：v0.10.13 E1 merge + 灰度反馈 ≥ 1 周后启动。E1 落地后先观察客户使用 guide 的方式（写法 / 图片量 / 是否跨项目复用），据此决定本期"模板是否携带 annotation_guide"的最终决策（首版倾向于模板不携带 guide_assets，详见 E2.2）。

体量预估 ~5-7d，独立 PR + 独立 review。

## E2.1 数据模型

**新表 `project_templates`**：

```sql
CREATE TABLE project_templates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  display_id VARCHAR(20) NOT NULL UNIQUE,        -- T-001 / T-002 ...
  name VARCHAR(255) NOT NULL,
  description TEXT,                              -- 模板说明，markdown 可选
  type_label VARCHAR(50) NOT NULL,               -- 与 Project.type_label 一致
  type_key VARCHAR(30) NOT NULL,

  -- 模板载荷（与 _CLONEABLE_PROJECT_FIELDS 对应）
  classes JSONB NOT NULL DEFAULT '[]',
  classes_config JSONB NOT NULL DEFAULT '{}',
  attribute_schema JSONB NOT NULL DEFAULT '{"fields": []}',
  label_config JSONB NOT NULL DEFAULT '{}',
  ai_enabled BOOLEAN NOT NULL DEFAULT false,
  ai_model VARCHAR(255),
  sampling VARCHAR(30) NOT NULL DEFAULT 'sequence',
  maximum_annotations INTEGER NOT NULL DEFAULT 1,
  show_overlap_first BOOLEAN NOT NULL DEFAULT false,
  iou_dedup_threshold FLOAT NOT NULL DEFAULT 0.7,
  box_threshold FLOAT NOT NULL DEFAULT 0.35,
  text_threshold FLOAT NOT NULL DEFAULT 0.25,
  text_output_default VARCHAR(10),
  rendering_config JSONB NOT NULL DEFAULT '{}',

  -- E1 整合：模板可携带 annotation_guide markdown 文本
  annotation_guide TEXT,
  -- guide_assets 模板不存（避免 storage key 跨实例引用混乱）；
  -- 应用模板时 UI 弹窗提示「该模板原项目曾配置 N 张指引图，模板不携带；需手动上传」。

  -- 共享语义
  scope VARCHAR(20) NOT NULL DEFAULT 'private',  -- private | organization | public
  organization_id UUID REFERENCES organizations(id) ON DELETE CASCADE,
  created_by UUID NOT NULL REFERENCES users(id),
  source_project_id UUID REFERENCES projects(id) ON DELETE SET NULL,
  -- 从哪个项目导出生成（NULL = 手工建）

  -- 元数据
  usage_count INTEGER NOT NULL DEFAULT 0,        -- 被引用次数（应用时 +1）
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  CONSTRAINT ck_template_scope CHECK (
    scope IN ('private', 'organization', 'public') AND
    (scope = 'public' OR organization_id IS NOT NULL OR scope = 'private')
  )
);

CREATE INDEX ix_project_templates_scope_type ON project_templates(scope, type_key);
CREATE INDEX ix_project_templates_org ON project_templates(organization_id)
  WHERE organization_id IS NOT NULL;
```

**Scope 语义**：

- `private`：只有 `created_by` 用户可见可用。
- `organization`：同 `organization_id` 内的所有 project_owner / super_admin 可见可用。
- `public`：所有用户可见可用；仅 `super_admin` 可创建 public 模板。

## E2.2 annotation_guide / guide_assets 在模板里的处理

**E1 落地后再 finalize**。当前倾向（首版）：

- 模板存 `annotation_guide`（Markdown 文本）。
- 模板**不**存 `guide_assets`（图片资源 storage key）—— 跨实例引用混乱、跨组织私密性风险、源项目删除会让所有依赖模板的新项目失效。
- 应用模板时 UI 给提示：「该模板原项目曾配置 N 张指引图，模板不携带；新项目需手动重新上传」。

如果 E1 反馈表明客户大量在 guide 中用图片，且确实需要跨项目复用，再加 Stage 2：worker 异步把图片 deepcopy 到新项目 storage namespace。

## E2.3 后端 API

**`apps/api/app/api/v1/project_templates.py`**（新路由 module）：

```
GET    /project-templates                       # 列表（按 scope 过滤可见）
  query: scope?, type_key?, search?, page, limit
POST   /project-templates                       # 创建模板（手工 or 从源项目导出）
  body: { ...template fields, source_project_id?: UUID }
  // 给 source_project_id 时, 自动从源项目 dump _CLONEABLE_PROJECT_FIELDS 进模板
GET    /project-templates/{id}                  # 详情
PATCH  /project-templates/{id}                  # 修改（只 created_by / super_admin）
DELETE /project-templates/{id}                  # 删除（只 created_by / super_admin；
                                                # usage_count > 0 时给 confirm 提示但不阻拦）
POST   /project-templates/{id}/duplicate        # 克隆模板（私有→可改）

# 应用模板：扩展现有 POST /projects 接 template_id
# 在 ProjectCreate 加 template_id: UUID | None = None
# 处理顺序: template_id > source_project_id > 手工字段
# template_id 给定时, 把模板字段 deepcopy 到 payload, 并 templates.usage_count += 1
```

**`ProjectCreate` schema**：加 `template_id: UUID | None = None`，与现有 `source_project_id` **互斥**（同时给则 400）。

**`_CLONEABLE_PROJECT_FIELDS` 重构**：把白名单提到 `apps/api/app/services/project_clone.py`（新 module）作为模块级 tuple，让 `projects.py` 和 `project_templates.py` 复用。

**Service 层**：

- `apps/api/app/services/project_template.py`（新）：`create_from_source_project(db, source_project, user)`、`apply_template(db, template, payload)`、`list_visible_templates(db, user, filters)`。

**权限**：

- 创建 `public` template → require `super_admin`。
- 编辑 / 删除 template → `created_by == user OR super_admin OR (scope=organization AND user is org admin)`。
- 应用 template → 仅检查可见性。

## 待解决决策

1. **scope=organization 的 admin 是否能提交 public 模板（走审核流程）**？首版倾向**否**，仅 super_admin 可创建 public（KISS）。
2. **template 是否支持版本号 / changelog**？首版**不**做，PATCH 直接覆盖；客户提需求再加。
3. **annotation_guide 在模板里是否同步包括 guide_assets**？默认**不**（详见 E2.2），E1 反馈后再 finalize。
