## 目标

I4 原意：canvas 批注的每条 stroke 带时间，评论卡片下显示迷你时间条，hover 评论高亮对应 stroke 区间。

## 前端改动（无后端 schema 变更）

- **`CanvasDrawingEditor.tsx`**：创建 stroke 时给每条挂 `id` + `started_at` + `ended_at`。`canvas_drawing.shapes[]` 已是 JSONB 数组，新字段向后兼容；旧 stroke 缺字段时 UI 降级为"无时间轴"模式。
- **`CanvasDrawingPreview.tsx`**：评论卡片下方新增迷你时间条（默认折叠）；hover 单条评论时通过 `useHoveredCommentStore`（底座已存在）把 stroke filter 从"全部"切到"按 timeline 区间"高亮。
