# v0.10.12 — CSP style-src sections 群续推

## 背景

ROADMAP §B 已在 v0.10.11 完成 `BatchesSection.tsx` 试点：inline style 迁到 CSS modules、文件级 `no-restricted-syntax` guard 防回潮，并写入迁移指南。当前 `style-src 'unsafe-inline'` 仍不能摘除，因为全站还存在大量 `style={{...}}`。

本阶段不改 CSP 头，继续按页面群分批迁移：先把 `pages/Projects/sections/` 这个高密度目录清掉，再推进 Workbench / Dashboard。
