## 1. 目标

- 让 1080p / 4K 多实例视频的解码、渲染和编辑保持稳定内存。
- 让 5K / 8K、全景和工业图像可以局部编辑，而不是简单放大 4096 常量。
- 将 RLE、连通域、轮廓和形态学重任务移出主线程。
- 历史从全帧 snapshot 转为 patch / tile diff，避免每个 stroke 复制整图。
- 建立可重复的浏览器性能门和泄漏检测，不只凭人工感受。

## 2. Phase A · 基准与 ADR

新增性能研究报告与 ADR-0053，输入至少覆盖：

- 720p / 1080p / 4K 视频，1 / 10 / 50 个真实 SAM Mask。
- 5K / 8K 图片、超宽全景、稀疏小对象、50% noise 和棋盘格极端 Mask。
- brush、lasso、fill hole、morphology、undo / redo、快速切 50 帧。
- Chrome 主线程 long task、JS heap、GPU bitmap、decode / render / stroke p50 / p95。

ADR-0053 冻结 tile 大小、halo、cache budget、worker 数、history patch 和超限策略；无报告不改尺寸上限。

## 3. 视频缓存

### P1 · 字节预算 LRU

- 用 alpha、bitmap、RLE 和中间 buffer 的估算字节代替固定 96 条。
- 预算可按设备内存分档，但有稳定最小 / 最大值；不能无界增长。
- active / selected 对象可 pin，但 pin 总量超预算时降低预取，不突破硬上限。
- 淘汰、task 切换、annotation version 变化都 close `ImageBitmap`。

### P2 · AABB 裁剪与加载隔离

- decode 后计算 Mask AABB，只保存 cropped alpha / bitmap 和 offset。
- picking、渲染、导出预览使用 offset，不物化第二份全帧 RGBA。
- 并发请求与 decode worker 有上限；优先当前帧 / 选中对象，再预取相邻帧。
- 单项错误使用 all-settled 语义，不清空整帧 records。
- ETag / 304 与 content sha256 避免重复下载 / decode。

## 4. Worker 与 history

- RLE encode / decode、bounds、components、holes、contour、morphology 进入专用 Worker pool。
- 消息传递使用 transferable buffer；主线程不保留重复 Uint8Array。
- stroke 渲染仍即时；pointer up 后异步生成 patch / RLE，saving 显示可取消状态。
- history 保存 dirty tile / patch diff，并设字节预算；超预算淘汰最旧本地 stroke，不影响已提交 annotation history。
- Worker crash / timeout 返回 error 状态并保留主 Buffer，不自动清稿。

## 5. 5K / 8K tile editor

### P3 · Sparse tile contract

- 编辑态按固定 tile 懒加载，未访问 tile 不物化全图 Buffer。
- brush / lasso 跨 tile 时计算受影响 tile；形态学使用 halo，边界结果与全图算法一致。
- 空 tile 不上传；保存时流式合并为 canonical RLE，或由 ADR-0053 决定 tile-object 持久化。
- 首版优先保持持久格式仍为 canonical COCO RLE，避免消费者感知 tile。
- viewport 只解码可见 tile + 小范围预取；缩略层只用于显示，不能作为编辑真值。

### P4 · 上限与降级

- 按宽、高、总像素、tile 数、runs 和输出 bytes 分别设上限。
- 设备能力不足时进入只读预览或要求缩小 ROI，不让浏览器 OOM。
- 全图 morphology / fill hole 超预算时要求 ROI 或后台 job；不静默跑到页面冻结。
- 视频大于既有上限先支持 cropped ROI correction；全帧 8K tracker 另立 backend 预算。

## 6. 性能门

最终数值由 ADR-0053 基准冻结，最低必须证明：

| 场景 | 通过条件 |
|---|---|
| 1080p，20 个 Mask，播放 300 帧 | heap / bitmap 稳态，无持续增长 |
| 4K，5 个 Mask，20 strokes + undo / redo | 无倍增内存，无连续 long task |
| 快速切换 50 帧 | 旧响应零回写，并发不超上限 |
| 8K 图片局部 brush / lasso | 只加载相交 tile，未访问区域不分配全图 Buffer |
| Worker 异常 | 稿件保留、可重试、主线程仍可响应 |

## 7. 非目标

- 不承诺无限分辨率或无限实例。
- 不把 tile 直接暴露为 AAP / COCO 格式，除非 ADR-0053 证明 canonical RLE 无法生成。
- 不引入 WebGPU 作为硬依赖；可研究但必须有 CPU / Canvas fallback。
- 不改变 Mask 语义、AI 模型或格式矩阵。
- 不做语义 / 全景分割。

## 8. 测试、文档与退出门

- 增 deterministic benchmark runner，固定浏览器版本、机器信息、warmup 与采样次数。

- 补 tile 边界、halo、跨 tile brush、Worker timeout、cache pressure 和低内存降级测试。
