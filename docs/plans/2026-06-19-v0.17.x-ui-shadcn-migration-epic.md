# v0.17.x · UI 全量迁移到 shadcn/ui(Epic)

> 规划日期 2026-06-19 · 分支 `UI-refactor` · 范围:把 `apps/web` 自维护的 CSS Modules + `tokens.css` 视觉体系,**全量**迁到 Tailwind v4 + shadcn/ui,直到原有 `*.module.css` 与 `tokens.css` 全部退役、CI 门禁完成时代切换。
> 设计基调与 token / 组件单一真值源见 [`2026-06-19-v0.17.0-ui-design-system.md`](2026-06-19-v0.17.0-ui-design-system.md)。

## 1. 背景与目标

### 1.1 为什么做

自维护 UI 的美观度与可访问性达不到成熟组件库;`tokens.css` + CSS Modules 双套暗色靠人工纪律(B-32/36/38/39 系列暗色 bug 即源于此)。迁到 shadcn/ui 后:行为原语(Dialog/Dropdown/Tooltip 焦点与键盘)由 Radix 兜底,视觉由统一 token + Tailwind 工具类约束,暗色由 `data-theme` 单点驱动。

### 1.2 现状盘点(迁移面)

- `*.module.css` 共 **201** 个。重灾区:`pages/Workbench` 65、`pages/Projects` 26、`components/ui` 20(换完即删)、`pages/ModelMarket` 10、`pages/Dashboard` 9、`components/projects` 7、`components/shell` 6、`pages/Review` 5、`pages/Admin`/`pages/Login` 各 3。
- 工作台 65 经实测细分:**~55 个是 DOM 面板**(含挂在 `stage/` 下的对话框/侧栏,引用通用语义 token)→ 可全迁;**仅 ~10 个真 Konva 叠加层**(像素定位/z-index)→ 改指 `--sc-*` 后白名单保留。画布**专属**变量仅 `--color-canvas-checker-a/b` 2 个。详见阶段 6。
- 自维护基础组件 `components/ui/` 20 个,按引用数(= 迁移杠杆)排:`Icon` 139、`Button` 105、`Toast` 68、`Badge` 55、`Modal` 42、`Card` 36、`Avatar` 18、`ProgressBar` 11、`TabRow`/`StatCard` 10、`SearchInput` 7、`DropdownMenu`/`Switch` 5、`ContextMenu` 3、`Tooltip` 2。
- 现有 CI 门禁:`scripts/check-css-tokens.mjs`(176 行)扫 `apps/web/src/**/*.css`,禁造名 / 禁 fallback,护暗色。

### 1.3 终态成功判据

1. `apps/web/src` 下 `*.module.css` 收敛到**仅剩约 10 个 Konva 叠加层 CSS**(显式白名单 + 注释),且全部改指 `--sc-*`、**不残留任何 tokens.css 变量**。其余全部退役。
2. `tokens.css` 退役;暗色统一由 `shadcn.css` 的 `--sc-*` + `data-theme` 驱动。
3. Tailwind preflight 转为全局(删 `.tw-scope` 局部 reset)。
4. `check-css-tokens.mjs` 退役,替换为 Tailwind 时代门禁(禁裸色 / 禁任意色值 / 暗色 token 化,详见 §4)。
5. 视觉:全站符合设计规范(中性基底 + 彩色点缀),light/dark 双主题截图基线通过。
6. `pnpm lint && pnpm typecheck && pnpm test` 全绿;Playwright 截图回归通过。

### 1.4 红线(贯穿全程)

- **渐进 + 可回退**:每阶段独立可上线;迁移期新旧栈共存(`.tw-scope` 隔离),任一阶段出问题可停在该版本。
- **行为零回退**:只换皮,不改业务逻辑 / 数据流 / 路由语义;每个迁移点用截图 diff + 既有单测把关。
- **不碰 Konva 画布渲染**:工作台画布(`stage/` 下 Konva/three 渲染)不在本 Epic;只迁其外围面板 / 工具栏 / 弹窗。
- **薄适配优先于大改调用点**:高引用原语(Toast 68、Icon 139)用适配层 / 批量 codemod,不手改上百处。

## 2. 迁移顺序(原语 → 页面易→难 → 外壳 → 工作台 → 退役)

总思路:**先换地基零件(原语),让全站观感一次性抬升;再按"低风险高可见"顺序逐页换壳;外壳(sidebar/topbar)放在范式验证成熟后;工作台最后且最谨慎;最后统一退役旧 CSS 与门禁。**

- [x] Tailwind v4 + `@tailwindcss/vite` 接入,与 CSS Modules 共存(跳过全局 preflight,`.tw-scope` 局部 reset)。
- [x] `shadcn.css`:Geist + 彩色点缀 token;`dark` variant 重定向到 `[data-theme="dark"]`。
- [x] `components.json` + `lib/utils.ts(cn)` + 首批 shadcn 组件。
- [x] `/dashboard-next` 垂直切片(参考实现 + 验收基线)。
- [x] **补**:落地设计规范文档(本目录)。
- [x] **补**:补齐全套 shadcn 原语 —— 已落地 `dialog / sheet / dropdown-menu / context-menu / tooltip / switch / select / checkbox / popover / label / textarea / scroll-area / alert-dialog`(纯 `radix-ui`,无新依赖)+ `sonner`(新增依赖,Toaster 适配本项目 `useTheme().resolved` / `--sc-*`,**调用点迁移留待 v0.17.2**)。连同阶段 0 已有的 10 个,`components/shadcn/ui/` 共 25 个原语。
- [x] **补**:新 CI 门禁 `scripts/check-tw-tokens.mjs` 以 **non-blocking(warning)** 模式上线(扫 `*.tsx` 的 `className`:裸色 / Tailwind 任意色值 / 语义色暗色配对),并入 `pnpm lint`;CI 发 `::warning::` 注解,先观测不阻断,v0.17.7 转 blocking。

### 阶段 1 — 原语替换 wave 1(v0.17.1):Button / Badge / Card / Icon

最高杠杆、最机械。把 `@/components/ui/{Button,Badge,Card}` 与 `@/components/ui/Icon` 的引用改到 shadcn / lucide。

- 验收:全站按钮 / 徽标 / 卡片观感统一为新基调,截图 diff 人工确认。

### 阶段 2 — 原语替换 wave 2(v0.17.2):交互原语 + 删 `ui/`

低风险、高可见的"门面"先行。

### 阶段 5 — 外壳 + 审核(v0.17.5):Shell + Review

### 阶段 6 — 工作台(v0.17.6):面板全迁 + 画布叠加层抽离

实测把工作台 65 个 module.css 细分(`grep var(--color-` + 目录归类):

- **~55 个是 DOM 面板 / 对话框 / 侧栏 / 工具栏**(含挂在 `stage/` 下的 `VideoTrackPanel` / `VideoAttributesEditor` / `VideoChapterSidebar` / `CanvasToolbar` / `BoxListItem` / 各 `*Dialog`,以及 `shell` 31 + `selectionCard` 8)。它们引用的全是**通用语义 token**,1:1 映射 `--sc-*` → **全迁 shadcn**,删 module.css。
- **仅 ~10 个是真 Konva 叠加层**(`ImageStage` / `ImageBackdrop` / `BoxRenderer` / `ResizeHandles` / `SelectionOverlay` / `DrawingPreview` / `BlurhashLayer` / `Minimap` / `VideoKonvaStage` / `VideoPlaybackOverlay`)—— 像素定位 / z-index 编排,Tailwind 化无收益。**保留为 CSS,但把 `var(--color-*)` 全部改指 `--sc-*`**(语义有等价物);显式列入门禁白名单 + 注释原因。
- 实测画布**专属**变量仅 2 个:`--color-canvas-checker-a/b` → 折进 `shadcn.css` 为 `--sc-canvas-checker-a/b`,**不另建 `canvas.css`**。

结果:工作台对 tokens.css 的依赖**彻底切断**,残留收敛为 ~10 个改指 `--sc-*` 的画布叠加 CSS。

### 阶段 7 — 退役 + 门禁重写(v0.17.7)

见 §3 / §4。`tokens.css` **彻底删除**(零变量残留:checker 已折进 `shadcn.css`,叠加层已改指 `--sc-*`);`*.module.css` 仅剩 ~10 个画布白名单;preflight 转全局(删 `.tw-scope`);旧门禁 `check-css-tokens` 退役删除,新门禁转 blocking 并覆盖那 ~10 个白名单(允许 `--sc-*`、禁裸色)。

## 3. CSS Modules / tokens.css 退役路径

1. **逐区清零**:每个阶段迁完一个目录,即删该目录 `*.module.css`(由该阶段 PR 携带,保证「迁移 + 删除」原子)。
2. **`tokens.css` 彻底删除**(阶段 7,实测可零残留):
   - 画布叠加层(~10 个)把 `var(--color-*)` 改指 `--sc-*`(实测它们用的 23 个通用语义变量在 `--sc-*` 都有等价物)。
   - 唯一画布专属的 `--color-canvas-checker-a/b` 折进 `shadcn.css`(`--sc-canvas-checker-a/b`)。
   - 至此无任何文件消费 `--color-*` → 整删 `tokens.css`(含底部兼容别名段 `--color-primary → --color-accent` 等);`main.tsx` 移除 `import "./styles/tokens.css"`。
3. **preflight 转全局**(阶段 7):
   - `shadcn.css` 把 `@import "tailwindcss/theme.css" + utilities.css` 改回 `@import "tailwindcss"`(含 preflight)。
   - 删除 `.tw-scope` 局部 reset;各页根节点去掉 `tw-scope` class。
   - 全站回归测一遍(preflight 全局后 margin/border 基线变化需截图核对)。
4. **验证**:`find apps/web/src -name "*.module.css"` 结果为空或仅画布白名单;`grep -r "tokens.css\|--color-"` 无残留(画布白名单除外)。

## 4. CI 门禁:从 check-css-tokens 到 Tailwind 时代

### 4.1 现状

`scripts/check-css-tokens.mjs`(`pnpm lint:css-tokens`,并入 `pnpm lint`)扫 `apps/web/src/**/*.css`:① 禁用未在 `tokens.css` 定义的 `--color-*`;② 禁 `var(--x, fallback)`。护的是 CSS Modules 时代的暗色。

### 4.2 迁移期(阶段 0–6):双门禁并行

- **旧门禁保留**:仍扫残留 `*.module.css`,对未迁页面继续护暗色 —— 迁移期它依然有效,逐区缩小扫描面。
- **新门禁 non-blocking 上线**(阶段 0):新增 `scripts/check-tw-tokens.mjs`,扫 `apps/web/src/**/*.tsx` 的 `className`:
  - 禁裸色:`#hex` / `rgb(` / `oklch(` 出现在 className 字符串。
  - 禁任意色值:`bg-[#...]` / `text-[rgb(...)]` / `border-[...]` 颜色任意值。
  - 暗色配对提示:检测 `text-<hue>-600` 是否伴随 `dark:text-<hue>-400`(警告级,引导对齐设计规范 §2.2)。
  - 先 `::warning::`(参考 `check-doc-version-prefix.mjs` 的非阻断范式),积累后转硬阻断。

### 4.3 终态(阶段 7):时代切换

- `*.module.css` 归零 → `check-css-tokens.mjs` 无可扫,**退役删除**;`pnpm lint:css-tokens` 从 `pnpm lint` 摘除。
- `check-tw-tokens.mjs` 转 **blocking**,并入 `pnpm lint`。
- 视情接入 `eslint-plugin-better-tailwindcss`(class 排序 / 合法性 / 冲突检测),与新扫描器配合。
- 更新 `CLAUDE.md §6`:从「CSS 变量三铁律」改写为「Tailwind 时代:语义 token + 固定调色板、禁裸色 / 任意值、暗色走 data-theme」。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| preflight 全局化打乱未迁页面 | 全程用 `.tw-scope` 隔离,**只在阶段 7 最后一次性切全局**并截图回归 |
| 高引用原语手改易错(Button 105 / Icon 139) | codemod 脚本批量改 import + props;改完跑 typecheck + 截图 diff |
| `Toast`(68)/`useToastStore` 调用点广 | 保留 store 薄适配,内部转 `sonner`,**不改调用点** |
| shadcn `table` 大数据量性能 | 保留 `@tanstack/react-virtual`,只换单元格皮 |
| 工作台画布样式误伤 | 实测残留仅 ~10 个 Konva 叠加 CSS;改指 `--sc-*` 不重写逻辑;显式 `box-sizing` 自洽防 preflight flip;白名单 + 注释,杜绝腐化 |
| 暗色对比度回退 | 每页 light/dark 双截图基线;颜色全部走设计规范表 |
| bundle 体积(Radix 多包) | 按需 `shadcn add`;构建后跑 `pnpm size` 看增量 |
