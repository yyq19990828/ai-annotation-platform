## 2. 迁移规约(桶 A,子agent 必读)

**完全沿用 v0.17.4 计划 §2 的规约**(颜色 token 映射、彩色暗色配对、门禁、禁 style + useElementStyle、UA 漏样基线、复用 ui/、只换表现、测试)。样板:`pages/Admin/SystemHealthPage.tsx`、`pages/Admin/AdminPeoplePage.tsx`、`pages/Dashboard/DashboardPage.tsx`、`components/ui/Modal.tsx`、`components/shell/TopBar.tsx`(刚迁的 chrome 范例)。

工作台特有要点:
- **tw-scope**:工作台是一个长驻 SPA 区。各 shell 顶层面板(`WorkbenchShell`/`WorkbenchLayout`/`Topbar`/各 Drawer/各浮动面板 `FloatingPanelShell`)若是独立渲染区/portal,根加 tw-scope;嵌在已 scope 容器内的子件(selectionCard/*、面板内部行)不加。**浮动面板 / Drawer / Dialog 若 portal 到 body,根必加 tw-scope**。逐件判断,拿不准就加(tw-scope 幂等无害)。
- **selectionCard/** 8 件是选中信息卡的组合子件,渲染在 `SelectedAnnotationCard` 内 —— 该卡若有 tw-scope 则子件不加。
- **复用既有 `ui/` 组件**:工作台大量自绘按钮/输入,优先换 `ui/Button`/`ui/Modal`/`ui/Switch`/`ui/Tooltip` 等。
- **动态值密集**(画布坐标投影、浮层定位、置信度条宽、轨道色):一律 `useElementStyle` + `w-[var(--x)]`;动态用户色(类别/轨道色)用 SVG 属性或 useElementStyle 设 `background`,**不要** className 里 `bg-[var(...)]`(触任意色门禁)。
- **不碰画布渲染逻辑**:只换 DOM chrome 的 className;Konva/坐标/标注交互/hooks/props 零改。

## 3. 桶 B 规约(画布叠加层 token 改指)

对 10 个画布 css 文件:
1. 把文件内每个 `var(--color-X)` 改成对应 `var(--sc-Y)`(实测 23 个通用语义变量在 `--sc-*` 都有等价物;映射表见 `shadcn.css` 顶部 `@theme inline`)。常用:`--color-accent`→`--sc-brand`、`--color-border`→`--sc-border`、`--color-bg-elev`→`--sc-card`、`--color-fg`→`--sc-foreground`、`--color-success`→`--sc-positive`、`--color-danger`→`--sc-destructive`、`--color-warning`→`--sc-caution`。
2. 画布棋盘格 `--color-canvas-checker-a/b` → 先在 `shadcn.css` 的 `:root` / dark 块加 `--sc-canvas-checker-a/b`(取 tokens.css 现值),再把叠加层引用改 `var(--sc-canvas-checker-a/b)`。
3. 这 10 个文件**不 Tailwind 化、不删**;在 `check-css-tokens`/新门禁的白名单里登记(v0.17.7 门禁重写时收口),本版顶部加注释说明「画布叠加层:像素编排保留 CSS,色彩走 --sc-*」。
