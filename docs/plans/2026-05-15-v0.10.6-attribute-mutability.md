## Context

v0.7.6 起 attribute schema 框架已完整（6 种 input_type / 必填校验 / `visible_if` 条件级联 / AttributeForm 自动渲染）。CVAT 把属性区分为 `mutable`（每帧可变，如 occluded / orientation）与 `immutable`（轨迹级，如 vehicle_color），视频侧 track 的逐帧覆盖语义就靠这个开关划分。我们之前没有 mutable 概念，所有属性变更都影响 track 整体；视频侧 track 属性也没有逐帧编辑 UI。

v0.9.41 落地的 [`useDirtyTracker`](../../apps/web/src/pages/Workbench/state/useDirtyTracker.ts) 是基础设施骨架，无消费者。本子版本让它首次承担「批量改 mutable 属性 → pointerup/blur 一次 PATCH」的消费场景。是 v0.10.4 epic 的第 3/4 子版本。

## Scope

### 后端

- **schema 扩展（无新表/列）**：扩 [`schemas/_jsonb_types.py`](../../apps/api/app/schemas/_jsonb_types.py) `AttributeField` 加 `mutable: bool = False`（默认 immutable，向后兼容）。`class_definitions` 已是 JSONB，无需 alembic。
- **视频 track 逐帧覆盖字段**：track 表 `keyframes` 已存 `attributes` overrides；需要新增/验证 keyframe schema 支持「按 attribute key 局部覆盖」。检查 [`video_track`](../../apps/api/app/db/models/) 现状决定是否新加 alembic。
- 单测：覆盖 mutable=true 字段在 PATCH attribute 时只影响目标帧 keyframe；mutable=false 字段影响整 track。

### 前端 — AttributeForm

- 改 [`shell/AttributeForm.tsx`](../../apps/web/src/pages/Workbench/shell/AttributeForm.tsx)：
  - mutable 字段在视频任务下显示「当前帧覆盖 / track 默认值」双行；
  - 表单 onChange 区分 mutable / immutable：immutable 走整 track PATCH（现有路径），mutable 走 keyframe override PATCH（新路径）；
  - 图片任务下 mutable 标记被忽略（行为 = immutable，向后兼容）。

### 前端 — VideoTrackPanel mutable 属性表格

- 改 [`shell/VideoTrackPanel.tsx`](../../apps/web/src/pages/Workbench/shell/VideoTrackPanel.tsx)（若存在 — 待勘察）：mutable 属性以表格列展示「track 默认值 / 当前帧覆盖」；点击切到该 keyframe 编辑模式。

### 前端 — useDirtyTracker 首次消费

- 改 [`state/useDirtyTracker.ts`](../../apps/web/src/pages/Workbench/state/useDirtyTracker.ts)：补 flush API（如果骨架还未提供）。
- 改 `AttributeForm`：批量改多个 mutable 属性时累积 dirty bits，blur 或 pointerup 时一次 PATCH（避免逐字段请求风暴）。
- 单测：覆盖 dirty 累积 / flush 时机 / 失败重试 / 切 annotation 清空。

## 验证

- pytest：mutable PATCH 仅影响当前帧 keyframe，不污染 track 默认；immutable PATCH 影响整 track（含所有 keyframe 派生）。
- 前端单测：覆盖 useDirtyTracker 在 mutable 属性下的累积 + 单次 flush + 失败重试；AttributeForm mutable 双行显示。
- 浏览器烟囱：视频任务下选中 track → 改 `occluded`（mutable）→ 当前帧 keyframe 出现 override，跳到其它帧值还原；改 `vehicle_color`（immutable）→ 整 track 改。

## Notes

- mutable/immutable 概念与 M4-β 的 `is_occluded` 字段**不冲突**：M4-β 是固化的 4 个一等状态位（含 occluded），M4-γ 是项目自定义 attribute schema 上的可变性开关。
- 不涉及 v0.10.7 Mask 编辑器；I13 子项 I13.1 / I13.3 / I13.4 已在 v0.7.6 完成，本期只补 I13.2。
- 衔接 M4-δ：useDirtyTracker 在 mask 编辑场景也可复用（笔刷一笔一笔不入 history，松手前累计 flush 一次）。
