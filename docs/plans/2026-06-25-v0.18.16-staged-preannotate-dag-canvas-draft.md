# v0.18.16 — DAG 画布 + 节点检查器（两列预标编排）

> 状态：**已落地**（2026-06-25 创建，同日实现）。
>
> 范围：把 [0.18.15](./2026-06-25-v0.18.15-model-io-contract-and-crop-remap-draft.md) 的受限树形**竖排卡片**编排，重做成**左 DAG 画布 + 右节点检查器**的两列交互。后端零改动（复用 `stagesGraph` → `pipeline_stages` + 0.18.15 的校验 / 投递烘焙 / 几何回映）。

## 落地说明（与草案的偏差）

5 个 PR 全部实现并测试通过（`pipelineGraph` 纯函数 19 测 + `PipelineGraphCanvas` 组件 2 测 + 全量 1672 测全绿；tsc / eslint / css-token 干净；`pnpm build` 验证 react-flow 独立成 `PipelineGraphCanvas` chunk 174 kB / gzip 56 kB，不进主包）。与草案的关键偏差：

- **子侧 `supported_inputs` 可达性不在 DAG 引擎判**（草案 §7.4）：`canReparent` 只做拓扑校验（无环 / 深度 ≤ 3 / 父产几何 / 单父），可达性沿用 0.18.15 端点 422 兜底——能力数据在各 `StageCard` 自持的 `capabilitiesQ` 里，图层拿不到，复制一份得不偿失且易漂移。
- **节点名不重复角色**（草案 §5）：徽标已写角色名（检测 / 分割 / 分类），节点不再另起一行重复；源节点徽标「源」+ 名「检测」。
- **`onReconnect` 与 `onConnect` 共用改父语义**：拖已有边的端点 = 拖新边落到节点，都归一到 `onReparent(child=target, newParent=source)`，单一路径少分叉。
- **加子保留节点 `+` 按钮为主路径**（草案 §6 备注）：拖 handle 是进阶手势，节点上的 `+` 是稳路径（两者都受 `canAddChild` 门控：产几何 + 深度 < 3 + 项目 ≥ 2 backend）。

## 0. 动机

竖排 `StageCard` 随并行 / 嵌套阶段**无限拉长页面**：每加一个阶段就多一整张卡，depth-3 + 并行扇出时滚动地狱。结构（谁是谁的父、并行还是串行）也只能靠缩进脑补。

把编排区换成**受限可交互 DAG**：左列画布一眼看清拓扑、点选节点，右列只渲染**当前选中节点**的参数 —— 页面高度恒定（右列永远一张卡），结构所见即所得。

**技术选型**（已与用户确认）：
- 渲染用 **`@xyflow/react`（react-flow v12）**，要拖拽连边 / handle / minimap 级别的成熟交互。
- v1 **支持「拖拽改父」(re-parenting)**：拖节点入边到另一个合法几何节点即改父。
- 代价：把「受限树」规则**反向约束**进通用 DAG 引擎（`isValidConnection` / `onReconnect` 严校验 + 非法回弹）。

## 1. Goals / Non-Goals

### Goals
1. **两列布局**：左 `PipelineGraphCanvas`（react-flow），右选中节点参数检查器。页面高度不随阶段数增长。
2. **节点**：源(检测) + 各下游；角色徽标(检测/分割/分类) + 运行态圆点 + 迷你计数(目标/成功)。选中态高亮。
3. **加阶段**：节点上 `+`（产几何且 depth<3 → 加子；源 → 加并行）；**删除**级联删后代。
4. **拖拽改父**：拖某节点入边端点到另一**合法几何节点** → re-parent；非法落点实时红 + 回弹；改父后级联重算深度。
5. **受限实时校验**：单父树、`depth≤3`、父产几何、子 `supported_inputs` 可达、无环 —— 全部映射到「`+` 是否出现」「连线是否合法」「节点是否标红」。
6. **配置持久**：切换选中节点不丢各自配置。
7. **bundle 隔离**：react-flow 经 `React.lazy` + `Suspense` 仅在 `/ai-pre` 详情面板按需加载。

### Non-Goals
- 不放开**自由多父 DAG**（仍是受限单父树；只是用 DAG 引擎渲染 + 拖拽编辑）。
- 不改后端协议 / worker / 校验（沿用 0.18.15）。
- 不支持**节点自由摆位**：位置由分层布局算法决定（`nodesDraggable=false`），用户只拖**边**改父，不拖节点位置。
- 不引入 dagre/elk 自动布局：拓扑是我们自己的受限树，手算分层布局即可（少一个依赖）。

## 2. 依赖

- 新增 `@xyflow/react`（v12，当前包名；旧 `reactflow` v11 不用）。需 `import "@xyflow/react/dist/style.css"`。
- 画布组件 `React.lazy(() => import("./PipelineGraphCanvas"))`，用 `<Suspense fallback={…}>` 包住 —— 与 `App.tsx` lazy 加载 `WorkbenchPage`、`AnnotationGuideSection` lazy 加载 `MarkdownEditor` 同惯例，把 react-flow chunk 隔离出主包。

## 3. 数据模型（复用 0.18.15，不新增真值源）

`stagesGraph: Array<{ sid, parentSid }>`（`parentSid="root"`=源）仍是**唯一真值**。react-flow 的 `nodes`/`edges` 是**受控派生**（`useMemo`），手势回调改写 `stagesGraph` / `stagePayloadsRef`，不让 react-flow 自持真值。

抽出**纯函数**（可单测、与 react-flow 解耦）：
```ts
// utils/pipelineGraph.ts
buildFlow(stagesGraph, payloads, stats, selectedSid): { nodes: Node[]; edges: Edge[] }   // 派生 + 分层布局坐标
depthBySid(stagesGraph): Record<string, number>                                          // 复用现有
descendantsOf(stagesGraph, sid): Set<string>                                             // 级联删 / 环检测
canReparent(stagesGraph, payloads, childSid, newParentSid): { ok: boolean; reason?: string }  // 改父校验
canAddChild(stagesGraph, payloads, parentSid): boolean                                   // + 子按钮门控
```

## 4. 分层布局算法

- `col = depth - 1`（源 depth=1 → col 0）。每列内按兄弟出现序排行。
- `x = col * COL_W`、`y = rowInCol * ROW_H`（同列居中可选）。re-parent / 增删后重算 + `fitView` 平滑过渡。
- `nodesDraggable={false}`：节点位置不可手动拖（避免与算法布局打架），只拖边改父。

## 5. 自定义节点（`nodeTypes`）

- **source 节点**：检测徽标 + 源 backend/model 摘要 + 检出框数(运行态)。无入 handle；有出 handle（`Position.Right`）。
- **stage 节点**：角色徽标(检测/分割/分类，复用 0.18.15 `roleOf` 配色) + 名称/命名 + 运行态圆点(待运行/运行中/已完成) + 迷你计数(目标/成功)。入 handle（`Position.Left`）；**产几何的**才有出 handle（`Position.Right`）—— 没出 handle 物理上就连不出子，把「叶子不可有子」编码进 UI。
- 选中 = ring 高亮（描边 token）。键冲突节点 = danger 描边。
- 点击 `onNodeClick` → `setSelectedSid(sid)`（源用保留 sid `"root"`）。

## 6. 边与手势

| 手势 | react-flow 钩子 | 行为 |
|---|---|---|
| 拖出 handle 落到空白 | `onConnectEnd` | 弹「新建子阶段」→ `addStage(sourceSid)`（仅当 source 产几何 + depth<3） |
| 拖出 handle 落到已有节点 | `onConnect` | 若 target 已有父 → 改父；否则连边（受 `isValidConnection` 约束） |
| 拖**已有边**的端点到新节点 | `onReconnect(oldEdge, newConn)` | re-parent：`child.parentSid = newConn.source`，校验通过才提交、否则回弹 |
| 落点合法性 | `isValidConnection(conn)` | 实时判定（连线变红/绿）：见 §7 |
| 删除节点 | 节点 `🗑` / `onNodesDelete` | `removeStage(sid)` 级联删后代 |

- 边 `reconnectable`，`onReconnectStart/End` 处理「拖走没落到合法点 → 删边？」——v1 策略：拖飞=回弹保持原父（不允许悬空孤儿）。
- 加阶段**也保留节点上的 `+` 按钮**（不依赖精细拖拽）：`+子`（产几何且 depth<3）、源 `+并行`。拖 handle 是进阶路径，`+` 是稳路径。

## 7. 受限校验（把 0.18.15 gating 反向约束进 DAG）

`isValidConnection(conn)` / `canReparent()` 同一套规则：
1. **source 产几何**：`payload(source).write.target ∈ {geometry, intermediate}`（否则不能当父）。
2. **无环**：`target` 不是 `source` 的祖先（用 `parentSid` 链上溯）。
3. **改父后深度 ≤ 3**：重算 `target` 子树的最大深度（`target` 新深度 = `depth(source)+1`，加上子树残余高度 ≤ 3）。
4. **子可达**：`target` 的 `supported_inputs` 与新父产物兼容（产几何的子须含 `bbox_prompt`/`crop`；前端读 `capabilities`，与端点 422 门控同判据）。
5. **单父**：树模型天然单父；re-parent = 替换入边，不新增第二个父。

非法 → react-flow 连线红 + 不落 / 回弹，并 toast 原因（与端点 422 文案对齐）。

## 8. 检查器（右列）

- 选中**源** → `PreannotateConfigForm`（现有 `cfg`）+ 源信息。
- 选中**下游** → 该 `StageCard` 配置体。
- **持久化方案**：所有 `StageCard` 渲染在右列容器内、加 `hidden` prop，非选中的 `display:none`（**CSS 隐藏而非条件卸载**，保住各自 `usePreannotateConfig` 状态 + 已发的能力查询）。同一实例唯一、状态留存、只一个可见。
  - 备选（不采纳）：把配置状态上提到容器、右列单一 form 实例 —— 更省内存但要大改 `StageCard`/`usePreannotateConfig`，风险高、收益小（节点数本就少）。
- canvas 节点展示数据来自 `downstreamPayloads`（StageCard 已上抛）+ `stats`，与 StageCard 可见与否无关。
- 空选 → 「点选左侧节点编辑参数」。

## 10. 风险

- **把树规则反约束进通用 DAG**：`isValidConnection`/`onReconnect` 必须写严，否则能拖出非法中间态。缓解：所有规则收敛到 `canReparent()` 单一纯函数，UI 与校验共用、单测覆盖环/深度/可达/单父。
- **受控 vs react-flow 内部态**：坚持 `stagesGraph` 单一真值，nodes/edges 全 `useMemo` 派生；`nodesDraggable=false` 防位置漂移。
- **状态持久**：`StageCard` 必须 **CSS 隐藏**不卸载；条件渲染会丢配置 —— 加测试守住。
- **bundle**：react-flow 不小；`React.lazy`+`Suspense` 隔离到 ai-pre 详情，测 chunk 体积。
- **可测性**：react-flow 在 jsdom 需 mock `ResizeObserver`/`getBoundingClientRect`；交互逻辑尽量留在纯函数层测，组件层只测「选中→右列切换」「+/删除改 stagesGraph」。

## 11. 验收

- 加 / 删 / 拖拽改父 任意操作后，`stagesGraph` 恒为**合法受限树**（≤3 层、父产几何、无环、单父）；非法拖拽回弹 + 提示。
- 页面高度恒定（右列单卡），与阶段数无关。
- depth-3 链路(`person → 检测 hat → hat 分类 color`)能在画布搭出、能跑（对接 0.18.15 worker，后端零改动）。
- 切换选中节点，各节点配置不丢。
- react-flow chunk 不进主包（按需加载）。

## 12. 兼容性

- 后端 `pipeline_stages` payload 组装逻辑不变（仍由 `stagesGraph` + `downstreamPayloads` 派生）。无 DB migration、无协议改动、无新环境变量。
- 纯前端编排 UI 重做；`StageCard` 配置体、`usePreannotateConfig`、运行/并发/键冲突逻辑全部复用。

## 13. 后续优化：节点易用性与信息增强（同版本增量）

> 状态：规划中。仍归在 **v0.18.16**（同主题打磨，不另起版本号）。DAG 画布落地后体验仍偏"骨架"——节点信息单薄、可达性只在跑批时报错、拖拽手势靠猜。本节把这些短板拆成分期增量。

### 13.0 已修复（落地中）

- **新建节点造出 depth>3 致画布崩溃**：`depthBySid` 原依赖数组顺序（假设父先于子出现），改父后子常排在新父之前 → 深度被低估 → `canAddChild` 误判可加 → 造出 depth>3；`buildFlow.computeDepth` 又无环/深度防护致递归爆栈。已改：`depthBySid` 顺父链递归（顺序无关 + 环兜底）、`computeDepth` 加 `seen` 防护、`addStage` 加超深兜底。

### 13.1 决策（已与用户确认）

1. **节点固定宽 + hover 浮层**：不做可变宽（布局稳）；主信息留在节点，全量信息（backend·model·任务·父框类别·pad·写回键·变体）走 hover 浮层。
2. **可达性前移 = 标红警示，不硬拦**：子模型吃不了父产物时画布上即标红 + tooltip 原因，但**不阻断运行**，最终仍交后端 422 兜底（与受控真值源解耦，避免误拦）。
3. **运行进度条进节点（试做）**：运行中节点贴一条细进度（成功/目标），先试效果；若过花再退回"只圆点+计数、明细留右栏"。

### 13.2 节点数据模型扩展

`StageNodeData` 从"角色 + 单行 detail"扩为结构化多槽（节点显主信息，浮层显全量）：

| 槽位 | 内容 | 来源 | 显示位 |
|---|---|---|---|
| 副标题 | backend 名（下游现仅显 `model_id`，看不出后端） | `payload.ml_backend_id` → 名 | 节点 |
| 就绪态 | payload=null / 缺关键配置 → "待配置" + 虚线描边 | `payload == null` | 节点 |
| 父框过滤 | "仅 person/car" / "全部框" | `parent_class_filter` | 节点（芯片）+ 浮层 |
| 投递/ROI | crop(pad 0.08) / 整图框提示 | `roi` / `input` | 浮层 |
| 写回摘要 | `hat_color, hat_type`（带前缀）/ "全部属性" | `write` | 节点 + 浮层 |
| 进度条 | 运行中 成功/目标 细条 | `stat` | 节点（运行态） |
| 警示标 | 不产属性 / 可达性不符 → 角标 ⚠ + tooltip | 见 13.3 | 节点 |

### 13.3 可达性前移（标红警示）

`StageCard` 把自身能力旗标（`acceptsCrop` / `acceptsBboxPrompt` / `producesAttributes` / `producesGeometry`）随 payload 上抛。`ProjectDetailPanel` 据此在画布上：

- 子吃不了父产物（产几何的子既不接 `crop` 也不接 `bbox_prompt`）→ 节点角标 ⚠ + tooltip（文案对齐端点 422），**不拦运行**；
- 不产属性的分类子 → ⚠（现仅右栏提示，提到画布）。

注意：这是**警示层**，不进 `canReparent` 硬校验（决策 2）——`canReparent` 仍只做拓扑（无环/深度/父产几何/单父）。

### 13.4 交互打磨

- **拖拽可发现性**：节点 hover 时出/入 handle 高亮；空态放 ghost「+ 加第二阶段」CTA；画布角落一句"拖节点圆点到另一节点可改父"。
- **合法落点高亮**：`onConnectStart` 时把所有合法父描边变绿、非法变灰（复用 `canReparentConn`）。
- **删除级联提示**：删带后代的节点时 toast "将连带删除 N 个子阶段"。
- **键盘导航**（P2）：方向键移动选中、Enter 进右栏（Delete 删已具备）。

- 不展开节点也能从画布看出：每个阶段用哪个 backend、是否已配置、对哪些父框跑、写回什么。
- 子模型与父不兼容时画布即标红（不必跑批），但仍可强行运行（后端兜底）。
- 节点信息增强不撑大固定宽布局；hover 浮层显全量。
