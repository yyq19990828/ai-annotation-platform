# v0.18.19 · sam3 PCS 迭代 refinement(多正负 exemplar + text 组合 + 阈值重过滤)

> 草案 (2026-06-25). 本 epic 第 3/3 版。复用 [v0.18.17](2026-06-25-v0.18.17-interactive-seg-dual-backend-sam-iterative.md) 的前端迭代会话基建。
> 仅涉及 **sam3-backend**(gsam2 无 PCS)。

---

## 1. 背景与源码结论(解决「PCS 全图相似不好用」)

sam3 的 PCS(Promptable Concept Segmentation, 经 `type=exemplar`/`text` 触发; 注: `type=bbox` prompt 已于 v0.18.17 退役并入 `exemplar`)当前是「一发定生死」: 每请求 `reset_all_prompts` 后只加 **一个正框**, 阈值写死, 无法排除误检 / 补回漏检。官方 `examples/sam3_image_interactive.ipynb` 的交互循环(`set_text_prompt → add_geometric_prompt(正/负框) → set_confidence_threshold`)的能力被整组丢弃。

源码证实 PCS 原生支持但 backend 未用上:

| 原生能力 | 证据 | 现状 |
|---|---|---|
| 多 exemplar 累加 | `geometry_encoders.py: append_boxes` 走 `concat_padded_sequences`(累加非覆盖) | ❌ 每请求只加 1 框 |
| 负框排除 | `add_geometric_prompt(box, label=False, state)`; demo 有 "Negative Box" | ❌ 只发 `label=True` |
| 点作几何 prompt | `append_points` 存在 | ❌ 未用 |
| text + 几何组合 | `add_geometric_prompt` 仅在 `language_features` 缺失时补 dummy "visual" → 可先 set_text 再加框 | ❌ text/几何 二选一 |
| 廉价阈值重过滤 | `set_confidence_threshold(thr, state)` 从 `state["boxes"]` 重过滤、不重跑 backbone | ❌ 阈值写死 |

## 2. 范围

- ✅ `type=exemplar` 升级: 接收 `exemplars[]`(多正/负框累加)+ 可选 `text` 组合。
- ✅ per-request `score_threshold` 重过滤(无状态: 每请求重发全量 exemplars + 阈值)。
- ✅ 前端 PCS refine 会话(加正框扩召回 / 加负框去误检 / 拖阈值实时增减), 复用 v0.18.17 会话组件。
- ✅ `output: box|mask|both` 可选(沿用现有字段): exemplars 路径与现单框/text 路径一致, 三分支已在 `_build_results` 落地, 增量成本几乎为零(只需把 `output` 透传到 `predict_exemplars`)。
- ❌ `type=bbox` prompt 已在 v0.18.17 直接退役(无别名); 本版不涉及, PCS 单一入口即 `exemplar`。
- ❌ 点作几何 prompt(`append_points` for PCS): 评估收益后决定是否纳入(默认不做, 见开放问题)。

## 3. 无状态契约

与 v0.18.17 一致: 前端维护「进行中 exemplar 集 + 阈值」, 每次操作重发全量。backend 无状态: 一次 `reset_all_prompts` → (可选)`set_text_prompt` → 顺序多次 `add_geometric_prompt(box, label)` → `_forward_grounding`(读 per-request 阈值)。backbone_out 仍按图 `embedding_cache` 命中。

> 注: 官方 `set_confidence_threshold` 的「纯重过滤不重跑」依赖服务端保留 state, 与无状态冲突。无状态下每次重发会重跑 grounding head(transformer decoder + heads, **不重跑 backbone**), 略贵但换可扩展性, 取舍合理。

## 4. 任务分解(sam3-backend)

### 4.1 协议 `schemas.py`
- `Context` 扩展(`type=exemplar`):
  - `exemplars: list[{bbox:[x1,y1,x2,y2], label:bool}] | None`(归一化 xyxy; 多正负框)。
  - 兼容: 旧 `context.bbox` **坐标字段**(单框 `[x1,y1,x2,y2]`)保留(此处 `bbox` 指字段名, 非已退役的 prompt 类型), 缺 `exemplars` 时退化为单正框。
  - `text: str | None` 已存在, 允许与 `exemplars` 同时传。
  - `score_threshold` 已存在, 复用。
  - `output: Literal["box","mask","both"] = "mask"` 已存在, 复用(exemplars 路径生效)。
- validator: `exemplars` 非空时校验每项 bbox 长度=4。

### 4.2 predictor.py
- `_predict_geometric` 重构为 `predict_exemplars(image, exemplars, text, *, output="mask", score_threshold, cache_key, ...)`:
  1. `_prime_state` 拿 backbone_out。
  2. `reset_all_prompts(state)`。
  3. 若 `text`: `set_text_prompt(text, state)`。
  4. 遍历 `exemplars`: 协议 xyxy → cxcywh → `add_geometric_prompt([cx,cy,bw,bh], label, state)`(累加)。
  5. `_apply_score_threshold(score_threshold)` 后取 `state` 的 boxes/masks/scores。
  6. `output` 透传给现有 `_build_results`(box/mask/both 三分支已就绪, 不新增逻辑)。
- 保留 `predict_bbox`(单框)/ `predict_exemplar`(单框)做兼容薄封装, 内部转 `predict_exemplars` 单元素列表。
- 误检/重叠: 评估 PCS 是否返回重叠重复实例, 必要时加轻量 NMS/dedup(单独评估, 默认不加)。

### 4.3 main.py
- `type=exemplar` 路由读 `exemplars[]`(无则退化单 `context.bbox` 坐标字段)+ `text` + `output` → `predict_exemplars`。(`bbox` prompt 已于 v0.18.17 直接退役, 无别名兜底。)
- `/setup`: supported_prompts 不变(已含 exemplar, 不再列 `bbox`); 可在 setup 里标注 exemplar 支持多框 + text 组合(供前端开关)。

### 4.4 平台 + 前端
- `apps/api`: context 透传, 无 schema 改动; `capability_registry.py` exemplar 文案补「多正负框 + text 组合 + 阈值」。
- 前端 PCS refine 会话(复用 v0.18.17 组件):
  - 拖正框 → 出全图相似实例。
  - 继续加正框(扩召回)/ 加负框(去误检)/ 拖阈值滑块(实时增减)。
  - 可选叠加 text 概念。
  - `output` 选择器(box/mask/both), 沿用现有 exemplar 工具的 outputMode(`useInteractiveAI.ts:61`)。
  - 每次操作重发全量 exemplars + threshold + output; 满意后提交。

## 5. 验收

1. 无 GPU: `schemas` 多框/兼容退化单测 + 路由单测。
2. GPU 机三条交互链路肉眼可见:
   - 「加一个负框 → 对应误检实例消失」。
   - 「加第二个正框 → 漏检实例补回」。
   - 「拖低阈值 → 结果增多 / 拖高 → 减少」。
   - text + exemplar 组合: 文本框 "car" + 负框排除某辆 → 该车消失。
   - `output=box` 出 rectanglelabels / `mask` 出 polygonlabels / `both` 配对返回, 三模式各验一次。
3. 旧单框请求(`type=exemplar` + 单 `context.bbox` 坐标字段)行为回归不破。

## 6. 风险

- **每轮重跑 grounding head**: 无状态代价; backbone 缓存命中下可接受, 但 exemplar 多 + 大图时延迟需实测。
- **vendor 升级面**: 依赖 `append_boxes` 累加语义 + `add_geometric_prompt(label)` 正负约定; sam3 README 升级复核清单补充。
- **NMS 取舍**: 是否需要 dedup 取决于 PCS 实际输出, 落地时先观测再决定, 勿提前加复杂度。

## 7. 开放问题

- **B · 点作 PCS 几何 prompt**: `append_points` 可用, 但与 SAM-style 点交互(v0.18.17)语义易混; 默认不纳入, 待用户反馈再评估。
- **D · 版本边界**: 本版若工作量超预期, 可单独抬到 0.19.x epic, 不必硬塞 0.18.x。
