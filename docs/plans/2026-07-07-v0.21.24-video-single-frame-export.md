# v0.21.24 · 视频单帧几何导出（COCO-seg / keypoint / OBB）

状态：**计划（2026-07-07）**。[视频单帧工具 epic](2026-07-07-video-single-frame-tools-epic.md) 收尾版本。把 v0.21.21–23 落库的
视频**单帧非 bbox 几何**接进导出链路。**依赖 v0.21.21/22**（几何已落库）；可与 22/23 并行。**只导单帧几何**，track segmentation
导出（DAVIS 等）归 v0.21.20 PR4/PR5。

## 动机 · 视频导出全链 bbox-only（带证据）

- `services/export_video.py`：MOT/YOLO/KITTI 各格式全部 `frame.get("bbox")`（`:73/:141/:161-228`），**无 segmentation/keypoint/
  OBB 分支**。
- v0.21.21–23 会落 `video_polygon`/`video_polyline`/`video_keypoint`/`video_rotated_bbox`/矢量化 mask，但导出侧读不到 → 标注了
  导不出，闭环缺口。
- 对照：图片侧已有 COCO-seg / keypoint / OBB 导出可参照格式（与 track 导出 v0.21.20 PR4 共享 seg 序列化逻辑，避免各写一遍）。

## 定稿决策（拟）

- `export_video.py` 扩几何分支：单帧 `video_polygon`/矢量化 mask → **COCO-seg**（`segmentation` 多边形）；`video_keypoint` →
  **COCO-keypoints**（`keypoints`+`num_keypoints`，骨骼来自 `keypoint_schema`）；`video_rotated_bbox` → **OBB**（DOTA/YOLO-OBB 或
  COCO 扩展，格式对齐图片侧 OBB 导出）。
- 帧维度：单帧几何按 `frame_index` 归属对应帧的 image/annotation 记录（对齐现有 `video_bbox` 逐帧导出）。
- **与 v0.21.20 协同**：seg 序列化（polygon → COCO `segmentation`）逻辑抽公共函数，单帧（本版本）与 track（v0.21.20 PR4）共用。

## 实现分阶段（PR）

- **PR1 · COCO-seg（单帧 polygon/mask）**：`export_video.py` 加 seg 分支，抽公共 polygon→segmentation 序列化。
- **PR2 · keypoint + OBB**：加 keypoints / OBB 导出分支。
- **验证**：每 PR ① 含对应几何的视频项目导出、下游工具（COCO 可视化 / 训练脚本）读得懂；② bbox 导出（MOT/YOLO/KITTI）零回归；
  ③ 空几何 / 混合几何项目导出不崩。CHANGELOG（Added）+ 版本 bump。

## 不在范围

- track segmentation 导出（video COCO-seg track / DAVIS PNG）→ v0.21.20 PR4/PR5。
- 真·栅格 mask 导出 → 单独立项。

## 风险

- **下游格式兼容**：COCO-seg / keypoint / OBB 须被真实训练/评测链读懂；先对齐图片侧已验证的导出格式。
- **seg 序列化重复**：单帧与 track 若各写一份 polygon→segmentation 会漂移；PR1 抽公共函数是硬要求。
- **混合几何项目**：一个视频项目可能同时有 bbox/polygon/keypoint，导出需按几何类型分派、互不干扰。
