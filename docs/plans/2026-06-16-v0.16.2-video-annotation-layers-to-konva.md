## 3. 设计要点

### 3.1 track 形状复用 vs 新建

- 视频框本质是 box,但带**轨迹语义**:关键帧 vs 插值帧(虚线区分)、遮挡态、轨迹预览连线、ghost 参考框、按 track 派生色(`colors.ts` `getTrackColor`)。
- 决策:**不直接复用 `KonvaBox`**(它含 resize handle/group 外圈等图片专属交互件),而是新建 `VideoKonvaTrackShape`,但**线宽/填充/标签文本全调 `annotationVisual.ts` 纯函数**,保证与图片同源。常量从 `boxVisual.ts` 取。
- 共性后续可抽公共 `<AnnotationRect>` 基元,但本版不强求(避免过早抽象),先把视频跑通。

### 3.2 标签:DOM → Konva Text 的回归点

- DOM 标签白送的能力(字体/抗锯齿/断行/CSS 暗色)在 Konva 要手动等价:
  - 字体:`fontFamily="var(--font-sans)"`(图片 `ImageStageShapes.tsx:139` 已这么用,Konva 读 CSS var 经计算值)。
  - 颜色:类别色经 JS 注入(非 CSS),暗色对比度按 v0.15.27 §5 自检。
  - 断行/截断:Konva Text 无自动断行,长标签按图片现成处理(定宽 + 省略),`annotationVisual.buildLabelText` 统一产出文本。
  - 位置:原 DOM 用 CSS var 算框上/下(`VideoTextLayer.tsx:46-49`),Konva 用 `Label` 的 offset 等价。

### 3.3 scale 抵消替代 non-scaling-stroke

- 旧 SVG 靠 `vectorEffect="non-scaling-stroke"`(`VideoTrackShape.tsx:24`)恒定线宽;Konva 无此,改 `strokeWidth = annotationVisual.strokeWidthFor(selected) / scale`(抄图片 `:93`)。
- 关键帧圆点半径、虚线 dash、issue pin 半径同理全部 `/scale`。

### 3.4 每帧 bbox 来源不变

- track 在当前帧的显示 bbox 仍由 `videoStageGeometry.resolveTrackAtFrame()`(纯逻辑)算出,Konva 只负责画。关键帧/插值/遮挡判定不动。

## 5. 已知风险 / 未尽事项

- **Konva Text 长标签换行**:最易回归;以图片标签为黄金参照,逐字号/长名对照截图。
- **类别色填充对比度**:v0.15.27 已改类别色,Konva 下在亮底视频帧上需复检(沿用 v0.15.27 §5 自检,必要时极淡暗罩 layer)。
- **ghost/邻帧框**:旧栈 ghost 在 InteractionLayer(`:211-218`),本版归入 tracks layer 渲染;真正的「邻帧框交互/请求」属上层逻辑不动。邻帧**绘制**能力此前视频已部分有,迁移保持等价,扩展留 v0.16.3 机会项。
- **本版无交互**:Konva 形状先 `listening=false`,选中态靠 props 传入(选中 id 来自共享 state),不接事件——避免与 v0.16.3 交互改造交叉。

## 6. 验证策略

- **konva-mock 渲染测**:给定一个 track + 关键帧数据,断言 Konva `Rect`/`Circle`/`Line`/`Text` 的几何与样式 props(线宽 /scale、填充 alpha、dash);选中/插值/遮挡态切换断言。
- **视觉设置联动测**:改 `annotationVisual` 入参,断言形状 props 随动(与图片共用纯函数,逻辑测一处)。
- **Playwright 对照**:同帧同 track,新旧栈截图 diff(扣除已知的填充色差异);缩放后线宽恒定。
- **回退**:flag 关走旧栈,旧 SVG 测试全绿。
