# v0.13.8 · 3D 框自动贴合 + RGB 上色遮挡修复

> 状态:待实现(2026-06-03)。
> 计划归属 epic:点云 + 图像联合标注工作台。前序:v0.13.4 投影联动、v0.13.5 三视图框精修(已建 `worldToBox` 几何底座)、v0.13.6 RGB 上色 + 深度联动(已建 `depthmap` 栅格)、v0.13.7 相机悬浮环绕布局。
> 本版收两件事:①「画粗框 → 一键贴合」**标注生产力**(A1),②「RGB 上色穿模背景串色」**视觉真度**(B1)。**纯前端、复用 v0.13.5/0.13.6 既有 geometry,后端零改动、零迁移、零端点**。
>
> **明确非目标(本版不做,留 v0.13.9):跨帧轨迹 / track_id schema / 邻帧标注复制**。`group_id` 当前语义为「同 task 内平等成员同组」(`annotation.py:50` 注释 + `task.py:114` 自增空间),task-scoped 不可复用作 dataset-scoped track,**需要专门切片设计 schema + 迁移 + 端点 + UI**,与本版的纯前端体验项不应混做。

## 背景

v0.13.3 落地 3D 框新建 + PSR 编辑后,实际标注流是「目测大致放一个粗框 → 三视图拖边角精调到贴合点云」。两块痛点至今仍占用户大头时间:

1. **粗框 → 精框的拖动量很大**:刚放置的框尺寸用类别默认(如 car 4.5×1.8×1.5m),实际车体可能 4.2×1.75×1.55m,标注员要在三视图里逐边拖到刚好包住车体点云。**SUSTech POINTS / xtreme1 / CVAT 通行做法是一键 fit:** 框内点云算 AABB → 直接收紧 + 贴地。在 v0.13.5 我们已经实现了 `worldToBox`(把 world 点转入 box-local 坐标系),做这件事的几何底座完全就位。
2. **v0.13.6 RGB 上色背景串色**(自认 MVP 限制):逐点投影到相机像面取像素颜色,**没有 z-test**,后方背景点取到的是前方建筑物的像素 → 视觉上背景被前景"染色",在密集街景里看着像穿模。深度栅格 `depthmap.ts` 已经在 v0.13.6 做了(同版「深度联动」用它画热力图 + hover 读最近点),复用它做 z-test 就把这块"伪 feature"修真。

研究依据:[14-point-cloud-image-fusion.md](../research/14-point-cloud-image-fusion.md);SUSTech POINTS `fit_object` 算子(框内点 AABB + 朝向 PCA)、xtreme1 「Auto Fit」按键。

## 已定决策(2026-06-03)

- **A1 拆三个口径,按钮分清楚,不堆"智能"黑盒**(可单独触发 / 可组合):
  1. **`fit_size`(收尺寸)**:保中心 cx/cy/cz + 朝向 yaw/pitch/roll 不动,只把 sx/sy/sz 收到「box-local AABB + 可配 padding」。最常用,最安全。
  2. **`fit_bottom`(贴地)**:保中心 cx/cy + sx/sy/sz + yaw/pitch/roll 不动,把 cz 下移到「框内最低点 Z = box 下沿」。可独立按,也可与 `fit_size` 组合。
  3. **`fit_yaw`(贴朝向,可选,L1 内做)**:保中心 + 尺寸 + pitch/roll 不动,只把 yaw 转到「框内点云 XY 平面 PCA 主轴」。**风险口径**:点云稀疏 / 框选错时 PCA 主轴可能歪,所以**不进默认连击,只给独立按钮 + 工具栏次级菜单**(标"实验")。
- **A1 触发口径**:工具栏新增「贴合」按钮组 + 默认快捷键 `Q`(默认 = `fit_size + fit_bottom` 连击,因为这是最常用组合);三个原子动作各自在按钮组分按钮里,鼠标 hover 显示快捷键。多选时对每个选中框各执行一次(纯前端循环 + 现有乐观更新批量 PATCH)。
- **B1 z-test 实现策略**:在 `colorize.ts` 的"逐点投影采样像素"循环里,投影命中后,把"该点到相机的深度"与 `depthmap` 栅格在该像素的"最近深度"对比,**深度差超容差(配置:10cm)就判遮挡 → 不上色,保留原色(高度色带)**。深度栅格 v0.13.6 已经按相机 + 帧建一次,接入即用。
- **B1 容差不开 UI**:统一硬编码 10cm(常见 LiDAR 噪声 ~3-5cm,城市目标 10cm 是经验值),不暴露给标注员调参 — 调参成本 > 收益。

## 现状盘点(已就位的地基)

- **`three-d/geometry/box3d.ts`**:`worldToBox(world, psr)` / `boxLocalAabb(points)` —— v0.13.5 三视图为 GPU 裁切建好了 box-local 转换,纯函数已单测;`fit_size` / `fit_bottom` 直接调用,**无需新加几何原语**。
- **`three-d/geometry/depthmap.ts`**:`buildDepthMap(points, calib)` 返回每像素格的最近深度 + 3D 坐标 + 投影像素;`sampleDepthAt(map, u, v)` O(1) 查询。v0.13.6 已经在用,接 colorize 就是新增一个参数。
- **`three-d/geometry/colorize.ts`**:`colorizeByProjection(points, calibs)` 当前签名是「点 + 多相机标定」,**新增可选 `depthMaps: DepthMap[] | null` 参数**,有就跑 z-test、无就降级到 v0.13.6 行为(保持向后兼容,默认关闭遮挡测试时性能不退步)。
- **`PointCloudScene.setPointColors` / `getPointPositions` / `getBaseColors`**:v0.13.6 已暴露,L2 无需改 scene 类。
- **工具栏 + 快捷键**:`ThreeDWorkbench.tsx` 控件浮条已是「按钮 + Tooltip」范式(参见 v0.13.7 状态条 / PSR 浮层),A1 新增按钮组沿用同样的 module css 类。3D 台的本地热键已在 v0.13.4 修复中拆出(`stageKind==="3d"` 时本地处理 `B/V/W/E/R`),`Q` 新加同入口即可。
- **乐观更新 + 批量 PATCH**:`useUpdateAnnotation` 已支持单框乐观更新(v0.13.4);多选批量贴合是「for each selectedId → schedulePatch(psr')」,无并发问题。

## 切片(细化到可实现)

### L0 · 自动贴合内核纯函数 + 单测
新增 `three-d/geometry/autofit.ts`:

```ts
// 三个原子动作,每个返回新 PSR(不变 → 原值);均不修改入参
function fitSize(points: Float32Array, psr: PSR, padding: number = 0.05): PSR
function fitBottom(points: Float32Array, psr: PSR): PSR
function fitYaw(points: Float32Array, psr: PSR): PSR  // 标"实验",PCA 二维主轴
```

- `fitSize`:`worldToBox(points, psr)` → 取 box-local AABB → 新 size = AABB extent + 2×padding,新 center = psr.center + R · ((AABBmin + AABBmax)/2)(因为收尺寸时本地原点可能偏移,要把世界中心补回 box-local 包围盒中心)。
- `fitBottom`:`worldToBox` → 取 box-local Z 最小值 z_min,新 cz = psr.cz + (z_min + sz/2)(把 box 下沿对齐到点云最低点)。仅改 cz,其余完全不动。
- `fitYaw`:box-local XY 平面点 PCA → 主轴角 θ → 新 yaw = psr.yaw + θ。需特判「点数 < N_min(如 20)→ 返回原 psr,不动」防稀疏炸偏。
- 框内空(0 个 inside 点):全部返回原 psr,不动、不抛错。

**`autofit.test.ts` 覆盖**:
- 一个真贴合的轴对齐点云:fit_size 后 size == 点云 AABB extent + 2×padding(toBeCloseTo)。
- 框比点云大:fit_size 收紧;框比点云小:fit_size 扩大;两边对称。
- 旋转 30° 的 box + 旋转 30° 的点云:fit_size 后 size 不变(因为 box-local AABB 跟点云贴合)。
- fit_bottom:点云下沿在 z=0,box 中心 cz=5,sz=2 → 新 cz = 1(下沿到 0)。
- fit_yaw:沿 X 轴拉长的点云,初始 yaw=0 → 新 yaw ≈ 0(已对齐);初始 yaw=π/4 → 新 yaw ≈ 0(转回主轴)。
- 边界:空 points / 全部 outside / 点数 < N_min → 返回原 psr。

### L2 · RGB 上色 z-test 遮挡修复
- `colorize.ts` 改造:`colorizeByProjection(points, calibs, depthMaps?: DepthMap[])`,新增可选 `depthMaps` 参数:
  - 有 depthMaps:对每点投影命中相机时,查 `depthMaps[cam_i]` 在 (u,v) 的最近深度 d_grid;算该点深度 d_point = (extrinsic · point).z;若 d_point - d_grid > **0.10m** 判定被遮挡,跳过该相机候选;所有候选都被遮挡 → 该点不上色(保留 base 高度色带)。
  - 无 depthMaps:保持 v0.13.6 行为(向后兼容,等价于无 z-test)。
- `ThreeDWorkbench.tsx` 调用方:从 `PointCloudScene` 拿 depthMaps(v0.13.6 已建)透传进 `colorize`;UI 上**不新增开关**(上色开 = 自动启用 z-test,不让用户管这种内部细节)。
- **`colorize.test.ts` 新增 3 例**:
  - 给一个 2 点(前 + 后)合成场景 + 1 相机:无 depthMaps → 两个点都被上色(回归 v0.13.6 行为);有 depthMaps → 仅前点上色,后点保留 base。
  - 容差边界:depth 差 = 0.05m(< 容差)→ 上色;= 0.15m → 不上色;= 0.10m 临界 → 不上色(`>` 严格)。
  - 全相机均被遮挡 → 该点 baseColor 原样返回(逐字节比对)。
- **验证**:取真实示例集 `pc-scene-a`,前景车辆遮挡街景:开上色后,**车辆轮廓内的近点取彩色,后方建筑墙面的点保留高度色带**(目测可见的"穿模感"消失)。
- **性能口径**:深度栅格已建一次/帧/相机,z-test 是每点每相机一次 O(1) hash 查询,新增开销在 1e6 × 3 量级是 10ms 级,主线程仍可接受;不进 worker 化(留 v0.14.x)。

## 风险

- **fit_size padding 默认值**(0.05m = 5cm)需要在示例集 `pc-scene-a` 上目测调一次:太大 → 框松、和点云有缝;太小 → 框压在点云上、视觉拥挤。**预案**:跑 L1 时浏览器实测 3-5 个车,定一个,不暴露给用户调。
- **fit_yaw PCA 在框选过大/过小时方向反转 180°**(主轴不分前后):本版**仅标实验、无快捷键**,标注员误用代价只是再按一下转回去,可接受。彻底解法需要"已知车头朝向先验"——配合 v0.13.9 跨帧轨迹做。
- **z-test 在标定不准的相机上会反向恶化**:外参偏差大 → 前景点投到错位像素 → 深度栅格记错位的深度 → 本该上色的点被误判遮挡。本版假设 `pc-scene-a` 标定可信(已经过 v0.13.4-0.13.7 实测);标定信任度未来要做的话,出在「上色调试浮窗」单独的工具(非本版 scope)。
- **多选批量贴合发 N 个 PATCH 并发**:`useUpdateAnnotation` 当前单条乐观更新,N 条并发理论上现有通路可承担(每条独立 id);若实测出现 toast 风暴(N 个失败提示),L1 末尾做一次降噪(合并 toast),否则不动。

## 非目标(本版不做,留 v0.13.9+)

- **跨帧轨迹 / `track_id` schema / 邻帧标注复制**:需要 schema 设计(dataset-scoped vs 全局 UUID)、迁移、相邻 task 查询端点(可能复用 `sequence_order`)、前端会话/帧间状态。完整切片,单独立 v0.13.9 计划。
- **fit_size 多类别先验**(类别默认 padding / 类别 min-size):需要分类标签 → 阈值表,本版统一 5cm padding。
- **遮挡上色 worker 化**:本版 z-test 主线程开销可接受(<10ms 量级),worker 化作 0.14.x 性能切片打包做。
- **fit_yaw 高级化**(车头朝向先验 / 基于跟踪历史):依赖跨帧。
- **「实验」标志 fit_yaw 的产品化**(进入快捷键 / 默认连击):需要更多数据集实测,本版仅工具栏按钮起步。
