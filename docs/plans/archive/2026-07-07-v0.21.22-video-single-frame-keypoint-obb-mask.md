# v0.21.22 · 视频单帧 keypoint + rotated-box(OBB) + mask

状态：**计划（2026-07-07）**。[视频单帧工具 epic](2026-07-07-video-single-frame-tools-epic.md) 第二版本。在 v0.21.21 建立的
单帧几何地基上，补齐**其余三种非 AI 几何**：keypoint（COCO 骨骼）、rotated-box(OBB)、mask 笔刷。**依赖 v0.21.21**（schema
变体范式 / 视频栈渲染 / 工具交互三件套已就位）。**不含 AI 工具（→ v0.21.23）、不含 track。**

## 动机 · 三种几何各有独立复杂度（带证据）

- **keypoint**：图片侧 `KeypointTool.ts` 依赖 `keypoint_schema`（节点+骨骼，`ToolBinding.keypoint_schema` `_jsonb_types.py:328`），
  草稿句柄 `KeypointDraftHandle`（`tools/index.ts:102-107`：放满 `nodeCount` 自动 commit），渲染含骨骼连线（`ImageStageShapes`）。
  视频侧零支持。
- **rotated-box(OBB)**：图片 `RotatedBboxTool.ts` + `DragInit.rotateBox`（`tools/index.ts:86`，旋转手柄拖拽）+
  `RotatedBboxGeometry`（`_jsonb_types.py`，含 `angle`）；视频栈 `videoKonvaInteraction.ts` 无 `rotateBox` 分支、渲染无旋转矩形。
- **mask**：图片 `MaskTool.ts` + `useMaskEditor`（笔刷 `DragInit.maskBrush` `tools/index.ts:81`）+ 提交时**矢量化转 polygon**
  （`mask_to_multi_polygon`，图片侧无栅格存储，见 v0.21.20 缺口 4）；视频侧有 `useVideoBitmapCache`/`CanvasDrawingLayer` 但无
  单帧 mask 编辑→矢量化管线。

## 定稿决策（拟）

### keypoint
- schema：`VideoKeypointGeometry`（`type="video_keypoint"`+`frame_index`+`points: Keypoint[]`），并入 `Geometry` 联合。
- 复用 `KeypointTool` + `KeypointDraftHandle`。
- **工具单位（✅ epic 决策 2 破例）**：单帧几何沿用 bbox 单位子开关，但 keypoint 需 `keypoint_schema`（`ToolBinding.keypoint_schema:328`）——
  **让 bbox 工具单位携带 `keypoint_schema`**（唯一破例，因几何共享 bbox 单位）；`VideoModesConfig` 加 `keypoint` 开关。项目配置 UI
  需在视频 bbox 单位下暴露 keypoint 骨骼配置。
- 渲染：节点 + 骨骼连线（复用 epic 路 B 的共享渲染器 keypoint 分支，或视频栈新增）。

### rotated-box(OBB)
- schema：`VideoRotatedBboxGeometry`（`type="video_rotated_bbox"`+`frame_index`+cx/cy/w/h/`angle`）。
- 交互：视频栈接 `DragInit.rotateBox`（`tools/index.ts:86`）旋转手柄；复用 `RotatedBboxTool`。
- 渲染：视频栈旋转矩形分支。

### mask（矢量化，不引栅格）
- **✅ epic 决策 3：单帧 mask 先矢量化**——笔刷编辑（复用 `useMaskEditor`/`MaskTool`）→ 提交时 `mask_to_multi_polygon`
  → 落 `video_polygon`/`video_multi_polygon`（复用 v0.21.21 的 polygon 变体，或新增 multi_polygon 变体）。**不引 per-frame 栅格
  存储**（与 v0.21.20 缺口 4 结论一致，真·栅格 mask 单独立项）。
- mask 编辑底图取当前帧 `ImageBitmap`（`useVideoBitmapCache`）。

## 实现分阶段（PR）

- **PR1 · keypoint**：schema 变体 + 工具单位 `keypoint_schema` + 交互（复用 `KeypointDraftHandle`）+ 渲染（节点/骨骼）+ 提交。
- **PR2 · rotated-box(OBB)**：schema 变体 + 视频栈 `rotateBox` 交互 + 旋转矩形渲染 + 提交。
- **PR3 · mask 笔刷**：接 `useMaskEditor`/`MaskTool` + 当前帧底图 + 矢量化转 polygon 落库。
- **验证**：每 PR E2E ① 对应几何画/编辑/带 `frame_index`/归一化；② 切帧只在所属帧显示；③ 前序几何（bbox/polygon/polyline）
  + track 零回归；④ keypoint 骨骼连线正确、OBB 角度正确、mask 矢量化轮廓贴合。CHANGELOG（Added）+ 版本 bump。

## 风险

- **keypoint schema 依赖项目配置**：视频工具单位无 `keypoint_schema` 时工具不可落点（对齐图片 `nodeCount=0` 语义
  `tools/index.ts:104`）；需项目配置 UI 支持。
- **OBB 旋转手柄在视频栈的坐标系**：旋转角与归一化坐标换算须对齐图片 `RotatedBboxTool`，错则角度漂移。
- **mask 矢量化容差**：沿用图片 `mask_to_multi_polygon` 的 simplify 容差（见 research 13）；视频逐帧数据量放大，需注意 JSONB 体积。
