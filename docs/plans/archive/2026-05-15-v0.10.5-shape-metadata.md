# v0.10.5 — 图片工作台形状元数据一等态（M4-β）

> 对应 roadmap：[ROADMAP/archive/2026-05-12-image-workbench-optimization.md](../../ROADMAP/archive/2026-05-12-image-workbench-optimization.md) Wave γ I15。
> 父 epic：[2026-05-14-image-workbench-wave-beta-gamma-epic.md](2026-05-14-image-workbench-wave-beta-gamma-epic.md)。
> ✅ **已落地于 commit `41b69be`（2026-05-15）**。

## Context

CVAT 把 `z_order` / `lock` / `hidden` / `outside` / `occluded` 作为 shape 一等状态位，工作台快捷键与右键菜单可直接切。我们之前只有前端 transient lock / hidden（仅 UI 态，刷新即丢），DB 字段全空白。本子版本把 4 个状态位升级为持久化 + UI 控件 + 快捷键 + 渲染层消费，是 v0.10.4 epic 的第 2/4 子版本。

## Scope

### 后端

- 新增 alembic [`0065_annotation_shape_metadata.py`](../../apps/api/alembic/versions/0065_annotation_shape_metadata.py)：annotations 表加 `z_order int default 0` + `is_locked` / `is_hidden` / `is_occluded` 三个 `bool default false`，全部 not null。
- 改 [`db/models/annotation.py`](../../apps/api/app/db/models/annotation.py)：加 4 mapped_column。
- 改 [`schemas/annotation.py`](../../apps/api/app/schemas/annotation.py)：`AnnotationOut` 直传 + `AnnotationUpdate` 接受 partial PATCH。
- 改 [`services/annotation.py`](../../apps/api/app/services/annotation.py)：`update()` 方法签名加 4 kwargs，只在非 None 时赋值。
- PATCH 路径（[`api/v1/tasks.py:858`](../../apps/api/app/api/v1/tasks.py)）已字段级，`**fields` 自动透传，**无需端点改动**。

### 前端渲染

- 改 [`stage/ImageStage.tsx`](../../apps/web/src/pages/Workbench/stage/ImageStage.tsx)：新增 `visibleSortedUserBoxes` memo：先 filter `!is_hidden`，再按 `z_order` ASC 排序（同 z_order 保持原数组顺序作 tie-breaker，避免选中态闪烁）；user 层 `.map` 走它。
- 改 [`stage/ImageStageShapes.tsx`](../../apps/web/src/pages/Workbench/stage/ImageStageShapes.tsx)：`KonvaBox` / `KonvaPolygon` 新增 `occluded` prop → 触发 `dash=[4,3]/scale` + `opacity=0.5`；与 `selfIntersect` 红色虚线视觉互斥（selfIntersect 优先）。
- 改 `ImageStage` 编辑态门控：`isPrimarySingleSelect` 与 `editable` 在 `is_locked` 时为 false → 不渲染 resize/move/vertex handle；polygon 同步。

### BoxListItem 三个 toggle

- 改 [`stage/BoxListItem.tsx`](../../apps/web/src/pages/Workbench/stage/BoxListItem.tsx)：用户态卡片新增 3 个 toggle 按钮（`eye` / `eyeOff`、`lock` / `unlock`、`circleDot` for occluded），`aria-label` + `title` 含快捷键提示；active 态不透明，否则 55% 透明。
- 新 prop `onToggleFlag?: (flag) => void` 仅在非 AI 框时渲染。

### 字段级 PATCH 入口

- 改 [`state/useWorkbenchAnnotationActions.ts`](../../apps/web/src/pages/Workbench/state/useWorkbenchAnnotationActions.ts)：新增 `handlePatchShapeFlag(id, flag, value)`，复用现有 `mutations.update` + `history.push` + 离线 enqueue 兜底；写入 `update` 历史 kind 支持撤销重做。

### 快捷键 L / H / O / `[` / `]`

- 改 [`hotkeys`](../../apps/web/src/pages/Workbench/state/hotkeys.ts) HOTKEYS 表：新增 3 条 L/H/O 描述，更新 `[`/`]` 描述为「选中态：z_order ±1；否则 threshold」。
