### 1.3 不在本版本

- 多边形闭合距离、笔刷半径范围、Minimap 阈值等中低价值常量:先观察本版字段的实际使用率再决定。
- 视频 / 点云字段(v0.15.5 / v0.15.6)。
- `afterBoxCreate` 的第三模式「画完继续画同类不选中」:与现有 draft/选中状态机耦合深,等 `reuse_active` 验证后再议。

### 1.4 成功判据

1. **默认零回归**:不动设置的用户,画框/吸附/缩放/渲染行为与 v0.15.3 完全一致(所有默认值 = 原硬编码值)。
2. `afterBoxCreate=reuse_active` 时:有 activeClass → 画完直接落库并 toast 类别名;无 activeClass → 回退弹 ClassPickerPopover(不静默产出 unknown,守住 `useWorkbenchAnnotationActions.ts:375` 的「unknown 不污染最近类」约定)。
3. 抽屉里拖 `snapThresholdPx` / `fadedOpacity` / `maskOverlayOpacity`,画布行为/渲染**实时**变化。
4. `confirmDelete=multi_only` 时单删不弹窗、多选删弹确认;`always` 时均弹。
5. SAM 输出模式:无项目默认的项目里,选 box → 关浏览器重开 → 仍为 box;有项目默认的项目仍尊重项目默认。
6. `uv run pytest -q` / `pnpm test` / `pnpm lint` 全绿。

## 3. 设计要点

### 3.1 配置注入方式

`ImageStage` 已从壳层接收 rendering 配置(smoothImage 等同款路径),新字段沿同一 props/context 通道下发,**不**让 stage 直接 import settings store——保持 stage 可测试性(现有测试以 props 驱动)。

### 3.2 `afterBoxCreate=reuse_active` 的语义边界

- 「当前类别」= `activeClass`(ClassPalette 选中项);沿用后**仍写入最近类别**(与弹窗确认同路径),保证 recent 列表语义一致。
- 快捷改类不受影响:落库后仍可经上下文菜单/快捷键改类(v0.10.33 canvas context menu 已有)。
- AI 产出的框不走此分支(AI 框类别来自模型,本设置只管手画)。

### 3.3 删除确认弹窗

复用现有确认弹窗范式(如 `SkipTaskModal` 的轻量 Modal 壳),不引新依赖;`multi_only` 判定 = 本次删除影响 annotation 数 > 1(含批量选中删除)。undo 路径不变,确认只是前置闸门。

### 3.4 SAM 输出模式记忆键

`workbench.{userId}.sam.outputMode:{projectId}`(沿用 v0.13.10 userId 分桶约定,避免共享机器串台)。只记「用户显式点过的」,初始智能默认不回写。

## 5. 已知风险 / 未尽事项

- **`fadedOpacity` 散布 4 处同字面量**(`ImageStageShapes.tsx:105/253/411/545`):先抽模块级常量再参数化,避免漏改;grep 验证无残留 `0.35` 字面量(faded 语义处)。
- **`reuse_active` 误标风险**:沿用类别画错了要手动改类。toast 显示类别名 + 文档明确说明;默认仍 `pick_class`,选择权在用户。
- **`recentClassesLimit` 缩小**时已存 localStorage 列表截断:读侧 slice 即可,无迁移。
- ClassPickerPopover 关闭原因枚举(`ClassPickerCancelReason`)与 reuse 分支的交互:reuse 分支根本不挂 popover,确认无状态泄漏(draft 清理路径单测覆盖)。

## 6. 验证策略

- **优先级矩阵单测**(samTextOutput):项目默认 × session × local × 智能默认 共 8 组合断言。
- **行为开关单测**:afterBoxCreate 两态、confirmDelete 三态,各覆盖正反例。
- **参数透传测**:ImageStage 收到非默认 snapThresholdPx 后,吸附判定边界(7px 不吸 / 8px 吸 → 改为读 props 值)。
- **手工端到端**:抽屉切 `reuse_active` → 连画 3 框零弹窗;切回 `pick_class` 行为复原;暗色模式下抽屉新控件无硬编码颜色(`pnpm lint:css-tokens`)。
