# v0.21.21 · 视频单帧几何地基 + polygon/polyline

状态：**计划（2026-07-07）**。[视频单帧工具 epic](2026-07-07-video-single-frame-tools-epic.md) 首个版本。建立视频**单帧
非 bbox 几何**的全链地基（schema 变体 / 视频栈几何渲染 / 工具交互 / 提交层 / 工具栏），并用 **polygon + polyline** 两种几何
端到端跑通验证。**不含 keypoint/OBB/mask（→ v0.21.22）、不含 AI 工具（→ v0.21.23）、不含 track（正交轴 B，见 v0.21.20）。**

**本版本 PR1 落地已定架构决策**（epic 决策 1：**路 B 务实切分**）——复用 `tools/*` 工具单元 + 抽共享几何渲染器 + 视频栈薄
封装 DragInit 派发，不统一整个 ImageStage。

## 动机 · 视频单帧只有 bbox（带证据）

- 后端：视频单帧几何仅 `VideoBboxGeometry`（`_jsonb_types.py:408-422`，`type`+`frame_index`+x/y/w/h），`Geometry` 联合
  （`:616-628`）无 `video_polygon`/`video_polyline`（全仓 grep 0 命中）。
- 前端工具栏：`VIDEO_TOOLS` 硬编码 `select`/`box`/`track` 三项（`ToolDock.tsx:81-84`），`VideoTool` 类型同（
  `useWorkbenchState.ts:31`）。
- 前端交互：`videoKonvaInteraction.ts` 只有 bbox `draw`/`move`/`resize`（`:49-104`），无 polygon 草稿。
- 前端渲染：`VideoKonvaTrackShape.tsx` 78 行只 `<Rect>`；`VideoKonvaStage.tsx onCreate:95` 签名硬编码 `{x,y,w,h}`。
- 前端提交：`buildVideoCreatePayload`（`useVideoAnnotationActions.ts:79-110`）只认 `video_bbox`/`video_track_bbox`。
- 对照：图片侧 `PolygonTool.ts`/`PolylineTool.ts` 已是纯 `ToolPointerContext → DragInit` 工具单元，`ImageStage.tsx:894`
  的 `onCommitPolygonGeometry` 消费 polygon 草稿——**可复用的现成件**。

## 定稿决策（拟）

### 0 · 架构：共享工具单元 + 抽几何渲染（✅ epic 决策 1：路 B 务实切分）
- **复用 `tools/PolygonTool`/`PolylineTool`**（零改，无 stage 依赖）——视频栈接入这两个工具单元的 `polygonDraft` 句柄
  （`tools/index.ts:88-96 PolygonDraftHandle`）。
- **抽一层几何 shape 渲染**（新 `stage/geometryShapes/` 或复用 `ImageStageShapes` 的 `<Line>` 分支）供视频栈调用；视频专属
  帧过滤 / 坐标换算胶水留在 `VideoKonvaStage`。**不统一整个 ImageStage**——DragInit 派发在视频栈薄封装。

### 1 · schema：加两个单帧变体
- `_jsonb_types.py`：新增 `VideoPolygonGeometry`（`type="video_polygon"`+`frame_index`+`points: list[[x,y]]` 归一化）、
  `VideoPolylineGeometry`（`type="video_polyline"`，不闭合），并入 `Geometry` 联合（`:616`）。载荷照图片
  `PolygonGeometry`/`PolylineGeometry` + `frame_index`。**坐标红线**：points 归一化 [0,1]。

### 2 · 交互：视频栈接 polygon/polyline 草稿
- `videoKonvaInteraction.ts` / `VideoKonvaStage`：`videoTool==="polygon"|"polyline"` 时走 `polygonDraft` 逐点落点（复用图片
  `PolygonDraftHandle`），Enter/双击闭合提交；不经 bbox 的 `draw`/`resize` 分支。

### 3 · 渲染：视频栈加 `<Line>`
- 当前帧的 `video_polygon`/`video_polyline` 按帧过滤后渲染（镜像 `VideoKonvaStage:328` 对 `video_bbox` 的帧过滤），
  `<Line closed>` / `<Line>`（复用共享渲染器或视频栈新增分支）。

### 4 · 提交：扩 create/update payload
- `buildVideoCreatePayload`（`:79-110`）加 `video_polygon`/`video_polyline` 分支：`geometry={type,frame_index,points}`；
  `buildVideoUpdateCommand`（`:114-119`）加对应 update。

### 5 · 工具栏 + 工具单位（✅ epic 决策 2：沿用 bbox 单位扩子开关）
- `VIDEO_TOOLS`（`ToolDock.tsx:81-84`）加 `polygon`/`polyline` 两项 + `VideoTool` 类型（`useWorkbenchState.ts:31`）扩。
- **可用性门控走 bbox 单位子开关**：`VideoModesConfig`（`_jsonb_types.py:300-318`）从 `{box, track}` 扩加 `polygon`/`polyline`
  布尔位；`_at_least_one_enabled` 校验（`:312-318`）放宽为「至少一个几何开关可用」。polygon/polyline 共享 bbox 单位的
  classes/attribute_schema，**不建独立 `ToolBinding`**。ToolDock 的 `visibleVideoTools` 过滤（`ToolDock.tsx:163-167`）同步扩。

## 实现分阶段（PR）

- **PR1 · 架构决策 + schema + 渲染**：落地共享/复刻决策；加两个 schema 变体（后端）；视频栈 `<Line>` 渲染（先只读渲染已有
  数据，可用 seed 造数据验证）。
- **PR2 · 交互 + 提交**：视频栈接 polygon/polyline 草稿 + create/update payload；工具栏加两项。端到端：画 → 落库 → 重拉可见。
- **验证**：E2E ① 视频某帧画 polygon/polyline、归一化坐标正确、带 `frame_index`；② 切帧后只在所属帧显示；③ `video_bbox`
  单帧 / bbox track 零回归；④ 若走共享渲染器，图片侧 polygon/polyline 零像素回归。CHANGELOG（Added）+ 版本 bump（§10 全量同步）。

## 风险

- **架构岔路未定则本版本画不准**：PR1 第一件事必须落地共享 vs 复刻。
- **平行栈帧过滤易漏**：`video_polygon` 帧过滤须与 `video_bbox` 完全一致（`VideoKonvaStage:328`），否则跨帧串显。
- **共享渲染器回归图片**：走路 B 时图片侧 polygon/polyline 须逐一验零回归。
