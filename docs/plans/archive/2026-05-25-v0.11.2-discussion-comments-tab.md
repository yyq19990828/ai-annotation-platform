# v0.11.2 · DiscussionPanel comments tab

> [epic 索引](2026-05-25-v0.11-annotation-feedback-convergence.md) · B 组（前端）· 依赖：v0.11.1 骨架

## 目标

把现有 `CommentsPanel` 的评论能力迁入 DiscussionPanel 的 comments tab，统一标注级与任务级评论的展示与提交入口。

## 前端改动

- comments tab 内容：
  - `annotationId` 非 null → **标注级评论**（现有 `useAnnotationComments` / `useTaskCommentsInfinite` 既有路径）。
  - `annotationId` 为 null → **任务级评论**：复用 v0.10.20 已落的 `useFeedbacks({ kind: "comment", anchor_type: "task" })` + `useTaskCommentsInfinite`，按 `created_at desc` 合并显示（feedback-source 行带 `__source` 标记，与现 `CommentsPanel` 一致）。
  - 复用 `CommentInput` 子组件提交（标注级走 annotation_comments、任务级走 `useCreateFeedback`）。
- 仍在 `flags.discussionPanel` 后；旧 `CommentsPanel` 路径保留（v0.11.5 才删）。

## 验证

- `pnpm --filter web typecheck` + `lint:css-tokens`。
- flag on 走查：
  - 选中某框 → comments tab 显示该标注评论，可提交。
  - 不选框（annotationId=null）→ 显示任务级评论（合并两源），可提交任务级评论。
- dark mode 走查。

## 回退

flag off 即回退到旧 `CommentsPanel`。

## 备注

合并显示逻辑与现 `CommentsPanel` 等价，本切片只是搬到常驻面板 + 支持 annotationId=null 的任务级上下文。**不**改后端契约（端点沿用 v0.10.19/0.10.20 已定型的 POST /feedbacks）。
