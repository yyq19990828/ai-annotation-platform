# v0.17.2 · 原语替换 wave 2(交互原语 + 退役全部 ui/ module.css)

> 规划日期 2026-06-19 · 分支 `UI-refactor` · 属 [v0.17.x 全量迁移 Epic](2026-06-19-v0.17.x-ui-shadcn-migration-epic.md) 阶段 2。
> 前置:v0.17.1 已把 Button/Badge/Card/Icon 改为 shadcn 适配层(零调用点 churn)。
> 设计 token / 语义色见 [设计系统规范](2026-06-19-v0.17.0-ui-design-system.md)。

---

## 1. 目标与范围

退役 `components/ui/` **剩余全部 16 个 `*.module.css`**,把交互原语的行为兜底交给 Radix(shadcn),数据可视化组件的样式从 module.css 改写为 Tailwind。延续 v0.17.1 的**适配器策略:保留各组件 prop API + import 路径 → 调用点零改动**。

**16 个组件分两类**:
- **A 类(9 个,有 shadcn 等价物)**:`Modal Toast Switch TabRow SearchInput Avatar DropdownMenu ContextMenu Tooltip` → 内部委托给对应 shadcn 原语(Radix 兜底焦点/键盘/a11y)。
- **B 类(7 个,无 shadcn 等价物,纯样式/SVG)**:`ProgressBar StatCard RadialProgress Sparkline Histogram SectionDivider AssigneeAvatarStack` → 内部 module.css → Tailwind className 改写,逻辑/SVG 不动。

---

## 2. 关键决策:对 Epic 阶段 2「删 ui/ 整目录」的细化

Epic 阶段 2 原设想:引用归零 → 删 `ui/` 整目录。**本版改为**:

> **`ui/` 降级为 shadcn 薄适配层;本版退役其全部 16 个 module.css(真目标);物理删目录 + repoint 全站 300+ import 推迟,合并到 v0.17.7 收口统一 codemod。**

**理由**:① 适配器是稳定的内部组件门面(`@/components/ui/*`),无 CSS 债,留着无害且是常见架构;② repoint 300+ import 是纯机械 churn,集中在末版一次做(可脚本化 + typecheck 兜底)远比本版混进交互原语重写更安全;③ 与 v0.17.1 把「视觉/行为改动」与「机械 import 搬迁」分离的原则一致。

**退役口径**:`-16 module.css`(epic §6 表记 v0.17.2「-20」是含 Button/Badge/Card/Icon 的旧口径;那 4 个已在 v0.17.1 退役,本版退剩余 16,合计 20。Epic 表后续同步)。

## 3. A 类:两个硬骨头(Modal / Toast)

### 3.1 Modal(43)→ Radix Dialog

旧 API:`{ open, onClose, title?, width=560, children }`,自管 portal + overlay + Esc + body lock。
**方案**:保留该 API,内部改用 `radix-ui` 的 `Dialog`**原语**(`Dialog.Root/Portal/Overlay/Content/Close`),**不用** shadcn 的 `Dialog` 包装(其 API 是 Trigger/Content 组合式,且 `width` 不便注入)。这样:① 43 处调用零改动;② 焦点陷阱 / Esc / 滚动锁 / `aria-modal` 由 Radix 兜底(去掉手写 `useEffect` Esc + body overflow);③ `width` 动态值 → `Dialog.Content` 是 forwardRef,用 `useElementStyle` 注入 `max-width`(绕 eslint inline-style)。样式用 Tailwind 复刻 shadcn dialog 观感(`bg-card rounded-xl border shadow-lg` + overlay `bg-black/50`,overlay 阴影特例 rgba 允许)。关闭按钮复用 `<Icon name="x">`。
删 `Modal.module.css`。

### 3.2 Toast(useToastStore,~104)→ sonner

旧:`useToastStore.push({ msg, sub?, kind? })`(kind ∈ `success|warning|error|""`),`<ToastRack/>` 渲染栈(挂在 `App.tsx` L184/L225 两处)。
**方案**:
- 保留 `useToastStore` 导出与 `push` 签名(~104 调用点零改动)。`push` 内部改为委托 sonner 的 `toast()`:`success→toast.success`、`warning→toast.warning`、`error→toast.error`、`""→toast`;`msg→` 主文案、`sub→{ description }`。TTL(error 6s / warning 4.5s / 其它 3.5s)→ sonner `duration`。删除 `toasts` 数组 + `setTimeout` 自管逻辑(sonner 接管)。
- `ToastRack` → 改为渲染 v0.17.0 已落地的 `<Toaster/>`(`shadcn/ui/sonner`,已接 `useTheme().resolved`)。`App.tsx` 两处 `<ToastRack/>` 换 `<Toaster/>`(或让 `ToastRack` 内部直接 `return <Toaster/>`,App.tsx 都不用改 —— **优先后者**,零 App 改动)。
- 删 `Toast.module.css`;`Icon` 依赖随之移除。

> `useToastStore` 仍是 zustand store(`push` 仍可 selector 取),只是 `push` 副作用换成 sonner;保持 store 形态避免动 `const push = useToastStore(s=>s.push)` 这类调用点。

### 3.3 A 类其余 7 个 → shadcn 委托(保 API)

| 旧组件(引用) | shadcn 原语 | 适配要点 |
|---|---|---|
| `Switch`(6) | `switch` | `{checked,onChange,disabled,label,title,data-testid}`:内部 `<Switch checked onCheckedChange={onChange}>` + 可选右侧 `<label>`。UA 无关(Radix 渲染 button,但 shadcn switch 自带完整 class,无 UA 漏样)。 |
| `TabRow`(11) | `tabs` | `{tabs:string[],active,onChange}`:映射 `Tabs value={active} onValueChange` + `TabsList/TabsTrigger`。 |
| `SearchInput`(8) | `input` | `{placeholder,value,onChange,width?,kbd?,onClick?,readOnly?}`:`input` + 内嵌 `lucide Search` + 右侧 `kbd`。**⚠ UA 坑**:原生 `<input>` 在非 .tw-scope 老页面漏 UA 边框/内边距 → shadcn input class 已含 `border bg-transparent`,但需确认 `border-border` 色(同 v0.17.1 Button 基线教训)。`width` 动态 → useElementStyle。 |
| `Avatar`(19) | `avatar` | `{initial,size,style}`:`Avatar` + `AvatarFallback`{initial};size sm/md/lg → `size-6/8/10`。`style` → useElementStyle。 |
| `DropdownMenu`(10) | `dropdown-menu` | **较复杂**:旧 API 是 render-prop(`trigger(ctx)` + `items`/`content` 双模式 + align/minWidth/zIndex/panelStyle)。Radix `DropdownMenu` 受控映射:`trigger` → `DropdownMenuTrigger asChild`、`items` → `DropdownMenuItem` 列表、`content` 模式 → 直接塞 `DropdownMenuContent`。保留 render-prop 签名以零 churn(10 处)。**本组件单独一个 commit,重点测**。 |
| `ContextMenu`(4) | `context-menu`(或复用 dropdown 定位) | `{open,x,y,items,onClose}` 是**坐标驱动**(右键弹),与 Radix `ContextMenu`(包裹 trigger)范式不同。可用 Radix `DropdownMenu` + 虚拟定位锚点(`x,y`)实现,或保留手写定位仅换样式。**评估后择一,单独 commit**。 |
| `Tooltip`(3) | `tooltip` | `{name,desc?,hotkey?,side?,delay?,children}`:`Tooltip`(需 `TooltipProvider`,App 根挂一次)+ `TooltipTrigger asChild`{children} + `TooltipContent`{name/desc/hotkey 三行}。 |

## 4. B 类:7 个数据可视化组件(module.css → Tailwind,逻辑不动)

无 shadcn 等价物,**只改皮(样式来源)不改 SVG/计算**。多数 module.css 很薄(颜色靠 props 传入)。

| 组件(引用) | 退役要点 |
|---|---|
| `ProgressBar`(12) | **不用 shadcn progress**(旧组件三层叠条:底 track + `inProgressValue` 副条 + `value` 主条 + `aiValue`)。把 module.css 的轨道/填充改成 Tailwind(`bg-muted` 轨 + 语义色填充),`color` prop 仍可覆盖(arbitrary color 会触 tw-tokens warning → 评估是否改 prop 为语义枚举,或局部豁免)。 |
| `StatCard`(11) | 设计 §5 范式(中性卡 + 彩色图标片 + trend + sparkline)。`{icon,label,value,trend,sparkValues,sparkColor,hint}` → 复刻 `/dashboard-next` 的 StatCard 组合。 |
| `RadialProgress`(2) / `Sparkline`(4) / `Histogram`(3) | SVG 渲染,颜色靠 props。module.css 多为容器/文字样式 → Tailwind 替换;SVG 逻辑不动。 |
| `SectionDivider`(3) | `{label,hint}` 纯排版 → Tailwind(`text-xs font-medium text-muted-foreground` + 分隔线)。 |
| `AssigneeAvatarStack`(6) | 头像叠层 → 复用上面迁好的 `Avatar` + Tailwind 负 margin 叠放。 |

## 5. 执行顺序(按 commit-group,逐组验证)

地基→简单→复杂→硬骨头,每组一 commit,组内 typecheck+lint+相关单测绿后再下一组:

1. **G1 简单 shadcn 委托**:Switch / TabRow / Avatar / Tooltip(+ App 根挂 `TooltipProvider`)。
2. **G2 input 类**:SearchInput(注意 UA 坑)。
3. **G3 B 类纯样式**:SectionDivider / Sparkline / Histogram / RadialProgress / ProgressBar / StatCard / AssigneeAvatarStack。
4. **G4 Modal → Radix Dialog**(43 处,重测对话框开合/Esc/焦点)。
5. **G5 Toast → sonner**(useToastStore 委托 + ToastRack→Toaster;全站 toast 冒泡验证)。
6. **G6 DropdownMenu / ContextMenu**(最复杂,render-prop + 坐标定位,重测)。

> 也可按风险合并成 2-3 个提交;关键是 Modal/Toast/Dropdown 各自独立、可单独回退。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| **UA 默认样式漏出**(v0.17.1 教训) | SearchInput(`input`)、Modal close(`button`)等原生元素在非 .tw-scope 下需带 preflight 等价基线(`appearance-none border-0 border-border bg-transparent` / input 同理);shadcn input/switch 自带 class 多数已覆盖,逐个核对 computed border/bg。 |
| Modal 改 Radix 后焦点/滚动行为变化 | Radix 兜底优于手写;重测 43 处典型(表单弹窗、确认框、抽屉式);保留 `width`。 |
| Toast 换 sonner 后样式/位置/堆叠变化 | sonner Toaster 已接主题;确认位置(默认右下)与设计一致,必要时配 `position`/`richColors`;kind→sonner 类型映射核对。 |
| DropdownMenu render-prop / ContextMenu 坐标定位与 Radix 范式不符 | 保留原 API 签名,内部尽量用 Radix;ContextMenu 坐标驱动若 Radix 不便,保留手写定位只换样式。各自独立 commit,重测。 |
| ProgressBar `color`/Sparkline `sparkColor` 等 prop 传任意色 → tw-tokens warning | 优先把 color prop 收敛为语义枚举(sky/emerald/...);确需任意色的 SVG `fill`/`stroke`(非 className)不在门禁扫描面,问题仅在 className,逐个评估豁免。 |
| 一次性 16 个组件 churn 大 | 按 §5 分 6 组提交,逐组验证可回退;Modal/Toast/Dropdown 隔离。 |
