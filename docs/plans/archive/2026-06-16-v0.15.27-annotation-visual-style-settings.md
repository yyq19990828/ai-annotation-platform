> 规划日期 2026-06-16 · 范围:把图片与视频工作台里散落、且**两端各写各的**标注视觉常量(标签字号、线宽、闭合形状填充透明度)收敛成 `common.*` 共享设置;并把「显示框标签」从二态 toggle 升级为三态显隐,新增标签内容多选与选中态独立填充透明度。Epic 见 [`2026-06-11-v0.15.x-workbench-settings-epic.md`](2026-06-11-v0.15.x-workbench-settings-epic.md)。

> **前置依赖(硬)**:v0.15.3(四子树 schema + 字段注册表 + 设置抽屉)、v0.15.4(已落 `image.showBoxLabels` / `image.fadedOpacity` / `image.maskOverlayOpacity`,本版在其基础上改造)。

## 1. 背景与目标

### 1.1 痛点盘点(全部已核对源码,2026-06-16)

图片与视频两条工作台对同一类视觉属性**各自硬编码、且值与机制都不一致**,三层分歧:

| 属性 | 图片(`ImageStageShapes.tsx`,Konva) | 视频(SVG `<rect>` + DOM 标签) | 分歧层级 |
|---|---|---|---|
| 标签字号 | `boxVisual.ts:1` `BOX_LABEL_FONT_PX=12`,渲染 `/scale` 跟画布缩放 | `VideoTextLayer.tsx:53` 读**同一常量** 12,但 DOM 固定 CSS px | 参数已共用;**渲染机制不同**(缩放 vs 固定 px) |
| 标签显隐 | `image.showBoxLabels` 二态 toggle(`ImageStage.tsx` 8 处 `showLabel=`) | **恒显**,无开关 | 图片有开关、视频没有 |
| 线宽 | `sw=(selected?2:1.5)/scale`(`:93/225/395/545/697`) | `strokeWidth={selected?3:2}`(`VideoTrackShape.tsx:22`,`non-scaling-stroke`) | **参数值不同**(1.5/2 vs 2/3)+ 机制不同 |
| 闭合形状填充 | `hexToRgba(color, isAi?0.08:0.07)`(`:109/261/423/558`) | `rgba(255,255,255,0.08/0.03)`(`VideoTrackShape.tsx:20`) | **语义都不同**(类别色 vs 纯白) |

用户诉求(2026-06-16 讨论确认):
1. 标签**字号**可调;**未选中是否显示标签** → 升级为三态。
2. 可闭合标注的**内部填充透明度**可调。
3. **线宽**可调。
4. 倾向图片/视频**共用**一套值,并借本版**统一**两端当前不一致的默认值。
5. 增强项纳入:**选中态填充透明度独立**、**标签内容多选**(类别名/ID/置信度/属性)。

### 1.2 设计取舍:统一到哪一层(关键决策)

**只统一参数与默认值,不合并渲染栈。** 详见 §3.1 架构说明。

- 视频继续用 SVG(归一化 viewBox + `non-scaling-stroke` + DOM 文字)、图片继续用 Konva —— 二者各自合身(视频框稀疏、跟随 `<video>` letterbox;图片重顶点/掩膜/拖拽)。第三方里 CVAT 全 SVG、Label Studio 全 Konva,**问题不在选哪套,而在本仓库混用导致默认值漂移**。
- 解法:建**共享视觉规格模块** `annotationVisual.ts`(默认值单一来源 + `settings→绘制值` 纯函数),Konva 路径与 SVG/DOM 路径都消费它。分歧只留在最后的 draw call,逻辑/默认值/参数全收口。
- 顺手修体验缺口:**视频填充由纯白改为类别色**(与图片对齐),让视频框也带类别色块。
- 「视频整体搬到 Konva」**不在本版**,作为未来 ADR 触发条件记录(§5)。

### 1.3 本版字段清单(全部 `workbench.common.*`,图片+视频共享)

| 字段 | 控件 | 默认(=统一后基准) | 消费点 |
|---|---|---|---|
| `labelFontSize` | slider 8–24 step 1 | 12(=现 `BOX_LABEL_FONT_PX`) | `ImageStageShapes`(`/scale`)、`VideoTextLayer`(CSS px) |
| `labelVisibility` | select:`always` / `selected`(仅选中时) / `none` | `always`(=现 `showBoxLabels:true`) | 图片标签门控 + 视频标签门控(视频本版补显隐) |
| `labelContent` | **multiselect**:`class` / `id` / `score` / `attrs` | `["class"]`(=现状仅类别名) | `shapeLabelText()`(图片)+ 视频标签文本组装 |
| `strokeWidth` | slider 1–5 step 0.5 | 1.5(图片基准;选中态 = 基值+0.5) | `ImageStageShapes` 5 处 `sw`、`VideoTrackShape` |
| `fillOpacity` | slider 0–0.6 step 0.01 | 0.07 | 闭合形状(框/多边形/旋转框)填充,图片+视频(视频改类别色后同步) |
| `fillOpacitySelected` | slider 0–0.8 step 0.01 | 0.12 | 选中对象填充加重(修「选中看不清」缺口;现状图片选中不加重、视频 0.08) |

> **闭合形状** = box / polygon / rotated box;line(折线)/ point 无 fill,`fillOpacity` 对其无效(天然干净)。

### 1.4 注册表需扩展:`multiselect` 控件类型

`workbenchSettingsFields.ts` 现有 `WorkbenchSettingControl` 只有 toggle/slider/select/text。`labelContent` 需新增:

```ts
| { type: "multiselect"; options: Array<{ value: string; label: string }>; min?: number }
```

存储为 `string[]`(子树字段类型从 `boolean|number|string` 扩到含 `string[]`)。抽屉/Settings 页渲染一组 checkbox/chips;`min:1` 兜底至少留「类别名」避免空标签。

### 1.5 不在本版

- 标签位置(auto/inside/outside)、描边色模式(color by instance/group/label)、AI vs 人工差异化样式 —— 留观察。
- 点云标注样式(点云另有 `pointcloud.*` 体系,与 2D 标签语义不同)。
- 视频渲染栈搬迁(见 §5)。

### 1.6 成功判据

1. **默认零回归**:不动设置的用户,图片与视频的标签/线宽/填充观感符合「统一后基准」(图片完全不变;视频线宽 2/3→1.5/2、填充白→类别色 = **有意为之的统一**,在 CHANGELOG 显式说明)。
2. 抽屉拖 `labelFontSize`/`strokeWidth`/`fillOpacity`/`fillOpacitySelected`,图片与视频画布**同步实时**变化。
3. `labelVisibility=selected`:仅选中对象显示标签,图片与视频一致;`none` 时两端均不显示。
4. `labelContent` 勾选 `score`:AI 预标注框标签出现置信度;取消勾选 `class` 被 `min:1` 拒绝(始终保留类别名)。
5. 旧用户 `image.showBoxLabels:false` 经迁移后 = `common.labelVisibility:"none"`,行为不变。
6. `uv run pytest -q` / `pnpm test` / `pnpm lint`(含 `lint:css-tokens`)全绿。

## 3. 设计要点

### 3.1 架构:为何不合并渲染栈(写入 ADR)

- 图片 = Konva/Canvas(`<Rect>`/`<Text>`),缩放靠 `/scale`,适配重顶点/掩膜/拖拽。
- 视频框 = SVG `<rect>`,归一化 `viewBox="0 0 1 H"` + `vectorEffect="non-scaling-stroke"` 自动跟随 `<video>` letterbox;标签 = DOM 覆盖层(白送字体/抗锯齿/i18n/暗色 tokens)。
- 第三方:CVAT 全 SVG、Label Studio 全 Konva —— **统一一套即可消除漂移,选哪套无所谓**;本仓库痛点是混用,不是选型。
- 决策:**统一参数(共享规格模块),不统一栈**。搬迁触发条件(任一成立才重评):视频要做逐顶点编辑 / 像素掩膜 / 单帧上百形状。

### 3.2 共享视觉规格 `annotationVisual.ts`

纯函数,**不依赖** settings store/React,接收已解析的 `common` 配置 + 形状上下文,返回绘制原语:

```ts
export const VISUAL_DEFAULTS = { labelFontSize: 12, strokeWidth: 1.5, fillOpacity: 0.07, fillOpacitySelected: 0.12 };
// 标签文本:按 labelContent 勾选项组装(class 必含,score 仅 AI/有置信度时拼)
export function buildLabelText(ann, content: string[], isAi): string
// 填充 alpha:闭合形状用类别色;选中走 fillOpacitySelected
export function fillAlpha(selected: boolean, cfg): number
// 线宽:选中 = base + 0.5(图片再 /scale,视频原样)
export function strokeWidthFor(selected: boolean, cfg): number
// 标签是否渲染:always | (selected && labelVisibility==="selected")
export function shouldShowLabel(selected: boolean, visibility): boolean
```

图片侧再对字号/线宽 `/scale`,视频侧原样用 —— **机制差异只体现在调用点的最后一步**。

### 3.3 `labelVisibility` 迁移(bool→enum + 跨子树搬移)

- alembic:遍历 `users.preferences->workbench`,`image.showBoxLabels===false → common.labelVisibility="none"`,否则 `"always"`;删 `image.showBoxLabels`。无该键的用户取 `common` 默认 `"always"`。
- 前端 `ImageStage.tsx` 8 处 `showLabel={workbenchConfig.image.showBoxLabels}` → 改为 `shouldShowLabel(selected, common.labelVisibility)`(`ImageStageShapes` 内部已有 `selected`,门控下沉到 shape 内更准,壳层只传 `visibility`)。
- 视频:`VideoObjectsLayer` 需把每个 track 的 `selected` 传入 `VideoTextLayer`,实现「仅选中时」(现状视频标签恒显,本版补门控)。

### 3.4 用户级,不进 lockable

纯视觉、**不改标注落点数据**,不影响两个标注员的产出一致性 → 归用户 preferences,不参与项目锁定(对照 epic 三原则①)。

## 5. 已知风险 / 未尽事项

- **视频默认观感变化是有意的破坏性变更**:线宽 2/3→1.5/2、填充白→类别色。需 CHANGELOG 显式说明,并自检暗色模式下类别色填充对比度(避免浅色类别在亮底视频帧上看不清——必要时给视频帧加一层极淡暗罩或描边优先)。
- **`fillOpacity` 散布多处同字面量**(图片 `0.07`/`0.08` 4 处、视频白色 2 处):先全部抽到 `annotationVisual.ts` 再参数化,grep 验证无残留 `0.07`/`255,255,255,0.0` 字面量。
- **`labelContent` 的 `score`/`attrs`**:需确认 `Annotation` 上有置信度/属性字段可读;若 AI 框无 score 则该项对人工框自然为空,不报错。
- **multiselect 控件**是注册表首个非标量控件,抽屉与 Settings 页两处渲染都要适配;`getFieldValue`/`buildFieldPatch` 的 `WorkbenchSettingValue` 类型需含 `string[]`。
- **视频「仅选中时」门控**依赖 `VideoObjectsLayer` 能拿到 selected track id —— 确认现有选中状态可下传(若选中态在更外层,需提一级 props)。

## 6. 验证策略

- **纯函数单测**(`annotationVisual.test.ts`):`buildLabelText` 各勾选组合(含 `min:1` 兜底)、`fillAlpha` 选中/非选中、`strokeWidthFor` 选中 +0.5、`shouldShowLabel` 三态 × 选中真值表。
- **迁移单测**:`showBoxLabels:false/true/缺失` → `labelVisibility` 三态;回滚不丢数据(或标注不可逆,二选一在迁移用例里固定)。
- **参数透传测**:ImageStageShapes 收到非默认 `strokeWidth`/`fillOpacity` 后 `<Rect>` props 反映;VideoTrackShape 同。
- **手工端到端**:抽屉调字号/线宽/填充 → 图片与视频画布同步变化;`labelVisibility=selected` 两端仅选中显标签;暗色模式抽屉新控件 + 视频类别色填充无硬编码颜色(`pnpm lint:css-tokens`)。
