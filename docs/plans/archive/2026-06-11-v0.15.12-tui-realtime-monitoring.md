## 背景

v0.15.10 的 TUI ML Backend 监控已较细(GPU 利用率/温度/功耗/显存/CPU/缓存命中率),但是 **5s 轮询 REST 快照**,看不到:

- 实时性:1s 级变化、瞬时负载。
- 池/预热维度:模型是否 `loaded`、`idle_unload_seconds` 倒计时、`last_request_age_seconds`、`pool`/`video_pool` 占用——这些**只在 WebSocket `/ws/ml-backend-stats` 推送,REST 没有**。
- 趋势:没有时序曲线,只有当前值。

后端已有 [ws.py:278](../../apps/api/app/api/v1/ws.py:278) `/ws/ml-backend-stats`:Celery beat `publish_ml_backend_stats` 每 1s 推 `MLBackendStatsSnapshot` 到 Redis channel `ml-backend-stats:global`,WS 转发;订阅者计数键 `ml-backend-stats:subscribers`(INCR/DECR)控制 beat 是否采集——**闲时零开销,有订阅者才采集**。

## 关键架构障碍(已核实)

> `/ws/ml-backend-stats` 用 `decode_access_token(token)`([ws.py:281](../../apps/api/app/api/v1/ws.py:281))——**只认 JWT,不认 `ak_` api_key**,且要求 `super_admin / project_admin`。而 SDK/TUI 全程用 api_key。

→ 必须先改后端 WS 鉴权(范围 A),否则 TUI 用 api_key 连不上。

> SDK 现有 `Client` 是**同步 httpx**,无 WS 能力;TUI 是 Textual(asyncio)。

→ 不改同步 Client;新增独立 async WS 消费器,跑在 Textual 自己的事件循环里(范围 B)。

## 红线

1. **不动同步 `Client` / `_http`**:WS 是独立 async 模块,只在 `[tui]` extra 内,可整体删除。
2. **维持「只读为主」**:WS 纯订阅消费,不新增任何写操作。
3. **WS 鉴权改造最小化**:只动 `ml_backend_stats_socket` 一个端点,其余 WS 端点不碰;role 校验(super_admin/project_admin)照旧保留。
4. **可降级**:WS 连不上 / 无权限 / 后端老版本时,TUI 回退到现有 5s REST 轮询,不崩。

## 数据可行性(已核对 [ml_backend.py:194](../../apps/api/app/schemas/ml_backend.py:194))

`MLBackendStatsSnapshot` 字段:`backend_id` · `backend_name` · `state` · `gpu_info`(device_name/memory_used_mb/memory_total_mb/gpu_utilization_percent/temperature/power) · `host`(cpu_percent/memory_percent) · `cache`(hits/misses/size/capacity/hit_rate) · `model_version` · **`loaded`** · **`idle_unload_seconds`** · **`last_request_age_seconds`** · **`pool`** · **`video_pool`** · `timestamp`。

→ 加粗字段是 REST 拿不到、本版新增展示的;`timestamp` 支撑按时间累积做曲线。

## 范围 A · 后端 WS 鉴权认 api_key

[ws.py](../../apps/api/app/api/v1/ws.py) `ml_backend_stats_socket` 的 token 校验改为:

```
if token.startswith("ak_"):
    resolved = await api_key_service.resolve_token(db, token)   # 复用现有解析(含 revoked/expires 校验)
    若 None → close(1008)
    user = resolved.user
else:
    payload = decode_access_token(token)   # 原 JWT 路径
    user = ...
role = user.role
if role not in ("super_admin", "project_admin"): close(...)   # 校验不变
```

- 只动这一个端点;其余 WS(`prediction-jobs` / `video-tracker-jobs` / `notifications` / `preannotate` / `batches`)**不改**。
- 需在 WS handler 内拿到 db session(参照该文件已有 session 获取方式)。

## 范围 B · SDK 异步 WS 客户端

- **依赖**:`pyproject.toml` 的 `tui` extra 加 `websockets>=12`(同步 Client 仍只用 httpx,不受影响)。
- **新模块**(如 `tui/ml_stats_ws.py`):
  - 输入:base_url(http→ws 协议替换)、api_key;拼 `/api/v1/ws/ml-backend-stats?token={api_key}`。
  - async 生成器/回调:连接 → 收 JSON → `MLBackendStatsSnapshot.model_validate` → 投递给 TUI;内置心跳(后端发 `{"type":"ping"}`)处理与断线重连(指数退避)。
  - 跑在 Textual 的 asyncio loop(`run_worker` / `asyncio.create_task`),**不**用现有 thread worker。
- **models**:`MLBackendStatsSnapshot` 在 SDK 侧需有等价 Pydantic 模型(若 [models.py](../../packages/python-sdk/src/ai_annotation/models.py) 没有则补,字段对齐后端 schema)。

## 范围 C · TUI ML Backend 实时屏

[app.py](../../packages/python-sdk/src/ai_annotation/tui/app.py) ML Backend 详情屏:

- **数据源切换**:进入 Backend 详情屏 → 启动 WS 订阅(只订当前 backend / 全量过滤);离屏 → 关闭订阅(触发后端 DECR,停止采集)。WS 不可用则回退 5s REST(红线 4)。
- **新增实时字段区**:`loaded`(✅预热/⚪未加载)、`idle_unload_seconds`(空闲卸载倒计时)、`last_request_age_seconds`(上次请求年龄)、`pool` / `video_pool` 占用摘要。
- **滚动曲线**(Textual `Sparkline`):对每个 backend 维护最近 N 点(如 60)滚动窗口,按 `timestamp` 追加,渲染:
  - GPU 利用率 %
  - 显存占用(used/total)
  - 缓存命中率 %
- **主屏 ML Backends tab**:保留现有 5s REST 列表(总览不变);实时只在详情屏(避免主屏 N backend 同时开 N 条 WS)。
