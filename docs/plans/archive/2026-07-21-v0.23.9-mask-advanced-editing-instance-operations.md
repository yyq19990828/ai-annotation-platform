## 1. 基线、目标与成功定义

v0.23.8 已完成图片 / 视频原生 Mask AI 候选、Mask-as-prompt、scribble、Tracker 局部决定和视频
定向纠错。当前图片与视频共用二值 `MaskBuffer`、RLE codec、编辑会话和 renderer，但像素编辑仍只有
圆笔刷 / 橡皮；连通域和 hole 只有统计值，没有可选标签；图片转换只支持单对象原位操作；视频
Mask 的 outside、关键帧删除和 held 解析虽有底层能力，却没有完整的生产力入口；涉及多个实例的
拆分、合并和非重叠写入也没有原子事务合同。

本版本成功必须同时满足：

- 图片 `raster_mask` 与视频 `video_track_mask` 当前帧使用同一套区域加减、连通域、填洞、形态学和
  preview/report 算法；所有结果保持二值像素真值，不自动转 polygon。
- 每次 stroke 或高级操作只产生一个本地 history command；取消、Worker 失败和过期结果都不修改当前
  Buffer，undo / redo 可恢复逐像素相同的前后态。
- split、join 和非重叠绘制通过任务级原子 Mask mutation 提交；锁定、权限、范围成员或任一 annotation
  version 冲突时整批 409，不能部分落库。
- 视频 Mask 补齐关键帧复制、同轨 / 新轨粘贴、删除、outside、恢复 held 和当前帧组件拆轨；不会自动
  推断后续 identity，也不会隐式合并整条轨迹。
- 转换中心覆盖图片 / 视频、单对象 / 批量和 current-frame / keyframes 范围；dry-run 与 execute 基于
  同一冻结快照，明确 copy / replace 和有损报告，不以 AABB 冒充 rotated bbox。
- 1080p 常用操作记录 p50 / p95、主线程阻塞和峰值临时内存，为 v0.23.10 Worker / tile 重构提供基线。

## 2. 冻结合同

### 2.1 Buffer、坐标与二值语义

- `MaskBuffer.data[y * width + x]` 继续只允许 `0 | 255`；高级操作不得引入灰度 alpha、羽化或隐式
  阈值。坐标均为原图像素坐标，几何采样使用像素中心 `(x + 0.5, y + 0.5)`。
- brush / eraser 的 `shape = circle | square`、`radius = 1..200`。圆形命中
  `dx² + dy² <= radius²`；方形命中闭合像素范围 `[cx-r, cx+r] × [cy-r, cy+r]`，越界裁切。
- lasso / polygon add 与 subtract 共用 even-odd 扫描线；少于 3 个有效点不产生 command。add 写 255，
  subtract 写 0；闭合只影响预览，不向持久 geometry 写 polygon。
- flood fill 在 pointer-down 像素所在的同值区域工作；`connectivity = 4 | 8` 显式可见，默认 4。
  fill 与 erase 分别把该区域写 255 / 0；目标值等于写入值时返回 no-op，不进入 history。
- dirty rect 必须覆盖真实变化像素；operation report 统一包含 `before_area`、`after_area`、
  `changed_pixels`、`before/after_components`、`before/after_holes` 和 `bounds`。

### 2.2 连通域与 hole

- 前景 component 默认按 4 邻域标记；背景 hole 默认按 4 邻域标记，接触画布边界的背景不是 hole。
  UI 可切换 8 邻域时，component 与 flood fill 都使用所选邻域，但 hole 仍显示其实际合同，不能混用计数。
- component / hole membership 优先使用 run / span 索引，稳定元数据至少含 `id`、area、bounds、seed pixel
  和是否接触边界；只在受控像素阈值内允许全帧整数标签，避免 4096² `Int32Array` 额外占用约 64 MiB。
  选择必须 alpha / membership hit，不使用 AABB 代替。
- keep / delete / copy component、按阈值删除小组件、填当前 / 小于阈值 / 全部 hole 均先生成 preview，
  确认后才形成一个 command。空结果允许预览，但提交前必须二次确认。
- split components：源对象保留命中或面积最大的组件，其余非空组件创建同类对象；图片创建同类
  annotation，视频只在当前帧创建新 `video_track_mask`。来源、目标、组件面积与 digest 写入审计 lineage。
- join masks：只允许同任务、同媒体、同类别、可编辑的 Mask。图片 UI 显式选择“替换来源”或“创建副本并保留来源”。视频只在当前帧创建单 manual keyframe 的合并副本并保留全部源轨迹；在没有 frame suppression 合同前，不允许单帧 join 删除整条轨迹。

### 2.3 形态学、平滑与异步执行

- dilate / erode / open / close 使用 `kernel_shape = disk | square`、整数 radius `1..32`；open 固定为
  erode→dilate，close 固定为 dilate→erode，画布外一律视作背景。
- 去毛刺定义为删除面积小于等于阈值的前景 component；边界平滑定义为同一 kernel 的 close→open。
  本版本不提供名为 simplify 的独立像素操作，避免与 polygon 顶点 simplify 混淆。
- 预览计算对 1,000,000 像素以上 Buffer 或 morphology radius 大于 4 时必须走现有 Raster Mask Worker
  扩展路径；较小输入允许同步。取消通过终止本次 Worker / generation token 实现，晚到结果不得回写。
- Worker 接收 RLE 或 transferable alpha、纯 operation 参数与 `sessionId + generation + operationId`，只返回
  新 RLE / alpha 和 report；不读取 React 状态或对象存储。Worker 不可用时显示可恢复错误，不在主线程
  静默执行大操作。
- v0.23.10 才处理 tile、稀疏 Buffer、缓存预算和 5K / 8K；本版不扩大 4096×4096 / 16M 像素门。

### 2.4 编辑会话与 history command

- `useMaskEditor` 增加通用 `applyOperation` / `previewOperation` 边界；stroke、lasso、fill、component、hole、
  morphology 都复用同一 before / after RLE command，不在每个工具内另建 history。
- history command 至少保存 operation id/name、before/after RLE、report 和 scope；容量仍为 20，内存压缩和
  delta history 属于 v0.23.10。no-op 不清 redo，也不改变 dirty / revision。
- 新增显式 `materialize-held` 草稿意图：从上一 / 下一视频关键帧复制后进入 dirty，但不立即保存；不得
  通过伪造笔画制造 dirty。切帧、切题和关闭前继续遵守既有防丢稿确认。
- destructive preview 只有确认后才入 history；Esc 取消 preview，Ctrl/⌘+Z 撤销已确认 command，
  Enter 只确认当前 preview 或保存 dirty Buffer，不允许两个动作同时触发。

### 2.5 原子多对象 Mask mutation

- 新增任务级专用端点 `POST /tasks/{task_id}/annotations/mask-mutations:commit`；不扩写现有
  `/annotations/bulk-update`，后者继续禁止 geometry。
- 新增 `annotation_operations` 主表和 `annotation_lineage_edges` 多边关系表：主表记录 task / actor / kind、
  幂等 key、request digest、源 / 结果版本、report 和状态；edge 记录 operation、source、result、relation、
  版本与可选 frame。`task + actor + idempotency_key` 唯一，source / result 建查询索引。响应快照和表记录都
  不保存完整 RLE counts，也不把已删除对象 ref 变成新的 GC root。
- 请求包含 `idempotency_key`、operation、media/frame scope、同类 / 全部实例过滤条件、按稳定顺序排列的
  `expected_versions`、scope fingerprint，以及 `update | create | delete` mutations。geometry 只能是
  `raster_mask` 或 `video_track_mask`，内容引用必须已由当前任务 reserve，不能提交任意 object key。
- 服务端在事务内重算 scope fingerprint，按 Task row → task edit lock → video segment → RLE advisory → upload row → annotation UUID 的稳定顺序锁定资源，复核任务状态、
  assignment、task lock、annotation lock、视频 segment lease、类别、frame、版本和内容引用；任一不一致
  返回结构化 409，且不关联任何新内容引用。
- DB 提交原子完成更新、创建、删除、引用 linked 状态、task heartbeat 与一条聚合审计；对象存储先写产生的
  orphan 由既有宽限期 GC 回收。相同 idempotency key + request digest 返回同一响应，同 key 异参返回 409。
- 默认 overlap policy 为 `allow`。`erase_same_class` / `erase_all` 只影响当前媒体 / 帧中可见、未锁定且
  有编辑权限的其它原生 Mask；preview 必须列出对象、版本和 changed pixels。不能跳过 locked 对象后声称
  范围已完全非重叠：存在受保护重叠时显示 unresolved，并阻止“严格非重叠”确认。
- split / join 与 overlap 使用同一端点和响应，响应返回 operation id、updated / created / deleted、结果版本、
  before/after digest 和 audit id；前端收到成功前不清本地草稿。
- 稳定错误至少包含：428 `expected_versions_missing`；409 `version_mismatch`、`task_lock_conflict`、
  `annotation_locked`、`segment_lock_conflict`、`scope_stale`、`idempotency_conflict`；422
  `invalid_operation`、`class_mismatch`、`invalid_geometry`、`missing_ref`、`empty_result`。

### 2.6 视频关键帧生产力

- Mask 轨迹卡与右键菜单补齐上一 / 下一关键帧、复制当前解析 Mask、同轨 / 新轨粘贴、删除当前关键帧、
  标记 outside、恢复 held。底层继续复用既有 nearest-hold / outside 优先语义和版本化保存。
- clipboard 保存 RLE 正文、源 annotation / frame / digest、类别和源尺寸，只存在浏览器会话；尺寸不一致、
  类别无绑定或权限不足时禁用粘贴并给出原因。
- 同轨粘贴先进入 `materialize-held` dirty 草稿；新轨粘贴也先预览，确认后通过原子 mutation 创建单个
  manual keyframe。删除真实 keyframe 后若该帧由邻近关键帧 held，UI 必须明确显示“已恢复 held”，不能显示空白。
- outside 仅改变显式区间；“恢复 held”删除覆盖当前帧的 manual outside 标记并重新解析来源。
- 当前帧 component 拆成新轨只创建当前帧关键帧，不复制后续 keyframe / outside，不调用 Tracker 自动 Re-ID。

### 2.7 转换中心与派生几何

- 用共享 Dialog 替换图片转换的 `window.confirm`；所有入口统一显示 source / target、copy / replace、scope、
  对象列表与 `MaskConversionReport`。破坏性 replace 使用 AlertDialog 二次确认。
- dry-run 端点 `POST /tasks/{task_id}/annotation-conversions:dry-run` 返回带 TTL 的 `plan_token`、冻结
  versions / digests、逐对象结果和汇总；execute 端点 `POST .../annotation-conversions:execute` 只接受 token、
  idempotency key 与确认后的选项，并重验冻结快照。报告不一致或快照漂移整批 409。
- 支持矩阵：
  - 图片 polygon / multi_polygon ↔ raster_mask；
  - 视频当前帧 polygon / polygon track keyframe → video_track_mask manual keyframe；
  - polygon track 的 `keyframes` 范围逐关键帧转换；`materialize_held` 必须显式选择并显示新增帧数；
  - raster_mask / video_track_mask current-frame → bbox，结果为显式派生对象；
  - batch 对上述同源类型执行 copy / replace，单项失败只出现在 dry-run，execute 不允许部分成功。
- Mask → bbox 使用前景紧致 AABB；Mask → rotated bbox 本版本实现前必须冻结最小面积外接矩形、角度范围、
  坐标归一化和退化形状合同。若 M5 前仍无该合同，则从本版支持矩阵移除并顺延，禁止用 axis-aligned bbox
  填充 rotated geometry。
- copy 默认保留来源；单来源派生可建立 `parent_annotation_id`，但 split / join / 批量转换的完整来源关系以
  operation + lineage edges 为准，不能用单父字段伪装多父。replace 明确删除 / 更新来源。转换 codec 继续
  复用既有逐像素 fixture，不重写基础 contour 算法。

### 2.8 UI 与 shadcn 组件约束

- Mask 浮动工具栏只保留高频 brush / eraser / lasso add / subtract 的单选 `ToggleGroup`、尺寸和保存状态；
  flood、component、hole、morphology、overlap 和 conversion 收入分组 `DropdownMenu` / Dialog。
- 使用仓库已安装的 shadcn `ToggleGroup`、`DropdownMenu`、`Dialog`、`AlertDialog`、`Field`、`Input`、
  `Select`、`Progress` 和 `Button`；组件使用既有 semantic token，不新增裸色、任意色或 `.dark` selector。
- preview 面板显示 operation、范围、前后指标、受影响对象、执行状态和可取消按钮；禁用态必须显示
  locked / readOnly / capability / size / worker unavailable 的准确原因，不能只降低透明度。
- 不新增全局字母快捷键；保留 B / E、Shift+滚轮、Enter、Esc、Ctrl/⌘+Z / Shift+Ctrl/⌘+Z。

## 4. 非目标

- 不做 5K / 8K tile、稀疏 Buffer、delta history 或缓存预算重构；这些属于 v0.23.10。
- 不实现 semantic / panoptic class-map 的 label painting，也不增加新的持久 geometry。
- 不合并整条视频 Mask Track，不做跨帧 component Re-ID，不自动传播拆出的新轨迹。
- 不引入 Photoshop 式图层、软笔刷、羽化 alpha、图像颜色容差 flood fill或 GPU morphology。
- 不重写 RLE codec、contour 基础算法、Konva 工作台或通用 annotation bulk-update。
- 不让前端用多次 PATCH 模拟原子 split / join / overlap / batch conversion。

## 5. 浏览器与发布验收场景

1. 非正方形图片用方笔刷、圆橡皮和 lasso add/subtract 编辑，确认、undo、redo、刷新后逐像素一致。
2. 4 邻域下两个对角像素是两个 component，切 8 邻域后是一个；flood fill 只修改命中的标签区域。
3. donut + 三个小岛执行 fill current hole、delete small、keep component；预览与确认后的面积 / component /
   hole / changed pixels 一致，Esc 取消不改 Buffer。
4. 1080p morphology 在 Worker 执行；中途取消和快速切题都不回写，Worker 失败保留原 Buffer 和 history。
5. split components 创建同类实例并保留 lineage；并发修改任一来源后整批 409，刷新前没有部分对象变化。
6. join 两个图片 Mask 后 hole / 小岛保持；严格同类非重叠模式显示所有受影响对象，locked 重叠阻止确认。
7. 默认 allow overlap 与旧行为一致；切 `erase_same_class` 后只擦除同类、当前媒体的可编辑对象。
8. 视频从上一关键帧复制进入 dirty 但不立即保存；取消后原轨不变，确认后只新增当前 manual keyframe。
9. 视频删除真实 keyframe 后恢复 held；outside / restore held 的区间与相邻帧解析一致，窗口外字节不变。
10. 视频 current-frame component 拆成新轨只产生一个新 manual keyframe，不复制后续 identity。
11. 图片 / 视频转换 Dialog 的 dry-run 与 execute 报告一致；copy 保留来源，replace 版本冲突时零部分写入。
12. polygon track keyframes → Mask 只转关键帧；显式 materialize held 显示新增帧数，取消不产生内容引用。
13. Mask → bbox 是紧致派生框；若 rotated bbox 可选，其角度和最小面积 fixture 通过，绝不退化冒充 AABB。
14. 锁定 / 只读对象经 toolbar、右键、快捷键和 API 均不能执行高级操作，UI 显示一致原因。
