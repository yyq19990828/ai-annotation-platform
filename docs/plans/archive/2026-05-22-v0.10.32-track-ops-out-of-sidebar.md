# v0.10.32 · 轨迹操作"搬出侧栏"（快捷键 + 画布浮动条）

> 背景：[2026-05-21-video-workbench-roadmap.md](../../ROADMAP/2026-05-21-video-workbench-roadmap.md) Phase 2 深化了轨迹工具，但常用操作几乎全部集中在右侧 `VideoTrackPanel`。对不常看侧栏的标注员，每改一次"消失/遮挡/拆/删"都要把视线和鼠标移到侧栏，效率低。
>
> 本版本目标：**不依赖侧栏也能改 track 状态**——经"已有的两类入口（快捷键 + 画布浮动条）"补齐。
> 通用画布右键菜单是平台级新基建 + 右键平移共存的交互调优，风险与抽象都更大，**拆到 [v0.10.33](2026-05-22-v0.10.33-canvas-context-menu.md) 单独做**。

---

## 1. CVAT 的设计原则（调研结论，两个版本共用）

CVAT 让用户**完全不依赖侧栏也能干完绝大部分活**，靠同一操作给多条到达路径（常用操作 ≥2 条路径可达）：

| 层 | 承载操作 | 特点 |
|---|---|---|
| 侧栏条目 inline 按钮 | lock/hide/occluded/outside/keyframe/pin + 关键帧导航 | 一键 toggle |
| 侧栏条目下拉菜单 | propagate / copy / delete / 改色 / z-order / slice | 复杂操作 |
| 画布右键菜单 | 直接复用整个对象面板（DRY） | 鼠标用户（→ v0.10.33） |
| 全局快捷键 | 上面几乎每个操作都有键：`l/h/o/q/k/p`、`Ctrl+B` propagate、`e/r` 关键帧、`Del`、`Enter` 改色…，可自定义 | 手不离键盘 |
| 左侧画布工具条 | merge/split/join：激活模式后在画布上点对象 | 多选操作 |

本版本对应"全局快捷键"+"画布内按钮"两层。

## 2. 现状与差距

| 入口 | 现状 | 文件 |
|---|---|---|
| 右侧轨迹面板 | **几乎所有操作都在这里** | [VideoTrackPanel.tsx](../../apps/web/src/pages/Workbench/stage/VideoTrackPanel.tsx) |
| 画布浮动条 | **已存在但极简**：仅 改类 / 复制框 / 拆框 / 删除（4 个） | [VideoSelectionActions.tsx](../../apps/web/src/pages/Workbench/stage/VideoSelectionActions.tsx) |
| 全局快捷键 | **分发器已很丰富**（播放/seek/关键帧导航/工具切换/删除/循环轨迹/书签）。**缺**：键盘 toggle outside/occluded/lock/hide、propagate | [hotkeys.ts](../../apps/web/src/pages/Workbench/state/hotkeys.ts) / [useWorkbenchHotkeys.ts](../../apps/web/src/pages/Workbench/state/useWorkbenchHotkeys.ts) |

### 接线难点（本版本公共底座，必做前置）

视频快捷键当前统一走命令式 handle `videoControlsRef.current.*`（[useWorkbenchHotkeys.ts:322-366](../../apps/web/src/pages/Workbench/state/useWorkbenchHotkeys.ts)），
但**track 帧级状态变更（标记消失 / 遮挡）逻辑目前封在 `VideoTrackSidebar` 内**（`markSelectedTrack` 等，调用 `addOutsideRange` / `upsertKeyframe` 再 `onUpdate`），快捷键和浮动条都够不到。

→ **第一步：把"对选中 track 施加帧级状态变更"的动作上提到共享处**（VideoStage 或新 `useVideoTrackActions` hook），让侧栏、快捷键、浮动条调用同一组回调，避免 outside/occluded 写入逻辑重复实现。v0.10.33 的右键菜单也复用这组回调。

## 3. 改动清单

### 3.0 公共底座（前置）
- 将 [VideoTrackSidebar.tsx](../../apps/web/src/pages/Workbench/stage/VideoTrackSidebar.tsx) 内的 `markSelectedTrack`（消失/遮挡写入）、以及 toggle 隐藏/锁定/propagate 触发，抽为一组与具体 UI 解耦的回调（`useVideoTrackActions(selectedTrack, frameIndex, { readOnly, lockedTrackIds, onUpdate, ... })`）。
- 侧栏改为消费这组回调（行为不变，纯重构）。
- 验证：现有 `VideoTrackSidebar.test.tsx` 不回归。

### 3.A 补全键盘快捷键
1. [hotkeys.ts](../../apps/web/src/pages/Workbench/state/hotkeys.ts)：新增 action type + 按键映射（仅 `hasSelectedVideoTrack` 时消费）：
   - `o` → 当前帧标记消失/恢复（`videoToggleOutside`）
   - `q` 或 `/` → 当前帧遮挡/恢复（`videoToggleOccluded`）
   - `l` → 锁定/解锁选中轨迹（**注意与现有 `Alt+L` 清除播放范围区分**；CVAT 用裸 `l`）
   - `h` → 隐藏/显示选中轨迹
   - propagate 键（CVAT 是 `Ctrl+B`；我们已有 `Ctrl+M` 书签，**核对冲突后再定键**）
2. **键位冲突审计（关键工作量）**：逐一核 `l`/`o`/`q`/`h` 在当前 video 命名空间是否已占用（`o` 在 draw 组已是 toggle occluded，需确认 video 模式下的归属），冲突则调整或加 `hasSelectedVideoTrack` 守卫。
3. [useWorkbenchHotkeys.ts:316](../../apps/web/src/pages/Workbench/state/useWorkbenchHotkeys.ts) switch：新增 case，调用 §3.0 共享回调。
4. `HOTKEYS` 表补描述，让快捷键帮助面板（`?`）自动列出。
5. 补 `hotkeys.test.ts` 用例覆盖新键 + 冲突回归。

### 3.C 充实画布浮动操作条
1. 扩展 [VideoSelectionActions.tsx](../../apps/web/src/pages/Workbench/stage/VideoSelectionActions.tsx)：在现有 4 个按钮上补 标记消失 / 标记遮挡 / 锁 / 隐藏（带 `aria-pressed` 反映当前态），透传 §3.0 共享回调。
2. [VideoStage.tsx:1234](../../apps/web/src/pages/Workbench/stage/VideoStage.tsx) 渲染处补传新 props + 当前帧 outside/occluded 状态。
3. 注意按钮增多后浮动条布局/换行，避免遮挡框本身。

## 4. 验收口径
- 选中一条轨迹，**不点击侧栏任何元素**，仅用快捷键 / 浮动条，能完成：标记消失并恢复、标记遮挡、锁定/隐藏、删除。
- 帧级状态写入结果与经侧栏操作**完全一致**（同一组共享回调 → 同一 `onUpdate` 路径，无重复实现）。
- `readOnly` / 轨迹锁定时，新入口同样禁用（与侧栏一致）。
- 新键位与现有 video 快捷键无冲突；快捷键帮助面板自动列出新键。
- `VideoTrackPanel`/`VideoTrackSidebar` 测试与 `hotkeys.test.ts` 不回归；新增入口补单测。
