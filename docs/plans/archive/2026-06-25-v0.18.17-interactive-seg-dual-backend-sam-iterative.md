# v0.18.17 · 双 backend SAM-style 迭代交互(point 累加 + multimask 候选 + interactive_box)

> 草案 (2026-06-25). 本 epic 第 1/3 版, 后接 [v0.18.18 mask_input 回灌](2026-06-25-v0.18.18-interactive-seg-mask-input-refeed.md) · [v0.18.19 sam3 PCS refine](2026-06-25-v0.18.19-sam3-pcs-iterative-refinement.md)。
> 关联协议: [ml-backend-protocol.md](../../docs-site/dev/reference/ml-backend-protocol.md) §2。

## 1. 背景与源码结论

工作台当前的 AI 点/框交互是「一发定生死」: 单点单框出一个 mask, 不可迭代精修、无候选可选。两个 backend 底层其实都用同一套 SAM2-style API, 升级面共享。

| 证据 | 位置 | 现状 |
|---|---|---|
| gsam2 用 `SAM2ImagePredictor.predict(point_coords,point_labels,box,mask_input,multimask_output)` | `grounded-sam2-backend/predictor.py:156/172/206` | 写死 `multimask_output=False`、无累加 |
| sam3 同签名 `SAM3InteractiveImagePredictor.predict(...)` | `sam3-backend/vendor/sam3/sam3/model/sam1_task_predictor.py:229` | 被 `enable_inst_interactivity=False` 关闭 |
| sam3 一次 `set_image` 同产 PCS + sam2 特征, `model.predict_inst(state, **kw)` 复用 | `vendor/sam3/sam3/model/sam3_image.py:624` | 未接入 |
| sam3 multiplex 权重自带 `tracker.*`, 开 inst 自动装载 | `vendor/sam3/sam3/model_builder.py:548-555` | 无需额外下载 |

→ 「正负点累加 + multimask 候选 + 单框单 mask」是一次**协议层升级, 两 backend 同一前端组件复用**。gsam2 权重已常驻、最省; sam3 仅需开 `enable_inst_interactivity=True`(显存 +2-3GB)。

## 2. 范围

- ✅ `context.type=point`: 正/负点累加 + `multimask_output` 候选(单点歧义出 3 选 1)。
- ✅ `context.type=interactive_box`(新增, **统一名**): 单框单 mask; **双 backend 同名**(gsam2 由旧 `bbox` 迁入, sam3 经 inst 新增)。
- ✅ `bbox` **退出交互 prompt 命名空间**(仅留作几何形状); gsam2 旧 `bbox`→`interactive_box`, sam3 旧 `bbox`→`exemplar`(本就同底层别名)。**直接退役, 不留兼容别名**(项目未正式上线, 无历史请求需兜底)。
- ✅ 双 backend(sam3 开 inst / gsam2 复用)+ 平台门控 + 前端统一交互组件。
- ❌ 不含 `mask_input` 回灌(→ v0.18.18)。
- ❌ 不含 sam3 PCS exemplar 多框 refine(→ v0.18.19)。

### 2.1 已确认决策(2026-06-25)

- **D1 · 点会话生命周期 = 显式提交**: 一串点持续精修同一 mask; **Enter / 双击提交**落标注并开新会话, **Esc 重置**丢弃。
- **D2 · 候选 UI = top-1 + 切换键**: 默认采纳最高 iou; Tab/按钮在 3 候选间循环。挂现有 `PendingCandidate`。
- **D3 · interactive_box 工具 = 新增独立工具**(`InteractiveBoxTool`), 双 backend 共用; 不复用 `SmartBoxTool` 模式切换。
- **D4 · 类型统一**: `interactive_box` 双 backend 同名同义; `bbox` 退役为纯几何形状(见 §2 第 2 条)。负点手势沿用现有 `Alt+点击`(`SmartPointTool.ts:5`), 不另发明。

## 3. 无状态迭代契约

前端维护「进行中的 prompt 集」, **每次点击重发全量点**(SAM 支持 resend-all 累加), backend 无状态, 图像 embedding 按图 `embedding_cache` 缓存(命中点击 <50ms)。不引入服务端会话。

## 4. 任务分解(逐文件)

### 4.1 协议层(单一来源)
- `apps/_shared/protocol_v2/` Context: 新增 `multimask_output: bool = False`。
- `apps/sam3-backend/schemas.py`: `Context.type` 加 `"interactive_box"`; 加 `multimask_output`。
- `apps/grounded-sam2-backend/schemas.py`: 同上 `"interactive_box"` + `multimask_output`。

### 4.2 sam3-backend
- `predictor.py`:
  - `_load_model`: `enable_inst_interactivity=True`(选项 A → B)。
  - 新增 `predict_interactive(image, points, labels, box, *, multimask_output, cache_key, simplify_tolerance)`:
    - 复用 `_prime_state`(开 inst 后 `state["backbone_out"]` 含 `sam2_backbone_out`)。
    - 调 `self._model.predict_inst(state, point_coords=px, point_labels=lab, box=box_px, multimask_output=...)`。
    - 返回 `(masks CxHxW, iou C, low_res CxHxW)`; multimask 时按 iou 降序取候选, 复用 `mask_to_multi_polygon` 出 polygon, 候选间用 `score` 区分。
  - 像素换算: 协议归一化 → 像素(同 gsam2)。
- `main.py`: 路由 `point` / `interactive_box` → `predict_interactive`; 删 point 的 400; **删除 `ptype=="bbox"` 路由分支**(PCS 单框统一走 `exemplar`); `/setup.supported_prompts` 改 `["point","interactive_box","text","exemplar"]`(不再列 `bbox`)。
- README: 能力盘点表 point ❌→✅; vendor 升级复核清单加 `predict_inst` / `SAM3InteractiveImagePredictor.predict` 签名。

### 4.3 grounded-sam2-backend
- `predictor.py`:
  - `predict_point`: 加 `multimask_output` 参数透传; 多点累加(已天然支持 N 点, 仅需透传 multimask 并在候选时返回多条)。
  - `interactive_box` 路由 = 复用现有 `predict_bbox`(实现等价, 仅协议名换), 加 `multimask_output` 透传。
- `main.py`: `ptype=="bbox"` 分支**直接改名为** `ptype=="interactive_box"`(路由不变, 仍 box→mask); `/setup.supported_prompts` 改 `["point","interactive_box","text"]`。**无需改模型加载/权重**。

### 4.4 平台 apps/api
- `services/capability_registry.py`: interactive_seg 条目文案补 `interactive_box`(supported_prompts 列表)。
- `schemas/ml_backend.py`: `InteractiveRequest` docstring 补 `interactive_box` 说明(context 仍透传, 无 schema 改动)。

### 4.5 前端(双 backend 共用组件 — 本版最大改动面)
- `SmartPointTool`: 由「每点单请求」改为「累加全量点」。正点=单击 / 负点=`Alt+点击`(沿用 `SmartPointTool.ts:5` 现有约定); `useInteractiveAI.ts:204` 的 `points:[pt]` 改为累加数组重发。
- 新增 `InteractiveBoxTool`(emit `interactive_box`), 双 backend 共用; 与 sam3 的 `exemplar`(PCS)工具并列。
- `useWorkbenchState.ts:39` `SamSubTool` 枚举: `"bbox"` → `"interactive_box"`。
- 工具启停: 读 `/setup.supported_prompts`(`interactive_box`/`point`/`exemplar` 各自门控)。
- **会话态(D1)**: 「进行中 prompt 集」前端状态; **Enter/双击提交**落标注并开新会话, **Esc 重置**丢弃; 提交前可继续加点/撤销。此组件 v0.18.19 PCS refine 直接复用。
- **候选(D2)**: multimask 出 3 候选挂 `PendingCandidate`, 默认 top-1, Tab/按钮切换。

## 5. 验收

1. 无 GPU: 两 backend `schemas`/路由单测 + `/setup` 反映新 supported_prompts。
2. GPU 机:
   - sam3 `type=point` 单点出 mask; 累加正负点精修肉眼正确; `multimask_output=true` 返回 3 候选。
   - sam3 `type=interactive_box` 单框单 mask(区别于 `exemplar` 的全图相似)。
   - gsam2 `interactive_box` 出单 mask(= 旧 `bbox` 行为, 仅改名); **旧 `type=bbox` 请求应 422(已退役, 不兜底)**; `point` 默认 multimask_output=False 行为不变。
3. 前端: 工作台挂 sam3 与 gsam2 项目, 点/框交互闭环; Enter/双击提交、Esc 重置、候选 Tab 切换、撤销均可用。

## 6. 风险

- **显存(sam3)**: 开 inst 常驻 +2-3GB; 3090 与 PCS + idle-unload 余量实测; 可能下调 `SAM3_EMBEDDING_CACHE_SIZE`(条目现含 `sam2_backbone_out`, 单条更大)。
- **首图变重(sam3)**: `set_image` 多算 sam2 分支 + conv_s0/s1; 命中点击不受影响。
- **前端会话模型**: 与现有一次性 AI 工具交互范式不同, 是本版主要工作量; 组件必须可被 v0.18.19 复用。

## 7. 开放问题(C/D/E 已拍板, 见 §2.1)

- **E · 兼容别名** → **已决: 直接退役**。`bbox` prompt 不留别名(项目未上线, 无历史请求)。旧 `type=bbox` 请求直接 422。
- **F · 提交手势冲突核对** → **延后到实现时探讨**。`Enter`/`双击`/`Esc` 与工作台现有快捷键(多边形闭合双击、Esc 取消选择等)可能撞键; 做到 `SmartPointTool` 会话改造时再核对键位独占, 避免静默失交互。
