## Context

当前 SAM（grounded-sam2 / sam3）出的 mask 都走「polygon 化 → 用户接受 → 入库」的单向流程，用户不能在 mask 像素层做笔刷精修。CVAT 的 `masksHandler.ts` 用独立离屏 canvas 承载像素 alpha，支持圆/方笔刷、橡皮、polygon-plus / polygon-minus 布尔操作、Shift+滚轮调笔刷半径，最后 RLE 压缩落库。

我们的 v1 范围比 CVAT 小一档：**仅做「mask 中间编辑态 + 转 polygon 入库」**，不改 DB schema 也不引入新 geometry kind。RLE 独立 mask 形状留 v0.11+ 与 I9 Ellipse / I10 Skeleton 一起做 `geometry.kind` 统一收口。本子版本是 v0.10.4 epic 的第 4/4 子版本，也是 epic 收尾节点。

## Scope

### v0.10.7 范围（v1：mask 临时态 + 转 polygon）

**MaskTool 工具**：
- 新增 [`stage/tools/MaskTool.tsx`](../../apps/web/src/pages/Workbench/stage/tools/MaskTool.tsx)：基于离屏 `<canvas>` 元素（不入 Konva 主层，避免 hit-test 拖累）维护一个像素 alpha mask；pointermove 在 canvas 上画 / 擦。
- 新增 [`stage/shared/MaskCanvas.tsx`](../../apps/web/src/pages/Workbench/stage/shared/MaskCanvas.tsx)：离屏 canvas 组件，封装 init / brush / erase / clear / toAlphaImageData / fromPolygon。
- 控件：Shift+滚轮调笔刷半径（5px - 200px）；`B` / `E` 切笔刷/橡皮；`Esc` 取消编辑、`Enter` 确认转 polygon。

**SAM 候选精修入口**：
- 改 [`stage/AIPredictionPopover.tsx`](../../apps/web/src/pages/Workbench/stage/AIPredictionPopover.tsx)：候选 polygon 出来后新增「精修」按钮 → 进入 MaskTool 模式，把 polygon → 离屏 canvas alpha mask 作为起点。
- 改 [`shell/ToolDock.tsx`](../../apps/web/src/pages/Workbench/shell/ToolDock.tsx)：MaskTool 也可独立激活（不一定从 SAM 入），从一张空白 mask 开始画。

**polygon 输出转换**：
- 新增 [`stage/shared/geometry/maskToPolygon.ts`](../../apps/web/src/pages/Workbench/stage/shared/geometry/maskToPolygon.ts)：marching-squares 算法把 alpha mask 转为外环 polygon（一个连通分量取最大的；多分量提示用户选择或先布尔合并）。
- 调用 `polygon-clipping`（已在 deps）做后处理简化与去自相交。
- 落库：转出的 polygon 走现有 `submitPolygon` 路径，与手画 polygon 等价。

**单测**：
- `maskToPolygon` 输入若干典型 alpha mask（圆形 / 矩形 / 多边形锯齿）→ 输出 polygon 顶点合理（去重 / 闭合 / 不自交）；
- MaskCanvas brush/erase/clear 单测。

## Notes

- 不引入 `d3-contour`，marching-squares 用 polygon-clipping 周边自研实现，体积可控。
- 编辑态期间不影响 Konva 主层 hit-test（离屏 canvas 与 Konva 并行）。
- 与 v0.10.4 `useSamCache` 协同：精修结果不写 cache（cache 只针对 prompt → 后端响应；用户笔刷修改属于本地后处理）。
