# v0.20.3 · 从 ML Backend 一键预填项目配置（类别 + 属性）

状态：草案（draft）。把现有「从 backend 导入属性」升级为统一的「**从 ML Backend 预填项目配置**」入口，
补齐**类别**这条被裁掉的 gap，并以**实际预标数据**做「实际出现过」过滤作为补充。
**A（/setup 自报）为主 + B（扫预标数据）补充**（2026-06-30 探讨后定）。依赖 v0.20.0。

## 背景：三态盘点（实测）

| 维度 | backend /setup 自报 | 前端能拿到 | 现有预填入口 |
|---|---|---|---|
| **属性** | ✅ `output_attribute_schema` | ✅ 透传到 `InstanceModelItem` | ✅「导入属性」对话框（v0.18.0）+ v0.20.2 一键补全 |
| **类别** | ✅ yolo `entry["classes"]`（协议支持） | ❌ `InstanceModelItem` **把 classes 裁掉了** | ❌ 无入口，用户手抄 |
| **从预标数据扫** | — | — | ❌ 没有 |

**核心判断**：预标数据里的类别 ⊆ backend 自报 `classes`、属性 key ⊆ `output_attribute_schema`
——数据是 /setup 的**子集**。所以 90% 价值用「配置期从 /setup 预填」就能拿到，更轻更早更可靠；
「扫预标数据」只在「想**过滤成实际出现过的子集**」时多给价值，作补充。

## 目标

一个入口、两块内容（类别 / 属性），都来自 backend `/setup` 一键合并进选中工具单位；
可选用项目已落库的预标数据，把候选标记/过滤为「实际出现过」。

## 工作项

### WS1 · 后端透传 backend 自报的 classes（A 的前提）

- `InstanceModelItem`（`apps/api/app/schemas/ml_capabilities.py`）加 `classes: list[str] = []`，
  从 `health_meta.capabilities.models[].classes`（live 探测同源）透传；缺省 `[]` 向后兼容。
- `/instances` 端点构造处一并填充（与本版健壮性改造同文件，注意仍走逐 backend try/except）。
- capability-registry snapshot 受影响则由 pre-commit 钩子重生成（勿手改）。

### WS2 · 「导入属性」升级为「从 backend 预填配置」（A 主体，前端）

- `ImportAttributesFromBackendDialog` → 重命名/扩展为 `PrefillFromBackendDialog`，内分 **类别** / **属性** 两区：
  - 类别区：列出 `model.classes`，勾选后合并进选中 unit 的 `tool_bindings[unit].classes`
    （同名覆盖、自动配色 + order 续接；复用 ClassesSection 现有的新增类别逻辑）。
  - 属性区：沿用现有 `output_attribute_schema` → `AttributeField` 流（不回退已有能力）。
- `ClassesSection` 的「导入属性」按钮文案/入口相应更新为「从 backend 预填」。

### WS3 · 用预标数据做「实际出现过」过滤（B 补充，可选后做）

- 后端加一个轻量聚合端点：给定 project，返回该项目 predictions 里 **distinct** 的 `polygonlabels` 类别名
  + 出现过的 attribute key 集合（一次 SQL distinct，不回放每条预测）。
- 预填对话框里给候选打「实际出现过」badge，并提供「只保留出现过的子集」过滤开关。
- **数据驱动是增强不是主干**：backend 不自报 classes（开放词表/动态类）时，此端点即唯一类别来源。

## 风险

中。WS1 跨前后端字段（含 snapshot 重生成）；WS2 动 ClassesSection 合并逻辑（类别同名覆盖须不误删存量）；
WS3 引入新端点 + 扫库聚合（注意大项目 distinct 性能，加 project 维度索引或 limit）。A（WS1+2）可独立先上，B（WS3）择机。

## 验收

- 项目绑定 yolo → 预填对话框列出 COCO 类别，勾选一键加进 bbox 工具单位，无需手抄。
- 属性预填行为不退化（沿用现有导入）。
- （B）扫到的「实际出现过」类别能在候选里高亮，并可一键过滤成子集。

## 排期与依赖

- **依赖 v0.20.0**；与 **v0.20.1（推荐 key）+ v0.20.2（属性一键补全）同窗口**——三者都动 ClassesSection +
  Import/Prefill 对话框 + 属性链，**强烈建议合并迭代或紧邻排**，共同收敛成「配置预填」主题，避免反复改同一批文件。
- WS1+WS2（A）可独立交付；WS3（B）可作为后续小增量。

## 不在范围

- ❌ 自动**应用**预填（不经用户勾选直接写项目配置）：保持「推荐 + 用户确认」，不擅改配置。
- ❌ 跨工具单位/跨项目的类别体系治理：本版只做「单 unit 内一键合并」。
- ❌ 回放每条预测做统计画像：WS3 只取 distinct，不做计数/分布分析（另议）。
