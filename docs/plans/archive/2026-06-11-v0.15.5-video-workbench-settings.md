- 播放速率**档位列表**自定义(`VIDEO_PLAYBACK_RATES` 数组本身):类型收窄(`VideoPlaybackRate` 联合类型,`:87`)牵连面大,收益存疑,先只做默认值。
- 缓存容量/预取窗口/重试策略(`useVideoBitmapCache.ts:25`、`useVideoFramePreview.ts:56-62` 等):统一归 v0.15.7 性能档位,本版不碰。
- Tracker 默认模型的**项目级**决定(修 `mock_bbox` 准 bug):v0.15.7;本版粘性记忆已能缓解(选过一次 sam2_video 就记住)。
- 循环区间/书签(已有 sessionStorage 按 task 持久化,`videoNavigationState.ts`)语义不动。

### 1.4 成功判据

1. **默认零回归**:不动设置的用户,播放/步进/对话框行为与 v0.15.4 一致。
2. 设置 `defaultPlaybackRate=0.5` 后,新开视频任务初始速率 0.5x;播放中手动调到 2x 再暂停恢复,本会话内保持 2x(jog 复位逻辑只复位到 defaultPlaybackRate 而非硬编码 1)。
3. `largeFrameStep=grid` 且任务采样步长为 5 时,Shift+→ 前进 5 帧(一个网格单元);无采样网格时回退 10。
4. 关键帧对话框:选 30 帧 / backward / 覆盖 → 提交 → 重开对话框,三项均保持;**取消**不回写。
5. Tracker 对话框同上,且 modelKey 记忆在项目维度可用模型变化时安全回退(记忆值不在当前 MODELS 列表 → 用现状默认)。
6. 抽屉「实验特性」开 WebCodecs → localStorage 键写入 → 刷新后 `isWebCodecsExperimentEnabled` 为 true(既有逻辑接管)。
7. `pnpm test` / `pnpm lint` 全绿(后端仅 schema 字段,`uv run pytest -q` 顺带)。

## 3. 设计要点

### 3.1 注册表的「localStorage 直写型字段」

WebCodecs toggle 不走 preferences PATCH,注册表需要一种 `storage: "local"` 字段声明(读写器自带)。这也为后续同类设备级开关(如未来 GPU 相关)留好形状——注册表从「preferences 字段表」泛化为「设置字段表」,但本版只加这一种特例,不过度设计。

### 3.2 对话框粘性的回写时机

**提交成功才回写**(onSubmit resolve 后),取消/失败不回写——避免「试了一下 60 帧没敢点」也被记住。`videoDialogMemory.ts` 提供 `readDialogMemory<T>(key, validate)` / `writeDialogMemory`,validate 兜底脏 JSON 与枚举漂移(如记忆的 rangePreset 不在 `RANGE_PRESETS` → 丢弃)。

### 3.3 `largeFrameStep=grid` 与采样网格

`VideoPlaybackOverlay` 已接收采样信息(`videoSamplingGrid.ts` 体系);`grid` 模式下 step = samplingStep,无网格(samplingStep<=1)回退 10。这直接解决「Shift+→ 跨多个网格单元造成困惑」的原始痛点,且默认不变。

### 3.4 jog 复位语义

`PAUSED_JOG_PLAYBACK` 的 `rate: 1` 改为 `rate: defaultPlaybackRate` 需谨慎:jog(JKL)体系的 rate 与播放 rate 是两个概念(`VideoJogPlayback`)。本版只动**任务打开时的初始播放速率**与**暂停复位目标值**,JKL 倍速链(连续按 L 加速)逻辑不动;实现时若发现 jog 复位与初始速率共享路径有副作用,允许收窄为「仅初始速率」,在 PR 里说明。

## 5. 已知风险 / 未尽事项

- **`VideoPlaybackRate` 联合类型**(`VideoStage.tsx:87`):defaultPlaybackRate 的取值域限定为现有 5 档,schema 用枚举而非自由 float,杜绝「设置了 3x 但档位列表没有」的悬空值。
- **Tracker modelKey 记忆 vs 项目能力**:不同项目绑定的 ML backend 不同;回退规则(记忆值不在列表 → 默认)必须有单测。v0.15.7 项目级默认落地后,优先级变为 项目默认 > 用户记忆 > 现状硬编码,本版代码留好插入点(初值解析单独函数)。
- **VideoStage.test.tsx 体量大**(79.6K):动初始化路径可能牵连快照;按既有测试组织小步改,避免重写。

## 6. 验证策略

- **单测**:videoDialogMemory 读写/容错;两对话框「提交回写、取消不回写、脏记忆回退」;largeFrameStep 三态(数字/grid 有网格/grid 无网格);初始速率注入。

- **回归红线**:JKL 倍速链、循环区间、书签行为不变(既有测试守)。
