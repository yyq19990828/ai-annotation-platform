# v0.11.4 · DiscussionPanel issues tab + IssueLayer 双向联动

> [epic 索引](2026-05-25-v0.11-annotation-feedback-convergence.md) · B 组（前端）· 依赖：v0.11.1 骨架

## 目标

issues tab 列出像素锚点 issue（`kind=issue` / `anchor_type=pixel`），与画布 `IssueLayer` 图钉双向联动定位。

## 现状

- `IssueLayer.tsx`（`pages/Workbench/stage/image/`）已渲染 pixel-anchored feedback 为图钉（Circle + "i"，status 配色 open=橙/resolved=绿/wont_fix=灰，armedForDrop 落点创建），v0.10.20 已落。
- 缺：右栏 tab 化的 issue 列表 + 列表↔图钉的双向定位。

## 前端改动

- issues tab 内容：
  - `useFeedbacks({ kind: "issue" })` 列表 + 按 `status` 过滤。
  - 单击列表项 → `Konva.Stage.to({ x, y, scale })` 平移定位到对应图钉 + 高亮（IssueLayer 已支持高亮 id 加阴影）。
  - 反向：hover / 单击 IssueLayer 图钉 → 切到 issues tab + 高亮对应列表行（复用类似 `useHoveredCommentStore` 的轻量共享 store，或新建 `useActiveIssueStore`）。
- 仍在 `flags.discussionPanel` 后。
