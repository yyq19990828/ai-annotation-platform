# v0.15.x · 工作台设置体系 Epic(通用 / 图片 / 视频 / 点云)

> 规划日期 2026-06-11 · 范围:把三大工作台(image / video / three-d)散落的硬编码常量、会话级 toggle、每次重选的对话框默认值,收敛到「通用 / 图片 / 视频 / 点云」四分类的统一设置体系。本文件是**索引 + 取舍说明**,每个版本的详细计划见各自 plan 文件。

## 2. 三条设计原则(贯穿五版)

1. **用户级 vs 项目级双维度**:纯手感/显示偏好(缩放步长、点大小、透明度)归用户 preferences;影响标注产出一致性的(3D 默认框尺寸、传播覆盖策略、AI 默认模型)归项目配置并可锁定用户侧。判别标准:**配错了会不会让两个标注员产出不一致** —— 会,就是项目级。
2. **「记住上次」≠ 设置项**:toggle 类状态(SAM 输出模式、点云相机上色、传播对话框参数)用户要的是「别重置我」,不是「去设置页配置」。这类做**会话粘性持久化**(localStorage 按 userId 分桶,沿用 `useWorkbenchConfig` 的 `workbench.{userId}.*` 键名约定),不进设置页,避免稀释设置页。
3. **档位 > 原始数值**:缓存容量、预取窗口这类常量归并成「性能档位」三档暴露,不做 about:config;真正的实验项(WebCodecs)单独「实验特性」分组。

## 5. 明确不做(本 epic 范围外)

- **快捷键自定义**:`hotkeys.ts` 硬编码数组改为可配置是独立重活(冲突检测、cheat-sheet 联动、per-stage 作用域),收益面窄,等真实诉求。
- **mask 编辑颜色 / 框虚线模式 / 标签字号**等纯视觉微调:低价值,且部分受 CSS token 体系约束(CLAUDE.md §6),不为此开口子。
- **自动保存间隔**:当前由后端驱动,客户端定时备份是另一套机制。
- **per-project 用户偏好**(同一用户在不同项目存不同手感):双维度叉乘让存储与 UI 复杂度翻倍,先观察单维度够不够用。

## 6. 验证总策略(贯穿五版)

- **回归红线**:现有 5 个偏好字段(smoothImage / cssImageFilter / controlPointsSize / snapToGrid / longTaskSampleRate)+ layout 子树 + v0.10.10 项目锁定行为,五版都不得破。每版 `uv run pytest -q` / `pnpm test` / `pnpm lint` 全绿。
- **迁移验证(v0.15.3 单独)**:对含旧平铺 preferences 的存量用户行,迁移后 GET /auth/me/preferences 输出新子树形态且值不变;回滚脚本可逆。
- **每版默认值 = 现状**:所有新设置项的默认值必须等于当前硬编码值(如 zoomStepFactor=1.1、snapThresholdPx=8、pointSize=0.06),保证「不动设置的用户行为 byte 级不变」——这是每版最重要的回归判据。
