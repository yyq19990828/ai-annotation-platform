# v0.10.28+ · 数据类型语义重构 + 几何工具扩展（Epic 协调计划）

> 状态：进行中 · 起草 2026-05-20
> 触发：用户反馈 ① 新建项目"数据类型"半模板半自定义、语义矛盾；② 图像几何工具只有矩形框，需扩展旋转框/关键点等。

## 1. 问题诊断（实锤）

新建项目 Step1（`apps/web/src/components/projects/steps/Step1DataTypeAndTools.tsx`）渲染的"数据类型"
用的是 `constants/projectTypes.ts` 的 `PROJECT_TYPES` —— 7 项全是**任务级**预设
（图像·目标检测 / 图像·实例分割 / 图像·关键点 / 3D点云·立体框 / 视频·多模态 / 视频·时序追踪 / 多模态·图文对）。
名字写死了任务，但下方"工具集"又是**全自定义多选** → 出现"选了关键点却没有关键点工具"的矛盾。

代码里其实已有一套更干净的 `constants/toolUnits.ts::PROJECT_DATA_TYPES`（image/video/lidar 纯媒体类型），Step1 未采用。

## 2. 方向决策（已与用户确认）

- **数据类型层**：B 路线 —— 纯媒体类型 + 全自定义工具集。任务表达完全交给工具集。
- **`type_key`**：彻底退役（迁移消费方到 `data_type` / `tool_bindings`）。
  - ⚠️ 约束：物理删列受阻于 **video 子类型抽象缺失**（`data_type` 只到 video 粒度，无法区分 track/mm）。
    本 epic 做到 **UI 退役 + `data_type` 接管媒体维度分流 + 列保留**；删列单独排期（待 video 工具单元抽象就绪）。
- **新增几何工具**：旋转框（rotated bbox）、关键点（COCO 范式·命名+骨骼）、折线（polyline）。
  - 旋转框 → **独立 `rotated_bbox` 工具单元**。
  - 关键点 → **新 `keypoint` 工具单元** + 骨骼配置。
  - 折线 → 复用已占位的 `polyline` 工具单元。

## 3. 几何 Schema 固化定义（后端 `apps/api/app/schemas/_jsonb_types.py`，归一化坐标 [0,1]）

```python
class RotatedBboxGeometry(BaseModel):
    type: Literal["rotated_bbox"] = "rotated_bbox"
    cx: float; cy: float          # 归一化中心
    w: float; h: float            # 归一化宽高（>0）
    angle: float                  # 度数 [0,360)，绕中心顺时针

class PolylineGeometry(BaseModel):
    type: Literal["polyline"] = "polyline"
    points: list[list[float]]     # 归一化 [x,y]，min_length=2，开放不闭合

class KeypointGeometry(BaseModel):   # COCO 范式
    type: Literal["keypoint"] = "keypoint"
    points: list[Keypoint]        # Keypoint{ x:float, y:float, v:int∈{0,1,2} }，顺序与单元 schema.nodes 对齐
```

骨骼/命名拓扑承载（**类别级元数据**，不进每个实例几何）——扩展 `ToolBinding` 增加可选字段：

```python
class KeypointSchema(BaseModel):
    nodes: list[KeypointNode]     # KeypointNode{ name:str, color:str|None } 有序
    edges: list[list[int]]        # 骨骼连线，节点索引对 [[i,j],...]

class ToolBinding(BaseModel):
    enabled: bool = False
    classes: list[ToolClassEntry] = []
    attribute_schema: AttributeSchema = ...
    keypoint_schema: KeypointSchema | None = None   # 仅 keypoint 单元使用
```

`ToolUnitId` 两端新增：`"rotated_bbox"`、`"keypoint"`（`polyline` 已存在）。
