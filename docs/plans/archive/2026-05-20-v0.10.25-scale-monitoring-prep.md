# v0.10.25 · 业务规模 / 监控触发项提前布局

> 主题：把 ROADMAP「等业务规模 / 监控触发（先观察、不做）」一节的 4 项**提前**落地为可上线 / 可上手的形态，不等阈值真正触发。用户决策：可提前布局。

## 背景

ROADMAP §「等业务规模 / 监控触发」长期挂着 4 条「先观察」项。本版把它们做成「平时无害、规模到达时即用」的就绪形态：

1. **predictions 月分区 Stage 2**（ADR-0006）：触发阈值单月 INSERT > 100k 或总行数 > 1M。
2. **batch_summary stored 列**：当前实时 GROUP BY，未到瓶颈。
3. **审计日志归档物化**（ADR-0007）：partition + beat archive 框架已闭环，缺冷数据查询回源。
4. **`/health/celery` 真实心跳秒数**：当前 `last_heartbeat_seconds_ago` 硬编码 0。

## 范围（做什么）

### #4 `/health/celery` 真实心跳（最低风险，无迁移）
- 新建 `app/workers/heartbeat.py`：beat task 周期写 Redis key `celery:hb:{worker}` = unix ts（SETEX，TTL > 间隔）。
- `celery_app.py` beat_schedule 加 `worker-heartbeat`（间隔由 config 控制）。
- `health.py::_check_celery`：读 Redis key，`last_heartbeat_seconds_ago = now - ts`（无 key → None），替换硬编码 0；Prometheus Gauge 同步真实值。
- `config.py` 加 `worker_heartbeat_interval_seconds`（默认 30）。

### #3 审计归档查询层回源（无迁移）
- partition + archive + async_job 已闭环（迁移 0037 + `audit_partition.py` beat），缺「归档到 MinIO 的冷数据无端点可读」。
- `GET /audit-logs` 加 `include_archived` 语义说明 + 新增 `GET /audit-logs/archives`（列出已归档月份）+ `GET /audit-logs/archives/{year}/{month}`（回源读 jsonl.gz，super_admin only）。
- 复用现有 `audit_partition_service` / storage_service，不新增表。

### #2 `batch_summary` 物化列（中风险，迁移 0079）
- `projects` 加 `batch_summary JSONB`（default `{}`）。
- 写时维护：8 个触发点全部汇入 `BatchService._sync_project_counters()`，仅此一处加 batch 聚合 GROUP BY 写入。
- API 改读列（`list_projects` / `get_project` 删实时 GROUP BY，fallback 容错）。
- 迁移 0079：加列 + 一次性 GROUP BY 回填。

### #1 predictions 月分区 Stage 2（最高风险 / 破坏性，迁移 0080，主进程亲自做）
- 按 0037 模板：rename → 建 RANGE(created_at) 分区父表（PK `(id, created_at)`）→ 预建子分区 → INSERT SELECT → DROP legacy。
- PK 重塑 + 下游复合 FK：
  - `prediction_metas` 加 `prediction_created_at` + 复合 FK / UNIQUE。
  - `annotations` 加 `parent_prediction_created_at` + 复合 FK（nullable）。
- model 同步：`Prediction` PK 改 `(id, created_at)`；下游加冗余列。
- 自动建分区：beat task `ensure_future_prediction_partitions`（复用 audit 模式）。
- **dev 应用验证**；生产侧仍按 ADR-0006 阈值触发执行（迁移就绪、battle-tested）。

## 不做（明确排除）
- batch_summary 触发器 / 独立 beat 重算：写时更新已足够，避免最终一致性窗口。
- 归档物化视图（月度汇总 BI）：等 10M+ 行触发。
- predictions 分区的生产执行：仅 dev 应用 + 就绪，不在无压力的生产强行 swap。
