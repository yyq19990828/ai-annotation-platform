## 1. 结论

下一版在点云主视图增加纯前端、会话态的测量 overlay。用户通过独立“测量”工具吸附真实点云，构造两点或多段路径，并读取三维总长、水平总长与首尾高差。测量不属于 Annotation，不调用标注 API，不进入撤销栈、导出、审计或账号偏好；切换任务时全部清理。

当前 `geometry/ground.ts` 只以高度中位数提供放框 fallback，不具备可解释地面分割、残差或置信合同。本版不得把它包装成“地面预览”，也不增加法向、曲率、平面度、持久化 measurement geometry 或自动拟合消费路径。

## 2. 当前事实

- `PointCloudScene` 已持有主点云的 raycaster、渲染点到源点的 stride 和点云资源生命周期，能够返回真实点云命中，不需要新 loader 或后端端点。
- `ThreeDWorkbench` 已用 `ThreeDTool`、统一键盘处理和 canvas click/drag 阈值管理选择、连续建框与点云分割；测量必须接入同一事件所有权，不能另挂全局 canvas listener。
- `usePointCloudScene` 是 React 状态向命令式 Three.js 场景同步的唯一边界；测量路径沿用该边界，不从 DOM 或测试探针直接改 scene。
- 当前没有 measurement Annotation 类型、API、导出合同或用户偏好。本版保持这些公共实体为零增量。

## 3. 用户合同

1. 左侧 3D 工具栏显示“测量”，快捷键为 `M`；锁定、审核和 viewer 只读场景仍可使用。
2. 激活后，每次单击必须命中主点云中的真实渲染点；未命中只提示，不创建自由空间锚点。
3. 第一个点建立起点，后续点依次形成多段路径；连续点击同一个源点不重复追加。
4. 两个及以上锚点后，`Enter` 或“完成当前”把草稿放入当前任务的测量列表；完成后工具保持激活，可继续新建。
5. 草稿存在时 `Esc` 只取消当前草稿；草稿为空时 `Esc` 回到选择工具。`V` 始终回到选择工具。
6. 每条完成结果可隐藏、显示或删除；“全部清除”只清理测量，不改标注。
7. 切换 task 后草稿和已完成结果全部清空，旧 task 的测量线不能泄漏到新点云。

读数口径：

- 三维总长：各段 `sqrt(dx² + dy² + dz²)` 之和。
- 水平总长：各段 `sqrt(dx² + dy²)` 之和。
- 首尾高差：最后锚点 `z -` 第一锚点 `z`，保留正负号。
- 世界坐标和距离单位沿用工作台 ISO 点云坐标，显示单位为米。

## 4. 数据流与实体边界

```text
canvas click
    │ drag threshold + point raycast
    ▼
MeasurementAnchor(source point index, world xyz)
    │ React session state
    ├──────────────► pure distance summary ─► measurement panel
    │
    └──────────────► usePointCloudScene ─► PointCloudScene measurement layer

Annotation API / history / export / preferences
                    ▲
                    └──────── no edge
```

Entity delta: `+1 / -0`，只增加一个前端 `ThreeDTool="measure"` 工具态。没有新路由、API、Schema、数据库表、迁移、环境变量、依赖、后台服务或长期 feature flag。

## 6. 实施与验收门

### Slice A · 数值与渲染合同

- 新增纯函数并锁定三维总长、水平总长、首尾高差。
- `PointCloudScene.pickPoint` 只返回真实命中的渲染点及其源点索引，不使用 `groundZ` fallback。
- measurement layer 每次同步前释放旧 geometry/material，scene dispose 时不遗留资源。

验收：纯函数测试通过；空路径与单点读数为零；典型 `3-4-12` 夹具返回 `13 / 5 / 12`。

### Slice B · 交互与会话生命周期

- 工具、快捷键、canvas click/drag、完成、取消、隐藏和删除接入现有 3D 状态机。
- 单条路径最多 64 个锚点，单任务会话最多 20 条完成结果；达到上限时明确提示。
- 切 task 清空结果，切换工具只丢弃未完成草稿，已完成结果保留到 task 切换或用户删除。

验收：测量过程没有 Annotation POST/PATCH/DELETE；相机拖动不落锚点；覆盖层按钮不会穿透为点云点击；只读场景可测量。

## 7. 风险与回滚

- **事件冲突**：canvas click 可能来自 OrbitControls 拖动或覆盖层冒泡。继续使用现有 pointer-down 位移阈值，并要求 measurement 分支只接受主 canvas target。
- **点命中歧义**：稀疏或远距离点可能难命中。第一版保持显式失败，不回落自由空间或地面平面，避免制造虚假精度。
- **资源泄漏**：频繁加删路径会重建 Three.js 对象。每次同步和 scene dispose 都统一释放 geometry/material，并用事件驱动 renderer 只提交必要帧。
- **回滚**：移除测量工具入口和 session state 即可；没有数据库、对象存储、导出产物或用户偏好需要迁移或清理。

## 8. 最脆弱假设

本计划假设标注员在判断目标尺寸、框体合理性和场景间距时会高频使用测距。如果真实使用表明测量几乎不改变决定，应停止后续地面/几何辅助层扩展；已实现的会话态工具可直接隐藏，不留下数据债务。
