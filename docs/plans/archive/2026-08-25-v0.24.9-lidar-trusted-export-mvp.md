# v0.24.9 · LiDAR 可信导出 MVP

> Status: implemented and verified
>
> 规划日期：2026-08-25
>
> 基线：当前工作树含尚未发版的 v0.24.8 跨帧任务中心改动；本计划只新增导出合同、实现与文档，不改版本源、不提前发版。

## 1. 结论

本版只交付“严格预检 + 单相机 KITTI 真值导出”。平台原生 AAP JSON 与 Point Mask 保持原行为；nuScenes 暂时在点云导出 UI 中禁用，API 以稳定问题码拒绝，不再生成带零 timestamp、固定 scene token 或单位 ego pose 的伪标准包。

KITTI 必须显式选择一个 camera role。每个导出任务都要有该角色对应的图像、有效内外参和真实宽高；任一任务不满足时，在创建 `AsyncJob` 前返回可定位问题列表。worker 打包前重复同一校验，防止排队期间元数据漂移绕过门禁。

## 2. 冻结合同

### 2.1 请求与预检

- `ExportRequestBody` 增加可选 `lidar.kitti_camera_role`，只在点云项目选择 KITTI 时消费。
- 项目与批次各提供 LiDAR 导出预检端点；请求携带 `targets` 与同一 `lidar` 选项。
- 响应包含 `ready`、可选 camera roles、已选 role、检查 task 数、总问题数及有上限的问题明细。
- 问题至少区分：nuScenes 尚不可信、未选择相机、相机角色不存在、帧缺相机、标定缺失或非法、图像宽高缺失或非法、主点云/轴约定缺失或非法。
- `aap_json` 与 `pointmask` 不依赖 KITTI 相机，不因 KITTI 之外的标定缺口失败。

### 2.2 KITTI 几何

- `Annotation.geometry.type=box_3d` 继续是唯一 3D 真值；不持久化派生 2D 框。
- 标注框存于平台 ISO 8855 坐标。每帧先按主点云数据集的 `axis_convention` 逆映射到数据源 LiDAR 坐标，再使用所选相机的 row-major `extrinsic`、可选 `rect` 和 `intrinsic` 投影。
- 2D bbox 使用 8 个角点与 12 条边对近裁剪面裁剪后的投影包围盒；与图像边界求交，部分可见时计算 `truncated = 1 - clipped_area / raw_area`。
- 完全在相机后方、投影退化或与图像无交集的对象不写入 `label_2`，并进入 `export_report.json`；这类几何可见性不是数据合同错误，不阻止整包。
- `dimensions` 固定输出 `height width length`；`location` 使用相机坐标中的底面中心；`rotation_y` 由框局部 +X 朝向在相机 XZ 平面求得；`alpha = rotation_y - atan2(x, z)`，角度归一化到 `[-π, π]`。
- `occluded` 继续读取属性并限制为 0–3；`truncated` 只使用真实投影结果，不再信任手工占位属性。
- `calib/*.txt` 只写所选相机的真实 `P2`、`R0_rect`、`Tr_velo_to_cam`，不得生成 identity 或 `.unverified` 文件。

### 2.3 失败语义

- 预检失败返回 409 结构化详情；导出 API 在失败时不得创建 `AsyncJob`、不得派发 Celery、不得生成 ZIP。
- worker 重检失败使既有 job 进入失败态，错误详情保留稳定 issue code。
- 直接请求点云 `nuscenes` 一律返回 `nuscenes_export_not_trusted`；恢复入口必须另立实现计划并具备真实 pose、timestamp 与引用完整性测试。

## 3. 数据流

```text
targets + lidar.kitti_camera_role
              │
              ▼
项目/批次 preflight ── issues ──► UI 相机选择与修复清单
              │ ready
              ▼
导出 API 重检 ──► create AsyncJob ──► export worker 重检
                                      │
Annotation(box_3d, ISO) ──────────────┤
Dataset axis convention ──────────────┼─► KITTI 投影/裁剪
selected camera calib + image size ───┘        │
                                               ▼
                                label_2 + calib + export_report
```

## 4. 变更面

实现覆盖 API、service、worker packaging、前端和文档；不做数据库迁移，不新增环境变量。

- 后端 schema：`apps/api/app/schemas/export.py`
- 后端 API：`apps/api/app/api/v1/projects.py`、`apps/api/app/api/v1/batches.py`
- 预检与投影：`apps/api/app/services/exporting/lidar.py`，必要时新增一个窄 service 文件
- 打包与 worker 参数：`apps/api/app/services/exporting/packaging.py`、`apps/api/app/workers/export.py`
- 前端 API / UI：`apps/web/src/api/projects.ts`、`apps/web/src/api/batches.ts`、`apps/web/src/pages/Dashboard/ExportModal.tsx`
- 测试与合同：LiDAR API/serializer/packaging tests、ExportModal tests、OpenAPI snapshot
- 文档：用户导出说明、点云数据模型、`CHANGELOG.md`、Epic 与路线索引

## 5. 实施切片与验收门

1. **严格预检**：项目与批次端点返回逐 task / camera 问题；导出创建前复用同一 service。验收：缺相机、坏矩阵、缺宽高、nuScenes 均无 job。
2. **KITTI 真值投影**：移除 bbox/identity 占位，生成真实字段与可见性报告。验收：固定 fixture 覆盖正常、近裁剪、部分出画面、完全不可见和非 ISO 数据源轴。
3. **打包与 UI**：显式相机选择、问题列表、禁用 nuScenes。验收：相机切换会重新预检，通过后请求携带 role；失败不可点击入队。
4. **全链验证**：后端定向测试、前端单测、typecheck、lint、OpenAPI、文档构建与真实 Chromium 手工/自动验收。

## 6. 非范围

- 不实现完整 nuScenes tables、pose、timestamp、token 链或 sweep。
- 不实现多相机 COCO 派生 2D。
- 不新增标定修复、图像尺寸探测或历史数据回填；预检只诚实指出缺口。
- 不改变 AAP JSON、Point Mask、视频 KITTI 和图片导出合同。
- 不处理 3D Quality / GT / Consensus，也不改变 WebGPU 实验资格。

## 7. 回滚

若真实投影出现标准不一致，关闭点云 KITTI UI 与 API 入口，保留 AAP JSON / Point Mask；不得恢复 `-1` bbox、identity calibration 或 nuScenes 假字段。该回滚不需要数据库降级。
