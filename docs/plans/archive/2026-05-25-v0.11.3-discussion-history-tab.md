# v0.11.3 · DiscussionPanel history tab

> [epic 索引](2026-05-25-v0.11-annotation-feedback-convergence.md) · B 组（前端）· 依赖：v0.11.1 骨架

## 目标

history tab 渲染审计/变更时间线，支持标注级与任务级两种上下文（与 comments tab 同步切换）。

## 后端改动（条件性）

- `useAnnotationAuditHistory` 现按 annotation 查。任务级需要 `GET /tasks/{id}/audit-history`：
  - **若该端点已存在**（v0.10.19 plan 曾提及）→ 仅前端接入，无后端改动。
  - **若不存在** → 本切片补该端点（聚合该 task 下所有 annotation 的 audit + task 级动作），复用现有 audit 序列化工具。开工前先 grep 确认。

## 前端改动

- `useAnnotationAuditHistory(annotationId | null, taskId?)`：
  - `annotationId` 非 null → 现有标注级查询。
  - null → 降级查 `GET /tasks/{id}/audit-history`。
- history tab 复用 `AnnotationHistoryTimeline` 子组件渲染。
- 仍在 `flags.discussionPanel` 后。

## 验证

- `pnpm --filter web typecheck` + `lint:css-tokens`。
- 若新增端点：`cd apps/api && uv run pytest`（补端点测试）。
- flag on 走查：选框 → 标注级历史；不选框 → 任务级历史均正确渲染。
- dark mode 走查。

## 回退

flag off 回退；若新增了端点，端点本身向后兼容（纯新增 GET），无需回退。
