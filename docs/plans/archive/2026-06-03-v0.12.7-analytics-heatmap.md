## 目标
1. `/admin/analytics` 三个手搓 CSS 条面板升级为 recharts。
2. 新增工时热力图(星期 × 小时),呈现团队作息分布。

## 实现

### 后端
- `analytics_queries.activity_heatmap(days)`:DuckDB 查 `task_events`,`dayofweek(started_at)`(**0=周日 .. 6=周六**)× `extract('hour' FROM started_at)` 聚合 `kind='annotate'` 事件计数;days 钳制 `[1,365]`;`_connect_reader` + try/finally,对齐既有 3 个查询。
- `admin_analytics.py`:`PanelName` Literal 加 `"activity_heatmap"` + 分支。

### 前端
- `adminAnalytics.ts`:`"activity_heatmap"` 枚举 + `HeatmapCell` 接口 + `activityHeatmap()`。
- `AnalyticsPage.tsx`:吞吐 → recharts `LineChart`、reject → 横向 `BarChart`、耗时保留 KPI;新增热力图面板(7 行星期 × 24 列小时 CSS grid)。
  - recharts 颜色经 `cssVar()` 运行时读 token;热力图格子 `background: var(--color-accent)`,强度走 `--heat-opacity`(`useElementStyle` 注入,§6 合规,无内联 style)。
  - 星期标签 `WEEKDAY_LABELS = ["周日"..."周六"]` 下标直接对齐后端 dayofweek 约定。
