# v0.17.14 · 视频参考框完整卡尔曼滤波

> 源自 [ROADMAP](../../ROADMAP.md) 视频 epic 延后项「参考框完整卡尔曼滤波（P3）」。
> 把参考框运动预测从「最近两关键帧恒速外推」升级为「遍历先行关键帧前向滤波 + 末段预测」的完整恒速卡尔曼。
> **红线**:默认仍为关（默认=现状）;纯前端启发式,零后端依赖,不引矩阵库。

## 1. 现状

`trackReferenceAtFrame`(`apps/web/src/pages/Workbench/stage/videoStageGeometry.ts:212`)两档:

- `predict=false`(默认):取最近关键帧 bbox。
- `predict=true`:取当前帧之前最近两个可见关键帧恒速外推 `b + (b-a)/span·dt`。

问题:只用末两帧 → 单段噪声放大、无平滑、无加速度、无不确定度,变速/转向素材上漂移明显。

实验开关 store:`videoReferencePredict.ts`(localStorage boolean,`useSyncExternalStore` 即时生效);设置字段 `experiment.videoReferencePredict`(`workbenchSettingsFields.ts:537`)。

## 2. 模型:解耦为 4 个 1D 恒速卡尔曼

8 维状态 `[cx,cy,w,h,vx,vy,vw,vh]` 在恒速模型下四维互不耦合,F/Q/R/P 块对角,**等价于 4 个独立 1D CV-KF**,免 8×8 矩阵求逆。每维 `d ∈ {cx,cy,w,h}`:

```
状态 x_d = [p, v]ᵀ
F(dt) = [[1, dt],[0, 1]]            // p' = p + v·dt
H = [1, 0]                          // 只观测 p
R = r                              // 标量,创新协方差 S 标量,无需求逆
Q(dt) = q·[[dt³/3, dt²/2],[dt²/2, dt]]   // 连续白噪声加速度模型
```

坐标:存储是左上角 `{x,y,w,h}`,滤波前转中心 `cx=x+w/2, cy=y+h/2`,输出后转回。中心化让平移与缩放解耦。

## 3. 算法

```
trackReferenceKalman(track, frame, preset):
  K = 当前帧之前的可见关键帧(升序)            // getTrackIndex().visibleKeyframes
  if K.length < 2: 回退最近关键帧(predicted=false)   // 同现状 fallback

  每维初始化: p=K[0].center_d; v=(K[1]-K[0])/Δframe; P=[[σ0²,0],[0,σv0²]]
  for i in 1..last: dt=Δframe; predict(dt); update(K[i].center_d)
  dt = frame - K[last].frame; predict(dt)            // 末段外推,不 update
  bbox = clampGeom(中心→左上角)
  return { bbox, predicted:true, originFrame:K[last].frame, uncertainty? }
```

单维标量化(无矩阵求逆):

```
predict: p += v*dt; P00 += dt*(2*P01 + dt*P11) + Qpp; P01 += dt*P11 + Qpv; P11 += Qvv;
update:  S = P00 + r; k0 = P00/S; k1 = P01/S; y = z - p;
         p += k0*y; v += k1*y;
         (P00,P01,P11) -= 增益修正
```

## 4. 噪声预设(放 `experiment.*`,不外露原始数值)

| 档位 | 语义 | 行为 |
|---|---|---|
| **平稳** | 小 q / 大 r | 信模型,顺滑抗噪,跟突变慢 |
| **灵敏** | 大 q / 小 r | 信观测,紧跟最新关键帧 |

中心与尺寸内置不同 q(尺寸更稳,`q_size < q_pos`),作为预设常量。

## 5. 不确定度可视化（本版已实现）

末段 predict 后各维 `√P00 = σ`。`runReferenceKalman` 输出 `sx/sy/sw/sh`,经 `TrackReferenceResult.uncertainty` → `VideoGhostView.uncertainty` 传到 Konva 层。`VideoKonvaTracksLayer` 在参考框外画一圈淡色虚线 `<Ellipse>`,半轴 = 框半宽高 + 2σ(≈95% 置信)。dt 大、关键帧稀时 P 自然增长 → 椭圆膨胀,直观表达「预测越不确定」。仅 kalman 档有 `uncertainty`,linear/off 不画。

## 7. 边界与回退

- 先行可见关键帧 < 2 → 回退最近关键帧,同现状。
- outside ranges:`visibleKeyframes` 已过滤;跨遮挡大 dt → Q 累积、P 增大,预测自然变不确定。
- 滤波全程不 clamp(破坏线性高斯假设),仅出口 `clampGeom` 一次。
- dt 用 `frame_index` 之差,非物理时间,与现状一致。

## 8. 性能与缓存

O(N),N=先行关键帧数(非总帧数)。可按 track + lastKeyframeFrame 记忆前向滤波后验,扫帧时只重算末段 predict。沿用现有 `WeakMap<track,...>` 模式(本版若量级无压力可后置)。

## 9. 测试 `videoReferenceKalman.test.ts`(确定性)

1. 线性运动+噪声 → KF 输出方差 < 两点外推方差。
2. 恒速序列 v 收敛真值。
3. 变速/转向 → KF 漂移 < linear 漂移。
4. 回退:关键帧 < 2 / 跨 outside range。
5. 平稳 vs 灵敏:阶跃输入下灵敏档响应更快。
6. clamp 只在出口生效。

`videoStageGeometry.test.ts` 既有 `trackReferenceAtFrame` 用例随签名改适配。
