# v0.10.24 · 生产上线 / 监控触发杂项收口

> 主题：从 ROADMAP「等业务规模 / 监控触发」「现在可做」两节挑一组低风险、可立即开工的生产上线杂项，一次收口。不抢视频 / 工作台主线。

## 背景

巡检生产就绪面发现三处缺口，均小颗粒、低风险：

1. **版本号四处漂移**：`/health` 聚合端点硬编码 `version: "0.7.6"`、FastAPI `title version=0.8.8`、`pyproject.toml=0.1.0`、`apps/web/package.json=0.8.8`。运维 scrape `/health` 拿到的版本号长期 stale，是真实的监控误报。
2. **dev 无 SMTP 收件箱**（ROADMAP §「现在可做」）：`app/services/email.py` 的 admin「发送测试邮件」是真实 smtplib 代码，但本地无收件箱可验证，只能对着公网 SMTP 试。
3. **Celery worker 无健康探针 / 无优雅关闭窗口**：`docker-compose` 的 `celery-worker` / `celery-beat` 既无 `healthcheck` 也无 `stop_grace_period`，生产部署时编排层无法判活、SIGTERM 直接砍在途任务。

## 范围（做什么）

### 1. 版本号单源真值
- `app/config.py` 加 `app_version: str = "0.10.24"`。
- `app/main.py` `FastAPI(version=settings.app_version)`。
- `app/api/health.py` `/health` 返回 `settings.app_version`（删硬编码 `0.7.6`）。
- `pyproject.toml` `0.1.0 → 0.10.24`、`apps/web/package.json` `0.8.8 → 0.10.24`。
- 发版从此只改 config + 两个 manifest 三处。

### 2. dev SMTP 测试链路（mailpit）
- `docker-compose.yml` 加 `mailpit` service（`axllent/mailpit`，SMTP `1025` / UI `8025`，`readyz` healthcheck）。
- `.env.example` 加 SMTP 段，给出 mailpit 默认值与 host/容器两种连法说明。
- `SystemSettingsService` 已有 env fallback（`_env_default → getattr(settings, key)`），env 配的 SMTP_* 直接被 email.py 读到，无需改后端代码。

### 3. Celery 健康探针 + 优雅关闭
- `celery-worker` 加 `healthcheck`（`celery -A app.workers.celery_app inspect ping -d celery@$HOSTNAME`）+ `stop_grace_period: 30s`。
- `celery-beat` 是调度进程不响应 inspect ping，只加 `stop_grace_period: 30s`。

## 不做（明确排除）

- **Celery 全局 `task_time_limit` / `soft_time_limit`**：`gpu` 队列的视频 tracker 可能合法跑很久，全局硬超时有误杀风险，也不在 roadmap 上。需要时按 per-task 维度单独排期。
- **API/web 的 docker healthcheck**：dev 下 API/web 跑 host 不进 Docker，保持注释现状。
- **`/health/celery` 真实心跳秒数**：仍待客户提分钟级新鲜度需求（ROADMAP 监控触发项）。

## 验证

- `docker compose config --quiet` 通过。
- `uv run pytest tests/test_health.py` 全绿（无测试断言版本字符串，改动安全）。
- `settings.app_version == "0.10.24"`。
- mailpit：smtplib 发信到 `localhost:1025` → mailpit `/api/v1/messages` 收到（与 admin 按钮同一 smtplib 路径）。
- celery healthcheck：容器内执行 `inspect ping` exit 0；重建后 `docker inspect` State.Health = healthy。
