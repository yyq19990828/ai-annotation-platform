# v0.15.24 · 相机图「2D 框种 3D 框」(frustum fit)

> 规划日期 2026-06-14 · 范围:[点云+图像联合标注 epic](../ROADMAP/2026-06-14-pointcloud-image-joint-annotation.md) **Phase 1 首版**。在相机投影视图上拖一个 2D 矩形 → 该相机标定反算视锥 → 选出锥内点云 → `autofit.psrFromPoints` 拟合 3D box 初值 → 落 box_3d 并选中微调。读方向(3D→2D 投影)已于 v0.13.4 完成,本版补写方向起点。
>
> **前置依赖(硬)**:v0.13.4(`CameraProjectionView` + `projection.ts` `projectPoints`)、`autofit.ts`(`psrFromPoints`/`fitYaw`/`fitBottom`)、`SensorCalibration`、v0.15.7(项目级 `box3dDefaultSize`)。**遵守 epic 决策 J1-J4**:box_3d 唯一真值、2D 矩形瞬态不落库、不引入新标注类型、复用既有投影/拟合。

## 1. 背景与现状

### 1.1 要解决的问题

远处 / 稀疏 / 遮挡目标在点云主视图里难以直接框(点太少看不清边界),但在相机图上**一眼可见**。本版让标注者在相机图上一框,即在 3D 里生成一个位置/朝向/尺寸合理的 box_3d。这是「2D 辅助 3D」的最高杠杆动作。

### 1.2 现状(已读源码)——拟合段已就位

- `CameraProjectionView.tsx`(v0.13.4):相机图 + 投影 overlay,已有 `onClick`(反选框)、`onMouseMove`(深度 hover)。**当前 read-only,无画框交互**。
- `projection.ts`:`projectPoints(points, calibration)` 前向投影(lidar→像素 + 可见性),本版选点直接复用(前向投影每个点,判像素是否落在矩形内)。
- `autofit.ts`:`psrFromPoints(points, padding)` 从点簇拟合 PSR;`fitYaw`/`fitBottom`/`fitSize` 精修。**拟合段不用新写**。
- 3D 新框落库路径:点击放置新框已走 `useCreateAnnotation`(`ThreeDWorkbench.tsx`),复用即可。
- 项目级默认尺寸 `box3dDefaultSize`(v0.15.7)作空簇 fallback。

### 1.3 做 / 不做

**做**:
- `CameraProjectionView` 加「种框模式」:拖一个 2D 矩形(natural 像素系),mouseup 回调 `onSeedBox(rect, cameraRole)`。
- 新几何 `geometry/frustum.ts`:`selectPointsInRect`(前向投影选锥内点)+ `centralRay`(空簇 fallback)+ 深度门控(最近簇优先)。
- `ThreeDWorkbench` 编排:选点 → `psrFromPoints` 拟合(+ `fitYaw`/`fitBottom` 精修)→ `useCreateAnnotation` 落 box_3d → 选中进微调。
- 模式开关(工具按钮 + 快捷键,如 `B` 在相机面板聚焦时)+ 无标定相机灰置。

**不做**(守 epic 边界):
- 2D 矩形不落库(J2);相机图不做独立 2D 标注(J3)。
- 投影手柄拖拽微调留 Phase 2(v0.15.25)。
- 多相机交叉编辑留 Phase 3。
- 不自写相机模型;不引入点云语义分割辅助选点(纯几何视锥)。

### 1.4 成功判据

1. 相机图上框一辆**点云中等密度**的车 → 生成的 box_3d 在主视图里大致套住该车(位置对、朝向±合理、尺寸近似),微调 ≤ 3 步标准。
2. 框一辆**远处稀疏**车 → 至少生成位置正确的框(尺寸可能偏小,可微调);空簇时用默认尺寸框落在中央射线 × 估计深度处。
3. **唯一产物是 box_3d**:DB 无 2D 实体;取消种框(esc)不留任何痕迹(J1/J2)。
4. 无标定相机:种框入口灰置 + 「无标定」提示。
5. 视锥内前后两目标:深度门控取最近簇,不把背景点混进拟合(或允许手动收紧矩形重试)。
6. `pnpm test`(frustum 纯函数)/ `pnpm lint` 全绿。

## 3. 设计要点

### 3.1 视锥选点(`frustum.ts`,纯函数)

- **选点用前向投影,不建 4 平面**(更简单、复用 `projectPoints`):
  ```
  selectPointsInRect(positions, rect, calibration) → number[]   # 命中点索引
  ```
  对每个点前向投影到像素 + 可见性(在相机前方),保留像素落在 `rect`(natural 系)内者。O(N)。
- **深度门控**(`depthGate`):选中点按到相机距离做 1D 聚类(直方图找最近的密集峰),取**最近簇**——避免一框把前景车 + 背景墙一起拟合。MVP 用「最近点 + band 宽度」简化(`[d_min, d_min + bandMeters]`,band 可配),复杂留 Phase 2。
- **空簇 fallback**(`centralRay`):矩形内无点 → 反算矩形中心像素的射线(`inv(intrinsic)` 得相机射线,`inv(extrinsic)` 转 lidar 系),沿射线取估计深度(地面交点或固定 range)放一个 `box3dDefaultSize` 框。

### 3.2 拟合(复用 `autofit.ts`)

- 选中簇 `Float32Array` → `psrFromPoints(cluster, padding)` 得初始 PSR;再 `fitYaw`(点云主方向定朝向)+ `fitBottom`(贴地)精修。**不新写拟合**。
- 尺寸异常(簇太小/太大)→ clamp 到 `box3dDefaultSize` 量级,避免拟合出畸形框。

### 3.3 画框交互(`CameraProjectionView`)

- 新增 `seedMode: boolean` + `onSeedBox(rect, cameraRole)` props。`seedMode` 时:`onMouseDown` 记起点、`onMouseMove` 画矩形(canvas overlay,用 tokens 色)、`onMouseUp` 把显示坐标换算回 **natural 像素**(除以 `sx/sy`)发 `onSeedBox`;`esc` 取消。
- `seedMode` 时禁用 `onClick` 反选(避免冲突),光标改 crosshair。
- 无 `calibration` → `seedMode` 不可进(种框无意义),figcaption 标「无标定」。

### 3.4 编排与落库(`ThreeDWorkbench`)

- `onSeedBox` → 取当前帧点云 positions(已有)→ `selectPointsInRect` + `depthGate` → 拟合 PSR → `useCreateAnnotation`(类别走既有新框流:active class 或弹类别选择器,与点击放置新框一致)→ 选中新框(进 gizmo 微调)。
- 模式开关:相机面板工具栏一个「种框」toggle + 快捷键(相机面板聚焦时 `B`);开则所有有标定相机进 `seedMode`。
- 历史:新框落库自动进 `useThreeDHistory`(撤销复用既有)。

## 5. 风险 / 未尽

- **标定依赖**:外参/内参不准 → 选点偏、框偏。无标定相机不开放种框;标定差的数据靠 Phase 2 微调兜底。
- **视锥多目标**:深度门控只能缓解,前后严重重叠仍可能混簇;允许「收紧矩形重试」+ Phase 2 微调。
- **拟合畸形**:稀疏簇 `psrFromPoints` 可能出畸形尺寸,需 clamp + 默认尺寸兜底。
- **朝向二义**:`fitYaw` 主方向可能差 180°(车头车尾);MVP 接受,微调时翻转(已有旋转 gizmo)。
- **像素↔natural 换算**:`CameraProjectionView` 已有 `sx=cssW/natW` 缩放约定,种框矩形务必换算回 natural 再投影,与 `projectPoints`(基于原图 intrinsic)对齐。
- **守 J2**:务必确认 2D 矩形不进任何持久化;只 `useCreateAnnotation` 落 box_3d。

## 6. 验证策略

- **纯函数单测**(`frustum.test.ts`):造一组标定 + 已知 3D 点 → 投影到已知像素 → 断言 `selectPointsInRect` 命中矩形内点、排除矩形外 / 相机后方点;`depthGate` 在「近簇 + 远簇」里取近簇;矩形内无点时 `centralRay` 给出合理射线方向。
- **真实数据**:有相机标定的 nuScenes scene——① 中密度车:种框 → 主视图框大致套住,微调 ≤3 步;② 远车稀疏:位置正确即过;③ 空白区:默认尺寸框落在射线上;④ 无标定相机:入口灰置。
- **决策红线**:DB 查无新增 2D 实体(只多一个 box_3d annotation);esc 取消不留痕;关闭种框模式后 `onClick` 反选恢复。
- **回归**:`seedMode=false` 时 `CameraProjectionView` 行为与 v0.13.6 一致(投影 + 反选 + 深度 hover 不变)。
