> 规划日期 2026-06-19 · 适用范围:`apps/web` 前端全量迁移到 shadcn/ui 后的视觉与组件单一真值源。

## 1. 设计原则

1. **中性基底,彩色点缀**:背景 / 表面 / 文字 / 边框一律走中性黑白灰;颜色只出现在「需要一眼分辨语义」的地方(状态、趋势、AI、告警、图标片)。一屏里彩色面积应远小于中性面积。
2. **暗色优先**:标注是长时间盯屏场景,深色是主场。任何颜色都要先在纯黑底(`#000`)上验证可读性,再回看浅色。
3. **单一真值源**:中性色与圆角走 `shadcn.css` 的 `--sc-*` token;语义彩色走固定的 Tailwind 调色板映射(下表)。**不在组件里写裸 hex / rgb / oklch**,也**不写 `bg-[#xxx]` 这类任意值**。
4. **token 改一处、全站生效**:换主色 / 调圆角 / 改边框深浅 → 改 `shadcn.css`;换某个语义的色相 → 改本规范的语义映射并全局替换 className。

## 2. 色彩系统

### 2.1 中性基底(shadcn `--sc-*` token)

定义于 `apps/web/src/styles/shadcn.css`,light 走 `:root`、dark 走 `[data-theme="dark"]`(对齐现有 `useTheme` 的 `<html data-theme>` 机制,**不用** shadcn 默认的 `.dark` class)。

| 语义 | token | 浅色 | 深色(主场) | 用途 |
|---|---|---|---|---|
| 页面背景 | `--sc-background` | `#ffffff` | `#000000` | body / 页面底 |
| 卡片表面 | `--sc-card` | `#ffffff` | `#0a0a0a` | 卡片 / 面板 |
| 浮层表面 | `--sc-popover` | `#ffffff` | `#0a0a0a` | 下拉 / 弹出 |
| 主文字 | `--sc-foreground` | `#171717` | `#ededed` | 标题 / 正文 |
| 次级文字 | `--sc-muted-foreground` | `#737373` | `#a1a1a1` | 说明 / 元信息 |
| 次级表面 | `--sc-secondary` / `--sc-muted` | `#f5f5f5` | `#1a1a1a` | 灰底块 / hover 底 |
| 发丝边框 | `--sc-border` | `#ebebeb` | `#2a2a2a` | 1px 描边(主旋律) |
| 主操作 | `--sc-primary` | `#171717` 实心黑 | `#ededed` 反白 | 主 CTA 按钮 |
| 焦点环 | `--sc-ring` | `#0070f3` | `#0070f3` | focus-visible |

> Tailwind 工具类映射:`bg-background / bg-card / text-foreground / text-muted-foreground / border-border / bg-primary / ring-ring` 等(`@theme inline` 已绑定)。

### 2.2 语义彩色点缀板(Tailwind 调色板,固定语义)

颜色**不进 token**,直接用 Tailwind 自带调色板的固定语义映射。统一写法:**柔底 `/10` + 实色文字 + 暗色提亮**(`text-xxx-600 dark:text-xxx-400`),保证黑白底上都通透。

| 语义 | 色相 | 柔底 / 文字 className | 出现场景 |
|---|---|---|---|
| 信息 / 总量 | `sky` | `bg-sky-500/10 text-sky-600 dark:text-sky-400` | 任务总量、计数类指标 |
| 正向 / 完成 | `emerald` | `bg-emerald-500/10 text-emerald-600 dark:text-emerald-400` | 已完成、进度条、↑ 趋势、Active |
| AI / 模型 | `violet` | `bg-violet-500/10 text-violet-600 dark:text-violet-400` | AI 接入、预标注、置信度 |
| 进行中 / 待办 | `amber` | `bg-amber-500/10 text-amber-600 dark:text-amber-400` | 进行中、待审核(Warning) |
| 异常 / 阻断 | `rose` | `bg-rose-500/10 text-rose-600 dark:text-rose-400` | ↓ 趋势、失败、Critical、删除 |

**点缀三种载体**(参考 AnnotatePro / LabelCraft):
- **图标圆片**:`flex size-9 items-center justify-center rounded-full bg-<hue>-500/10 text-<hue>-600 dark:text-<hue>-400`(统计卡右上角)。
- **状态药丸**:`Badge variant="outline"` + `border-<hue>-500/25 bg-<hue>-500/10 text-<hue>-600 dark:text-<hue>-400` + 前置 `size-1.5 rounded-full bg-current` 圆点。
- **数据强调**:进度条 `[&>*]:bg-emerald-500`、趋势文字 `text-emerald-600 / text-rose-600`、链接 / 选中态 `text-brand`。

### 2.3 状态 → 颜色 映射(全站统一,禁止各页自定义)

| 业务状态 | 色相 |
|---|---|
| 进行中 `in_progress` | amber |
| 已完成 `completed` | emerald |
| 待审核 `pending_review` | sky |
| 已归档 / 停用 | 中性 `muted-foreground` |
| 失败 / 异常 / Critical | rose |
| AI 已接入 / 预测 | violet |

### 2.4 禁则(对应 CI 门禁)

- ❌ 组件里写裸色:`#171717` / `rgb(...)` / `oklch(...)`(阴影、画布 checker 等少数特例除外,见迁移 epic)。
- ❌ Tailwind 任意色值:`bg-[#0070f3]` / `text-[rgb(...)]`。
- ❌ 自造语义:状态色必须取自 §2.3,不在某页临时用「蓝色表示完成」。
- ❌ 用 `.dark` class 做暗色:本项目暗色走 `[data-theme="dark"]`,用 `dark:` 变体即可(已在 `shadcn.css` 重定向)。

## 3. 圆角 / 间距 / 字重

| 维度 | 取值 | 说明 |
|---|---|---|
| 基础圆角 | `--sc-radius: 8px` | 按钮 / 输入 / 徽标 = `rounded-md`(8px) |
| 卡片圆角 | `rounded-xl`(12px) | 卡片 / 面板 / 大容器 |
| 描边 | `1px` `border-border` | 发丝边是主旋律,**少用阴影** |
| 阴影 | 几乎不用 | 仅浮层(popover/dropdown/dialog)用 shadcn 默认 `shadow-*` |
| 标题字重 | `font-semibold tracking-tight` | 页标题 `text-2xl`、卡标题 `text-base` |
| 数字 | `tabular-nums` | 所有指标 / 计数等宽对齐 |

## 5. 组合范式(从 PoC 沉淀)

参考实现:`apps/web/src/pages/Dashboard/DashboardPageNext.tsx`。

**统计卡**(中性卡 + 彩色图标片 + 趋势):
```tsx
<div className="rounded-xl border border-border bg-card p-5">
  <div className="flex items-start justify-between">
    <span className="text-[13px] font-medium text-muted-foreground">{label}</span>
    <div className="flex size-9 items-center justify-center rounded-full bg-sky-500/10 text-sky-600 dark:text-sky-400">
      <Icon className="size-[18px]" />
    </div>
  </div>
  <div className="mt-2 flex items-center gap-2">
    <span className="text-3xl font-semibold tracking-tight tabular-nums">{value}</span>
    <TrendChip value={trend} />   {/* ↑ emerald / ↓ rose */}
  </div>
  <p className="mt-1 text-xs text-muted-foreground">{caption}</p>
</div>
```

**状态药丸**:
```tsx
<Badge variant="outline" className="gap-1.5 rounded-full border-amber-500/25 bg-amber-500/10 text-amber-600 dark:text-amber-400">
  <span className="size-1.5 rounded-full bg-current" /> 进行中
</Badge>
```

**数据表行**:`TableRow.group` + hover 显隐「打开」按钮;进度列 = 文案 + `Progress` 着色条;状态列用上面的药丸。

## 6. 暗色与共存(实现约束)

- 暗色由 `<html data-theme="dark">` 驱动(`useTheme.ts`),`shadcn.css` 用 `@custom-variant dark ([data-theme="dark"] &)` 把 `dark:` 重定向过去 —— shadcn 组件零改动复用现有主题开关。
- 迁移期 Tailwind **不注入全局 preflight**,改用 `.tw-scope` 局部 reset(见 `shadcn.css` 底部),避免重置尚未迁移的 CSS Modules 页面。新页面根节点需挂 `className="tw-scope ..."`。
- **全量迁移完成后**:删 `.tw-scope` 局部 reset、改回全局 `@import "tailwindcss"`(含 preflight),并退役 `tokens.css`(见 epic 末阶段)。

## 7. 验收基线

- 任一新页面在 light / dark 双主题下:中性面积 >> 彩色面积;颜色全部可在 §2.2/§2.3 表里找到出处。
- `node scripts/check-css-tokens.mjs` 对残留 CSS Modules 仍通过;新增的 Tailwind 门禁(epic 末阶段)对 className 无裸色 / 无任意色值。
- 与 PoC 参考(`/dashboard-next`)观感一致:发丝边为主、阴影克制、数字等宽、彩色仅点缀。
