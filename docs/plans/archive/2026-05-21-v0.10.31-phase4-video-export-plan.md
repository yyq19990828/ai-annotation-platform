## 统一映射约定（先定义，各格式共用）

| 语义 | Video JSON / AAP | MOT | KITTI |
|---|---|---|---|
| outside 帧 | 保留 outside 区间 | 该帧从 gt 省略 | 该帧省略 |
| occluded | keyframe.occluded 保留 | 输出（conf=1） | occluded 列=1 |
| prediction source | source 字段保留 | conf 列承载（或省略） | 不区分 |
| 帧号 | 源帧号（D2） | 采样网格序号 1..N | 采样网格序号 0..N-1 |

集中放 `export_video.py` 的常量/注释，避免每格式各写一套。

## 共享底座（先做，0 个对外格式依赖它之前不能动）

新建 `apps/api/app/services/export_video.py`：

1. `source_frame_to_grid_index(frame_count, step) -> dict[int,int]`：源帧号 → 网格序号映射（基于 `derive_sampled_frames`）。
2. `effective_fps(source_fps, step) -> float`：采样后 fps = source_fps / step（写进 seqinfo.frameRate）。
3. `iter_track_grid_rows(geometry, *, frame_count, step, dims)`：对单 track 走 `resolved_track_frames(all_frames)` 展开 → 过滤 outside → 只取落在采样网格上的帧 → 重编号 → 产出 `(grid_frame, bbox_px, occluded, source)`。
4. 像素坐标：`bbox(0..1) × DatasetItem.width/height`，缺失回退 `IMG_W/IMG_H`。

> **校验点（D2）**：60fps 采样到 10fps（step=6），seqinfo.frameRate=10，帧号 1..N 落在网格上；改采样密度不破坏 geometry（源帧号不变）。

## 4.2 AAP 导出端（media_type + video 子块）

## 4.3 MOT 16/17/20 CSV

`export_video.py` 内 `build_mot_zip(...)`（或在 build_export_zip 视频分支组装）：
- 每 task = 一个 sequence 目录 `{sequence}/`：
  - `gt/gt.txt`：行 `frame,id,bb_left,bb_top,bb_w,bb_h,conf,x,y,z`（conf=1，x/y/z=-1）。
  - `seqinfo.ini`：`[Sequence]` name / frameRate=effective_fps / seqLength=网格帧数 / imWidth / imHeight / imDir=img1 / imExt=.jpg。
- frame=网格序号(1-based)，id=`derive_track_number`，outside 帧省略。
- sequence 名取 `task.file_name` 去扩展名（去重靠 dataset 相对路径，复用 `_label_rel` 思路）。
- **img1/ 帧序列（D1 不物理打包）**：zip 附带 `fetch_frames.py` —— 先按 `manifest.json` 回源视频，再用本地 ffmpeg 按各 sequence 的网格帧号（源帧号 → `img1/{grid_index:06d}.jpg`）抽帧。脚本内嵌「源帧号 ↔ 网格序号」映射表（写进 manifest 的 `frame_map`），纯标准库 + 调用系统 ffmpeg。

## 4.4 KITTI Tracking 2D

`export_video.py` 内 `build_kitti_zip(...)`：
- 每 sequence 一个 txt：`frame track_id type truncated occluded alpha x1 y1 x2 y2 h w l x y z rotation_y`。
- 2D 版：truncated=0，occluded∈{0,1}，alpha/3D 字段填 -1；type=class_name；frame=网格序号(0-based)。
- 与 MOT 同窗口、共用 `iter_track_grid_rows`。

## 4.1 视频并入 zip 管线（整合层）

- `build_export_zip` 增加 video 分支：按 `project.data_type=="video"` 路由到视频组装，按 format 产出：
  - `aap_json` → `annotations.json`(AAP 1.2) ；`video_json` → `annotations.json`(现 Video JSON)；`mot` → MOT 目录布局；`kitti` → KITTI 目录布局。
  - 通用附带：`manifest.json`（task → 视频文件 rel_path + 预签名 URL + video_metadata + 采样配置 + 各 sequence 的 `frame_map` 源帧↔网格序号）+ `fetch_videos.py`（类比 `fetch_images.py`，回源到 `videos/<rel>`）。
  - MOT/KITTI 额外附带 `fetch_frames.py`（回源视频后用 ffmpeg 按网格帧号抽 `img1/`）。
  - **不写** `data.yaml` / `images_manifest.json` / `fetch_images.py`（YOLO 图片专用）给视频。
- 抽出 `_image_extras(...)` / `_video_extras(...)` 分流现有附加产物逻辑。
- 缓存指纹（`_scope_fingerprint`）：format 已进 cache_key，新增 format 值天然区分，无需改。

## 4.7 前端导出选项

- `ExportFormat` 扩 `"video_json" | "mot" | "kitti"`；`ExportSection.tsx` video-track 分支：格式从写死 "Video JSON" → 可选按钮组 [Video JSON, AAP JSON, MOT, KITTI]。
- 帧模式（keyframes/all_frames）仅 Video JSON 显示；MOT/KITTI 隐含 all_frames+网格，AAP 透传源帧。
- `exportProject` 透传新 format；endpoint format pattern 扩 `coco|voc|yolo|aap_json|video_json|mot|kitti`。
