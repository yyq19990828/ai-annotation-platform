# v0.10.55 · 预测来源可见 + 可筛选（workbench）

- 日期：2026-05-24
- 范围：把预测的 `source`（`ml_backend` / `external_import`）暴露到前端,工作台按来源显示标识 + 筛选/隐藏
- 前置：v0.10.52/53（几何导入对称、外部导入可用）
- 关联：[v0.10.56 source overwrite（待定）]；本版是 source-overwrite 的前置基础

---

## 1. 背景与问题

ML 预标(`source='ml_backend'`)与外部导入(`source='external_import'`)的预测在同一 task 上**并存、不互删**(`get_predictions` 不按 source 过滤,[tasks.py](../../apps/api/app/api/v1/tasks.py))。但:

- **`PredictionOut` 不暴露 `source`**(`_build_out` 构造的 dict 无 source 字段),前端拿不到来源。
- 工作台 `predictionsToBoxes`([transforms.ts:207](../../apps/web/src/pages/Workbench/state/transforms.ts#L207))把所有预测的 `source` 硬编码成 `"prediction_based"`,无法区分来自模型还是导入。

→ 标注员看到两套候选框叠在一起,**无法分辨来源、无法按来源筛选/隐藏**。这也削弱了"先 ML 预标、再导入外部标注"的协作场景。

## 2. 目标 / 非目标

**目标**
- G1：`PredictionOut` 暴露 `source` 字段。
- G2：工作台候选框带来源标识(badge / 颜色 / 分组其一)。
- G3：工作台按来源**筛选/隐藏**(至少 ml_backend / external_import 两类的开关)。

**非目标**
- 按来源 destructive 清理(→ source overwrite,见 v0.10.56）。
- 跨 model_version 的筛选(已有 model_version 维度,本版不动）。

## 3. 实施步骤

### Step 1 — 后端暴露 source
- [apps/api/app/schemas/prediction.py](../../apps/api/app/schemas/prediction.py)：`PredictionOut` 增 `source: str | None`。
- [tasks.py `_build_out`](../../apps/api/app/api/v1/tasks.py#L1166)：dict 增 `"source": getattr(p, "source", None)`。
- **验证**：GET `/tasks/{id}/predictions` 返回含 source；ml_backend / external_import 各自正确。

### Step 2 — 前端携带 source
- [apps/web/src/types](../../apps/web/src/types)：`PredictionResponse` 增 `source`。
- [transforms.ts `predictionsToBoxes`](../../apps/web/src/pages/Workbench/state/transforms.ts#L183)：`AiBox` 增 `predictionSource`（区别于现有 annotation 语义的 `source` 字段，避免混淆），透传 `p.source`。
- **验证**：types 编译通过；AiBox 带真实来源。

### Step 3 — 工作台来源标识 + 筛选
- 候选框 UI 加来源标识（badge 文案「模型」/「导入」或描边色区分；遵循 tokens.css，**不硬编码颜色**，按 CLAUDE.md §6）。
- 候选列表/工具栏加来源开关（多选：模型 / 导入），隐藏对应来源的候选框。
- **验证**：preview → 同 task 有两来源预测 → 标识可辨 → 关「模型」只剩导入框,反之亦然。

## 4. 数据库迁移

- **无 DDL**。`source` 列已存在（`Prediction.source`），仅暴露 + 前端消费。

## 5. 文档同步（CLAUDE.md §5）

- `docs-site/api/`：PredictionOut 增 source 字段（OpenAPI 重新生成）。
- `docs-site/user-guide/workbench/`：候选框来源标识 + 按来源筛选说明。
- `CHANGELOG.md`：v0.10.55 条目。

## 6. 风险

| 风险 | 缓解 |
|---|---|
| `AiBox.source`（annotation 语义）与 prediction 来源混淆 | 新增独立字段 `predictionSource`，不复用 |
| 来源色硬编码破坏暗色模式 | 仅用 tokens.css 既有 `--color-*`，CI `lint:css-tokens` 把关 |
