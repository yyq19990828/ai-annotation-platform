# v0.13.7 · 相机悬浮环绕布局(SUSTech 式)

> 状态:已实现(2026-06-03)。L0~L3 全量落地 + 浏览器验证;L4 聚焦打磨 + CHANGELOG,窄屏自动折叠按「Simplicity First」scope-out(见 L4)。提交链:L0 `f879bb5` / L1 `54cad79` / L2 `6d53a6b` / L3 `629439f`。
> 计划归属 epic:点云 + 图像联合标注工作台。前序:v0.13.4 投影联动、v0.13.5 三视图框精修、v0.13.6 RGB 上色 + 深度联动。
> 本版承接 v0.13.6 顺延出来的「原 C3 朝向环绕布局」,经讨论由「网格挤压」改为「悬浮叠加」模型。

## 背景

当前 `ThreeDWorkbench` 是「主视图 + 固定 240px 三视图右栏 + 底部相机 strip」三块抢屏,且相机一字沉底:
1. **相机沉底 + 一字排**:多相机要横向滚动,「底部」与相机的物理朝向(前/后/左/右)脱钩,看哪个相机都要做一次脑内方位映射。
2. **三块常驻抢屏**:主视图被右栏(240px)+ 底栏(160px)夹住,且三视图栏即使未选框也常驻占位。

研究依据:`docs/research/14-point-cloud-image-fusion.md`;参照 SUSTech POINTS「相机按车体朝向贴主视图四周」的环绕布局。

## 已定决策(2026-06-03,与用户两轮确认)

- **方向 = C 朝向环绕(SUSTech 式)**,但落地为**悬浮叠加**而非网格挤压:
  - **主 3D 视图全屏化**:拆掉 `mainRow` 固定右栏 + 底部 `cameraStrip`,viewport 铺满,gizmo 标注空间最大且永不被压。
  - **相机面板 = 悬浮在主视图之上 + 按朝向锚定 + 每个独立展开/收起**(和控件浮条 / PSR 面板同一套「浮在 viewport 上」的设计语言)。
  - **位置由朝向决定、不做自由拖动**——自由拖动会丢掉「按朝向」的空间语义,而那正是选 C 的全部价值。
- **看大图 = 点标题栏 `⛶` 按钮弹大图浮层**(带完整投影 / 上色 / 深度 overlay);不抢图体本身的「点框反选 / 深度 hover」交互。
- **三视图收右下浮层**:复用现有 `TriViewPanel`,选中框才浮出,取消即隐,带折叠钮;未选框时零占位。
- **投影 / 上色 / 深度 / 命中零改动**:`CameraProjectionView` 已全按 `clientWidth/naturalWidth` 自适应缩放,面板尺寸随便变都自动跟随。

## 现状盘点(已就位的地基)

- `ThreeDWorkbench.module.css`:`.root`(纵向)→ `.mainRow`(横向:`.viewportWrap` flex:1 + `.triPanel` 固定 240px)→ 底部 `.cameraStrip`(flex:0, 横向滚动, img 高 160px)。
- 控件浮条 `.controls`、状态条 `.statusBar`、PSR 编辑面板 `.editPanel` 已是 absolute 浮在 `.viewportWrap` 内 —— **悬浮叠加是本工作台既有范式,本版只是把相机/三视图也纳入**。
- `CameraProjectionView`:投影 overlay / 上色 / 深度热力图 / 点投影反选命中全部按显示尺寸自适应(见组件头注「缩放约定」),布局变更对其透明。
- `TriViewPanel`:接 `selected / getPointsGeometry / editable / onEditPsr`,自带「未选中占位提示」;从右侧常驻栏改成浮层只动它的**外层容器定位**,内部逻辑不动。
- 数据现状:示例集 `pc-scene-a` 只有 `front / left / right` 三相机(无 rear);布局必须**自适应**,空朝向不留洞。

## 切片(细化到可实现)

### L0 · 朝向推导纯函数 + 单测
新增 `geometry/cameraAnchor.ts`:`cameraAnchor(calib: SensorCalibration | null, name: string): Anchor`,
`Anchor = 'top' | 'bottom' | 'left' | 'right' | 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right' | 'overflow'`。
- **外参优先**:由 extrinsic 取相机光轴前向向量在 lidar/world 水平面的方位角 θ → 归 8 扇区 → 锚点。
- **名字兜底**(外参缺失 / 退化):`front→top, rear|back→bottom, left→left, right→right, front_left→top-left`…
- **都推不出 → `overflow`**(落底部小条,不丢相机)。
- 验证:单测覆盖「外参朝前→top」「名字 left→left」「外参缺失走名字」「都缺→overflow」「同扇区两相机各得位」(纯函数,identity/简单外参构造,toBeCloseTo)。

## 风险

- **悬浮遮挡点云**:贴边放(边缘点云利用率低)+ 每个可独立收起 + 默认尺寸克制;不做大面积半透明。
- **朝向推导对外参约定敏感**:外参的相机坐标系前向轴(+Z vs +X)需对齐我们 `SensorCalibration` 约定;L0 单测用真实示例集外参兜一个回归点,推错时名字兜底不至于崩。
- **localStorage 状态膨胀 / 跨数据集串味**:key 带 dataset/role 维度,只存布尔收起态,可忽略。

## 非目标(本版不做)

- 相机面板自由拖动 / 自定义停靠(保「按朝向」语义)。
- 6+ 相机(nuScenes FL/FR/RL/RR)实测调优 —— L0 锚点已按 8 扇区设计预留,但本版只在 3 相机示例集验证。
- 遮挡 z-test、上色 worker 化、外部数据集 adapter(沿用 v0.13.6 顺延项)。
