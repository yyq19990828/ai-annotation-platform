> 对应 roadmap：[ROADMAP/[archived]2026-05-12-image-workbench-optimization.md](../../ROADMAP/[archived]2026-05-12-image-workbench-optimization.md) Wave β I2 + I6.1 + I6.2 + I8.2 占位。

## Context

Wave α (v0.9.41) 已经把图片工作台的共享 hooks / longtask 观测 / 标注偏好等基础设施落地；Wave β 必做项里 polygon 性能（I2）与 SAM 缓存（I6）是收益最直接的两块，纯前端 + 一条 e2e 烟囱测占位即可闭环。本子版本不动后端 schema、不动协议，是 v0.10.4 epic 的第 1/4 子版本。

## Scope

**目标**：500 顶点 polygon 拖动 ≥60fps、100 polygon 同屏选择 <100ms、SAM 重复点击 <100ms。

### I2.1 Douglas-Peucker LOD（顶点简化）

- 新增 [`stage/shared/geometry/simplify.ts`](../../apps/web/src/pages/Workbench/stage/shared/geometry/simplify.ts)：闭合多边形 RDP 简化（环切两段分别 RDP 合并，避免单纯开链 RDP 拆环），+ `epsilonForScale(scale, dim)` 工具。
- 接入 [`KonvaPolygon`](../../apps/web/src/pages/Workbench/stage/ImageStageShapes.tsx)：
  - `renderPs = useMemo(...)` 在「非编辑 + 非选中 + 顶点 >60」时按 `epsilon = 1/(scale * max(imgW, imgH))` 简化；
  - 编辑态用原顶点保证手感。
- 单测：[`simplify.test.ts`](../../apps/web/src/pages/Workbench/stage/shared/geometry/simplify.test.ts) 7 例，覆盖近共线剔除 / 偏离保留 / ≥3 顶点保底 / 200-顶点 circle massive reduction / epsilonForScale。

### I2.2 自相交检测增量化

- [`polygon.ts`](../../apps/web/src/pages/Workbench/stage/shared/geometry/polygon.ts) 新增 `isSelfIntersectingIncremental(points, changedIdx)`：O(n) 只检查与变更顶点相邻的 2 条边 vs 其它非相邻边。保留 `isSelfIntersecting` O(n²) 全量版做兜底。
- [`ImageStage.tsx`](../../apps/web/src/pages/Workbench/stage/ImageStage.tsx)：`drag.kind === "polyVertex"` 时走增量，否则走全量。
- 单测：扩 [`polygonGeom.test.ts`](../../apps/web/src/pages/Workbench/stage/__tests__/polygonGeom.test.ts) 5 例（正常顶点 / 触发交叉 / <4 顶点 / 越界 / 与全量结果一致）。

### I2.3 R-tree polygon 顶点视口粗筛

- 扩 [`iou-index.ts`](../../apps/web/src/pages/Workbench/stage/iou-index.ts) 新增 `buildVertexIndex(points)`：单 polygon 顶点 rbush 索引；`verticesInBBox(bbox) → number[]` 返回视口内顶点下标（排序后）。
- `KonvaPolygon` 新增 `viewportBBox` prop；编辑态 + 顶点 >=60 时跑视口粗筛，屏外顶点 / 屏外边句柄不渲染 Konva 节点。
- `ImageStage` 计算归一化视口 bbox（含 8px buffer）传入。
- 单测：[`iou-index.test.ts`](../../apps/web/src/pages/Workbench/stage/iou-index.test.ts) 新增 4 例。

### I2.4 顶点拖拽 commit 路径（复查 = no-op）

复查现有 [`ImageStage.tsx:399`](../../apps/web/src/pages/Workbench/stage/ImageStage.tsx) pointerup-only commit + [`handleCommitPolygonGeometry`](../../apps/web/src/pages/Workbench/state/useWorkbenchAnnotationActions.ts) 单条 `update` 历史推栈，已经符合 roadmap I2.4 原意。新增 `polygonVertexBatch` history kind 经审视为冗余（每次单顶点拖拽本就是一个独立用户动作），不做。

### I6.1 SAM 候选前端 LRU 缓存

- 新增 [`state/useSamCache.ts`](../../apps/web/src/pages/Workbench/state/useSamCache.ts)：LRU 32 项，key = `${taskId}|${mlBackendId}|${ctxKind}|${normalize(ctx)}`，浮点 4 位小数 round 防抖动；`get` 触发 LRU 触摸；`clearAll()` 在 mlBackendId 变化时调用。
- 接入 [`useInteractiveAI.dispatch`](../../apps/web/src/pages/Workbench/state/useInteractiveAI.ts)：HTTP 调用前查缓存；命中即 `setCandidates`；miss 拿到结果（非空）写回。
- 单测：[`useSamCache.test.ts`](../../apps/web/src/pages/Workbench/state/useSamCache.test.ts) 10 例（坐标 round / key 顺序无关 / backend 隔离 / LRU 触摸 / clearAll / 覆盖 size 不变）。

### I6.2 embed 预热

- `useInteractiveAI` 新增 `warmup()`：每 `(taskId, mlBackendId)` 一次，发图中心 dummy point 静默触发 backend image encoder + cache，失败静默；返回值若非空写入 useSamCache。
- [`WorkbenchShell.tsx`](../../apps/web/src/pages/Workbench/shell/WorkbenchShell.tsx)：image 工作台 + 已绑 backend 时 useEffect 自动调用。

### I8.2 perf fixture（占位）

- 新增 [`e2e/tests/workbench-perf.spec.ts`](../../apps/web/e2e/tests/workbench-perf.spec.ts) 烟囱测：进入工作台后断言 `window.__workbenchPerf` 存在（已由 v0.9.41 useWorkbenchPerf 写入）。
- 完整 3×3 fixture（2K/8K/dense × 10/100/500 shapes）**推迟到 v0.10.5+**：需要后端 `_test_seed` router 加 `density` 参数 + 真实 fixture 图像 binary。
