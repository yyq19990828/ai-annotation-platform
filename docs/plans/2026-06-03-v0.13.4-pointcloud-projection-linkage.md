## 背景

v0.13.3 + 0.13.3-5 已让用户在 3D 工作台**画 / 选 / 编辑 3D 框**,并与标注列表共享选中态;但**相机图仍是只读平铺**,3D 框与图像彼此无关。联合标注的核心价值还差最后一步:把 3D 框经相机标定**实时投影**到各相机视图,标注员对照图像确认 / 校正 3D 框,且同一物体的 3D 与 2D 表示共享身份(`group_id`)。本切片补上,联合标注 MVP 即上线。

**关键判断:仍是前端为主,后端零新端点。** 标定已存进 `DatasetItem.metadata_`(ADR-0030)、manifest 已出 `calibration`;`group_id` 自增机制(`task.next_group_seq`,[`services/annotation.py:373`](../../apps/api/app/services/annotation.py#L373))v0.13.0 起就在。投影**实时算、不预存**(epic 基线),无新表、无迁移。

- **共享选中态 / 标注数据**:0.13.3-5 已把 `selectedId` / `onSelectBox` 接到壳层;相机 overlay 与 3D 视图消费**同一份** `useAnnotations` + `selectedId`,实时同步天然成立。

### 投影链(与后端 / 调研对齐)

世界点(lidar 系,米)`p=[x,y,z]`:

```
p_cam   = extrinsic · [x, y, z, 1]ᵀ        // 4x4 lidar→camera 外参
p_rect  = rect · p_cam   (KITTI 有 rect 时)  // 可选矫正
[u,v,w] = intrinsic · p_rect.xyz            // 3x3 内参
pixel   = [u/w, v/w]      (w>0 即在相机前方) // 透视除法
```

`w<=0`(点在相机后方)剔除该角点;一个框全部角点不可见 → 该相机不画。约定须与 SUSTechPOINTS 一致(`extrinsic·pt → intrinsic → 透视除法`),否则投影偏。

## 范围(做什么)

### 4-1 投影内核(纯函数 + 单测,小–中)
- `three-d/geometry/projection.ts`:`projectPoints(cornersWorld, calib) → { pixels: [u,v][], visible: boolean[] }`,实现上面的投影链(extrinsic → 可选 rect → intrinsic → 透视除法 + behind-camera 剔除)。
- 复用 `psrToCorners` 出 8 角点 → 投影 → 12 条边线(角点连边表与 `box3d.ts` 共用)。
- 单测 + **SUSTechPOINTS 对拍**:`third-party/SUSTechPOINTS/data/example` 同帧、同框,8 角点像素坐标应一致(epic 验证策略)。
- 锁坐标约定:extrinsic 方向(lidar→cam)、`rect` 用法、像素原点(左上)、欧拉角顺序(与 `box3d.ts` 同 `XYZ`)。

### 4-2 相机视图投影 overlay(渲染,中)
- 相机图从只读 `<img>` 升级为 `<img>` + 叠加 overlay(canvas):按 **显示尺寸 / 图像自然分辨率** 比例把像素坐标缩放后画投影框(12 边线,类别色)。`ResizeObserver` 跟随图尺寸重算。
- **实时**:3D 框 PSR 变(数值面板 / gizmo / 列表)→ overlay 即时重绘(消费同一份 `annotations` + `selectedId`,无额外状态)。
- **可见性**:全角点 behind-camera / 出画 → 不画该相机;部分出画 → 裁剪到画面内或淡化(MVP 可先「有可见角点就画、出界截断」)。

### 4-3 选中联动(3D↔2D 双向,中)
- 选中 3D 框 → 各相机投影**高亮**(承共享 `selectedId`,0.13.3-5 已通)。
- **反向**:点相机里的投影框 → `onSelectBox(该 3D 框 id)` 选中 3D 框(overlay 命中测试:点到投影多边形内)。
- **最佳相机提示**:状态条 / 角标显示该框被几个相机看到 / 哪个相机正对(可见角点数最多者)。

### 4-4 group_id 跨模态身份(基础设施,小)
- 新建 3D 框时分配 `group_id`(复用 `next_group_seq` 自增 / `groupAnnotationMut`)。
- 同物体的 3D 框 +(未来)各相机 2D 框共享 `group_id`;选中按 `group_id` 聚合高亮。
- **本切片只打通身份 + 投影可视化**;相机视图上独立绘制 / 编辑 2D 框成员留 v0.13.5+(见「不做」)。

## 设计决策(草案,落地前细化)

- **D1 实时投影、不预存**(epic 基线):每次按 `calibration` 现算,省存储、改框即时反映。性能靠「只投选中 / 可见框 + canvas 批量重绘」。
- **D2 overlay 用 canvas**(非 SVG):数十框 × 12 边线,canvas 全量重绘更省;SUSTechPOINTS 亦 canvas。
- **D3 投影纯函数与 `box3d.ts` 同模块、同坐标约定**:作为 3D↔2D 单一真值,三视图(0.13.5)与未来 2D 联动复用。
- **D4 标定缺失降级**:无 `calib` 的相机不画投影(3D-only),不阻断(承 ADR-0030 降级条)。

## 不做(明确排除)
- 相机视图上**独立绘制 / 编辑 2D 框**(`group_id` 下的 2D 成员、2D 单独校正)—— v0.13.5+。
- 从投影**预存生成** 2D 框标注(本切片投影是实时可视化,不落库)。
- 三正交视图精修(ADR-0032 方案 B,已排 v0.13.5)、`point_mask_3d` 分割、多帧 / 轨迹。
- 标定可视化校验工具(epic 风险项,后续)。
- 不动后端(无新端点 / 迁移)、不动 2D Konva / 视频工作台。

## 风险
- **标定坐标约定**(最大风险):extrinsic 方向、KITTI `rect`、像素原点、图像缩放任一错位 → 投影整体偏。**核心缓解 = SUSTechPOINTS 像素级对拍**。
- **图像显示缩放**:`intrinsic` 基于原图分辨率,overlay 必须按 displayed/natural 比例缩放;`<img>` 懒加载 / resize 时重算(`ResizeObserver` + `naturalWidth`)。
- **性能**:多相机 × 多框重绘 —— 只投可见 / 选中框 + canvas 批量 + 编辑期节流。
- **双栈隔离**:相机 overlay 仍在 `three-d` 模块,不污染 Konva 2D 栈。

## 验证(成功标准)
- 投影纯函数单测 + **SUSTechPOINTS 对拍**(同 scene 8 角点像素一致)。
- 端到端(`P-PC01`):画 3D 框 → 各相机出现投影框;编辑 3D 框(平移 / yaw / 缩放)→ 投影实时跟随;选中 3D 框 → 投影高亮;点投影 → 选中对应 3D 框。
- 标定缺失的相机不画、不报错(降级)。
- `group_id`:新建 3D 框分配 group_id 并落库;同组聚合高亮。
- `typecheck` / `lint` / `build`(three 仍独立 chunk);确认无新后端端点(group 自增复用既有)。
- 2D / 视频 / 3D 工作台回归无影响。
