## 1. 本版目的

到 v0.23.23，客户端将同时存在多套各自有界的资源：

- background decoded tile LRU；
- committed Raster Mask render bitmap/alpha/RLE cache；
- editable Sparse Mask 512 tile cache；
- Mask history；
- Worker immutable packed base cache 与 source scratch；
- CPU morphology transient；
- WebGPU source/XOR/readback buffer；
- overview/compare tile。

“每套缓存都没有超自己的预算”不等于页面总峰值安全。v0.23.24 建立 task-scoped
`RasterResourceCoordinator`，使各 owner 在分配前做共同 admission、接收 pressure、按优先级释放
可重建资源，并补齐 background tile × Mask edit 的联合交互。

本版不把所有缓存重写成一个 Map，也不声称知道真实浏览器堆/显存总量。各 subsystem 继续拥有自己的
真值、LRU 和 dispose；coordinator 只负责：

- 逻辑字节分类与 ownership；
- reservation/commit/release；
- task/page generation；
- pressure 与 foreground priority；
- eviction/yield 回调；
- 联合 snapshot 和验收。

## 2. 冻结边界

### D1. 真值不可被协调器淘汰

不可重建或会丢用户状态的资源：

- dirty Mask edit tile；
- 尚未持久化的 current Mask revision；
- history 中按既有策略保留的 command；
- 正在原子应用的 operation source/response。

coordinator 只能：

- 拒绝新的大 operation；
- 触发既有 history budget policy；
- 提示用户保存/缩小 ROI；
- 释放其他可重建资源。

不能静默丢 undo、dirty tile 或当前 brush stroke。

### D2. 背景与 Mask 仍是独立 owner

coordinator 不直接读取：

- background pixels；
- RLE counts；
- history patch content；
- GPU mapped range。

它只持有 owner id、category、logical bytes、priority、reconstructible/pinned 与 generation。

### D3. 逻辑预算不是显存探测

- background `ImageBitmap` 按 decoded RGBA 估算；
- Raster Mask render 按 alpha + bitmap RGBA + retained RLE；
- sparse tile 按 alpha/packed bits/metadata；
- history 按 patch bytes；
- Worker cache/scratch 与 GPU buffers 按已知 typed array/buffer capacity；
- 同一 buffer 只由一个 owner charge，防 double count；
- 不将估算值命名为 `gpuMemory`/`heapUsed`；
- 不依赖 `performance.memory`。

### D4. 先保护交互，再做 prefetch

优先级：

```text
P0 current edit truth + in-flight atomic operation
P1 minimum visible background coverage + visible edit tiles
P2 target-LOD visible background + selected/current Mask render
P3 overview/compare/current task non-selected render
P4 overscan/directional/adjacent-task prefetch
P5 reconstructible cache growth/scratch retention
```

- P0/P1 已 admission 后不可被 P4/P5 挤出；
- Mask foreground operation 开始时暂停新 P4 background prefetch；
- 不销毁当前可见 background，只先停/evict non-visible detail；
- operation 完成后按当前 generation 重建 prefetch queue，不恢复 stale promises。

### D5. 200MP 背景不等于 200MP Raster Mask

当前 Raster Mask 合同仍是：

- dimension ≤8192；
- pixels ≤67,108,864；
- morphology input ROI ≤16,777,216。

因此：

- 超过上限的图片仍可使用 background tile 与 vector annotations；
- Raster Mask create/edit 必须按现有 capability 明确 disabled/read-only，而非扩大协议；
- 8192² fixture 用于 background + native Raster Mask 联调；
- 200MP fixture 用于 background/vector/已有兼容 overlay，不宣称可新建同尺寸 Raster Mask；
- 扩大 RLE/schema/run/ROI 上限另立版本。

## 3. Coordinator 合同

### 3.1 Category

```ts
type RasterResourceCategory =
  | "background-coverage"
  | "background-detail"
  | "background-prefetch"
  | "mask-render"
  | "mask-edit"
  | "mask-history"
  | "mask-compare"
  | "worker-base-cache"
  | "worker-scratch"
  | "cpu-transient"
  | "gpu-buffer";
```

### 3.2 Reservation

```ts
interface RasterResourceReservation {
  id: string;
  owner: string;
  generation: number;
  category: RasterResourceCategory;
  priority: 0 | 1 | 2 | 3 | 4 | 5;
  bytes: number;
  state: "reserved" | "committed" | "released";
  commit(actualBytes?: number): boolean;
  release(): void;
}
```

要求：

- prospective `reserve()` 成功后才能开始不可回退的大分配；
- 任一时刻的 hard invariant 为
  `chargedBytes = committedBytes + outstandingReservedBytes <= globalHardBudget`；
- 同一 allocation 从 reservation handoff 为 committed 时原子转账，不在同一瞬间 double charge，
  也不能先扣 reservation 再留下未计账空窗；
- actual > reserved 时必须按 total charged 做追加 admission，失败则释放 candidate；
- timeout/stale/dispose 自动 release；
- release 幂等；
- generation mismatch 不得 commit；
- owner 的 committed 与 outstanding reserved bytes 都必须能从 subsystem snapshot 对账；
- coordinator 不保留强引用到 ImageBitmap/typed array/GPUBuffer。

### 3.3 Evictor/pressure

每个 owner 可注册：

```ts
interface RasterResourceEvictor {
  owner: string;
  evictableBytes(): number;
  evict(targetBytes: number, reason: PressureReason): Promise<number> | number;
  pausePrefetch?(reason: PressureReason): void;
  resumePrefetch?(generation: number): void;
}
```

- evict 只处理 owner 明确声明的 reconstructible/unpinned；
- coordinator 按 priority/category 请求，不直接删；
- actual freed bytes 回报并与 release 对账；
- evict 超时不阻塞 P0，改试下一个 owner/拒绝 admission；
- pressure handler 不递归 reserve；
- foreground path 不等待长网络/GC。

### 3.4 Device tier

M0 先测当前各池的实际 plateau，再冻结总预算。不能直接把现有局部预算相加。

输入可包括：

- `navigator.deviceMemory`（缺失时 standard conservative）；
- `hardwareConcurrency` 只用于 concurrency，不推显存；
- viewport/DPR；
- page visibility；
- `saveData`；
- current source dimensions；
- platform-independent manual test override。

不使用 adapter info。

## 4. Pressure 策略

由轻到重：

1. 暂停 adjacent/directional/overscan prefetch；
2. abort 尚未开始 decode 的 prefetch；
3. eviction non-visible background detail；
4. 退回 coarser ancestor coverage；
5. eviction unselected Raster Mask render/compare；
6. bypass/clear Worker packed base cache；
7. 释放 idle grow-only scratch/GPU buffers（不销毁 active session truth）；
8. 降低 target background LOD；
9. 对新的大 morphology admission 返回 stable budget insufficient；
10. 若 P0 truth + requested transient 仍超门，保留 store/history，向用户提示缩小 viewport/保存后重试。

禁止：

- 为了释放内存自动保存或修改 annotation；
- eviction dirty Mask tile；
- 关闭正在显示且尚未 draw handoff 的 bitmap；
- 在 GPU failure 后同时保留 packed+GPU+dense 三份 transient；
- page hidden 一瞬间就销毁/recreate 全部资源。

## 5. Subsystem 接入

### 5.1 Background tile

- 分拆 coverage/detail/prefetch charge；
- visible target/ancestor pin；
- URL/Blob 只在 retained 时计相应 JS bytes；decoded image 另计；
- pause/resume prefetch；
- pressure 下降 LOD；
- stale generation release。

### 5.2 Committed Raster Mask render

- 复用 `useRasterMaskRecords` 的 reservation/LRU；
- 把局部 `maxCacheBytes` 变为 coordinator 子配额/owner policy；
- selected/editing pin；
- preview bitmap 的实际 decoded bytes；
- deferred/retry 与 pressure 联动；
- ImageBitmap close 对账。

### 5.3 Sparse edit store/history

- materialized tile、packed bits、retained history 分类别；
- dirty/current/history pinned 语义；
- viewport materialization admission；
- full scan/merge transient；
- save 成功后哪些 dirty 状态可降级；
- operation cancel/stale release。

### 5.4 Worker cache/scratch

- `RasterMaskPackedBaseCache` retained/scratch capacity 报告；
- CPU packed intermediate/transient lease；
- cache bypass 不视为 operation failure；
- pressure 可清 base cache，但不能删除 registered session/RLE；
- last session release 归零。

### 5.5 WebGPU

- source/XOR/readback/intermediate capacity 逐 buffer 报告；
- grow 前 reserve；
- pressure 只在无 in-flight job 时释放；
- device lost/runtime failure 立即 release logical capacity；
- CPU fallback 复用 packed source时不 double charge；
- tile background 不进入 WebGPU owner。

## 6. Page lifecycle 与多标签页

### 6.1 Visibility

- visible → normal；
- hidden 短时：暂停 P4/P5，不立即销毁；
- hidden 达冻结阈值：释放 background detail/prefetch、unselected Mask render、idle GPU buffers；
- visible 恢复：overview/coverage 优先，按 current generation 重建；
- dirty edit truth/history 保留；
- `pagehide.persisted=true`（进入 BFCache）：abort 网络/prefetch 与未提交 operation，释放
  ImageBitmap/GPU buffer/Worker scratch 等可重建资源，但保留 current Mask truth、dirty revision、
  history 与 session 重建描述；不得把 BFCache 当真正 unload；
- BFCache `pageshow.persisted=true`：重建 coordinator/Worker/provider，按 current generation
  重新注册 Mask session，先恢复 overview/coverage，再恢复 detail；旧 promise 仍由 generation fence
  丢弃；
- `pagehide.persisted=false` 或真正 unload：dispose 所有、abort queue、release coordinator；
  不依赖不可靠的 unload 回调完成持久化。

阈值由 M0/E2E 冻结，不以 setTimeout 长时间阻塞。

### 6.2 多标签页

浏览器没有跨 tab 精确总显存 API。本版最低要求：

- hidden tab 主动 shed reconstructible resources；
- 可选 `BroadcastChannel` 只广播 low-cardinality active/heavy/hidden pressure hint；
- hint 不作为 correctness/admission 唯一依据；
- channel 不传 task/content/adapter 信息；
- 两个 tab 同时打开大图时各自仍满足本地 hard budget；
- 不引入跨 tab distributed lock。

## 7. UI/产品行为

- 正常 pressure 不弹 toast；
- background 降 LOD 保留 coverage，可显示轻量“正在恢复清晰度”；
- tile/pyramid failure 与 memory pressure 区分；
- Mask operation 因预算拒绝时提示“缩小可见区域或保存后重试”，不说“GPU 不足”；
- 无 GPU 本身不是错误，不显示警告；
- 超过 Raster Mask 8192/67MP 上限时明确该工具不可用，vector 工具继续；
- debug panel/bug report 可查看资源摘要，但标注员默认不见内部 bytes。

## 8. 联合诊断

`WorkbenchRasterResourceSnapshot`：

- tier/global budget/reserved/committed/peak；
- per category/owner retained/reserved/evictable/pinned；
- pressure level/reason/eviction rounds/freed bytes；
- background level/coverage/cache/request；
- Mask render/edit/history；
- Worker session/base/scratch/transient；
- WebGPU state/buffers/in-flight；
- bitmap created/closed；
- abort/stale/denied admissions；
- page visibility/hidden shed；
- Long Task。

snapshot invariant：

```text
sum(owner committed) == coordinator committed
sum(owner outstanding reserved) == coordinator reserved
coordinator committed + coordinator reserved <= global hard budget
released reservation 不再出现
generation 结束后该 generation bytes == 0
dispose 后 global reserved/committed == 0
```

允许浏览器内部仍有不可观测缓存，但不得把它计作应用 owner。

## 10. 验收门

### Correctness

1. pressure/eviction 不改变 annotation/RLE/history/dirty revision。
2. background LOD downgrade 不改变 world coordinate。
3. budget denial/store cancel/stale response 零部分写入。
4. CPU/GPU route 的 patch/save/reload exact。
5. Raster Mask 上限外任务不暴露不可成功的 edit action。
6. generation/task/page disposal 后旧资源不可 commit。

### Resource

1. 所有 subsystem 接入后，应用逻辑
   `committed + outstanding reserved` 去重 charged peak ≤冻结 global hard budget。
2. P4/P5 pressure 先释放，P0/P1 不被错误 eviction。
3. 连续 20 次联合操作后 retained/capacity plateau。
4. hidden shed 后 reconstructible bytes 降至冻结比例，visible reopen 无 stale。
5. true dispose 后 coordinator、bitmap、Worker、session、GPU buffer 全归零；BFCache restore 后
   dirty Mask/history exact，且只重建 current generation。
6. 两 tab 各自不超过本地 hard budget，hidden tab 释放可重建资源。

### Performance

- background pan/zoom FPS ≥30、Long Task=0；
- foreground Mask operation p95 相对 v0.23.23 不恶化 >5%；
- tile prefetch active 不让 morphology p95 恶化 >5%；
- pressure eviction/re-admission 不产生 UI thread >50ms task；
- small image/no Mask 路径不因 coordinator 增加 >5% first paint/interaction p95。

## 11. 故障矩阵

| 场景                          | 预期                                                     |
| ----------------------------- | -------------------------------------------------------- |
| no GPU                        | tile 正常；Mask packed/dense CPU；GPU owner=0            |
| WebGPU initializing           | foreground CPU；tile prefetch 可暂停但 background 可见   |
| device lost                   | release GPU bytes；same-request CPU；background 不受影响 |
| tile decode burst             | reservation 限并发；Mask truth 不 eviction               |
| background cache full         | evict non-visible/降 LOD；coverage 保留                  |
| Mask render cache full        | unselected deferred/preview；selected/editing 保留       |
| history + dirty 接近预算      | 拒绝新大 operation/按既有 history policy；不丢 current   |
| Worker crash                  | transient release；store/history 不变；background 继续   |
| hidden                        | pause/shed，短时不销毁 truth/session                     |
| BFCache pagehide/pageshow     | shed reconstructible + rehydrate；dirty/history exact    |
| non-persisted pagehide/unload | dispose all；旧资源不可 commit                           |
| source generation switch      | old owner 全 release；stale=0                            |

## 12. Rollout 与回滚

- coordinator 可由内部 gate 关闭并退回各 subsystem 局部预算；
- tile/WebGPU gates 仍独立；
- 若联合总额过保守，可调 tier policy，不改数据格式；
- 若 owner 接入出现 leak，可逐 owner 回退，不删除 coordinator API；
- rollback 不扩大 current Raster Mask limits；
- 不通过关闭 ImageBitmap.close/eviction 规避 bug。
