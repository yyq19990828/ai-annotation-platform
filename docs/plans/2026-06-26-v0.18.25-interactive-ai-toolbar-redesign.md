## Epic 总览（交互工具栏重设计）

工作台有**两个 AI 浮层**，职责交叠、身份混乱，本 epic 拆解之：

| 浮层 | 是什么 | 命运 | 版本 |
|---|---|---|---|
| `AIToolDrawer`（左，贴 ToolDock） | 交互工具配置：后端/模型 + 极性/输出形态/叠加文本/阈值 | **整体退役** → 画布顶部居中浮块；引擎选择持久化 | **v0.18.25（本版）** |
| — 项目编排持久化（新概念） | `Project.preannotate_pipeline` 单列 JSONB（方案 A） + `/ai-pre`「保存为项目编排」 | 新增地基 | [v0.18.26](2026-06-26-v0.18.26-project-pipeline-persistence.md) |
| `AIPredictionPopover`「当前题 AI」（右上，AI 按钮） | 单图推理入口（复用 `PreannotateConfigForm`） | **保留，收为执行器**，加「运行当前题（按项目编排）」 | [v0.18.27](2026-06-26-v0.18.27-popover-run-project-pipeline.md) |

**核心决议**：① `AIToolDrawer` 退役、内容迁画布顶部居中浮块（pill，非全宽 bar）；② 引擎=后端+模型合并，选择按 `project×backend` 持久化；③ popover 不变编排编辑器，只新增「执行项目编排」；④ 项目编排持久化走方案 A（单列 JSONB），方案 B（多命名编排表）延后记 ROADMAP；⑤ 统一 picker `PreannotateConfigForm` 不动。

## 1. 背景

「今时不同往日」：4 个 backend、每后端多模型、多阶段预标注（路径 B 已落 v0.18.1–3）。模型选择空间从「几乎不用选」变「经常要选」，`AIToolDrawer` 两个痛点凸显：

- **藏太深**：模型选择器只有「过滤后 >1 模型」才渲染（`AIToolDrawer.tsx:155`），且整个浮层贴在 ToolDock 右侧、需选中 AI 工具才浮出。
- **不记忆**：`activeModelId` 是纯 `useState`（`useMLCapabilities.ts:70`），刷新即回落默认。

## 2. 目标 / 非目标

**目标**
- `AIToolDrawer` 退役，其内容（引擎选择 + 极性/输出形态/叠加文本/阈值 + 兼容性警告 + 状态指示）迁移到**画布顶部居中浮块**。
- 引擎（后端 + 模型合并为一个选择概念）选择**持久化**（按 backend，跟用户走、跨设备）。
- 前端为主；后端仅需让 `ai` 偏好子树支持 `model_by_backend` 子键 + 深一层合并（无 DB 迁移，prefs 是 JSONB）。

**非目标**
- 不碰 popover「当前题 AI」（→ v0.18.27）。
- 不引入项目编排（→ v0.18.26）。
- **不改** `PreannotateConfigForm` / `usePreannotateConfig`（统一 picker 单一事实源，保持纯净）。
- 视频 / 点云 stage 不加该浮块（point/box/exemplar 是图片交互；视频走 tracker、点云走自有交互）。

## 4. 设计与改动

### 4.1 新组件 `InteractiveToolBar`（横排浮块）

- 由 `AIToolDrawer` 内容迁来：**竖排改横排**，套 `MaskToolbar` 浮块外观（`absolute left-1/2 top-3 z-local-5` + 横向 `flex items-center gap-2.5`）。
- props 基本沿用 `AIToolDrawer` 现有签名（tool / backendName / capability / samPolarity+set / exemplar* / models / activeModelId+set / capabilityWarnings / interactiveBackends / selectedInteractiveId+onSelectInteractive）。
- **exemplar 控件最多**（引擎 + 输出形态 + 叠加文本 + 阈值滑杆 + 极性），横排易挤 → **阈值/叠加文本走「点开展开」二级浮层**（小 popover 锚定浮块），主条只留引擎 + 极性 + 输出形态 + 一个「更多」入口。其余工具（smart-point/smart-box）控件少，全平铺。
- 与 `MaskToolbar` **互斥**：mask 非 AI 工具，二者不同时在场，共用 `top-3` 居中位无冲突。

### 4.2 渲染点迁移

- `useWorkbenchShellModel.tsx`：
  - **删** `aiToolDrawer` prop 构造（`:1910-1955`）。
  - 在 `overlays`（`:2026`）紧邻 `MaskToolbar` 处加：`{isAIToolId(s.tool) && aiDrawerOpen && <InteractiveToolBar … />}`（props 即原 `aiToolDrawer` 那套）。
- `ToolDock.tsx`：**删** `aiToolDrawer` prop（`:37` 声明 / `:126` 解构）+ 渲染块（`:289-294`）。

> overlays 只在图片 stage 注入（`useWorkbenchShellModel.tsx` image 分支），天然满足「仅图片 stage」非目标。实装确认 exemplar/smart-point/smart-box 仅出现在图片 toolbar。

### 4.3 引擎选择 = 后端 + 模型合并

- 心智「这个工具用哪个 AI」。UI：
  - 多后端候选（`interactiveBackends.length >= 2`）→ 后端选择器（现状）+ 模型选择器两级，但视觉合并为「引擎」分区。
  - 单后端多模型 → 仅模型选择器（现状 `showModelSelector`）。
- 词汇复用现有 `groupModelsByTask`（`AIToolDrawer.tsx:76`）。本版不强行做成单一扁平下拉（避免过度设计），保留两级、视觉归一即可。

### 4.4 引擎选择持久化（修「不记忆」痛）——服务端、跟用户走、跨设备（实装方案）

> 讨论后定为**服务端**（非 localStorage），与已有的 AI 工具参数偏好（`useAiToolParamPrefs` → `params_by_backend`）及主题偏好一致，跨设备跟随账号、每位标注员各自一份。

- **前端**：新增 `useAiToolModelPref(backendId)`（镜像 `useAiToolParamPrefs`）——读 `ai.model_by_backend`、防抖写 `{ai:{model_by_backend}}`，按 backend 分桶。`useMLCapabilities` 加 `preferredModelId` 入参，activeModel 解析为「本会话显式选择 > 本偏好 > `pickDefaultModel`」（各级校验仍合法 model，自愈）。`useWorkbenchShellModel` 把 `modelPref.savedModelId` 喂入、并在 `onSetActiveModelId` 里 `setActiveModelId(id)` + `modelPref.save(id)`。
- **后端**：`AIToolPreferences` 加 `model_by_backend: dict[str,str]`（`schemas/user.py`）；`update_preferences`（`me.py`）把 `ai` 子树改「深一层合并」（`merged["ai"] = {**existing.ai, **incoming.ai}`），使 `params`/`model` 两个独立 writer 互不覆盖。**prefs 是 JSONB，无 DB 迁移**。
- 粒度：按 backend（同 backend 跨 prompt 共享一条记忆；日后要按 prompt 分别记再加键，YAGNI）。

## 5. 测试

- `useMLCapabilities` 持久化单测：`setActiveModelId` 落 storage；重挂载读回；storage 中非法 id → 回落 `pickDefaultModel`；切 backend 各记各的、互不串。
- `InteractiveToolBar` 渲染单测（从 `AIToolDrawer.test`（若有）迁移）：引擎选择 / 极性 / exemplar 控件门控（`exemplar_capabilities` 隐藏负框/文本）/ exemplar「更多」折叠展开。
- 回归：`ToolDock` 不再渲染 drawer（`data-testid="ai-tool-drawer"` 不在 ToolDock 右侧）；选 AI 工具浮块出现在画布顶部；选 mask → `MaskToolbar` 出现、AI 浮块消失（互斥）。
- `pnpm lint`（含 `check-tw-tokens.mjs`）：新浮块不得用裸色（CLAUDE.md §6）。

## 6. 验收

- 选 point/box/exemplar → 画布顶部居中浮块出现（引擎 + 参数），不再贴 ToolDock 右侧。
- 切引擎后**刷新页面，选择保留**。
- 选 mask → `MaskToolbar` 出现、AI 浮块消失。
- 视频 / 点云 stage 不出现该浮块。
