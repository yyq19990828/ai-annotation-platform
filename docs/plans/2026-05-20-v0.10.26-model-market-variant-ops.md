# v0.10.26 · 模型市场扩展 — 变体可观测 + 单变体预热

> ROADMAP §AI/模型「模型市场扩展」二期。①「模型版本对比 / AB 路由 UI」中**可落地、不膨胀**的一片：
> 把 v0.10.23 ModelPool 已具备的「单容器内多变体并存」能力暴露到模型市场（super admin 侧），
> 让管理员**看见**哪些变体已加载 + 各变体 cache 命中，并能**预热**任意目录变体到显存。
>
> ②「一键热更新模型权重」(`/reload`) 端点 + 前端按钮在 v0.9.x 已落；本期把它**泛化**为「可指定变体预热」。
> ③「注册时选变体」v0.10.23 已落（退化为 pool 请求级）。

## 范围（明确划界）

**做：**
- 变体可观测：模型市场每个 backend 可展开「变体」面板，列已加载变体（LRU 序）+ 各变体 cache 命中率 + 最近使用。
- 单变体预热：`/reload` 接受可选 `{sam_variant, dino_variant}`，预热指定变体进 pool；UI 变体下拉 + 「预热」按钮。

**不做（defer，仍留 ROADMAP）：**
- 加权 AB 路由（按 task hash / 权重自动分流到不同变体并打标）—— 需路由配置 + 结果打标 + 协议，体量大。
- 模型版本对比（同输入双变体并排 diff）—— 工作台级特性，独立 epic。

## 现状（已查证）

- `grounded-sam2-backend/main.py`：`/setup.params` 已含 `sam_variant`(enum tiny/small/base_plus/large) + `dino_variant`(enum T/B)；`/health` 返回 `pool`(=`{cap, loaded_variants, evict_count, per_variant_lru_ts}`) + `cache.buckets`(每变体 stats)。`/reload` 当前只热默认变体（无 body）。`_get_predictor(sv,dv)` 走 pool；变体校验逻辑见 `_resolve_variant`。
- `apps/api/app/services/ml_client.py`：`reload()` 无 body；`health_meta()` 仅保留 `gpu_info/host/cache/model_version` 四键 —— **未含 `pool`**，故 loaded_variants 当前没进库。
- `apps/api/app/api/v1/ml_backends.py:237`：`/reload` 端点无 body；`MANAGERS` 权限 + 审计。
- 前端 `RegisteredBackendsTab.tsx` 读 `health_meta`（已展示 model_version / gpu / cache hit）；`api/ml-backends.ts` reload 无 body；`useMLBackendReload` 仅传 backendId；`adminMlIntegrations.ts BackendHealthMeta` 无 `pool` 字段。

## 追加范围（容器直连观测 · 应用户反馈）

> 痛点：模型市场**按项目分组**，没有任何项目注册 backend 时一片空白，哪怕 AI 容器在跑。用户希望与注册解耦地观测容器健康/模型/可启动性。

**做：**
- env `ML_BACKEND_OBSERVE_URLS`（CSV/JSON list，留空回退 `ML_BACKEND_DEFAULT_URL`）。
- `GET /admin/ml-integrations/observe`：并发探测各 URL 的 `/health`+`/setup`，返回健康/延迟/显存/`model_version`/已加载变体/变体目录 + `registered`（是否已被项目注册占用）。
- `POST /admin/ml-integrations/observe/smoke-test`：试启动。**仅空池时** warm 指定变体→确认→自动 `/unload` 还原；容器已有变体常驻时**跳过**（不预热不卸载），避免驱逐在用模型 / 与注册 backend 冲突。super_admin only + 审计。
- 前端 `ObserveBackendsPanel`：渲染在模型市场顶部；每容器健康/变体目录 + 每变体「试启动」；`configured_count=0` 时不渲染。

**不做（defer）：**
- 带 token 的观测容器（observe URL 当前假定免鉴权，内网/dev 场景）。
- per-variant 精确卸载（backend `/unload` 是 clear_all；空池守护已规避冲突）。
