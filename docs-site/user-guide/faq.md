# FAQ

## 登录与账号

**Q: 忘记密码？**
点击登录页「忘记密码」，会发邮件链接重置。如未配置邮件服务，联系超级管理员手动重置。

**Q: 账号被锁定？**
本平台不做「临时锁定账号」处理。同一 IP 连续登录失败 ≥ 5 次后，下一次登录必须通过 **Cloudflare Turnstile CAPTCHA** 验证（滑块 / 人机校验）；通过后重置失败计数。如你完全无法完成 CAPTCHA，联系管理员或换网络环境。

**Q: 自助注册和邀请注册有什么区别？**
管理员开启「开放注册」后任何人可自行注册，默认获得 viewer 角色；通过邀请链接注册则按邀请预设角色加入对应项目。开放注册在生产环境默认要求邮箱验证，邀请注册恒视为已验证、无需再验。

**Q: 注册后能直接登录吗？**
若该环境开启了邮箱验证（生产默认开启），注册后需先点验证邮件里的链接才能登录，未验证时登录会被拦截并提示「邮箱未验证」。未开启验证时注册即可登录。

**Q: 没收到验证邮件 / 链接过期了怎么办？**
验证链接 24 小时有效。可在登录 / 验证页重新发送验证邮件（出于安全，无论邮箱是否存在都会提示已发送）。如平台未配置邮件服务，验证链接只写到后端日志，请联系超级管理员。

**Q: 在哪里修改密码？**
左侧导航「**设置**」→「修改密码」，填写旧密码和新密码提交即可。新密码至少 **8 位**，且需同时包含大写字母、小写字母与数字。

## 标注

**Q: 提交后能否撤回？**
- 状态 `submitted` 但还没被审核 → 可在「我的任务」撤回
- 已审核完成 → 不可撤回，需要联系管理员

**Q: 浏览器卡顿？**
- 单图标注 > 200 个对象时卡顿正常，可关闭「显示标注列表」侧栏
- 视频标注帧率高时建议用 Chrome / Edge

**Q: 草稿会丢失吗？**
标注操作即时写入服务端，不依赖定时保存。网络断开或后端 5xx 时，操作进入本地 **IndexedDB 离线队列**，联网后自动顺序回放，底部状态栏离线图标可查看队列状态。画布批注绘制中的笔触写入 `sessionStorage`（TTL 5 分钟），刷新前浏览器会弹原生确认弹窗防止误关。

**Q: 已有标注被「已被覆盖」半透显示是什么意思？**
AI 候选框与已有人工框的重叠度（IoU）超过项目设置的去重阈值（默认 0.7）时，该候选框会被标记为重复候选，视觉上半透显示。「全部采纳」会自动跳过这些候选，防止重复标注。这与审核无关。

**Q: 如何画旋转框？**
按 `W` 切到旋转框工具 → 拖框确定大小和中心 → 松开后选中框，拖动顶部旋转手柄调整角度。详见 [旋转框标注](./workbench/rotated-bbox)。

**Q: 多边形顶点怎么删除？**
选中多边形后，`Shift + 单击顶点` 删除该顶点（≤ 3 个顶点时拒绝删除）。

**Q: 怎么在多边形边上加新顶点？**
选中多边形，将鼠标悬停在某条边上出现「+」图标，按住 `Alt` 后单击即可插入新顶点。

**Q: 关键点绘制时如何标记被遮挡的节点？**
落点时用 `Alt + 左键单击` 标记可见性 `v=1`（被遮挡，位置已知）；右键单击则跳过当前节点（`v=0`，位置仍以点击坐标占位）。编辑已有关键点时，`Alt + 单击节点` 循环切换可见性。详见 [关键点标注](./workbench/keypoint)。

**Q: SAM / AI 工具没有响应？**
- 确认项目已注册交互后端：项目设置 → ML Backend → 确认有交互能力的 backend 已注册。
- 工具按钮置灰说明当前后端不支持该 prompt 类型，hover 工具按钮可看 tooltip 原因。
- 右下状态指示红色表示 `/setup` 拉取失败，可尝试刷新页面。

## 审核

**Q: 我能否回退已通过的任务？**
- 项目管理员可以
- 普通审核员不能

**Q: 退回时如何给标注员反馈？**
审核退回时可填写「退回理由」文本；退回后标注员在工作台任务队列可见「待重做」状态以及附带的审核备注。

## 数据导入导出

**Q: 支持哪些数据导入格式？**
图片 / 视频支持 ZIP（含媒体 + 可选的 JSON 标注）、直接上传单文件、或通过「存储连接器」（AWS S3 / Azure Blob / GCS / 本地挂载）批量导入。点云支持 nuScenes 格式（有转换脚本）和原生目录结构（`scenes/` + `cameras/` + `calibration/`）。详见 [数据导入](./datasets/import-images)。

**Q: 支持哪些导出格式？**
导出目标包括：`coco`、`yolo-det`、`yolo-obb`、`yolo-seg`、`aap_json`（原生格式，含所有几何类型）。旋转框不进 COCO，导出时跳过；关键点走 COCO `keypoints` 扁平数组格式。详见 [导出格式](./reference/export-formats)。

**Q: 如何导入 AI 预测结果作为候选？**
在「数据集」页面的「预测导入」入口，选择格式（YOLO / COCO / AAP JSON）和对应变体（det / obb / seg），上传文件后系统异步处理，处理完成后预测出现在工作台 AI 候选列表。YOLO OBB 格式需选 `yolo_variant=obb`。详见 [预测导入与导出](./datasets/prediction-import-export)。

**Q: 导入时如何关联到正确的任务？**
系统按文件名 stem（去扩展名）匹配数据集 item。确保预测文件名（如 `frame_001.txt`）与媒体文件名（`frame_001.jpg`）的 stem 一致。点云多 scene 场景请使用全局唯一的文件名 stem（加 scene 前缀）。

## 任务分派

**Q: 任务是自动分派还是手动分派？**
支持两种模式：项目设置可开启「自动分派」（标注员进入工作台时按队列自动拿下一条）；也可由管理员手动在「数据管理」页面批量指定标注员和审核员。

**Q: 批次是什么？**
批次（Batch）是项目内的任务分组单元，用于分阶段推进和权限隔离。一个批次对应一批任务，可设截止日期、指派标注员/审核员、独立管控进度。详见 [批次管理](./projects/)。

## AI 预标注

**Q: AI 预标注需要多久？**
- 交互式（SAM 点/框）：首次触发图像编码约 1.6-3 秒，命中 LRU 缓存后 < 50ms
- 批量预标：单张图约 2-5 秒（GroundingDINO + SAM 流水线），大批量建议错峰跑

**Q: 批量 AI 预标结果在哪里看？**
「AI 预标」页面（左侧导航）可查看批量预标任务进度和结果预览。完成后在工作台「AI 待审」列表可逐条采纳 / 驳回。

**Q: 项目没有配置 ML Backend，能用 AI 工具吗？**
不能。工具栏 AI 工具（S/G）需要项目注册至少一个支持对应 prompt 能力的交互后端。批量预标也需要绑定后端。

## 视频标注

**Q: 视频标注和图片标注的区别？**
视频任务进入「视频时间轴」工作台：标注会关联到帧，支持创建跨帧轨迹（Track）。工具按 `T` 切轨迹工具，`B` 切单帧框工具。详见 [视频追踪标注](./workbench/video-track)。

**Q: 如何快速给视频里同一目标跨帧补全轨迹？**
先在关键帧标注 bbox，然后用 AI 传播（`Ctrl + B`）让系统自动向后帧预测轨迹；或手动在各关键帧添加关键帧，系统对中间帧线性插值。详见 [AI 视频传播](./workbench/video-propagate)。

**Q: 视频轨迹和单帧框有什么区别？**
轨迹（Track）是同一目标跨多帧的关联标注，存储为 `video_track_bbox` 几何；单帧框（Frame Box）仅属于当前帧，存储为 `video_bbox` 几何。多个单帧框可在右键菜单「聚合为轨迹」合并。

## 性能

**Q: AI 预标注返回 0 个结果？**
- 文本提示：尝试更简洁的描述，或降低 `text_threshold` / `box_threshold`（在悬浮 AI 面板调整）
- Exemplar：示例区域太小或太模糊，尝试更清晰的示例；或降低 `score_threshold`
- 确认 prompt 语言为英文，多类别用 ` . ` 分隔
