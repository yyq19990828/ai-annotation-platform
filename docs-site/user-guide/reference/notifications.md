# 通知中心

右上角铃铛是个人通知中心。通知会持久保存，浏览器离线或 WebSocket 断开后，重新打开面板仍能看到未读消息。

## 会进入通知中心的事件

常见通知包括：

- 任务审核通过、退回、重新打开
- 批次被驳回、重新进入审核、被管理员锁定或解锁
- 失败预测重试开始、成功或失败
- 导出完成或失败
- 后台任务完成、失败或取消
- BUG 反馈评论、状态变化或重新打开

后台任务通知来自 `async_jobs` 的终态状态。批量预标、视频追踪、预测导入等任务完成后，除了右上角「后台任务」铃铛里的历史记录，也会在个人通知中心出现一条 `job.*` 通知。

## 已读、删除和清空

- 点开某条通知会按它的目标跳转，并自动标记为已读。
- 通知行右侧的删除按钮会删除该条通知；如果删除的是未读通知，未读数量会同步减少。
- 「全部已读」只把当前未读通知标记为已读。
- 「清空已读」会删除当前用户所有已读通知，不影响未读通知。

删除只影响自己的通知记录，不会影响其他用户，也不会删除后台任务、导出产物或原始业务对象。

## 通知偏好

进入「设置」→「通知偏好」可以按通知类型关闭站内通知。关闭后，新事件不会写入通知中心，也不会推送到在线会话；已经存在的历史通知不受影响。

当前可静音的类型覆盖任务审核、批次审核、失败预测重试、导出、后台任务终态、BUG 反馈和账号注销相关通知。
