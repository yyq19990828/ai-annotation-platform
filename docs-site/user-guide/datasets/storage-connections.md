# 存储连接器

> 适用角色：项目管理员 / 超级管理员

存储连接器让你把外部的对象存储（S3 / 阿里云 OSS / MinIO 等兼容服务）或 SFTP 服务器接入平台，之后在新建数据集时直接从这些来源批量导入文件，免去手动上传。

入口：左侧导航 **数据集** → 顶部 **数据连接器** 标签页。

## 新建连接器

1. 进入 **数据集 → 数据连接器**，点击右上角 **新建数据源**。
2. 填写信息：
   - **名称**：便于识别的名字，如 `aliyun-oss-prod`。
   - **类型**：`S3 / OSS` 或 `SFTP`（创建后不可更改）。
   - **范围**：
     - **个人**：仅你自己和超级管理员可见、可用。
     - **全局**：所有用户可用（仅超级管理员可创建）。
   - **连接参数与密钥**（按类型）：
     - **S3 / OSS**：Endpoint、Bucket、Region（可选）、Base prefix（可选，导入起始前缀）、是否 HTTPS、Access key、Secret key。
     - **SFTP**：Host、Port（默认 22）、Username、Base path（可选）、认证方式（密码 / 私钥）及对应凭据。
3. 点击 **新建数据源** 保存。

> 密钥（Access/Secret key、密码、私钥）会被加密存储，**不会**在任何界面或接口中再次显示。编辑时密钥留空即表示保持不变。

## 测试连通性

连接器列表中每条都有 **测试** 按钮。点击后平台会用保存的凭据真实建立一次连接：

- **连接成功**：提示成功，并显示探测到的样本文件数。
- **连接失败**：提示原因，常见为凭据错误、地址不可达，或**目标主机不在白名单内**（见下）。

建议新建后先测试，再用于导入。

## 主机白名单（超级管理员）

出于安全考虑，平台只允许连接器访问**白名单内**的主机。若测试时提示「目标不在白名单内」，需要超级管理员先把目标地址（域名 / IP / 网段）加入白名单。

- 条目可以是：网段（`10.0.3.0/24`）、单个 IP（`192.168.1.50`）、精确域名（`oss-cn-hangzhou.aliyuncs.com`）或后缀域名（`.aliyuncs.com`，匹配其所有子域）。
- 本机回环、内网元数据等地址会被**始终拒绝**，无法通过白名单放行。

## 在新建数据集时使用

1. 进入 **数据集 → 数据集管理**，点击右上角 **新建数据集**。
2. 第 1 步「选择来源」切到 **连接器导入**：
   - 选择一个连接器；
   - 填写 **Source path**（相对连接器的 base 路径的起始目录，留空表示根）；
   - 勾选是否 **递归扫描** 子目录；
   - 可选填写 **Include globs**（如 `*.jpg, *.png`）只导入匹配的文件。
3. 第 2 步「基本信息」：数据集**名称会自动取 Source path 的末段**（如 `data/dataset-A` → `dataset-A`），可按需改写；再确认描述与数据类型。
4. 点击 **开始导入**。导入在后台异步执行，可在第 3 步与右上角的任务铃中查看进度。

> **保留目录结构**：导入会按 Source path **内部**的子目录层级落库（源 `dataset-A/a/img.jpg` → 数据集内 `a/img.jpg`），不会多嵌套一层。后续源里新增子文件夹（如 `dataset-A/c/`）时，打开该数据集再次导入同一来源即可，已存在的文件按内容自动跳过、只补新增。

> 单次导入有文件数与总体积上限，避免误扫整个存储桶；超过上限任务会失败，请用 Source path / globs 缩小范围。

## 编辑与删除

- **编辑**：修改名称或连接参数；不填密钥则沿用原密钥。
- **删除**：移除连接器。已经导入到数据集的文件不受影响（文件已落入平台存储），但此后无法再用该连接器导入。

只有连接器的创建者或超级管理员可以编辑 / 删除；全局连接器仅超级管理员可管理。
