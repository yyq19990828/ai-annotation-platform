# 点云跨帧标注

scene 模式的点云项目里，同一物体会在一段录像里连续出现多帧。跨帧能力让你不必每帧从零画框，并能叠加邻帧参考检查时序连续性。scene 与 `frame_index` 的概念见 [Scene + frame_index 跨 task 帧序列地基](/dev/concepts/scene-and-frame-index)。

## 跨帧目标延续

同一辆车在一段录像里连续出现多帧时，不必每帧从零画框：

- **`Shift+→`**：把当前选中的 3D 框延续到**同 scene 的下一帧** task —— 系统在下一帧新建一个相同 PSR 的框（与源框共享 `group_id`，表示"同一物体"），自动跳到下一帧工作台并选中这个新框，你只需微调位置即可继续 `Shift+→`。
- **`Shift+←`**：同理延续到上一帧。
- 已到 scene 末帧再按 `Shift+→`、首帧再按 `Shift+←`，提示"已是该 scene 最后 / 首帧"，**不会**误跳到别的 scene。
- 仅在选中了一个 **3D 框**时生效；未选中或选中点云分割（PointMask）会有相应提示。
- 2D 图像序列里等价操作是 `Alt+→` / `Alt+←`（2D 的 `Shift+方向` 已用于 10px 平移）。

> 跨帧延续不是破坏性操作：新框只是源框的副本，调坏了可直接删除或撤销。

## 邻帧参考叠加

工具条「邻帧叠加」切换前后各显示几帧的同 `group_id` 历史 / 未来框作时序参考：

- 档位 **关 / 1 / 3 / 5**；选 K>0 后，选中某个有跨帧链(`group_id`)的框时，主视图 + 三视图叠加显示前后各 K 帧该物体的框。
- 参考框为**半透明虚线、不可选不可拖**，只读参考，方便判断时序连续性（这一帧的位置和上一帧是否对得上）。
- 当前档位记在浏览器本地，切 task 不重置。
