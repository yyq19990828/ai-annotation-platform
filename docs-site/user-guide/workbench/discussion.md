# 评论与问题

工作台的「讨论」面板分为「评论」「问题」「历史」：评论用于交流，问题用于记录需要处理的事项，历史用于查看已经发生的操作。Mask 质检仍使用独立页签。

## 不选标注也能留言

进入任务后，评论区默认显示「本任务全部讨论」，发送目标是「当前任务」。直接输入文字即可发送，不需要先创建标注。未采纳的 AI 候选、临时图形和多选状态都不会成为标注评论的目标。

阅读范围与发送目标互不影响：

| 控件     | 可选内容                             | 切换后的变化                         |
| -------- | ------------------------------------ | ------------------------------------ |
| 阅读范围 | 本任务全部讨论、仅任务留言、当前标注 | 只改变列表，不搬动草稿               |
| 发送目标 | 当前任务、已明确选择的正式标注       | 保存原目标草稿，恢复新目标自己的草稿 |

选中一个已保存标注后，可以明确选择「评论选中标注」。随后即使选中另一个标注，原草稿仍发给原标注；发送前请核对目标标签。标注已删除或不可访问时，该草稿会暂停发送，并提示返回任务留言，不会自动转换成任务评论。

「当前标注」阅读范围随选中的正式标注变化；取消选择或改为多选后，会回到任务范围并显示原因。其他阅读范围不会因画布选择改变。

任务留言只支持纯文字。标注评论保留已有的 @ 提及、附件、绘图和视频位置能力；不支持的控件不会出现在任务留言中。Enter 发送，Shift+Enter 换行；中文输入法选词时按 Enter 不会发送。

## 阅读与继续加载

全部讨论按时间从新到旧排列，包含任务留言和本任务的标注评论，不包含问题回复、产品 BUG 或任务退回记录。每条评论显示来源；点击可用的标注来源标签可选中对应对象。历史对象已不可定位时，仍可阅读保留下来的评论。

列表底部的继续加载入口用于读取更早内容。加载失败会显示重试，不会把失败当作空列表。附件按评论原来所属的标注下载，与当前选中对象无关；旧任务留言中没有受支持下载方式的附件会显示不可用。

编辑、状态和删除操作按当前权限显示。操作失败会保留内容并提示原因；如果发送请求失败，请核对后手动重试，系统不会自动重复发送。

## 草稿保留到什么时候

同一浏览器标签页、同一次登录期间，文字及已附加的内容按用户、项目、任务和目标分别保留。切换评论／问题／历史，隐藏、浮动或重新停靠面板，任务 A → B → A，以及离开工作台后通过站内导航或浏览器后退返回，都可恢复原目标草稿。

发送和上传也绑定原目标。请求较晚完成时，不会清空另一个任务的输入，也不会把附件挂到当前选中的标注上。发送失败后保留草稿；已有请求正在发送时，同一目标不能重复提交，其他目标仍可编辑。

文字草稿不承诺在刷新、关闭标签页或重新登录后恢复。有未发送内容时，浏览器会在支持的情况下提示离开风险；退出登录或切换账号会清除当前会话的讨论草稿。

弹窗中的笔触会随绘制保存到原标注草稿。关闭弹窗、切换页签或离开工作台后，同一登录会话内仍可重新打开继续绘制；「保存批注」把绘图留在输入区，点击「发送」才会提交评论。弹窗绘图与题图直接绘制不能同时进行。

在题图上直接绘制的活动批注另有五分钟的本标签页恢复记录，按用户、项目、任务和标注隔离。切任务或离开工作台前，笔触同时保存在会话草稿中，因此同一登录会话内离开超过五分钟再返回，仍可继续绘制。五分钟限制只作用于刷新后的恢复记录；它不保存文字或弹窗绘图草稿，也不会把没有用户归属的旧记录导入其他账号。

## 新建与筛选问题

在「问题」页选择新建任务问题，可记录不绑定画布位置的事项。图片和视频的任务问题表单都不要求坐标。需要具体位置时，选择「在画布选点」，再点击实际问题位置；视频会先确认源帧，保存位置、帧号及已有视图上下文。

问题默认显示「未解决」，可切换「全部」「已解决」「搁置」。筛选由服务端执行，较早的问题不会因为不在第一页而被漏掉。视频保留已有的整个项目范围，图片与点云不会因此增加跨项目定位入口。

「问题」页签和画布入口显示当前任务的未解决总数，不是列表当前加载条数。数量请求进行中显示加载状态，失败显示未知和重试入口，不把失败写成 0。画布图钉逐页加载，已有图钉会保留；加载未完成或失败时会显示覆盖状态，全部加载完成后提示才消失。

问题状态包括未解决、已解决和搁置。可用操作取决于当前任务权限；审核员可处理状态，并不因此获得修改他人正文或删除问题的权限。位置与视频源帧的说明见[视频任务审核](../review/#在视频画面标记问题)。

## 历史与布局

「历史」显示当前任务或标注的审计范围，只用于阅读，不是另一份可编辑评论。用方向键、Home、End 可在讨论页签之间移动，输入区保留独立焦点。列表随面板高度伸缩，输入区固定在底部；更多布局方式见[布局偏好与浮窗](./#布局偏好与浮窗)。
