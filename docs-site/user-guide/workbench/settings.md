# 工作台设置

工作台的个人偏好按 **通用 / 图片 / 视频 / 点云** 四类组织,有两个入口:

| 入口 | 路径 | 适用场景 |
|---|---|---|
| **工作台设置抽屉** | 工作台右上角齿轮菜单 →「工作台设置」 | 边看画布边调 —— 改动**实时生效**,所见即所得 |
| **个人设置页** | 顶部头像菜单 → 设置 →「标注偏好」 | 浏览/调整全部分类的字段 |

两个入口读写同一份配置,任一处改动都会自动保存(约 300ms 防抖)并跨设备同步。

## 抽屉只显示「通用 + 当前模态」

在图片任务里打开抽屉,只会看到「通用」和「图片」两组;视频 / 点云任务同理。要查看全部分类,走抽屉底部的「个人设置页」链接。暂无字段的分类(空分组)不会显示。

### 补充说明

- **边栏宽度**:左 / 右栏宽度占工作台宽度的 10%–35%,除设置项外也可直接拖拽边栏分隔条,双击分隔条回到默认 15%。
- **标注视觉(通用,图片 / 视频共用)**:标签字号、线宽、填充透明度、选中填充透明度,以及标签显隐与标签内容,都在「通用」组里,一套值同时作用于图片与视频画布,调一处两端实时同步。
  - **标签显隐**:`始终显示` / `仅选中时`(只给当前选中对象显示标签)/ `不显示`。
  - **标签内容**:按标注类型分段控制,顶部切换 `单帧 / 轨迹 / AI预测`,下方按段勾选字段;`类别名` 三段恒显(标「必选」)。单帧(图片手工框)可选 `分组号 / 属性`;轨迹(视频 track 框)可选 `轨迹号 / 状态(插值·遮挡) / 属性`;AI预测(图片预测框)可选 `来源(✦模型/导入)/ 置信度 / 分组号 / 属性`。不同类型只列对它有意义的字段——例如置信度仅 AI 框才有。
  - **线宽**:选中对象在所设线宽基础上自动加粗 0.5。
  - **填充透明度**:只作用于可闭合标注(框 / 多边形 / 旋转框);折线和关键点无填充。
- **SAM 输出形态**:SAM 文本 / Exemplar 输出形态不在设置页中展示,但会按账号记住用户上次显式选择;项目设置中的「SAM 文本预标默认输出」仍优先于个人记忆。
- **WebCodecs 精确解码**:本机实验开关,写入浏览器 localStorage,刷新后生效;仅在视频任务的设置抽屉显示。
- **性能档位(视频)**:影响视频帧预览缓存、`ImageBitmap` / WebCodecs 缓存和缩略图预取窗口。标准档等同旧默认行为;轻量档减少内存占用;激进档提高缓存和预取上限,适合长视频快速浏览。
- **性能档位(点云)**:控制点云加载时的抽稀上限——标准档 500,000 点、轻量档 250,000、激进档 1,000,000,切换后下次加载点云时生效。
- **点云主视图视角动作**:左上角「重置视角」恢复默认斜视,「俯视」切换 BEV,「重置相机布局」只恢复 2D 相机图浮窗的默认贴边布局,不会重置 3D 主视角。

## 项目锁定

项目管理员可以在项目设置中统一指定部分工作台规范:图像平滑、CSS 滤镜、控制点大小、网格吸附、3D 新框默认尺寸、关键帧复制是否覆盖目标关键帧、AI 传播默认模型。被项目锁定的字段在抽屉和设置页中均显示「项目锁定」徽章并禁用 —— 以项目配置为准,保证团队产出一致。

## 常见问题

- **改了没反应?** 抽屉中的改动对画布实时生效;若字段带「项目锁定」徽章,说明项目配置优先,个人值不生效。
- **换设备后设置丢了?** 偏好保存在账号上,登录同一账号即同步;布局类状态(栏宽、浮窗位置)另有本地缓存加速首帧,联网后以服务端为准。
