# 工作台设置

工作台的个人偏好按 **通用 / 图片 / 视频 / 点云** 四类组织,有两个入口:

| 入口 | 路径 | 适用场景 |
|---|---|---|
| **工作台设置抽屉** | 工作台右上角齿轮菜单 →「工作台设置」 | 边看画布边调 —— 改动**实时生效**,所见即所得 |
| **个人设置页** | 顶部头像菜单 → 设置 →「标注偏好」 | 浏览/调整全部分类的字段 |

两个入口读写同一份配置,任一处改动都会自动保存(约 300ms 防抖)并跨设备同步。

## 抽屉只显示「通用 + 当前模态」

在图片任务里打开抽屉,只会看到「通用」和「图片」两组;视频 / 点云任务同理。要查看全部分类,走抽屉底部的「个人设置页」链接。暂无字段的分类(空分组)不会显示。

## 当前可调字段

**通用**

| 字段 | 说明 | 默认 |
|---|---|---|
| 性能采样率 | PerformanceObserver longtask 采样率,0–1 | 0.05 |
| 删除确认 | 控制单删 / 多选删除前是否弹确认 | 不确认 |
| 最近类别数量 | 类别选择器里保留的最近类别数量 | 5 |
| 邻帧叠加 | 前后各显示几帧参考框;0 为关闭 | 关闭 |

**图片**

| 字段 | 说明 | 默认 |
|---|---|---|
| 图像平滑 | 关闭后像素清晰,适合医学影像 / 像素艺术 | 开启 |
| CSS 图像滤镜 | 如 `brightness(1.2) contrast(1.1)`,留空恢复原图 | 空 |
| 控制点大小 | 顶点拖拽手柄半径 | 6px |
| 画框后行为 | 画完 bbox 后选择类别,或沿用当前类别直接落库 | 选择类别 |
| 吸附阈值 | polygon / polyline 顶点和边吸附的屏幕像素阈值 | 8px |
| 滚轮缩放步长 | `Ctrl`/`⌘` + 滚轮缩放的单步倍率 | 10% |
| 淡化透明度 | AI 候选被人工框覆盖时的淡化程度 | 0.35 |
| 显示框标签 | 控制 bbox / polygon / polyline / keypoint 的类别标签显隐 | 开启 |
| Mask 覆盖透明度 | Mask 编辑器红色覆盖层透明度 | 0.45 |

SAM 文本 / Exemplar 输出形态不在设置页中展示,但会按账号记住用户上次显式选择;项目设置中的「SAM 文本预标默认输出」仍优先于个人记忆。

**视频**

| 字段 | 说明 | 默认 |
|---|---|---|
| 默认播放速率 | 打开视频任务时的初始播放速率 | 1x |
| 大步进帧数 | 时间轴聚焦时 `Shift+←/→` 使用的帧数;采样网格模式按一个采样单元跳转 | 10 帧 |

视频任务的工作台设置抽屉还会显示「实验特性」分组。WebCodecs 精确解码是本机实验开关,写入浏览器 localStorage,刷新后生效。

**点云**

| 字段 | 说明 | 默认 |
|---|---|---|
| 点大小 | 点云渲染点径;与 3D 工具条滑块同步 | 0.06 |
| 点选模式 | 点云分割工具的矩形 / 套索 / 多边形模式 | 矩形 |
| 显示地面网格 | 控制 3D 主视图地面参考网格显隐 | 开启 |
| 显示坐标轴 | 控制主视图左下角坐标轴显隐 | 开启 |
| 相机灵敏度 | OrbitControls 阻尼;值越小惯性越强 | 0.10 |

## 项目锁定

项目管理员可以在项目设置中统一指定部分渲染参数(图像平滑、CSS 滤镜、控制点大小、网格吸附)。被项目锁定的字段在抽屉和设置页中均显示「项目锁定」徽章并禁用 —— 以项目配置为准,保证团队产出一致。

## 常见问题

- **改了没反应?** 抽屉中的改动对画布实时生效;若字段带「项目锁定」徽章,说明项目配置优先,个人值不生效。
- **换设备后设置丢了?** 偏好保存在账号上,登录同一账号即同步;布局类状态(栏宽、浮窗位置)另有本地缓存加速首帧,联网后以服务端为准。
