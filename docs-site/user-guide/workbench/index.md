# 标注工作台 — 界面与快捷键

进入工作台前，标注页（`/annotate`）的着陆态是按项目分组的**批次卡片网格**：每张卡含批次封面缩略图、状态与进度（标注中 / 送审 / 通过），点卡即进入该批次的任务队列；左侧栏顶部「全部待标任务」可跨批次平铺全部待标任务，进入某批次后标题区「返回全部批次」回到卡片概览。

工作台是日常标注的主要工作场所，由以下区域组成：

![工作台布局概览](../images/workbench/layout-overview.png)

工具：`V` 选择（点选 / 移动已有标注与预标注，默认工具，`Esc` 回退到它）· `B` 矩形 · `W` 旋转框 (OBB) · `P` 多边形 · `L` 折线 · `F` 关键点。平移画布用 `Space` + 拖拽或右键拖拽。完整快捷键列表见下方（按工作台代码 SoT 自动生成）。

图片画框时，预览随拖拽位置更新；松手后以最后的位置完成绘制，无需停留等待画布刷新。

图片、视频和点云任务使用同一个工作台外壳：画布和工具栏、状态栏作为一个整体，任务队列、类别面板、标注详情和讨论面板可调整位置；画布内容按任务类型切换。

图片和视频的左侧工具栏会随画布面板高度调整：空间不足时，优先保留选择工具与当前工具，其余收进底部“更多工具”。菜单保持原有分组、图标和快捷键，暂不可用的工具会显示原因。用方向键移动、Enter 选择、Esc 关闭；菜单打开时按字母不会切换画布工具。放大浏览器页面或拖动停靠分隔线后，工具入口会重新分配，已有草稿继续保留；空间恢复时工具回到主栏。

「讨论」面板提供评论、问题和历史。没有选中标注时也可发送任务文字留言；阅读范围与发送目标分别选择，草稿随原任务和标注保留。使用方法与恢复边界见[评论与问题](./discussion)。

工具图标按几何和操作区分：旋转框显示带手柄的倾斜矩形，多边形显示不规则闭合轮廓，折线显示开放线段，关键点显示相连节点，Mask 显示笔刷。视频的多边形、折线和 Mask 轨迹带有跨帧轮廓，与单帧工具区分；点云建框使用立体框。图片与视频中相同的单帧工具保持相同图标，悬停可查看名称和操作说明，快捷键沿用原有设置。

- 图片任务显示图像画布，支持 bbox、旋转框 (OBB)、多边形、折线、关键点 (COCO 范式骨骼)、原生 Raster Mask、SAM、AI 候选采纳和画布批注；[Mask 笔刷编辑器](./mask-brush) 可创建、重新编辑 Mask，并在 polygon / multi_polygon 与 Mask 之间做显式转换。
- 视频任务切到视频时间轴视图，支持单帧矩形框 / 多边形 / 折线、跨帧轨迹、关键帧与轨迹操作，交互式 AI 工具也可用于单帧。详见 [视频追踪标注](./video-track)。
- 3D 点云任务切到 Three.js 工作台：可旋转 / 平移 / 缩放查看点云、按高度上色或经标定的相机图 RGB 上色，在主 3D 视图绘制并编辑 `lidar_box_3d` 框（gizmo W/E/R 平移 / 转 Z / 缩放 + 数值面板补齐三轴朝向），也可用 `point_mask_3d` 分割工具做矩形 / 套索 / 多边形选点并增删编辑点集。三视图精修作为一个整体停靠、组成标签或浮动，内部支持拖边 / 拖角 / 拖方向线精修；相机可全部悬浮在主视图四周，也可整组收进一个停靠图库，两种方式都保留实时投影与 3D↔2D 双向选中。详见 [3D 立体框标注](./3d-box)。

图片与视频画布右下角提供缩小、当前比例、放大和「适应」浮条，并贴齐画布可用区域的右侧边缘；图片任务还会在同一浮条中显示撤销 / 重做。浮条相对画布定位，展开或收起侧栏后会随画布边界一起移动。切换图片任务时会按新图尺寸重新适应；超大图的最小缩放比例会自动放宽到当前画布的完整适应比例，先放大后仍可使用工具条或 Ctrl / Command + 滚轮缩回全图。放大后出现的 Minimap 位于浮条上方，不会遮挡缩放操作。

图片交互工具、批量预标候选和视频追踪的入口、结果与审阅方式不同。按任务选择说明见 [AI 辅助标注](../ai/)，图片候选的接受 / 拒绝与数据边界见[审阅 AI 候选](../ai/candidate-review)。

Mask、交互 AI、二次推理和追踪审阅平时只显示左上角的小胶囊，宽度仅容纳图标与关键信息。悬停、键盘聚焦或点击后，同一表面向右、向下同步展开常用操作；移开光标后收起。文本输入与候选决策也在展开区内，完整设置通过“更多”打开。展开和收起保持左上角位置不变，宽高连贯过渡。

图片背景浏览不要求 WebGPU；没有独立 GPU 的浏览器仍可打开、缩放和平移图片。已生成高清切片的超大图会
先显示 overview，再按当前视口和缩放级别渐进加载清晰 tile。平移或放大时局部清晰度可能短暂变化，但
标注、Mask、Issue pin 与 Minimap 始终使用原图坐标，不会随清晰度层级改变。

required 超大图的切片仍在生成时，画布显示“高清切片生成中”和安全预览；生成失败时显示不可用提示和
“重新生成”按钮，不会自动下载并解码整张原图。重试仍受服务端冷却与频率限制。单个 tile 网络或解码
失败时会保留 overview，并显示“高清切片请求失败，正在自动重试”；恢复完成后提示自动消失，不应出现整块透明背景。若提示长期不消失，请保留任务编号和 BUG 反馈中的
Large Image Tile Diagnostics 联系管理员，不要在无法辨认目标细节时继续标注。

Minimap、评论画布和邻题预取只使用缩略图或 overview，不会在主画布之外重复加载 required 大图。浏览器不
支持 `createImageBitmap` 时会自动使用普通图片元素解码，功能保持一致。

背景图片尺寸与 Raster Mask 编辑上限是两条独立边界：能够查看超大底图，不代表能创建同尺寸 Mask。
Mask 是否可编辑以任务返回的能力提示为准；超过上限时仍可使用 bbox、Polygon 等矢量工具，具体限制见
[Mask 笔刷编辑器的“大画布图片”](./mask-brush#大画布图片)。

顶部 ⚙ 菜单里可以打开“隐藏孤儿标注”。孤儿标注指项目设置中已删除当前类别定义、但历史标注仍保留旧 `class_name` 的数据；开关打开后画布和右侧人工列表会同步隐藏，关闭时列表行会以“已删除”标记提示。

光标坐标按图像尺寸预留位置，鼠标移出图像后显示“—”，其余状态位置保持稳定。底部状态栏始终保持单行；空间不足时可横向滚动查看完整的锁状态、统计、类别和同步信息。

顶部左右箭头用于切换任务，悬停显示“上一个任务 / 下一个任务”；“提交”按钮将当前任务提交质检。仍有写入、Mask 或手工标注草稿、待同步离线操作时，提交会暂时禁用；必填属性缺失时会选中第一个缺失字段并把焦点移到对应控件。

顶部栏始终保持单行。窗口变窄时逐步省略项目名、文件名及辅助信息，操作按钮收起文字并保留图标与悬停提示；更窄时快捷键、智能切题、主题和设置收进“更多工具”。

「工作台设置 → 界面布局 → 面板与高级布局」可以调整任务队列、类别面板、标注详情和讨论面板；图片与视频标注还可调整当前题 AI，视频标注可调整视频追踪，点云任务可调整三视图精修和相机视图。画布可放到整个工作区的左、右、上、下边缘。外围面板可停靠在左侧、右侧或底部，也可拖到另一面板的中央组成标签。拖动分隔条调整停靠区大小；拖动面板标签完成停靠和合并；按住 Shift 拖动标签可浮动面板，点击标签旁的 × 隐藏面板。两个外围面板拖成上下共用一列时，默认平分高度；之后仍可拖动分隔条调整比例。类别列表随独立面板铺满可用高度，内容超出时在面板内滚动。相机视图通过“悬浮显示”切回逐路相机浮层，不生成独立的图库浮窗。

每个可隐藏面板的标签标题旁常驻 **×**，点击即可隐藏该标签对应的面板，无需先切换到它。合并标签时只隐藏点击的标签，上下排列时只隐藏当前这一块，不影响同列其他面板；最后一块隐藏后回收空组。画布没有 ×。隐藏后的面板可从布局设置的面板列表找回，位置和业务状态继续保留。

浮窗标签可直接拖回停靠区或其他面板的标签栏，无需按 Shift。浮窗创建时即应用最小尺寸约束，刷新或退出紧凑视口后保持相同尺寸。

画布通过布局设置换位或最大化 / 恢复，不能隐藏、浮动、关闭或与其他面板组成标签。换位会移动现有画布实例，当前任务、工具、图片视口、视频帧与播放状态、点云视角和未提交草稿都会保留。窄窗口下这些命令暂时禁用。

浮窗只在当前工作区内移动，可拖动标题栏和边缘调整位置与尺寸。浮窗内可以组合标签，但不能继续切分出上下或左右区域；工作台不提供独立浏览器窗口或跨屏拖出。

通过拖放或找回面板生成新列时，初始列宽为工作区宽度的 15%，拖拽示意框同步显示该宽度（受面板最小宽度约束），之后仍可拖动分隔条调整。停靠、拖放、合并标签、浮动或隐藏面板时，其他停靠区域会保留原有尺寸，腾出或新增占用的空间由画布所在区域吸收。将两列拖成上下排列时沿用目标列宽，将两行拖成左右排列时沿用目标行高。窗口空间不足或面板内容要求更大的最小尺寸时，布局会按最小尺寸约束调整。

最大化画布和专注画布布局会保留各停靠区域的尺寸；恢复画布后继续使用这些尺寸。在最大化状态保存布局、刷新页面或切换到紧凑布局，也会保留恢复时所需的尺寸。

顶部「布局」弹层提供标准、专注／恢复，也可输入名称保存当前布局，或直接应用当前工作类型下的已存预设。完整预设与跨工作类型管理位于「工作台设置 → 界面布局」，配有按真实分栏比例绘制的 16:9 示意图，并按当前工作类型显示：

| 预设         | 布局                                                         |
| ------------ | ------------------------------------------------------------ |
| 标准标注     | 左侧任务与类别上下各半、中心画布、右侧标注详情与讨论上下各半 |
| 专注画布     | 最大化画布，退出专注时恢复原布局                             |
| 审核协作     | 画布右侧保留标注详情，底部通栏显示讨论                       |
| 图片 AI 审阅 | 当前题 AI 与标注详情成组，画布保持可见                       |
| 视频追踪     | 视频追踪与标注详情成组，画布保持可见                         |

应用预设后，每个左右侧栏的宽度均为工作区的 **15%**：标准标注、图片 AI 审阅和视频追踪为左右各 15%，审核协作仅保留 15% 的右栏。底部讨论按预设分配高度；之后仍可拖动分隔条或在设置中调整宽度。

点云任务的完整布局设置还提供三种工作方式：“框体精修”显示三视图并隐藏相机，“传感器融合”显示相机并隐藏三视图，“点级分割”隐藏两者。它们保留画布及其他工作台面板的位置；相机显示时沿用上次悬浮或停靠模式。

预设卡片以高亮边框和勾选标记显示当前布局；面板排列、显隐或浮窗不匹配预设时，自动高亮“自定义布局”。仅调整分隔条尺寸不会改变预设归属。“面板与高级布局”显示每个面板的当前状态，点击可显示或隐藏。

顶部「布局」弹层与「工作台设置 → 界面布局 → 我的预设」共用同一份命名布局清单，可以把当前排列另存为预设，随账号保存，最多 5 组。填写名称后保存；使用已有名称保存即为更新该预设，不额外占用名额。顶部弹层只列出当前工作类型可直接应用的预设；每条预设仍记录保存时的工作类型，跨类型查看、重命名和删除请进入完整设置。紧凑布局、布局只读或账号布局尚未读取完成时，保存与应用暂时禁用。若另一设备先修改了预设，本次操作不会覆盖其结果；界面会刷新最新清单并提示重新操作。

应用预设只改变布局，不改变当前工具、选中对象、任务、视频进度或标注草稿。提示中的撤销可恢复上一次替换前的布局；应用下一个预设或刷新页面后，不再保留此前的撤销点。标准标注、审核协作、图片 AI 审阅和视频追踪均按示意图应用完整排列，不保留此前的画布靠边位置或面板显隐；专注画布退出时恢复进入前的布局。“重置为标准布局”恢复左侧任务与类别、中心画布、右侧标注详情与讨论。

隐藏面板后，可从「工作台设置 → 界面布局 → 面板与高级布局」的面板列表找回；选择已经显示的面板会将其聚焦。恢复时优先回到原来的位置，原位置不可用时放到默认区域。顶部左右两个按钮分别收起或展开画布左侧、右侧的所有停靠面板，跟随实际位置，不绑定面板名称。收起会保留分栏、标签顺序、列宽和上下比例，刷新后仍可原位展开；浮窗及画布上方、下方的面板不受影响。某侧没有面板时，对应按钮禁用。通过面板列表找回收起侧的内容时会展开该侧并聚焦目标。单独隐藏面板可用标签旁的 ×。进入评论或 Issue 时，讨论面板会先显示再切换到相应内容；隐藏讨论面板会保留尚未发送的输入。

布局按账号保存，标注与审核模式分别记忆，图片、视频、点云任务也各用自己的布局。图像与视频任务分别记忆面板位置，切换任务或刷新页面后会恢复各自布局。进入工作台时先显示本机缓存，账号布局读取完成前暂时不能拖动或切换面板。读取失败会显示提示；保存失败时保留当前调整，再次调整时会重试保存。布局损坏时显示只读标准布局，可在桌面宽度下显式重置；提示布局来自新版时，需要刷新到新版，不能用重置覆盖它。

窗口宽度不超过 1024px 时进入紧凑布局，面板菜单每次只显示一个临时浮层，停靠、缩放、预设、重置与布局撤销暂时禁用。重新放宽窗口后恢复桌面布局，临时浮层不会覆盖账号保存的桌面位置；进入紧凑布局会清除已有的预设撤销提示。

当前题 AI 与视频追踪属于布局面板：顶部入口会显示或聚焦同一实例，二者可同时显示；隐藏面板不会取消运行或清空表单草稿。三视图及相机停靠组件也随点云布局保存；逐路相机的悬浮位置和折叠态单独记忆，切换模式不会清空。相机的整组切换与排列恢复见[点云视图与上色](./pointcloud-view#相机面板)。选中信息卡保留原有浮层行为。标注详情中的“AI 待审”和“人工”分组保持原有折叠方式，空分组也会显示标题与数量。画布视觉和操作偏好见[工作台设置](./settings)。

## 图片连续创建

在类别面板开启“连续创建”，选择创建工具单元，再点一次类别。顶部显示“连续创建 · 类别 · 工具”；此后完成每个矩形框、旋转框、多边形、折线或模板关键点时，会沿用该单元的类别。Mask 和 AI 候选仍使用各自的保存流程；从区域类别进入连续创建时使用多边形工具。

每个新对象重新读取项目的属性默认值，不继承上一对象的属性。缺少必填项时，几何保留在画布上，只需补齐字段并保存；保存中暂停下一对象，失败时保留草稿供重试。断网时须先保存到本机离线队列，才能继续；恢复联网后自动同步。连续模式下画布手势用于新对象，即使与已有几何重叠也可绘制；调整已有几何时先退出连续创建。

切类别只影响下一对象，已保存的选中对象保持原类；有未完成草稿时先完成或取消它。Esc 先取消当前弹层或绘制草稿，没有草稿时退出连续创建并回到选择工具，也可点顶部“退出连续创建”。同项目切题保留合法的工具和类别，清空几何与属性草稿；切项目、媒体类型、进入审核或失去写权限会退出。模式不会随刷新保留，也不会跨设备同步。关闭模式后继续使用原有的绘制后选类设置。

## 数据持久化与离线队列

工作台在新增、编辑或删除标注后立即尝试保存。底部状态栏区分以下结果：

- **保存中**：请求尚未完成，或仍有需要保存的草稿，暂时不能提交任务。
- **已保存**：服务端已确认，且当前账号没有待同步操作。
- **仅保存在本机**：操作已保留在当前浏览器中，恢复连接后自动同步。
- **同步失败**：待同步记录仍被保留；展开离线队列，查看失败操作并重试。

断网或服务暂时不可用时，新建、修改和删除操作都可进入本机队列。只有浏览器确认记录已写入后，才会显示本机保存成功；本机保存失败时保留草稿并提示重试。刷新或切换任务不会删除已经接收的记录，新建操作重试也不会重复创建对象。

队列按账号隔离。退出时若仍有记录，可以留下并继续同步，或明确选择保留在本机后退出；之后需要在同一浏览器用原账号登录才能继续同步。其他标签页切换登录账号时，当前页面同步更新身份。任务已交接、权限变化或请求校验失败时，不会强行写入；先处理提示中的原因，再重试或明确删除不再需要的队列记录。

撤销/重做记录也按账号和任务隔离。重做创建会产生新的对象；如果该次重做失败，保留记录供重试，不会重复创建或直接复用已经撤销的对象。

**讨论草稿**不使用标注离线队列。同一次登录、同一浏览器标签页内，文字、附件和画布批注随原任务与目标保留，切题或站内离开后返回可恢复；刷新或重新登录不保证恢复文字或弹窗绘图。题图上直接绘制的活动批注还保留五分钟的本标签页恢复记录，按用户、项目、任务和标注隔离。有未发送内容时，浏览器会在支持的情况下提示离开风险。详见[草稿保留到什么时候](./discussion#草稿保留到什么时候)。

## AI 预标注

如果项目开启 AI 预标注，进入任务时已有候选框：

- 候选标签会显示来源：`模型` 表示 ML backend 预标，`导入` 表示外部文件导入的预测。
- 右侧「AI 待审」列表的「来源」开关可隐藏 / 恢复 `模型`、`导入` 两类候选；隐藏后画布和列表都会同步过滤，`全部采纳` 也只作用于当前可见候选。
- 选中候选 → 修正位置/类别 → `A` 采纳。
- 误识别 → `D` 驳回。
- 漏标 → 切换工具自行标注。

人工标注仍在「人工」分组中展示；采纳预测后会进入人工标注列表，并保留 AI 采纳来源标识。

选中单个 AI 候选时，画布旁会浮出**选中信息卡**：顶部按置信度阈值着色显示大置信度条与模型来源 / 候选序号（识别到 OCR 文本也会一并列出），下方是结构化几何指标，底部直接提供采纳 / 精修 / 忽略动作，无需回到右侧列表。选中人工框时卡片同样浮出，承载改类 / 锁定 / 隐藏 / 删除与几何指标（人工框不显示置信度）。

顶部 **AI** 按钮打开的 **当前题 AI** 面板对图片的当前任务或视频当前帧运行模型，结果仍进入“AI 待审”。保存过项目编排时，图片任务可按这条编排运行当前题；当前题 AI、二次推理和属性溯源的步骤与数据边界见[当前题 AI 与二次推理](../ai/current-task-inference)。视频任务会在它左侧显示 **追踪**入口；两个面板可同时停靠、组成标签或浮动，并随当前账号与工作类型恢复。

交互式分割（SAM 点/框/Exemplar）的详细说明见 [AI 工具组](./sam-tool)；项目级 AI 预标（批量预标注与批次管理）见 [AI 预标注](../projects/#ai-预标注)。

## 二次推理（选中框 → 补属性 / 产子框）

选中一个**已落库的人工或已采纳标注**（非 AI 待审候选、非交互工具态、图片任务）时，可以用左上方的 **二次推理** 胶囊补写属性或检测子框，通过**更多**打开完整设置。它直接更新已确认标注；适用条件、结果边界和面板开关见[当前题 AI 与二次推理](../ai/current-task-inference#对已确认标注做二次推理)。

## 属性溯源（✦ AI 徽标）

标注的属性表单里，来自预标、二次推理或多阶段编排的字段旁边会显示 `✦ AI` 徽标；人工编辑该键后徽标消失。具体溯源规则见[当前题 AI 与二次推理](../ai/current-task-inference#ai-属性溯源)。

## 父子标注（画布联动）

一层父子关系（如「车 → 车牌 / 车灯」）会在画布上给出两种呈现：

- **同胞高亮**：选中父框，它的所有直接子框在画布上以异色描边一起亮起，一眼看清归属；选中普通框（无子）无高亮。
- **Alt 拖动联动**：按住 `Alt` 拖父框主体时，子框按同样位移一起搬，一次撤销回到原位；不按 `Alt` 只搬父框（保留旧行为）。作用面限父框主体拖动，不与折线 / 关键点的 `Alt` 顶点交互冲突。当前 scope 为图片任务的 bbox 父框，视频 / 3D 与多边形父暂不联动。

## 阅读项目指引

项目发布指引后，工作台顶栏的设置按钮旁会显示「标注指引」入口，未读时带有提示。点击按钮打开与工作台设置相同大小的阅读窗口，正文独立滚动，底部始终保留阅读确认。点击窗口外部、点击「关闭指引」或按 Esc 返回标注界面；打开和关闭指引都不会自动确认阅读。

阅读正文后点击「确认已阅读」，保存成功才会同步到首页开工清单；指南更新后需重新确认。若保存失败，可保留页面并点击「重试」。

指引正文支持标题、表格、列表、代码和图片。宽表格与长代码块在正文内横向滚动，代码可复制，图片可点击放大；图片加载失败时可重试。工作台、首页和项目设置预览使用相同的阅读排版。
