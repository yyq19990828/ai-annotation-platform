# Bbox 标注

矩形框（轴对齐 Bounding Box）是最常用的目标框，适合标注与图像坐标轴对齐的物体。

1. 按 `B` 切到矩形工具
2. 在画布上按下鼠标 → 拖动 → 松开，即生成一个矩形
3. 在类别浮层选择类别，若缺必填属性，补齐后保存

同类对象较多时，可在类别面板开启[图片连续创建](./#图片连续创建)，选定矩形框单元和类别后逐个绘制。每次保存成功或离线队列持久接收后，才能开始下一个；属性逐对象填写，不继承前一对象的值。

## 从中心开始画框

在图片内按住 `Alt` 再拖动，按下的位置就是矩形中心，向任意方向拖动均向两侧展开。创建方式在按下时确定：拖动中松开 `Alt` 仍从中心展开；按下后才按 `Alt`，本次仍按原方式绘制。

也可在矩形工具的类别面板中，将“画框起点”从“角点”切换为“中心”，之后无需按修饰键。这是当前工作台会话的选项，换工具再回来仍保留，刷新后回到“角点”；[连续创建](./#图片连续创建)同样使用该起点选项。

拖到图像边界时，两侧半径会同时受限，中心始终留在按下位置。起点须在图像内，零面积或过小的框仍会被拦截。`Ctrl` / `Cmd` 单击保留 SAM 候选选择用途。

## 编辑已有 Bbox

- 单击 → 选中（出现 8 个控制手柄：4 角 + 4 边）
- 拖角或拖边 → 缩放
- 按住 `Alt` 拖动手柄 → 围绕原中心缩放
- 拖中心 → 移动

## 多选与批量操作

- `Shift + 单击` 画布中的框可叠加多选；`Ctrl + A` 全选当前帧全部人工框。
- 多选后，右侧属性面板顶部浮条可**批量改类别**；右键菜单可批量删除、锁定、隐藏。

## 常见错误

- **画框太小**：归一化宽或高低于 0.5%（即 `w < 0.005` 或 `h < 0.005`）的框会被拦截，提示重画
- **超出图像**：角点创建会裁到图像范围；中心创建同时限制两侧半径，保留中心
- **类别未选**：提交前必须为每个 Bbox 指定类别

## IoU 与 AI 去重高亮

工作台内部使用 IoU（Intersection over Union）做 **AI 候选去重**：当一个 AI 候选框与已有的人工框重合度超过项目设置的去重阈值（默认 0.7）时，该候选框会在列表中标记为「已被覆盖」并半透显示，`全部采纳` 时自动跳过这些候选，防止重复落库。

> 注意：IoU 在此是**去重/高亮**工具，不是审核评分。审核退回依据的是审核员的人工判断，不存在与「基准框」比对 IoU 的评分环节。
